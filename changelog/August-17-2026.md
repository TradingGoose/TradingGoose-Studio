### Design Decisions
- Copilot is a global workspace capability, not a dashboard widget. The panel stays mounted after closing when its authenticated channel is unchanged so navigation and visibility changes do not discard conversation state.
- Implicit `current_*` contexts identify the visible page selection only; `mergeCopilotContexts` prioritizes explicit mentions and prevents duplicate identities before sending a turn. Detailed data is read through authorized tools or bounded server processing rather than pushed from the page.
- Chat history is persisted as review-session turns and items. `app/api/copilot/chat/route.ts` serializes concurrent history mutations by locking the session row, preventing client save and stream completion from interleaving.
- Dashboard shared values remain owned by color-pair documents. `editWidgetServerTool` derives local versus shared fields from the widget contract rather than accepting a second, competing color-pair API.
