### Design Decisions

- Range presets belong to the market-provider layer because both workflow blocks and charts consume them. Provider capabilities and the planner own eligibility; UI components should not maintain separate retention or interval rules. Preset admission rejects a shortened range even though direct provider requests may still be retention-clamped.
- All is an explicit capability-backed window, not a duration estimate. The block requires the user to select the native interval before exposing All; chart resolution and provider planning may select that declared interval. These are deliberate boundary differences, not interchangeable defaults.
- The Historical Data tool accepts one selected window, while `MarketSeriesRequest.windows` retains the provider layer's priority-ordered selection contract. Removing tool-level `fallbackWindow` does not remove the planner's ordered-window behavior for other callers.
- Bar budgets and elapsed calendar time are distinct. Finite range/count planning can enforce retention budgets, but absolute dates are not shortened using a continuous-candle estimate. Provider adapters must complete the requested bounded fetch or report a limit/fetch failure rather than return silent partial success.
- Workflow condition evaluation must use resolved controller values and avoid evaluating inactive references. Shared condition matching is used by execution and tool UI metadata, while execution retains ownership of reference resolution and cycle detection.
- Localization follows the selected field configuration, not just a duplicated sub-block ID. Carrying full UI metadata preserves variant identity and dynamic option behavior; localizing a second reconstructed field would discard that context.

### Future Branch Guardrails

- Keep `rangeMode`, `rangePresetId`, and interval explicit in Historical Data. Missing or invalid selections must not inherit stale custom dates, switch candle intervals, or gain an inferred default/legacy backfill. Agent tools consume the canonical `window`, not a second copy of the block's range-selection UI contract.
- Offer latest ranges only when the selected interval supports the entire preset. Preserve calendar-candle checks and the stricter complete-history eligibility rule. Add All to a provider only with an unbounded native interval and corresponding adapter behavior; do not infer it from a long finite retention period.
- Keep Alpaca page size, bounded-history budget, and unbounded count limit distinct. Follow valid short/empty continuations, allow the inclusive endpoint, reset the consecutive-empty-page counter on progress, and fail on incomplete or over-budget bounded results. Do not restore a fixed total-page ceiling or silently stop after the first page.
- Preserve explicit custom dates except for declared time retention and existing session handling. Do not translate a returned-bar budget into calendar clipping. Retain epoch-zero/negative-bound tests and ISO serialization of chart viewport milliseconds.
- Resolve chart preset validity through the same window resolver used for loading. Preserve a valid configured interval and active preset even when its default button pairing is unsupported. All must stay unbounded across listing changes; finite backfill must stop once retention is full.
- Resolve condition dependencies before dependent references regardless of input order, preserve nested short-circuiting and cycle errors, and normalize only undefined to an empty condition value. Keep deferred notification/condition expression behavior intact.
- Preserve operation context when multiple operations map to one tool. Pass complete UI metadata and variant identity into localization and dynamic option loading; do not collapse distinct meanings of empty options, such as all statuses versus no status change, into one label.
- Keep catalog changes synchronized across English, Spanish, and Chinese, and retain generic API-key copy in merged market catalogs without overwriting selected-provider definitions. This is a clean contract update; no removed field/helper needs a legacy adapter.
