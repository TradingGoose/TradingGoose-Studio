### Design Decisions
- A tier's structural subscription identity is immutable after activation. Administrators must duplicate and archive instead of mutating owner type, usage/seat model, Stripe product or prices, or displayed prices for a live plan.
- Private availability is modeled as a user-to-tier grant rather than as an alternate catalog or checkout path. A private tier remains inactive to ungranted users even when its access code is known, and the code is never returned by display APIs.
- Organization subscription ownership is tied to the authenticated user's Stripe customer, not to a separate organization customer. Owner authorization, subscription-reference matching, and minimum/occupied-seat calculation all occur before Better Auth receives an upgrade request.
- The pending-execution row is the durable capacity marker. Local execution retains that marker until the shared job completes, while Trigger execution uses idempotent run tags and reconciliation to recover lost completion callbacks without a scheduled drain.
- Airtable recovery is initiated by normal create, update, and delete requests from lifecycle state stored with the webhook, rather than a periodic cleanup sweep that could lag or act without the current request's credential scope.
