### Design Decisions

- Keep capability policy in the model catalog. Editor conditions and provider sanitization consume the same metadata; unresolved references remain editable, while execution uses the resolved model and skips inactive dependent inputs.
- Treat exact catalog membership as the distinction between unknown and known unsupported OpenRouter capabilities. Real configured tuning with unknown support fails before browser POST or sanitization/SDK dispatch; literal Auto/default intent is exempt only for reasoning effort, verbosity and thinking level. The browser uses the existing model endpoint before resolving active controls; this requires no extra retry, cache, forwarding policy or configuration mutation.
- Preserve stored optional controls across model changes. Display and request sanitization determine effective behavior without silently changing workflow configuration or introducing legacy value conversion.
- Preserve native assistant/tool pairing and signed content. Exhausted tool loops fail rather than return pending calls as successful partial output; final-answer streaming follows the applicable provider contract.
- OpenRouter's documented Chat Completions continuation contract requires its returned reasoning state. Preserve the optional `reasoning` and `reasoning_details` fields as supplied rather than reconstructing, filtering, sorting or fabricating blocks. This verified narrow contract supersedes the earlier unverified-replay deferral without introducing arbitrary raw-message forwarding or legacy aliases.
- Classify Gemini tool-capable turns before publishing final bytes, preserving the sibling project's pending-versus-final distinction within this project's existing byte transport. Automatic/forced tool turns may delay first output until classified. Record completed usage before releasing their answer chunks; preserve immediate delivery when the active config cannot call tools.
- Carry known completed usage as snapshots. Preserve original errors and explicit metadata, including zero values; do not add an existing tool charge again or estimate usage for rejected calls and disconnected streams.
