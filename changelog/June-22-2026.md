### Design Decisions
- Mention labels and search text now come from message-backed copy helpers instead of being reconstructed inline. This keeps menu rendering and filtering on the same localization source of truth.
- Workspace entity mention groups remain driven by `apps/tradinggoose/widgets/widgets/copilot/workspace-entities.ts`, so mention options, submenu grouping, and context/entity-kind ownership do not fork into a second mention-specific registry.
- Locale changes intentionally clear and reload locale-sensitive source lists instead of trying to mutate previously loaded items in place. That keeps block and workflow-block naming aligned with the active locale and existing workflow-inspector copy.

### Shared Contracts and Helpers to Reuse
- Reuse `getCopilotMentionCopyFromMessages()` and `useCopilotMentionCopy()` from `apps/tradinggoose/widgets/widgets/copilot/components/user-input/mention-copy.ts` for any new mention-menu label, title, empty-state, or fallback copy.
- Reuse `getLogMentionSearchText()` from `apps/tradinggoose/widgets/widgets/copilot/components/user-input/mention-copy.ts` when log mentions need searchable text. It keeps log matching aligned with localized monitor trigger labels.

- Reuse `ensureSubmenuLoaded()` from `apps/tradinggoose/widgets/widgets/copilot/components/user-input/hooks/use-user-input-mention-sources.ts` as the canonical lazy-loading path for submenu data and locale refreshes.
