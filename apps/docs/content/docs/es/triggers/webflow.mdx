Activa el workflow cuando un nuevo elemento es creado en un Webflow CMS colección (requiere Webflow credentials)

<Callout type="info">
  Este trigger se basa en webhooks. Configura la URL del webhook en el servicio externo para enviar eventos a TradingGoose.
</Callout>

  <Card title="Usar como un Herramienta" href="/tools/webflow">

  </Card>
</Cards>
