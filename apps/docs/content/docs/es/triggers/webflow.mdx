Activa el workflow cuando se crea un elemento nuevo en una colección CMS de Webflow (requiere credenciales de Webflow)

<Callout type="info">
  Este es un trigger **basado en webhook**. Configura el servicio externo para enviar eventos a la URL del webhook del workflow.
</Callout>

## Eventos

### Elemento de colección creado

Activa el workflow cuando se crea un elemento nuevo en una colección CMS de Webflow (requiere credenciales de Webflow)

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Conecta tu cuenta de Webflow con el botón "Seleccionar credencial de Webflow" de arriba.</div><div class="mb-3"><strong>2.</strong> Introduce el ID de sitio de Webflow (lo encontrarás en la URL del sitio o en la configuración del sitio).</div><div class="mb-3"><strong>3.</strong> Opcionalmente, introduce un ID de colección para supervisar solo colecciones específicas.</div><div class="mb-3"><strong>4.</strong> Si no se indica un ID de colección, el trigger se activará para los elementos creados en cualquier colección del sitio.</div><div class="mb-3"><strong>5.</strong> El webhook se activará cada vez que se cree un elemento nuevo en la colección o colecciones especificadas.</div><div class="mb-3"><strong>6.</strong> Asegúrate de que tu cuenta de Webflow tenga los permisos adecuados para el sitio indicado.</div>

### Envío de formulario

Activa el workflow cuando se envía un formulario en un sitio de Webflow (requiere credenciales de Webflow)

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Conecta tu cuenta de Webflow con el botón "Seleccionar credencial de Webflow" de arriba.</div><div class="mb-3"><strong>2.</strong> Introduce el Site ID de Webflow (se encuentra en la URL del sitio o en la configuración del sitio).</div><div class="mb-3"><strong>3.</strong> Opcionalmente, introduce un Form ID para supervisar solo un formulario específico.</div><div class="mb-3"><strong>4.</strong> Si no se proporciona un Form ID, el trigger se activará con cualquier envío de formulario en el sitio.</div><div class="mb-3"><strong>5.</strong> El webhook se activará cada vez que se envíe un formulario en el sitio especificado.</div><div class="mb-3"><strong>6.</strong> Los datos del formulario se incluirán en el payload con todos los valores de los campos enviados.</div><div class="mb-3"><strong>7.</strong> Asegúrate de que tu cuenta de Webflow tenga los permisos adecuados para el sitio especificado.</div>
