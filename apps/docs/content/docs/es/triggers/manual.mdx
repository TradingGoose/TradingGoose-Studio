El disparador manual añade un botón **Ejecutar** al flujo de trabajo. Úsalo cuando quieras ejecutar el flujo inmediatamente sin recopilar datos adicionales.

<Callout type="info">
Este es un disparador **manual**. No requiere configuración: solo haz clic en **Ejecutar**.
</Callout>

## Configuración

Sin configuración obligatorio. El manual trigger tiene No entrada campos y produces No salidas.

## Cuándo usarlo

- Quick sanity checks y smoke tests
- Workflows ese solo rely en internal variables o externo API llamadas
- Development y debugging

<Callout>
Necesitar structured entrada? Usar un Entrada Formulario trigger instead.
</Callout>
