El activador manual añade un botón Ejecutar a tu flujo de trabajo. Úsalo cuando quieras ejecutar el flujo de trabajo de inmediato sin recopilar datos adicionales.

<Callout type="info">
  Este es un activador **manual**. No se necesita configuración: solo haz clic en Ejecutar.
</Callout>

## Configuración

<ShowcaseCard>
  <BlockConfigPreview
    name="Manual Trigger"

</ShowcaseCard>

No se requiere configuración. El activador manual no tiene campos de entrada y no produce salidas.

## Cuándo usarlo

- Comprobaciones rápidas y pruebas de humo
- Flujos de trabajo que solo dependen de variables internas o llamadas a API externas
- Desarrollo y depuración

<Callout>
¿Necesitas una entrada estructurada? Usa un activador de formulario de entrada.
</Callout>
