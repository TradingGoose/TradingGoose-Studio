El disparador de chat crea una interfaz conversacional para tu flujo de trabajo. Despliega el flujo como un chat para que los usuarios interactúen mediante una URL compartible. Cada mensaje inicia una nueva ejecución.

<Callout type="info">
  Este es un **deployment-based** trigger. Usuarios interact con tu workflow mediante un hosted chat URL.
</Callout>

### Salida Esquema

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `input` | cadena | Últimos usuario mensaje |
| `conversationId` | cadena | Conversación hilo ID |
| `files` | archivos | Opcional uploaded archivos |

### Archivo Propiedades

| Propiedad | Tipo | Descripción |
|----------|------|-------------|
| `<chat.files[0].url>` | cadena | Signed download URL |
| `<chat.files[0].name>` | cadena | Original filename |
| `<chat.files[0].size>` | número | Archivo tamaño en bytes |
| `<chat.files[0].type>` | cadena | MIME tipo |

<Callout>
Cada conversación maintains su propio hilo. Usuarios puede tienen varios concurrent conversations.
</Callout>
