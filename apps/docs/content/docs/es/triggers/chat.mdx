El trigger de chat crea una interfaz conversacional para tu workflow. Despliega tu workflow como chat y los usuarios pueden interactuar con él a través de una URL compartible. Cada mensaje inicia una nueva ejecución del workflow.

<Callout type="info">
  Este es un trigger **basado en deployment**. Los usuarios interactúan con tu workflow a través de una URL de chat alojada.
</Callout>

### Esquema de salida

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `input` | string | Último mensaje del usuario |
| `conversationId` | string | ID del hilo de conversación |
| `files` | files | Archivos subidos opcionales |

### Propiedades del archivo

| Propiedad | Tipo | Descripción |
|----------|------|-------------|
| `<chat.files[0].url>` | string | URL de descarga firmada |
| `<chat.files[0].name>` | string | Nombre de archivo original |
| `<chat.files[0].size>` | number | Tamaño del archivo en bytes |
| `<chat.files[0].type>` | string | Tipo MIME |

<Callout>
Cada conversación mantiene su propio hilo. Los usuarios pueden tener varias conversaciones simultáneas.
</Callout>
