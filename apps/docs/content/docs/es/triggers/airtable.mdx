Activa un flujo de trabajo a partir de cambios en registros de Airtable, como eventos de creación, actualización y eliminación (requiere credenciales de Airtable)

<Callout type="info">
  Este es un activador basado en **webhook**. Configura el servicio externo para enviar eventos a la URL del webhook del flujo de trabajo.
</Callout>

<Cards>
  <Card title="Usar como herramienta" href="/tools/airtable">
    Consulta las acciones, operaciones y entradas de herramienta del flujo de trabajo para Airtable.
  </Card>
</Cards>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Conecta tu cuenta de Airtable con el botón "Seleccionar credencial de Airtable" de arriba.</div><div class="mb-3"><strong>2.</strong> Asegúrate de haber indicado el ID de la base y el ID de la tabla correctos arriba.</div><div class="mb-3"><strong>3.</strong> Puedes encontrar el ID de la base en la URL de Airtable: https://airtable.com/[baseId]/...</div><div class="mb-3"><strong>4.</strong> Puedes encontrar el ID de la tabla al hacer clic en el nombre de la tabla y revisar la URL.</div><div class="mb-3"><strong>5.</strong> El webhook se activará cada vez que se creen, actualicen o eliminen registros en la tabla especificada.</div><div class="mb-3"><strong>6.</strong> Asegúrate de que tu cuenta de Airtable tenga los permisos adecuados para la base especificada.</div>
