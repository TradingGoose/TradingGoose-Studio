Se activa cuando se publican elementos nuevos en un feed RSS

<Callout type="info">
  Este es un trigger basado en **polling**. TradingGoose comprueba la fuente a intervalos regulares en busca de cambios coincidentes.
</Callout>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Introduce la URL de cualquier feed RSS o Atom que quieras supervisar</div><div class="mb-3"><strong>2.</strong> El feed se comprobará cada minuto en busca de elementos nuevos</div><div class="mb-3"><strong>3.</strong> Cuando se publique un elemento nuevo, se activará tu workflow con los datos del elemento</div>
