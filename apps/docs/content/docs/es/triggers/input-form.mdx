Utiliza un disparador de formulario de entrada cuando un flujo de trabajo debe iniciarse desde el editor con campos tipados. El panel de ejecución muestra exactamente los campos que defines, por lo que el flujo de trabajo siempre recibe datos limpios.

<Callout type="info">
  Este es un **manual** trigger con structured entrada. Define tu esquema y run desde el editor.
</Callout>

Añadir campos en el Entrada Formato builder. Supported tipos:

- **cadena** — Texto valores
- **número** — Numeric valores
- **booleano** — True/false valores
- **json** — JSON objetos

### Salida Esquema

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `<blockName.field>` | varies | Cada campo defined en el Entrada Formato |
| `<blockName.input>` | json | Entire structured entrada payload |

## Flujos de trabajo secundarios

Entrada Formulario triggers también power el Workflow bloque. Cuando tú embed un secundarios workflow, el mapping step programas el secundarios formulario campos por tanto tú puede conectar variables desde el principal.

<Callout>
Necesitar un quick run botón con No campos? Usar un Manual Trigger instead.
</Callout>
