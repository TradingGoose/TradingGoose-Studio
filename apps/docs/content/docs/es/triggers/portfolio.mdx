Activar el workflow desde portfolio supervisar estado changes

<Callout type="info">
  Este es un **event-driven** trigger. Configured portfolio monitors emit workflow eventos cuando su condición matches.
</Callout>

## Configuración

Gestionar portfolio monitors desde el workspace **Supervisar** surface. Seleccionar un bróker cuenta, define el condición a evaluar, y choose el workflow destino que contiene este Portfolio trigger.

El `event` entregado siempre es `portfolio_state_condition_matched`. El mensaje `input` es `Portfolio state condition matched for {account}`; `{account}` usa `portfolio.identity.accountName` cuando está disponible y, en caso contrario, usa `portfolio.identity.accountId`.
