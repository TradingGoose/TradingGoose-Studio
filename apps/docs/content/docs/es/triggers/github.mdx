## Eventos

### Webhook de GitHub

Dispara un workflow desde eventos de GitHub como push, pull requests, issues y más

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Ve a tu repositorio de GitHub > Settings > Webhooks.</div><div class="mb-3"><strong>2.</strong> Haz clic en "Add webhook".</div><div class="mb-3"><strong>3.</strong> Pega la <strong>URL del webhook</strong> de arriba en el campo "Payload URL".</div><div class="mb-3"><strong>4.</strong> Selecciona el tipo de contenido elegido en el menú desplegable.</div><div class="mb-3"><strong>5.</strong> Introduce el <strong>secreto del webhook</strong> en el campo "Secret" si has configurado uno.</div><div class="mb-3"><strong>6.</strong> Establece la verificación SSL según tu selección.</div><div class="mb-3"><strong>7.</strong> Elige qué eventos deben disparar este webhook.</div><div class="mb-3"><strong>8.</strong> Asegúrate de que "Active" esté marcado y haz clic en "Add webhook".</div>

### Incidencia de GitHub abierta

Activa el workflow cuando se abre una incidencia nueva en un repositorio de GitHub

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Ve a tu repositorio de GitHub > Configuración > Webhooks.</div><div class="mb-3"><strong>2.</strong> Haz clic en "Añadir webhook".</div><div class="mb-3"><strong>3.</strong> Pega la <strong>URL del webhook</strong> de arriba en el campo "URL de payload".</div><div class="mb-3"><strong>4.</strong> Selecciona el tipo de contenido elegido en el menú desplegable.</div><div class="mb-3"><strong>5.</strong> Introduce el <strong>secreto del webhook</strong> en el campo "Secreto" si has configurado uno.</div><div class="mb-3"><strong>6.</strong> Configura la verificación SSL según tu selección.</div><div class="mb-3"><strong>7.</strong> Selecciona "Permíteme seleccionar eventos individuales" y marca <strong>issues</strong> (acción <strong>opened</strong>).</div><div class="mb-3"><strong>8.</strong> Asegúrate de que "Activo" esté marcado y haz clic en "Añadir webhook".</div>

### Versión de GitHub publicada

Activa un flujo de trabajo cuando se publica una nueva versión en un repositorio de GitHub

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Ve a tu repositorio de GitHub > Configuración > Webhooks.</div><div class="mb-3"><strong>2.</strong> Haz clic en "Añadir webhook".</div><div class="mb-3"><strong>3.</strong> Pega la <strong>URL del webhook</strong> anterior en el campo "URL de carga".</div><div class="mb-3"><strong>4.</strong> Selecciona el tipo de contenido elegido en el menú desplegable.</div><div class="mb-3"><strong>5.</strong> Introduce el <strong>secreto del webhook</strong> en el campo "Secreto" si has configurado uno.</div><div class="mb-3"><strong>6.</strong> Configura la verificación SSL según tu selección.</div><div class="mb-3"><strong>7.</strong> Selecciona "Permitirme seleccionar eventos individuales" y marca el evento <strong>Versiones</strong>.</div><div class="mb-3"><strong>8.</strong> Asegúrate de que "Activo" esté marcado y haz clic en "Añadir webhook".</div>

### Ejecución de workflow de GitHub Actions

Activa el workflow cuando una ejecución de GitHub Actions se solicita, está en curso o se completa

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Ve a tu repositorio de GitHub > Settings > Webhooks.</div><div class="mb-3"><strong>2.</strong> Haz clic en "Add webhook".</div><div class="mb-3"><strong>3.</strong> Pega la <strong>URL del webhook</strong> de arriba en el campo "Payload URL".</div><div class="mb-3"><strong>4.</strong> Selecciona el tipo de contenido elegido en el menú desplegable.</div><div class="mb-3"><strong>5.</strong> Introduce el <strong>secreto del webhook</strong> en el campo "Secret" si has configurado uno.</div><div class="mb-3"><strong>6.</strong> Configura la verificación SSL según tu selección.</div><div class="mb-3"><strong>7.</strong> Selecciona "Let me select individual events" y marca <strong>Workflow runs</strong>.</div><div class="mb-3"><strong>8.</strong> Asegúrate de que "Active" esté marcado y haz clic en "Add webhook".</div>
