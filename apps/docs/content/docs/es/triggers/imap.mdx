Se dispara cuando se reciben correos nuevos por IMAP (funciona con cualquier proveedor de correo)

<Callout type="info">
  Este es un disparador basado en **sondeo**. TradingGoose comprueba el origen en busca de cambios coincidentes a intervalos regulares.
</Callout>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Introduce los datos del servidor IMAP (host, puerto, configuración SSL)</div><div class="mb-3"><strong>2.</strong> Introduce tus credenciales de correo (usuario y contraseña)</div><div class="mb-3"><strong>3.</strong> Para Gmail: usa una <a href="https://support.google.com/accounts/answer/185833" target="_blank">Contraseña de aplicación</a> en lugar de tu contraseña habitual</div><div class="mb-3"><strong>4.</strong> Selecciona el buzón a supervisar (INBOX es el más habitual)</div><div class="mb-3"><strong>5.</strong> Si lo deseas, configura los criterios de búsqueda y las opciones de procesamiento</div><div class="mb-3"><strong>6.</strong> El sistema comprobará automáticamente si hay correos nuevos y disparará tu flujo de trabajo</div>
