Recibe webhooks de cualquier servicio o API

<Callout type="info">
  Este es un activador **basado en webhooks**. Configura el servicio externo para enviar eventos a la URL del webhook del flujo de trabajo.
</Callout>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Copia la URL del webhook y úsala en tu servicio externo o API.</div><div class="mb-3"><strong>2.</strong> Configura tu servicio para enviar webhooks a esta URL.</div><div class="mb-3"><strong>3.</strong> El webhook recibirá cualquier método HTTP (GET, POST, PUT, DELETE, etc.).</div><div class="mb-3"><strong>4.</strong> Todos los datos de la solicitud (encabezados, cuerpo, parámetros de consulta) estarán disponibles en tu flujo de trabajo.</div><div class="mb-3"><strong>5.</strong> Si la autenticación está habilitada, incluye el token en las solicitudes usando el encabezado personalizado o "Authorization: Bearer TOKEN".</div><div class="mb-3"><strong>6.</strong> Los campos comunes como "event", "id" y "data" se extraerán automáticamente del payload cuando estén disponibles.</div>
