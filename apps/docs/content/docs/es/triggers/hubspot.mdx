Activa un flujo de trabajo cuando se crea un contacto nuevo en HubSpot

<Callout type="info">
  Este es un activador **basado en webhook**. Configura el servicio externo para que envíe eventos a la URL del webhook del flujo de trabajo.
</Callout>

  </Card>

## Eventos

### Contacto creado en HubSpot

Activa un flujo de trabajo cuando se crea un contacto nuevo en HubSpot

#### Instrucciones de configuración

<div class="mb-3"><strong>Paso 1: Crea una cuenta de desarrollador de HubSpot</strong><br />Regístrate para obtener una cuenta de desarrollador gratuita en <a href="https://developers.hubspot.com" target="_blank">developers.hubspot.com</a> si aún no tienes una.</div><div class="mb-3"><strong>Paso 2: Crea una aplicación pública con la CLI</strong><br /><strong>Nota:</strong> HubSpot ha descontinuado la interfaz web para crear aplicaciones. Debes usar la CLI de HubSpot para crear y gestionar aplicaciones. Instala la CLI con <code>npm install -g @hubspot/cli</code> y ejecuta <code>hs project create</code> para crear una aplicación nueva. Consulta la <a href="https://developers.hubspot.com/docs/platform/create-an-app" target="_blank">documentación de HubSpot</a> para más detalles.</div><div class="mb-3"><strong>Paso 3: Guarda las credenciales de la aplicación OAuth</strong><br />Añade <code>https://www.tradinggoose.ai/api/auth/oauth2/callback/hubspot</code> a las URL de redirección OAuth de HubSpot. Obtén el <strong>Client ID</strong> y el <strong>Client Secret</strong> de la configuración de tu aplicación de HubSpot e introdúcelos en los campos anteriores.</div><div class="mb-3"><strong>Paso 4: Obtén el App ID y la Developer API Key</strong><br />En tu cuenta de desarrollador de HubSpot, busca el <strong>App ID</strong> (aparece debajo del nombre de tu aplicación) y la <strong>Developer API Key</strong> (en la configuración de la aplicación). Necesitarás ambos para los siguientes pasos.</div><div class="mb-3"><strong>Paso 5: Configura los scopes necesarios</strong><br />Configura tu aplicación para incluir el scope de OAuth requerido: <code>crm.objects.contacts.read</code></div><div class="mb-3"><strong>Paso 6: Guarda la configuración en TradingGoose</strong><br />Haz clic en el botón <strong>"Guardar configuración"</strong> de arriba. Se generará tu URL de webhook única.</div><div class="mb-3"><strong>Paso 7: Configura el webhook en HubSpot mediante la API</strong><br />Después de guardar, copia la <strong>URL del webhook</strong> y ejecuta los dos comandos curl de abajo (reemplaza <code>&#123;YOUR_APP_ID&#125;</code>, <code>&#123;YOUR_DEVELOPER_API_KEY&#125;</code> y <code>&#123;YOUR_WEBHOOK_URL_FROM_ABOVE&#125;</code> por tus valores reales).</div><div class="mb-3"><strong>Paso 8: Prueba el webhook</strong><br />Crea o modifica un contacto en HubSpot para activar el webhook. Revisa los registros de ejecución del flujo de trabajo en TradingGoose para comprobar que funciona.</div><div class="mb-3"><strong>Información adicional:</strong> El webhook se activará cada vez que se cree un contacto nuevo en tu cuenta de HubSpot, independientemente del origen (entrada manual, envío de formulario, API, importación, etc.).</div>

### Ticket de HubSpot eliminado

Activa un flujo de trabajo cuando se elimina un ticket en HubSpot

#### Instrucciones de configuración

<div class="mb-3"><strong>Paso 1: Crear una cuenta de desarrollador de HubSpot</strong><br />Regístrate para obtener una cuenta de desarrollador gratuita en <a href="https://developers.hubspot.com" target="_blank">developers.hubspot.com</a> si no tienes una.</div><div class="mb-3"><strong>Paso 2: Crear una aplicación pública con la CLI</strong><br /><strong>Nota:</strong> HubSpot ha dejado de ofrecer la interfaz web para crear aplicaciones. Debes usar la CLI de HubSpot para crear y gestionar aplicaciones. Instala la CLI con <code>npm install -g @hubspot/cli</code> y ejecuta <code>hs project create</code> para crear una nueva aplicación. Consulta la <a href="https://developers.hubspot.com/docs/platform/create-an-app" target="_blank">documentación de HubSpot</a> para más detalles.</div><div class="mb-3"><strong>Paso 3: Guardar las credenciales de la aplicación OAuth</strong><br />Añade <code>https://www.tradinggoose.ai/api/auth/oauth2/callback/hubspot</code> a las URL de redirección de OAuth de HubSpot. Obtén tu <strong>ID de cliente</strong> y tu <strong>secreto de cliente</strong> de la configuración de tu aplicación de HubSpot e introdúcelos en los campos de arriba.</div><div class="mb-3"><strong>Paso 4: Obtener el ID de la aplicación y la clave de API de desarrollador</strong><br />En tu cuenta de desarrollador de HubSpot, busca tu <strong>ID de la aplicación</strong> (aparece debajo del nombre de tu aplicación) y tu <strong>clave de API de desarrollador</strong> (en la configuración de la aplicación). Necesitarás ambos para los siguientes pasos.</div><div class="mb-3"><strong>Paso 5: Definir los ámbitos requeridos</strong><br />Configura tu aplicación para incluir el ámbito OAuth requerido: <code>crm.objects.contacts.read</code></div><div class="mb-3"><strong>Paso 6: Guardar la configuración en TradingGoose</strong><br />Haz clic en el botón <strong>"Guardar configuración"</strong> de arriba. Esto generará tu URL de webhook única.</div><div class="mb-3"><strong>Paso 7: Configurar el webhook en HubSpot mediante la API</strong><br />Después de guardar lo anterior, copia la <strong>URL del webhook</strong> y ejecuta los dos comandos curl de abajo (reemplaza <code>&#123;YOUR_APP_ID&#125;</code>, <code>&#123;YOUR_DEVELOPER_API_KEY&#125;</code> y <code>&#123;YOUR_WEBHOOK_URL_FROM_ABOVE&#125;</code> por tus valores reales).</div><div class="mb-3"><strong>Paso 8: Probar el webhook</strong><br />Crea o modifica un contacto en HubSpot para activar el webhook. Revisa los registros de ejecución del flujo de trabajo en TradingGoose para comprobar que funciona.</div><div class="mb-3"><strong>Información adicional:</strong> El webhook se activará cada vez que se elimine un ticket de tu cuenta de HubSpot.</div>
