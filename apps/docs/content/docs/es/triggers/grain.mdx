## Eventos

### Grain Webhook

Trigger webhook genérico para todos los eventos de Grain

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Introduce tu API Key de Grain (Personal Access Token) arriba.</div><div class="mb-3"><strong>2.</strong> Puedes encontrar o crear tu API key en Grain en <strong>Settings > Integrations > API</strong>.</div><div class="mb-3"><strong>3.</strong> Haz clic en <strong>"Guardar configuración"</strong> para crear automáticamente el webhook en Grain para los eventos <strong>All events</strong>.</div><div class="mb-3"><strong>4.</strong> El webhook se eliminará automáticamente cuando quites este trigger.</div>
