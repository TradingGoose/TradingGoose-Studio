Disparar un flujo de trabajo a partir de envíos de Google Forms (mediante un reenviador de Apps Script)

<Callout type="info">
  Este es un disparador **basado en webhook**. Configura el servicio externo para que envíe eventos a la URL de webhook del flujo de trabajo.
</Callout>

<Cards>
  <Card title="Usar como herramienta" href="/tools/google_forms">
    Consulta las acciones, operaciones y entradas de herramienta del flujo de trabajo para Google Forms.
  </Card>
</Cards>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Abre tu Google Form → Más (⋮) → Editor de secuencias de comandos.</div><div class="mb-3"><strong>2.</strong> Pega el fragmento de Apps Script de abajo en <code>Code.gs</code> → Guardar.</div><div class="mb-3"><strong>3.</strong> Activadores (icono de reloj) → Añadir activador → Función: <code>onFormSubmit</code> → Origen del evento: <code>From form</code> → Tipo de evento: <code>On form submit</code> → Guardar.</div><div class="mb-3"><strong>4.</strong> Autoriza cuando se te solicite. Envía una respuesta de prueba y comprueba la ejecución en TradingGoose → Registros.</div>
