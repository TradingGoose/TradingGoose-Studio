Dispara un flujo de trabajo a partir de mensajes y eventos del bot de Telegram

<Callout type="info">
  Este es un disparador **basado en webhook**. Configura el servicio externo para enviar eventos a la URL del webhook del flujo de trabajo.
</Callout>

<Cards>
  <Card title="Usar como herramienta" href="/tools/telegram">
    Consulta las acciones, operaciones y entradas de herramienta del flujo de trabajo para Telegram.
  </Card>
</Cards>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Envía el mensaje "/newbot" a <a href="https://t.me/BotFather" target="_blank" rel="noopener noreferrer" class="text-muted-foreground underline transition-colors hover:text-muted-foreground/80">@BotFather</a> en Telegram para crear un bot y copia su token.</div><div class="mb-3"><strong>2.</strong> Introduce el token del bot arriba.</div><div class="mb-3"><strong>3.</strong> Guarda la configuración y cualquier mensaje enviado a tu bot disparará el flujo de trabajo.</div>
