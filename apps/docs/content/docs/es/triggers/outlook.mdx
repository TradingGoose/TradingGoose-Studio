Se activa cuando se reciben correos nuevos en Outlook (requiere credenciales de Microsoft)

<Callout type="info">
  Este es un activador basado en **sondeo**. TradingGoose comprueba el origen en busca de cambios coincidentes a intervalos regulares.
</Callout>

<Cards>
  <Card title="Usar como herramienta" href="/tools/outlook">
    Consulta las acciones de flujo de trabajo, las operaciones y las entradas de la herramienta para Outlook.
  </Card>
</Cards>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Conecta tu cuenta de Microsoft con credenciales OAuth</div><div class="mb-3"><strong>2.</strong> Configura las carpetas de Outlook que se van a supervisar (opcional)</div><div class="mb-3"><strong>3.</strong> El sistema comprobará automáticamente si hay correos nuevos y activará tu flujo de trabajo</div>
