<Callout type="info">

## Eventos

### Webhook de Calendly

Dispara un flujo de trabajo desde cualquier evento webhook de Calendly

#### Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> <strong>Nota:</strong> Este disparador requiere una suscripción de pago de Calendly (plan Professional, Teams o Enterprise).</div><div class="mb-3"><strong>2.</strong> Obtén tu token de acceso personal en <strong>Settings > Integrations > API & Webhooks</strong> de tu cuenta de Calendly.</div><div class="mb-3"><strong>3.</strong> Usa la operación "Obtener usuario actual" en un bloque de Calendly para recuperar la URI de tu organización.</div><div class="mb-3"><strong>4.</strong> El webhook se creará automáticamente en Calendly cuando guardes este disparador.</div><div class="mb-3"><strong>5.</strong> Este webhook se suscribe a todos los eventos de Calendly (invitee created, invitee canceled y routing form submitted). Usa el campo <code>event</code> del payload para determinar el tipo de evento.</div>
