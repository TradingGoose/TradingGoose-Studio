Se activa cuando se reciben correos nuevos en Gmail (requiere credenciales de Gmail)

<Callout type="info">
  Este es un activador **basado en sondeo**. TradingGoose comprueba la fuente en busca de cambios coincidentes a intervalos regulares.
</Callout>

<Cards>
  <Card title="Usar como herramienta" href="/tools/gmail">
    Consulta las acciones de flujo de trabajo, las operaciones y las entradas de herramienta para Gmail.
  </Card>
</Cards>

## Instrucciones de configuración

<div class="mb-3"><strong>1.</strong> Conecta tu cuenta de Gmail con credenciales OAuth</div><div class="mb-3"><strong>2.</strong> Configura las etiquetas de Gmail que quieres supervisar (opcional)</div><div class="mb-3"><strong>3.</strong> El sistema comprobará automáticamente si hay correos nuevos y activará tu flujo de trabajo</div>
