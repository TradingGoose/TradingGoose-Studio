TradingGoose Studio es una plataforma de flujos de trabajo con IA para trading técnico con LLM. Combina análisis técnico y modelos de lenguaje de gran tamaño para respaldar tus decisiones de trading, desde el análisis y la investigación hasta los gráficos, la supervisión y la automatización de flujos de trabajo.

Crea flujos de trabajo de forma visual en un lienzo conectando bloques: agentes de IA, acciones de trading, indicadores técnicos, integraciones de API y más. La mayoría de los flujos de trabajo no requieren código. También dispones de compatibilidad completa con scripts de PineTS para crear indicadores y estrategias personalizados.

## Qué puedes crear

**Automatización de trading**
Conecta brókeres (Alpaca, Tradier, Robinhood), ejecuta órdenes, supervisa posiciones y automatiza estrategias de trading basadas en análisis de IA e indicadores técnicos.

**Análisis técnico y gráficos**
Escribe indicadores personalizados en PineTS, visualiza datos OHLCV con gráficos de velas interactivos, gestiona listas de seguimiento con datos de mercado en tiempo real y activa flujos de trabajo cuando se cumplan las condiciones de un indicador.

**Investigación asistida por IA**
Crea agentes de investigación que analicen datos de mercado, revisen noticias, procesen documentos financieros y generen informes con modelos de OpenAI, Anthropic, Google y otros proveedores.

**Procesamiento e integración de datos**
Conecta más de 120 servicios: bases de datos, herramientas de comunicación, CRM y API. Orquesta canalizaciones de datos complejas con condiciones, bucles, ejecución paralela y gestión de errores.

**Lienzo visual de flujos de trabajo**
Arrastra y suelta bloques para crear flujos de trabajo. Conecta modelos de IA, servicios de trading, bases de datos y API con acciones de apuntar y hacer clic.

**Infraestructura de trading**
Integraciones incorporadas con brókeres (Alpaca, Tradier, Robinhood) y proveedores de datos de mercado (Alpha Vantage, Finnhub, Yahoo Finance) para trading real y simulado.

**Scripts de PineTS**
Escribe indicadores personalizados en PineTS, un entorno de ejecución JavaScript/TypeScript compatible con Pine Script. Conecta señales de indicadores a la automatización de flujos de trabajo mediante la API `trigger()`.

**Extensibilidad**
Amplía la plataforma con servidores MCP, herramientas personalizadas, habilidades reutilizables y bases de conocimiento. AI Copilot te ayuda a crear y gestionar todo el espacio de trabajo.

**Varios triggers**
Inicia flujos de trabajo mediante la interfaz de chat, la API REST, webhooks, tareas programadas, señales de indicadores o eventos externos de servicios como Slack y GitHub.

## Integraciones incorporadas

TradingGoose se conecta con más de 120 servicios:

- **Trading**: Alpaca, Tradier, Robinhood, Kalshi, Polymarket
- **Datos de mercado**: Alpha Vantage, Finnhub, Yahoo Finance
- **Modelos de IA**: OpenAI, Anthropic, Google, Groq, Cerebras, DeepSeek, Ollama (local)
- **Comunicación**: Gmail, Slack, Teams, Telegram, WhatsApp, Discord
- **Productividad**: Notion, Google Sheets, Airtable, Jira, Linear
- **Desarrollo**: GitHub, GitLab, automatización del navegador (Stagehand)
- **Búsqueda y web**: Google Search, Perplexity, Tavily, Exa, Firecrawl
- **Bases de datos**: PostgreSQL, MySQL, MongoDB, Supabase, Pinecone, Qdrant

¿Necesitas algo personalizado? Usa la [integración MCP](/utilities/mcp) para conectar cualquier servicio externo o crea [herramientas personalizadas](/utilities/custom-tools).

## Opciones de despliegue

**Alojamiento en la nube**: Próximamente. Infraestructura gestionada con escalado automático y supervisión incorporada.

**Alojamiento propio**: Despliega en tu propia infraestructura mediante Docker, con compatibilidad con modelos de IA locales a través de Ollama para mantener la privacidad total de los datos.
