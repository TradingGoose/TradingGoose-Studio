TradingGoose admite dos sistemas de variables complementarios. Las **variables de entorno** almacenan configuración y secretos (claves de API, tokens, URL de bases de datos) fuera de las definiciones del flujo de trabajo y se resuelven al ejecutarlo. Las **variables de flujo de trabajo** mantienen estado compartido durante una ejecución: define sus valores iniciales en el panel Variables, referéncialas desde los bloques y actualízalas con un bloque Variables.

En conjunto cubren tanto la configuración externa como el flujo de datos interno. Las variables de entorno mantienen los secretos seguros y portables entre flujos de trabajo, mientras que las variables de flujo de trabajo permiten que los bloques se pasen datos entre sí sin conexiones directas.

## Tipos de variables

<Cards>
  <Card title="Variables de entorno" href="/variables/environment-variables">
    Gestiona claves de API, tokens y otros secretos a nivel personal o de espacio de trabajo. Se referencian con la sintaxis de doble llave y se resuelven cuando se ejecuta un flujo de trabajo.
  </Card>
  <Card title="Variables de flujo de trabajo" href="/variables/workflow-variables">
    Valores compartidos durante una ejecución del flujo de trabajo. Define los valores iniciales en el panel Variables y usa un bloque Variables para las asignaciones durante la ejecución.
  </Card>
</Cards>

## Comparación rápida

| | Variables de entorno | Variables de flujo de trabajo |
|---|---|---|
| **Ámbito** | Personal o de todo el espacio de trabajo | Un solo flujo de trabajo |
| **Duración** | Persistente en todas las ejecuciones | Los cambios duran solo la ejecución actual; cada nueva ejecución carga los valores iniciales guardados |
| **Uso típico** | Claves de API, tokens, configuración | Paso de datos entre bloques, estado |
| **Sintaxis de acceso** | `{{VARIABLE_NAME}}` | `<variable.name>` mediante menú desplegable |
| **Dónde editar** | Página Environment (se aplican permisos) | Panel/widget Workflow Variables; bloque Variables para cambios durante la ejecución |
