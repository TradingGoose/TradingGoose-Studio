TradingGoose admite dos sistemas de variables complementarios. Las **variables de entorno** almacenan valores de configuración y secretos (claves de API, tokens y URL de bases de datos) fuera de las definiciones del flujo de trabajo y se resuelven durante la ejecución. Las **variables de flujo de trabajo** actúan como almacén de datos global dentro de un solo flujo de trabajo y permiten que cualquier bloque lea y escriba estado compartido durante una ejecución.

En conjunto, cubren tanto la configuración externa como el flujo interno de datos. Las variables de entorno mantienen los secretos protegidos y transferibles entre flujos de trabajo. Las variables de flujo de trabajo permiten que los bloques intercambien datos sin conexiones directas.

## Tipos de variables

<Cards>
  <Card title="Variables de entorno" href="/variables/environment-variables">
    Gestiona claves de API, tokens y otros secretos en el ámbito personal o del espacio de trabajo. Se referencian con sintaxis de llaves dobles y se resuelven al ejecutar un flujo de trabajo.
  </Card>
  <Card title="Variables de flujo de trabajo" href="/variables/workflow-variables">
    Almacén global de pares clave-valor limitado a un solo flujo de trabajo. Crea, lee y actualiza variables desde cualquier bloque para compartir estado en todo el flujo de trabajo.
  </Card>
</Cards>

## Comparación rápida

| | Variables de entorno | Variables de flujo de trabajo |
|---|---|---|
| **Ámbito** | Personal o todo el espacio de trabajo | Un solo flujo de trabajo |
| **Duración** | Persistentes entre todas las ejecuciones | Persisten entre ejecuciones salvo que se restablezcan |
| **Uso habitual** | Claves de API, tokens, configuración | Transferir datos entre bloques, estado |
| **Sintaxis de acceso** | `{{VARIABLE_NAME}}` | `<variable_name>` mediante el desplegable |
| **Quién puede editar** | Página de configuración (se aplican permisos) | Panel Variables del editor |
