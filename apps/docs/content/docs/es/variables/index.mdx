TradingGoose admite dos sistemas de variables complementarios. Las **variables de entorno** almacenan valores de configuración y secretos (claves de API, tokens, URL de bases de datos) que permanecen fuera de las definiciones del flujo de trabajo y se resuelven en el momento de la ejecución. Las **variables de flujo de trabajo** actúan como un almacén de datos global dentro de un único flujo de trabajo y permiten que cualquier bloque lea y escriba el estado compartido durante una ejecución.

En conjunto cubren tanto la configuración externa como el flujo de datos interno. Las variables de entorno mantienen los secretos seguros y portables entre flujos de trabajo, mientras que las variables de flujo de trabajo permiten que los bloques se pasen datos entre sí sin conexiones directas.

## Tipos de variables

<Cards>
  <Card title="Variables de entorno" href="/variables/environment-variables">
    Gestiona claves de API, tokens y otros secretos a nivel personal o de espacio de trabajo. Se referencian con la sintaxis de doble llave y se resuelven cuando se ejecuta un flujo de trabajo.
  </Card>
  <Card title="Variables de flujo de trabajo" href="/variables/workflow-variables">
    Almacén global de pares clave-valor con ámbito de un único flujo de trabajo. Crea, lee y actualiza variables desde cualquier bloque para compartir estado en el flujo de trabajo.
  </Card>
</Cards>

## Comparación rápida

| | Variables de entorno | Variables de flujo de trabajo |
|---|---|---|
| **Ámbito** | Personal o de todo el espacio de trabajo | Un solo flujo de trabajo |
| **Duración** | Persistente en todas las ejecuciones | Persiste entre ejecuciones a menos que se restablezca |
| **Uso típico** | Claves de API, tokens, configuración | Paso de datos entre bloques, estado |
| **Sintaxis de acceso** | `{{VARIABLE_NAME}}` | `<variable_name>` mediante menú desplegable |
| **Quién puede editar** | Página de configuración (se aplican permisos) | Panel de variables en el editor |
