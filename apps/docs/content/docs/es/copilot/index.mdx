Copilot es un asistente con IA que funciona en todo el espacio de trabajo de TradingGoose, no solo en los workflows. Puede gestionar workflows, servidores MCP, skills, herramientas personalizadas, bases de conocimiento, despliegues, variables y otros recursos. En el espacio de trabajo de escritorio, abre o cierra su panel persistente con el control **Copilot** de la barra lateral global. El panel no está disponible en el diseño móvil del espacio de trabajo.

## Capacidades

Copilot tiene acceso a un conjunto completo de herramientas para toda la plataforma:

### Gestión de workflows
- **Editar workflows** — añade, elimina o reconfigura bloques y conexiones. Las ediciones se transmiten en tiempo real como vistas previas integradas antes de confirmarse.
- **Desplegar workflows** — comprueba el estado del despliegue e inicia nuevos despliegues.
- **Ejecutar workflows** — ejecuta workflows e inspecciona los resultados.
- **Gestionar variables** — obtiene y define variables globales del workflow.
- **Ver la consola** — recupera registros de ejecución y salida en streaming.

### Herramientas del espacio de trabajo
- **Gestionar servidores MCP** — crea, actualiza y configura conexiones de servidores MCP.
- **Gestionar skills** — crea, edita y elimina definiciones de skills reutilizables.
- **Gestionar herramientas personalizadas** — crea y edita esquemas y código de herramientas personalizadas.
- **Base de conocimiento** — consulta y referencia documentos de la base de conocimiento.

### General
- **Explicar** — responde preguntas sobre conceptos de TradingGoose o cualquier workflow del espacio de trabajo.
- **Planificar** — para tareas grandes, Copilot genera una lista de tareas y registra el progreso mientras completa cada paso.
- **Referenciar contexto** — usa el menú de menciones `@` para incluir chats anteriores, otros workflows, bloques específicos, documentos de la base de conocimiento, documentación, plantillas o registros de ejecución.
- **Adjuntar archivos** — adjunta archivos directamente a un mensaje para aportar contexto adicional.

## Niveles de acceso

El selector de nivel de acceso de la barra de entrada controla la autonomía de Copilot.

<Cards>
  <Card title="Limited (default)">
    Copilot se detiene antes de ejecutar cualquier llamada a herramienta que tenga una marca de interrupción y antes de ejecutar herramientas de integración. Revisa y aprueba cada acción.
  </Card>
  <Card title="Full">
    Copilot ejecuta automáticamente todas las llamadas a herramientas, herramientas de integración y ediciones de workflows sin confirmación. Usa este nivel cuando confíes en la tarea actual y quieras iterar con mayor rapidez.
  </Card>
</Cards>

## Modelos compatibles

Copilot admite modelos de Anthropic y OpenAI. Cambia el modelo activo desde la barra de entrada.

**Anthropic** -- claude-sonnet-4.6, claude-opus-4.6

**OpenAI** -- gpt-5.4, gpt-5.4-mini

## Configuración

<Steps>
  <Step>
    ### Alojado (tradinggoose.ai)

    Copilot funciona sin configuración adicional. Abre cualquier espacio de trabajo, usa el control **Copilot** de la barra lateral global para abrir el panel y empieza a conversar.
  </Step>
  <Step>
    ### Autoalojado

    Las instancias autoalojadas necesitan una clave de API de Copilot para conectarse al servicio de inferencia gestionado.

    1. Inicia sesión en [tradinggoose.ai](https://tradinggoose.ai) y abre **Settings > Copilot**.
    2. Haz clic en **Create** para generar una clave de API. Cópiala de inmediato: solo se muestra una vez.
    3. Define la variable de entorno `COPILOT_API_KEY` del despliegue autoalojado con el valor copiado.
    4. Reinicia la aplicación. El panel global de Copilot se conectará mediante la clave.
  </Step>
</Steps>

<Callout type="warn">
  Las claves de API conceden acceso completo a Copilot. Guárdalas de forma segura y rótalas si se ven comprometidas. Puedes eliminar una clave en cualquier momento desde la misma página de configuración; al eliminarla, el acceso se revoca de inmediato.
</Callout>

## Gestión de chats

Cada sesión de Copilot corresponde al usuario autenticado y al espacio de trabajo. El menú desplegable del encabezado muestra los chats anteriores agrupados por fecha (Hoy, Ayer, Esta semana, La semana pasada, Anteriores). Desde el encabezado puedes:

- **Cambiar de chat** -- haz clic en una conversación anterior para reanudarla.
- **Iniciar un chat nuevo** -- haz clic en el botón **+** del encabezado para crear una sesión.
- **Eliminar un chat** -- coloca el cursor sobre una entrada y haz clic en el icono de papelera. Un diálogo de confirmación evita eliminaciones accidentales.

El estado del chat se conserva al navegar por el espacio de trabajo o al contraer y volver a abrir el panel. Copilot sigue la página y la selección actuales, como el detalle de una base de conocimiento, un registro de ejecución seleccionado o un monitor. En el panel, el contexto actual solo identifica el diseño activo. Copilot puede leer ese diseño mediante sus herramientas del panel cuando la tarea necesita más detalles.

## Integración con el editor

Copilot reconoce el contexto. La página actual solo publica la identidad del objeto seleccionado, como el diseño activo del panel, la base de conocimiento, el registro de ejecución o el monitor. Usa el menú de menciones `@` cuando quieras añadir otro contexto explícito a un mensaje.

Cuando Copilot transmite una respuesta que incluye llamadas a herramientas, como añadir un bloque, crear una skill o configurar un servidor MCP, cada acción aparece como vista previa integrada. En el modo **Limited**, apruebas o rechazas cada cambio; en el modo **Full**, los cambios se aplican automáticamente.

Para deshacer una acción de Copilot, puedes revertir o editar cualquier mensaje anterior directamente en el chat. Los mensajes posteriores al punto editado se atenúan para indicar que se volverán a generar.

## Facturación

El uso de Copilot se factura por token según el proveedor del LLM subyacente:

- **Tokens de entrada** -- se facturan a la tarifa base del proveedor, sin margen adicional.
- **Tokens de salida** -- se facturan a 1,5 veces la tarifa base de salida del proveedor.

```
cost = (inputTokens * inputPrice + outputTokens * outputPrice * 1.5) / 1_000_000
```

<Callout type="info">
  Los precios se indican por millón de tokens. Consulta ejemplos detallados en la página [Cost Calculation](/execution/costs).
</Callout>
