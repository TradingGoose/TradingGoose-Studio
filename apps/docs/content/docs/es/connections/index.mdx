Las conexiones son las rutas que permiten que los datos fluyan entre los bloques de tu flujo de trabajo. Definen cómo se transmite la información de un bloque a otro y te permiten crear procesos sofisticados de varios pasos.

<Callout type="info">
  Las conexiones configuradas correctamente son esenciales para crear flujos de trabajo eficaces. Determinan cómo
  se mueven los datos por tu sistema y cómo interactúan los bloques entre sí.
</Callout>

Para crear una conexión, arrastra desde el puerto de salida de un bloque hasta el puerto de entrada de otro. Una vez conectados, los datos producidos por el bloque de origen quedan disponibles en el bloque de destino a través de las etiquetas de conexión.
