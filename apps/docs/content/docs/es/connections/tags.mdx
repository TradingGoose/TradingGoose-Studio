Las etiquetas de conexión son representaciones visuales de los datos disponibles de los bloques conectados, y ofrecen una forma sencilla de hacer referencia a datos entre bloques y a las salidas de bloques anteriores en tu flujo de trabajo.

### ¿Qué son las etiquetas de conexión?

Las etiquetas de conexión son elementos interactivos que aparecen cuando se conectan bloques. Representan los datos que pueden fluir de un bloque a otro y te permiten:

- Visualizar los datos disponibles de los bloques de origen
- Hacer referencia a campos de datos específicos en los bloques de destino
- Crear flujos de datos dinámicos entre bloques

<Callout type="info">
  Las etiquetas de conexión facilitan ver qué datos están disponibles de los bloques anteriores y usarlos en tu
  bloque actual sin tener que recordar estructuras de datos complejas.
</Callout>

## Sintaxis de etiquetas

Las etiquetas de conexión usan una sintaxis sencilla para hacer referencia a datos:

```
<blockName.path.to.data>
```

Donde:

- `blockName` es el nombre del bloque de origen (o su ID)
- `path.to.data` es la ruta separada por puntos hasta el campo de datos específico

Por ejemplo:

- `<agent1.content>` - Hace referencia al campo content de un bloque llamado "agent1"
- `<api2.data.users[0].name>` - Hace referencia al nombre del primer usuario del array users desde el campo data de un bloque llamado "api2"

### Tipos de referencia especiales

Además de las referencias a bloques, el resolver admite varios prefijos especiales:

- **Alias de disparador**: `<start.input>`, `<api.fieldName>`, `<chat.input>`, `<manual.input>` - referencias abreviadas a las salidas de los bloques de disparador
- **Variables**: `<variable.myVar>` - hace referencia a variables de flujo de trabajo por nombre
- **Bucles**: `<loop.item>`, `<loop.index>` - hace referencia al elemento o índice actual dentro de un bucle
- **Paralelos**: `<parallel.item>`, `<parallel.index>` - hace referencia al elemento o índice actual dentro de una ejecución paralela

## Referencias dinámicas de etiquetas

Las etiquetas de conexión se evalúan en tiempo de ejecución, lo que significa:

1. Siempre hacen referencia a los datos más actuales del contexto de ejecución
2. Se pueden usar en expresiones y combinar con texto estático
3. Se pueden anidar dentro de otras estructuras de datos
4. Se admite la indexación de arrays mediante la notación de corchetes (p. ej., `items[0]`)

### Ejemplos

```javascript
// Reference in text
"The user's name is <userBlock.name>"

// Reference in JSON
{
  "userName": "<userBlock.name>",
  "orderTotal": <apiBlock.data.total>
}

// Using trigger aliases
"User said: <start.input>"

// Using loop references inside a loop
"Processing item <loop.index>: <loop.item.name>"
```

<Callout type="warning">
  Al usar etiquetas de conexión en contextos numéricos, asegúrate de que los datos referenciados sean realmente un número
  para evitar problemas de conversión de tipos.
</Callout>
