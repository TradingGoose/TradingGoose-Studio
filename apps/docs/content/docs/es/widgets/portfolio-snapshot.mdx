## Descripción general

| Propiedad | Valor |
|----------|-------|
| **Clave** | `portfolio_snapshot` |
| **Categoría** | Trading |

Portfolio Snapshot es un resumen de solo lectura de una cuenta de bróker seleccionada durante un periodo de rendimiento compatible.

## Funciones

- **Resumen de rendimiento** -- Muestra rentabilidad, capital inicial y final, capital máximo y mínimo, y la serie de capital.
- **Detalles de la cuenta** -- Muestra el efectivo y el número de posiciones de la cartera seleccionada.
- **Enriquecimiento de precios** -- Añade valor con precios, cambio diario, porcentaje de cambio diario y cobertura como posiciones cotizadas respecto a posiciones aptas en la solicitud de precios.
- **Disponibilidad parcial** -- El enriquecimiento puede ser parcial o no estar disponible sin ocultar los datos de cartera del bróker.
- **Actualizar** -- `runtime.refreshAt` solicita nuevos datos del bróker y de precios.

## Uso

Selecciona un bróker y una cuenta, y elige `selectedWindow` entre los periodos compatibles con el proveedor. Configura un proveedor de mercado para añadir precios actuales. La actualización solicita un nuevo resumen; la falta de precios no impide mostrar el efectivo, las posiciones ni el rendimiento.

## Configuración

| Parámetro | Descripción |
|-----------|-------------|
| `provider` | Proveedor de trading usado para los datos de cartera. |
| `serviceId` | Identificador del servicio de bróker. |
| `portfolioIdentity` | Identidad canónica de la cuenta seleccionada. |
| `marketProvider` | Proveedor usado para enriquecer los precios. |
| `marketProviderParams` | Parámetros específicos del proveedor de mercado. |
| `marketAuth` | Credenciales opcionales del proveedor de mercado. |
| `selectedWindow` | Periodo de rendimiento compatible con el proveedor. |
| `runtime.refreshAt` | Marca de tiempo usada para solicitar una actualización. |
