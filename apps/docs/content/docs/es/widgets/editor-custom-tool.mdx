## Descripción general

| Propiedad | Valor |
|---|---|
| **Clave** | `editor_custom_tool` |
| **Categoría** | Editor |

Custom Tool Editor permite definir los tools que los agentes invocan. Cada tool contiene un esquema JSON con nombre, descripción y parámetros, y una función JavaScript que se ejecuta al invocarlo. Usa [Custom Tool List](/widgets/list-custom-tool) para explorar, crear e importar tools.

## Funciones

- **Config** y **Code** alternan las dos secciones.
- **Config** usa Monaco para el esquema de function calling de OpenAI. Debe incluir `type: "function"`, `function.name`, `function.description` y `function.parameters` con `type`, `properties` y `required`; valida en tiempo real.
- **Code** usa Monaco para el cuerpo que se ejecuta en `async function(params, environmentVariables)`. Referencia parámetros con `<paramName>` y variables con `{{VAR_NAME}}`.
- La **varita de IA** genera el esquema o código desde una descripción.
- El editor completa parámetros del esquema; `{{` abre variables de entorno y el patrón de etiqueta abre variables del workflow.
- **Export** descarga JSON de TradingGoose. **Save** valida, comprueba nombres duplicados y guarda; ante un error abre Config.
- El selector se sincroniza con Custom Tool List mediante el color de pareja.

## Uso

1. Añade el widget y selecciona un tool, o créalo/importa desde [Custom Tool List](/widgets/list-custom-tool).
2. En **Config**, escribe o genera el esquema JSON.
3. En **Code**, escribe la función JavaScript usando directamente los parámetros del esquema.
4. Pulsa **Save** y corrige los errores que aparezcan.

### Formato del esquema

```json
{
  "type": "function",
  "function": {
    "name": "myToolName",
    "description": "What the tool does.",
    "parameters": {
      "type": "object",
      "properties": {
        "paramName": {
          "type": "string",
          "description": "What this parameter is for."
        }
      },
      "required": ["paramName"]
    }
  }
}
```

Los tools exportados usan el formato JSON compartido de TradingGoose. Al importar desde la lista, los títulos y nombres de función duplicados se cambian automáticamente.

<Callout>Asigna el mismo **pairColor** a Custom Tool Editor y [Custom Tool List](/widgets/list-custom-tool) para abrir automáticamente el tool seleccionado.</Callout>

## Configuración

El tool se guarda como `customToolId` y se sincroniza por color. La sección activa se sincroniza entre el encabezado y el editor mediante eventos personalizados.
