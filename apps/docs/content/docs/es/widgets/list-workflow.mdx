## Descripción general

| Propiedad | Valor |
|----------|-------|
| **Clave** | `list_workflow` |
| **Categoría** | Lista |

El widget Lista de workflows muestra una lista navegable de todos los workflows del espacio de trabajo. Úsalo para crear workflows o carpetas, importar JSON de workflows y abrir cualquier workflow en el editor.

## Funciones

- **Explorar**: consulta todos los workflows del espacio de trabajo.
- **Buscar y filtrar**: encuentra workflows con rapidez.
- **Crear**: inicia una carpeta o un workflow desde el menú Create.
- **Importar**: importa un archivo JSON exportado por TradingGoose desde el menú Create. Si contiene skills, estas se importan primero y las referencias del workflow se vuelven a enlazar automáticamente.
- **Abrir en el editor**: haz clic en un workflow para abrirlo en el widget de edición.

## Uso

Añade este widget junto al editor de workflows para gestionarlos. El menú Create permite crear carpetas y workflows e importar archivos.

<Callout type="info">
  Las importaciones usan el formato JSON compartido de exportación de TradingGoose. Las skills incluidas se importan primero y se vuelven a enlazar automáticamente.
</Callout>
