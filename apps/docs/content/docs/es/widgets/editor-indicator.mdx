## Descripción general

| Propiedad | Valor |
|---|---|
| **Clave** | `editor_indicator` |
| **Categoría** | Editor |

Indicator Editor permite escribir y perfeccionar indicadores PineTS. Incluye Monaco con TypeScript, una guía de variables globales de PineTS y verificación en el servidor. Usa [Indicator List](/widgets/list-indicator) para explorar, crear e importar indicadores.

## Funciones

- **Editor Monaco** con resaltado TypeScript, autocompletado y definiciones PineTS.
- **Guía rápida** por categorías; al pasar el cursor muestra firma, descripción y ejemplos.
- **Verify** ejecuta el indicador con datos simulados e informa gráficos, marcadores y advertencias.
- **Export** descarga el indicador guardado como JSON de TradingGoose; guarda antes si hay cambios.
- **Save** conserva el código e infiere `inputMeta` de las llamadas `input.*` para mostrar controles.
- **Barra Wand** genera código PineTS desde una descripción en lenguaje natural.
- El menú de variables de entorno se abre al escribir `{{`.
- El **selector de indicadores** se sincroniza con Indicator List mediante el color de pareja.

## Uso

1. Añade el widget y selecciona un indicador, o créalo en [Indicator List](/widgets/list-indicator).
2. Escribe PineTS usando directamente `close`, `ta.sma`, `input.int` y `plot`, sin prefijo `$`.
3. Pulsa **Verify**, corrige errores y advertencias, y pulsa **Save**. El gráfico usará el código actualizado en la siguiente representación.

### Atajos

- **Wand toggle**: haz clic en la varita del margen para abrir o cerrar la barra de IA.

<Callout>Asigna el mismo **pairColor** a Indicator Editor e [Indicator List](/widgets/list-indicator) para abrir automáticamente el indicador seleccionado.</Callout>

## Configuración

No tiene configuración visible aparte del selector. El indicador se guarda como `pineIndicatorId` y se sincroniza mediante el almacén de color de pareja.
