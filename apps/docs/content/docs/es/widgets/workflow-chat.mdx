## Descripción general

| Propiedad | Valor |
|---|---|
| **Clave** | `workflow_chat` |
| **Categoría** | Utilidad |

Workflow Chat conecta por socket con el workflow activo, transmite respuestas en tiempo real y permite elegir qué salidas aparecen. Úsalo para probar triggers de chat, conversar con agentes o examinar respuestas.

## Funciones

- Cada instancia usa su propio socket en vivo.
- El selector de salidas elige bloques, elimina duplicados y persiste por workflow.
- Clear elimina la conversación actual y se desactiva si no hay mensajes.
- El selector cambia de workflow; si hay color de pareja, refleja la selección compartida.
- Resuelve el workflow desde parámetros, el canal de color o el registro y persiste la selección.

## Uso

### Añadir el widget

Selecciona **Workflow Chat**. Requiere un espacio de trabajo activo y se conecta al primer workflow disponible.

### Diseño del encabezado

- **Izquierda**: selector de salidas.
- **Centro**: selector de workflow.
- **Derecha**: botón para borrar el chat.

### Interacciones principales

1. Escribe y pulsa Enter.
2. Las respuestas aparecen durante la ejecución.
3. Limita la respuesta con el selector.
4. Borra para iniciar otra conversación.

### Sincronización por color

Con un color de pareja comparte el workflow con otros widgets; `gray` mantiene una selección independiente.

<Callout>Vincúlalo con **Workflow Editor** usando el mismo color para que el chat siga el workflow editado.</Callout>
