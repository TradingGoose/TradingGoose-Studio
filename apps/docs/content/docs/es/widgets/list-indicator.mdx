## Descripción general

| Propiedad | Valor |
|----------|-------|
| **Clave** | `list_indicator` |
| **Categoría** | Lista |

El widget Lista de indicadores permite explorar los indicadores PineTS personalizados del espacio de trabajo. Úsalo para buscar indicadores, crear nuevos, importar JSON exportado por TradingGoose y abrir el indicador seleccionado en el editor.

## Funciones

- **Explorar y buscar** indicadores del espacio de trabajo actual.
- **Crear** indicadores desde el menú Create.
- **Importar** indicadores con la acción **Import indicator** del menú Create.
- **Abrir en el editor** al seleccionar un indicador.
- **Vincular por color de pareja** mantiene sincronizados la lista y el editor de indicadores cuando comparten el mismo color.

## Uso

1. Añade el widget a un panel del espacio de trabajo.
2. Usa el menú Create para añadir un indicador o importar un archivo JSON exportado por TradingGoose.
3. Selecciona un indicador para abrirlo en el widget Indicator Editor vinculado.
4. Asigna un color de pareja para sincronizar los cambios de selección entre la lista y el editor.

<Callout type="info">
  Crear e importar requiere permiso de edición en el espacio de trabajo. Para explorar los indicadores existentes solo se necesita acceso al espacio de trabajo.
</Callout>
