## Descripción general

| Propiedad | Valor |
|----------|-------|
| **Clave** | `list_custom_tool` |
| **Categoría** | Lista |

El widget Lista de tools personalizados permite explorar los tools reutilizables del espacio de trabajo. Úsalo para buscar, crear e importar tools mediante JSON exportado por TradingGoose, y para abrir el tool seleccionado en el editor.

## Funciones

- **Explorar y buscar** tools personalizados del espacio de trabajo.
- **Crear** tools desde el menú Create.
- **Importar** tools con la acción **Import custom tools** del menú Create.
- **Abrir en el editor** al seleccionar un tool.
- **Vincular por color de pareja** mantiene sincronizados la lista y el editor cuando comparten el mismo color.
- **Gestionar cambios de nombre automáticamente** actualiza los títulos y nombres de funciones importados si coinciden con tools existentes.

## Uso

1. Añade el widget a un panel del espacio de trabajo.
2. Usa Create para añadir un tool personalizado o importar un archivo JSON exportado por TradingGoose.
3. Selecciona un tool para abrirlo en el widget Custom Tool Editor vinculado.
4. Asigna un color de pareja para sincronizar la selección entre la lista y el editor.

<Callout type="info">
  Crear e importar requiere permiso de edición. Para explorar los tools existentes solo se necesita acceso al espacio de trabajo.
</Callout>
