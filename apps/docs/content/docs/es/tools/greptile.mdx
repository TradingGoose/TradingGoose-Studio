Consulta repositorios en lenguaje natural y obtén respuestas con referencias de código relevantes. Greptile usa IA para comprender tu base de código y responder preguntas.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | cadena | Sí | Pregunta en lenguaje natural sobre la base de código |
| `repositories` | cadena | Sí | Lista de repositorios separados por comas. Formato: "github:rama:owner/repo" o solo "owner/repo" \(usa github:main de forma predeterminada\) |
| `sessionId` | cadena | No | ID de sesión para mantener la continuidad de la conversación |
| `genius` | booleano | No | Habilita el modo genius para un análisis más exhaustivo \(más lento, pero más preciso\) |
| `apiKey` | cadena | Sí | Clave de API de Greptile |
| `githubToken` | cadena | Sí | Token de acceso personal de GitHub con permiso de lectura del repositorio |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | cadena | Respuesta generada por IA para la consulta |
| `repository` | cadena | Nombre del repositorio \(owner/repo\) |
| `remote` | cadena | Remoto de Git \(github/gitlab\) |
| `branch` | cadena | Nombre de la rama |
| `filepath` | cadena | Ruta del archivo |
| `linestart` | número | Número de la línea inicial |
| `lineend` | número | Número de la línea final |
| `summary` | cadena | Resumen de la sección de código |

<div className="text-base font-semibold mb-2">Índice Repository (<code>greptile_index_repo</code>)</div>

Envía un repositorio para que Greptile lo indexe. La indexación debe finalizar antes de poder consultar el repositorio. Los repositorios pequeños tardan entre 3 y 5 minutos; los grandes pueden tardar más de una hora.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `remote` | cadena | Sí | Git remote type: github o gitlab |
| `repository` | cadena | Sí | Repository en owner/repo formato \(e.g., "facebook/react"\) |
| `branch` | cadena | Sí | Branch un index \(e.g., "main" or "master"\) |
| `reload` | booleano | No | Force re-indexing even if already indexed |
| `notify` | booleano | No | Enviar email notification cuando indexing completes |
| `apiKey` | cadena | Sí | Greptile clave de API |
| `githubToken` | cadena | Sí | GitHub Personal Token de acceso con repo read access |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `repositoryId` | cadena | Unique identificador para el indexed repositorio \(format: remote:branch:owner/repo\) |
| `statusEndpoint` | cadena | URL punto de conexión un check indexing status |

</div>

| `branch` | cadena | Branch name |

| `status` | cadena | Indexing status: submitted, cloning, processing, completado, o fallido |
| `filesProcessed` | número | Number de files processed so far |
| `numFiles` | número | Total número de files en el repositorio |
| `sampleQuestions` | matriz | Sample questions para el indexed repositorio |
