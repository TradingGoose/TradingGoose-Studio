## Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `server` | string | Sí | ID del servidor MCP en el que ejecutar la herramienta |
| `tool` | string | No | Nombre de la herramienta a ejecutar |
| `arguments` | json | No | Argumentos que se pasan a la herramienta |

## Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | array | Matriz de contenido de la respuesta de la herramienta MCP: el formato estándar para todas las herramientas MCP |

## Instrucciones de uso

Integra MCP en el flujo de trabajo. Puede ejecutar herramientas de servidores MCP configurados en los widgets del panel del espacio de trabajo.
