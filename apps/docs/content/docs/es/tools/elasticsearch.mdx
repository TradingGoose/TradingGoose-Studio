| `apiKey` | cadena | No | Elasticsearch clave de API |
| `username` | cadena | No | Username para básico auth |
| `password` | cadena | No | Password para básico auth |
| `index` | cadena | Sí | Índice name un search |
| `query` | cadena | No | Consulta DSL como JSON cadena |
| `from` | número | No | Desplazamiento inicial para la paginación \(predeterminado: 0\) |
| `size` | número | No | Número de resultados que se devolverán \(predeterminado: 10\) |
| `sort` | cadena | No | Ordenación specification como JSON cadena |
| `sourceIncludes` | cadena | No | Separados por comas lista de campos un incluir en _source |
| `sourceExcludes` | cadena | No | Separados por comas lista de campos un excluir desde _source |
| `trackTotalHits` | booleano | No | Registra la cantidad total exacta de coincidencias \(predeterminado: true\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `took` | número | Hora en milliseconds el search took |
| `timed_out` | booleano | Si el search timed out |
| `hits` | objeto | Buscar resultados con total cantidad y coincidente documents |

</div>
