## Herramientas

### `huggingface_chat`

Generar completions mediante Hugging Face Inference API

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | cadena | No | System instrucción un guide el modelo behavior |
| `content` | cadena | Sí | El usuario message contenido un send un el modelo |
| `provider` | cadena | Sí | El proveedor un usar para el API request \(p. ej., novita, cerebras, etc.\) |
| `model` | cadena | Sí | Modelo un usar para chat completions \(p. ej., Qwen/Qwen2.5-7B-Instruct\) |
| `maxTokens` | número | No | Máximo número de tokens un generar |
| `temperature` | número | No | Temperatura de muestreo \(0-2\). Los valores más altos producen resultados más aleatorios |
| `apiKey` | cadena | Sí | Hugging Face API token |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Operación success estado |
| `content` | cadena | Generated text contenido |
| `model` | cadena | Modelo usado para generation |
| `prompt_tokens` | número | Número de tokens en el instrucción |
| `completion_tokens` | número | Número de tokens en el completion |


## Uso Instrucciones

Integrar Hugging Face en el workflow. Puede generar completions mediante el Hugging Face Inference API.
