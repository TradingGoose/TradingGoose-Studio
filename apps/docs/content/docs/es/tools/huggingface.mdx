## Herramientas

### `huggingface_chat`

Generar completaciones con Hugging Face Inference API

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | No | Prompt del sistema para orientar el comportamiento del modelo |
| `content` | string | Sí | Contenido del mensaje del usuario que se envía al modelo |
| `provider` | string | Sí | Proveedor que se usará para la solicitud a la API \(p. ej., novita, cerebras, etc.\) |
| `model` | string | Sí | Modelo que se usará para las completaciones de chat \(p. ej., Qwen/Qwen2.5-7B-Instruct\) |
| `maxTokens` | number | No | Número máximo de tokens a generar |
| `temperature` | number | No | Temperatura de muestreo \(0-2\). Valores más altos hacen la salida más aleatoria |
| `apiKey` | string | Sí | Token de API de Hugging Face |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `output` | object | Resultados de la completación de chat |

## Instrucciones de uso

Integra Hugging Face en el flujo de trabajo. Puede generar completaciones con Hugging Face Inference API.
