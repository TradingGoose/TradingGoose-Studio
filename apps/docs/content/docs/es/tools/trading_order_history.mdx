## Herramientas

### `trading_order_history`

Recupera los envíos de órdenes del workspace registrados en un intervalo de fecha y hora.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `startDate` | string | Sí | Fecha y hora de inicio \(ISO 8601\). |
| `endDate` | string | Sí | Fecha y hora de fin \(ISO 8601\). |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `history` | array | Lista ordenada de envíos de órdenes registrados. |
| `count` | number | Número de registros devueltos. |
| `workspaceId` | string | ID del workspace usado para el filtrado. |
| `startDate` | string | Fecha y hora de inicio usada para el filtrado. |
| `endDate` | string | Fecha y hora de fin usada para el filtrado. |

## Instrucciones de uso

Obtiene el historial de envíos de órdenes registrado por la herramienta Trading Action para el intervalo de fechas seleccionado.
