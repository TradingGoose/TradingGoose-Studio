## Herramientas

### `trading_order_history`

Recuperar workspace orden envíos dentro de un datetime intervalo.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `startDate` | cadena | Sí | Iniciar datetime \(ISO 8601\). |
| `endDate` | cadena | Sí | Fin datetime \(ISO 8601\). |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | Orden historial record ID |
| `provider` | cadena | Trading proveedor |
| `recordedAt` | cadena | Registrado marca de tiempo |
| `logId` | cadena | Linked workflow log ID |


## Uso Instrucciones

Fetches orden submission historial registrado por el Trading Acción herramienta para el workspace y fecha intervalo.
