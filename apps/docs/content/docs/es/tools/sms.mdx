## Herramientas

### `sms_send`

Envía un SMS mensaje mediante el internal SMS servicio proporcionado por Twilio

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `to` | cadena | Sí | Destinatario phone número \(incluir país código, p. ej., +1234567890\) |
| `body` | cadena | Sí | SMS mensaje contenido |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el SMS fue enviados successfully |
| `to` | cadena | Destinatario phone número |


## Uso Instrucciones

Envía SMS mensajes directly mediante el internal SMS servicio proporcionado por Twilio. Sin externo configuración o OAuth obligatorio. Perfect para sending notificaciones, alertas, o general propósito texto mensajes desde tu workflows. Requiere válido phone numbers con país códigos.
