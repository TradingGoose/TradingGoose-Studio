| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |

| `subject` | cadena | Sí | Correo electrónico asunto |

| `contentType` | cadena | No | Contenido tipo para el email cuerpo \(texto o html\) |
| `replyToMessageId` | cadena | No | Mensaje ID a reply a \(para threading\) |
| `conversationId` | cadena | No | Conversación ID para threading |
| `cc` | cadena | No | CC destinatarios \(comma-separated\) |
| `bcc` | cadena | No | BCC destinatarios \(comma-separated\) |
| `attachments` | file[] | No | Archivos a attach a el email |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Correo electrónico enviar éxito estado |
| `status` | cadena | Delivery estado de el email |
| `timestamp` | cadena | Marca de tiempo cuando email fue enviados |

## Uso Instrucciones

Integra Outlook en el workflow. Permite leer, borrador, y enviar email mensajes. Permite ser usado en trigger modo a trigger un workflow cuando un nuevo email es received.
