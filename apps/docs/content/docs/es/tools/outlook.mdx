## Instrucciones de uso

Integra Outlook en el flujo de trabajo. Puede leer, redactar y enviar mensajes de correo electrónico. Se puede utilizar en modo de disparador para activar un flujo de trabajo cuando se recibe un nuevo correo electrónico.
