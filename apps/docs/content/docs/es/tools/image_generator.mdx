<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `model` | string | Sí | El modelo a usar \(gpt-image-1 o dall-e-3\) |
| `prompt` | string | Sí | Una descripción textual de la imagen deseada |
| `size` | string | Sí | El tamaño de las imágenes generadas \(1024x1024, 1024x1792 o 1792x1024\) |
| `quality` | string | No | La calidad de la imagen \(estándar o hd\) |
| `style` | string | No | El estilo de la imagen \(vívido o natural\) |
| `background` | string | No | El color de fondo, solo para gpt-image-1 |
| `apiKey` | string | Sí | Tu clave de API de OpenAI |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `output` | object | Datos de imagen generada |
