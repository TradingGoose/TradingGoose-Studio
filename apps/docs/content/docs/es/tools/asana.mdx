<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `taskGid` | string | No | El identificador único global \(GID\) de la tarea. Si no se proporciona, se obtendrán varias tareas. |
| `workspace` | string | No | GID del espacio de trabajo para filtrar tareas \(obligatorio cuando no se usa taskGid\) |
| `project` | string | No | GID del proyecto para filtrar tareas |
| `limit` | number | No | Número máximo de tareas a devolver \(predeterminado: 50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `ts` | string | Marca de tiempo de la respuesta |
| `gid` | string | Identificador único global de la tarea |
| `resource_type` | string | Tipo de recurso \(tarea\) |
| `resource_subtype` | string | Subtipo de recurso |
| `name` | string | Nombre de la tarea |
| `notes` | string | Notas o descripción de la tarea |
| `completed` | boolean | Indica si la tarea está completada |
| `assignee` | object | Detalles del asignado |
| `created_by` | object | Detalles del creador |
| `due_on` | string | Fecha de vencimiento \(YYYY-MM-DD\) |
| `created_at` | string | Marca de tiempo de creación de la tarea |
| `modified_at` | string | Marca de tiempo de última modificación de la tarea |
| `tasks` | array | Array de tareas \(al obtener varias\) |
