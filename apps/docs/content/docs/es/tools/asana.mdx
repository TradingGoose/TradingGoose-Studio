Recuperar un único task por GID o get varios tasks con filters

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `taskGid` | cadena | No | Identificador único global \(GID\) de la tarea. Si no se proporciona, se obtienen varias tareas. |
| `workspace` | cadena | No | GID del espacio de trabajo para filtrar tareas \(obligatorio cuando no se utiliza taskGid\) |
| `project` | cadena | No | Proyecto GID un filter tasks |
| `limit` | número | No | Número máximo de tareas que se devolverán \(predeterminado: 50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Operación success status |
| `ts` | cadena | Timestamp de el response |
| `gid` | cadena | Assignee GID |
| `resource_type` | cadena | Resource type \(task\) |
| `resource_subtype` | cadena | Resource subtype |
| `name` | cadena | Tarea name |
| `notes` | cadena | Tarea notas o description |
| `completed` | booleano | Si el task is completado |
