Cargar un archivo en OneDrive

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `fileName` | string | Sí | El nombre del archivo que se va a cargar |
| `file` | file | No | El archivo que se va a cargar \(binario\) |
| `content` | string | No | El contenido de texto que se va a cargar \(si no se proporciona ningún archivo\) |
| `mimeType` | string | No | El tipo MIME del archivo que se va a crear \(p. ej., text/plain para .txt, application/vnd.openxmlformats-officedocument.spreadsheetml.sheet para .xlsx\) |
| `folderId` | string | No | ID de carpeta en la que cargar el archivo |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si el archivo se subió correctamente |
| `file` | object | El objeto del archivo subido con metadatos, incluidos id, name, webViewLink, webContentLink y marcas de tiempo |

</div>

Integra OneDrive en el flujo de trabajo. Permite crear archivos de texto y Excel, cargar archivos y listar archivos.
