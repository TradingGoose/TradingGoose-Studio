## Herramientas

### `parallel_search`

Busca en la web con Parallel AI. Proporciona resultados completos mediante procesamiento inteligente y extracción de contenido.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `objective` | cadena | Sí | Objetivo de búsqueda o pregunta que se responderá |
| `search_queries` | cadena | No | Opcional comma-separated listar de buscar consultas a ejecutar |
| `processor` | cadena | No | Procesamiento método: base o pro \(predeterminado: base\) |
| `max_results` | número | No | Número máximo de resultados a devolver \(predeterminado: 5\) |
| `max_chars_per_result` | número | No | Máximo caracteres por resultado \(predeterminado: 1500\) |
| `apiKey` | cadena | Sí | Parallel AI API Clave |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `url` | cadena | El URL de el buscar resultado |
| `title` | cadena | El título de el buscar resultado |


## Uso Instrucciones

Integra Parallel AI en el workflow. Permite buscar el web.
