## Herramientas

### `openai_embeddings`

Genera embeddings de texto mediante OpenAI.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `input` | string | Sí | Texto del que se generarán los embeddings |
| `model` | string | No | Modelo que se utilizará para los embeddings |
| `encodingFormat` | string | No | Formato en el que se devolverán los embeddings |
| `apiKey` | string | Sí | Clave API de OpenAI |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `embeddings` | array | Matriz de vectores de embedding |
| `model` | string | Modelo utilizado para generar los embeddings |
| `prompt_tokens` | number | Número de tokens del prompt |


## Instrucciones de uso

Integra Embeddings en el workflow para generar embeddings a partir de texto.
