## Herramientas

### `openai_embeddings`

Genera embeddings a partir de texto con los modelos de embeddings de OpenAI

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `input` | string | Sí | Texto para el que se generan los embeddings |
| `model` | string | No | Modelo que se usará para los embeddings |
| `apiKey` | string | Sí | Clave de API de OpenAI |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `output` | object | Resultados de la generación de embeddings |

## Instrucciones de uso

Integra Embeddings en el flujo de trabajo. Puede generar embeddings a partir de texto.

## Notas

- Categoría: `tools`
- Tipo: `openai`


El campo Modelo carga los modelos de embeddings OpenAI disponibles del registro nativo. Selecciona un identificador completo como `openai/text-embedding-3-small`. La entrada se conserva exactamente; los textos que superan el límite del modelo se rechazan. El uso de tokens solo aparece cuando lo informa el modelo; el costo del modelo en USD no está disponible.
