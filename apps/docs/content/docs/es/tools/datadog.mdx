| `site` | string | No | Sitio/región de Datadog \(predeterminado: datadoghq.com\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Requerido | Descripción |
| --------- | ---- | --------- | ----------- |
| `title` | cadena | Sí | Título del evento |
| `text` | cadena | Sí | Cuerpo/descripción del evento. Admite markdown. |
| `alertType` | cadena | No | Tipo de alerta: error, warning, info, success, user_update, recommendation o snapshot |
| `priority` | cadena | No | Prioridad del evento: normal o low |
| `host` | cadena | No | Nombre del host a asociar con este evento |
| `tags` | cadena | No | Lista de etiquetas separadas por comas \(p. ej., "env:production,service:api"\) |
| `aggregationKey` | cadena | No | Clave para agrupar eventos |
| `sourceTypeName` | cadena | No | Nombre del tipo de origen para el evento |
| `dateHappened` | número | No | Marca de tiempo Unix cuando ocurrió el evento \(por defecto, ahora\) |
| `apiKey` | cadena | Sí | Clave de API de Datadog |
| `site` | cadena | No | Sitio/región de Datadog \(por defecto: datadoghq.com\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
