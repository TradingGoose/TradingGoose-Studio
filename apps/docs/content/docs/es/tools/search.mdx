## Herramientas

### `search_tool`

Buscar en la web. Devuelve el más relevantes web resultados, incluidos título, enlace, snippet, y fecha para cada resultado.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | cadena | Sí | El buscar consulta |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `results` | json | Buscar resultados |
| `query` | cadena | El buscar consulta |
| `totalResults` | número | Total número de resultados |
| `source` | cadena | Buscar origen \(exa\) |
| `cost` | json | Cost información \($0.01\) |


## Uso Instrucciones

Buscar en la web mediante Buscar herramienta. Cada buscar costs $0.01 por consulta.
