## Herramientas

### `search_tool`

Busca en la web. Devuelve los resultados web más relevantes, incluidos el título, el enlace, el fragmento y la fecha de cada resultado.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | string | Sí | La consulta de búsqueda |

#### Salida (contrato a nivel de bloque)

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `results` | json | Resultados de búsqueda |
| `query` | string | La consulta de búsqueda |
| `totalResults` | number | Número total de resultados |
| `source` | string | Fuente de búsqueda \(exa\) |
| `cost` | json | Información de coste \($0.01\) |

## Instrucciones de uso

Busca en la web con la herramienta Search. Cada búsqueda cuesta $0.01 por consulta.
