Extrae contenido estructurado de páginas web con compatibilidad completa de metadatos. Convierte el contenido a markdown o HTML a la vez que captura metadatos SEO, etiquetas Open Graph e información de la página.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | string | Sí | La URL desde la que extraer el contenido |
| `apiKey` | string | Sí | Clave de API de Firecrawl |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `markdown` | string | Contenido de la página en formato markdown |
| `html` | string | Contenido HTML sin procesar de la página |
| `metadata` | object | Metadatos de la página, incluida información SEO y de Open Graph |

</div>

Rastrear sitios web completos y extraer contenido estructurado de todas las páginas accesibles

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Requerido | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | cadena | Sí | URL del sitio web a rastrear |
| `limit` | número | No | Número máximo de páginas a rastrear \(predeterminado: 100\) |
| `onlyMainContent` | booleano | No | Extraer solo el contenido principal de las páginas |
| `apiKey` | cadena | Sí | Clave de API de Firecrawl |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `pages` | array | Array de páginas rastreadas con su contenido y metadatos |
| `total` | número | Número total de páginas encontradas durante el rastreo |
| `creditsUsed` | número | Número de créditos consumidos por la operación de rastreo |

</div>
