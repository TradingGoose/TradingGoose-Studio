| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |

| `limit` | número | No | Número máximo de páginas que se rastrearán \(predeterminado: 100\) |
| `onlyMainContent` | booleano | No | Extract solo main content desde pages |
| `apiKey` | cadena | Sí | Firecrawl Clave de API |

| `html` | cadena | Página contenido HTML |
| `title` | cadena | Página title |
| `description` | cadena | Página description |
| `language` | cadena | Página idioma |
| `sourceURL` | cadena | Source URL de el página |

</div>
