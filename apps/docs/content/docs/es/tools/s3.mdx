| `objectKey` | string | Sí | Clave/ruta del objeto en S3 \(p. ej., folder/filename.ext\) |
| `file` | file | No | Archivo que se va a subir |
| `content` | string | No | Contenido de texto que se va a subir \(alternativa al archivo\) |
| `contentType` | string | No | Encabezado Content-Type \(se detecta automáticamente a partir del archivo si no se indica\) |
| `acl` | string | No | Lista de control de acceso \(p. ej., private, public-read\) |

| Parámetro | Tipo | Descripción |

| `uri` | string | URI de S3 del objeto subido \(s3://bucket/key\) |
| `metadata` | object | Metadatos de la subida, incluido el ETag y la ubicación |

## Instrucciones de uso

Integra S3 en el flujo de trabajo. Carga archivos, descarga objetos, enumera el contenido de un bucket, elimina objetos y copia objetos entre buckets. Requiere una clave de acceso de AWS y una clave de acceso secreta.
