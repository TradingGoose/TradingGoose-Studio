## Herramientas

### `elevenlabs_tts`

Convertir TTS con voces de ElevenLabs

#### Entrada

| Parámetro | Tipo | Requerido | Descripción |
| --------- | ---- | -------- | ----------- |
| `text` | string | Sí | El texto para convertir a voz |
| `voiceId` | string | Sí | El ID de la voz a usar |
| `modelId` | string | No | El ID del modelo a usar \(por defecto eleven_monolingual_v1\) |
| `apiKey` | string | Sí | Tu clave API de ElevenLabs |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `audioUrl` | string | La URL del audio generado |
| `audioFile` | file | El archivo de audio generado |

## Instrucciones de uso

Integra ElevenLabs en el flujo de trabajo. Puede convertir texto a voz.
