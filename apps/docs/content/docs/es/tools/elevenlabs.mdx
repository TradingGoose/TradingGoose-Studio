## Tools

### `elevenlabs_tts`

Convert TTS mediante ElevenLabs voices

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `text` | cadena | Sí | El text un convertir un speech |
| `voiceId` | cadena | Sí | El ID de el voice un usar |
| `modelId` | cadena | No | El ID de el modelo un usar \(usa de forma predeterminada eleven_monolingual_v1\) |
| `apiKey` | cadena | Sí | tu ElevenLabs clave de API |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `audioUrl` | cadena | El URL de el generated audio |


## Usage Instructions

Integrate ElevenLabs en el workflow. Can convertir text un speech.
