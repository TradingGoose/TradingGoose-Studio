## Herramientas

### `trading_get_portfolio_detail`

Obtener cuenta resumen, cash, posiciones, y órdenes desde Alpaca o Tradier.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `portfolioIdentity` | json | Sí | Canonical portfolioIdentity seleccionado por el bróker cuenta campo. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `summary` | cadena | Estado mensaje para portfolio detail retrieval. |
| `provider` | cadena | Bróker/proveedor usado para el solicitud. |
| `portfolioDetail` | json | Canonical portfolio detail con cash, posiciones, y resumen. |


## Uso Instrucciones

Portfolio detail bloque ese devuelve cuenta resumen, cash, posiciones, y órdenes desde Alpaca o Tradier.
