## Herramientas

### `trading_get_portfolio_detail`

Obtén el resumen de la cuenta, el efectivo, las posiciones y las órdenes de Alpaca o Tradier.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `portfolioIdentity` | json | Sí | portfolioIdentity canónico seleccionado por el campo de cuenta de bróker. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `summary` | string | Mensaje de estado de la recuperación del detalle de la cartera. |
| `provider` | string | Bróker/proveedor usado para la solicitud. |
| `portfolioDetail` | json | Detalle de cartera canónico con efectivo, posiciones y resumen. |

## Instrucciones de uso

Bloque de detalle de cartera que devuelve el resumen de la cuenta, el efectivo, las posiciones y las órdenes de Alpaca o Tradier.
