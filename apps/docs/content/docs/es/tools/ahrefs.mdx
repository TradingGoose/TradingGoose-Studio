<div className="text-base font-semibold mb-2">enlaces entrantes (<code>ahrefs_backlinks</code>)</div>

Obtener un lista de backlinks pointing un un dominio objetivo o URL. Devuelve detalles about cada enlace entrante incluido origen URL, anchor text, y dominio calificación.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `target` | cadena | Sí | El dominio objetivo o URL un analizar |
| `mode` | cadena | No | Modo de análisis: dominio \(dominio completo\), prefijo \(prefijo de URL\), subdominios \(incluye todos los subdominios\), exacto \(coincidencia exacta de URL\) |
| `date` | cadena | No | Fecha para datos históricos en YYYY-MM-DD formato \(usa de forma predeterminada today\) |
| `limit` | número | No | Número máximo de resultados que se devolverán \(predeterminado: 100\) |
| `offset` | número | No | Number de resultados un skip para pagination |
| `apiKey` | cadena | Sí | Ahrefs Clave de API |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `urlFrom` | cadena | El URL de el página containing el enlace entrante |
| `urlTo` | cadena | El URL being linked un |
| `anchor` | cadena | El anchor text de el link |
| `domainRatingSource` | número | calificación de dominio de el linking dominio |
| `isDofollow` | booleano | Si el link is dofollow |
| `firstSeen` | cadena | cuando el enlace entrante was primero discovered |

</div>
