Analizar documentos PDF con la API OCR de Mistral

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `filePath` | string | Sí | URL de un documento PDF que se procesará |
| `resultType` | string | No | Tipo de resultado analizado \(markdown, text o json\). El valor predeterminado es markdown. |
| `pages` | array | No | Páginas específicas que se procesarán \(array de números de página, a partir de 0\) |
| `apiKey` | string | Sí | Clave de API de Mistral para esta solicitud. |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si el PDF se analizó correctamente |
| `content` | string | Contenido extraído en el formato solicitado \(markdown, text o JSON\) |
| `metadata` | object | Metadatos de procesamiento, incluidos jobId, fileType, pageCount e información de uso |

</div>
