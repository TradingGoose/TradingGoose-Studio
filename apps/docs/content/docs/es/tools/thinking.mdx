## Herramientas

### `thinking_tool`

Processes un proporcionado thought/instruction, making it disponible para subsequent steps.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `thought` | cadena | Sí | Tu internal reasoning, analysis, o thought process. Usar este a think mediante el problem step por step antes responding. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `acknowledgedThought` | cadena | Acknowledged thought process |


## Uso Instrucciones

Añade un step donde la model explicitly outlines su thought process antes proceeding. Este puede mejorar reasoning quality por encouraging step-by-step analysis.
