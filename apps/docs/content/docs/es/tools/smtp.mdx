## Herramientas

### `smtp_send_mail`

Enviar correos electrónicos via SMTP servidor

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `smtpHost` | cadena | Sí | SMTP servidor nombre de host \(p. ej., smtp.gmail.com\) |
| `smtpPort` | número | Sí | SMTP servidor puerto \(587 para TLS, 465 para SSL\) |
| `smtpUsername` | cadena | Sí | SMTP autenticación nombre de usuario |
| `smtpPassword` | cadena | Sí | SMTP autenticación contraseña |
| `smtpSecure` | cadena | Sí | Seguridad protocolo \(TLS, SSL, o Ninguno\) |
| `from` | cadena | Sí | Remitente email dirección |
| `to` | cadena | Sí | Destinatario email dirección |
| `subject` | cadena | Sí | Correo electrónico asunto |
| `body` | cadena | Sí | Correo electrónico cuerpo contenido |
| `contentType` | cadena | No | Contenido tipo \(texto o html\) |
| `fromName` | cadena | No | Visualización nombre para remitente |
| `cc` | cadena | No | CC destinatarios \(comma-separated\) |
| `bcc` | cadena | No | BCC destinatarios \(comma-separated\) |
| `replyTo` | cadena | No | Dirección de correo electrónico para las respuestas |
| `attachments` | file[] | No | Archivos a attach a el email |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el email fue enviados successfully |
| `messageId` | cadena | Mensaje ID desde SMTP servidor |
| `to` | cadena | Destinatario email dirección |
| `subject` | cadena | Correo electrónico asunto |


## Uso Instrucciones

Envía correos electrónicos mediante cualquier SMTP servidor (Gmail, Outlook, personalizado servers, etc.). Configure SMTP connection configuración y enviar correos electrónicos con completo controlar over contenido, destinatarios, y adjuntos.
