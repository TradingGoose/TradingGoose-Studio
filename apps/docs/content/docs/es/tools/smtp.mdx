## Herramientas

### `smtp_send_mail`

Enviar correos electrónicos mediante servidor SMTP

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `smtpHost` | string | Sí | Nombre de host del servidor SMTP \(p. ej., smtp.gmail.com\) |
| `smtpPort` | number | Sí | Puerto del servidor SMTP \(587 para TLS, 465 para SSL\) |
| `smtpUsername` | string | Sí | Nombre de usuario de autenticación SMTP |
| `smtpPassword` | string | Sí | Contraseña de autenticación SMTP |
| `smtpSecure` | string | Sí | Protocolo de seguridad \(TLS, SSL o None\) |
| `from` | string | Sí | Dirección de correo del remitente |
| `to` | string | Sí | Dirección de correo del destinatario |
| `subject` | string | Sí | Asunto del correo |
| `body` | string | Sí | Contenido del cuerpo del correo |
| `contentType` | string | No | Tipo de contenido \(text o html\) |
| `fromName` | string | No | Nombre para mostrar del remitente |
| `cc` | string | No | Destinatarios CC \(separados por comas\) |
| `bcc` | string | No | Destinatarios CCO \(separados por comas\) |
| `replyTo` | string | No | Dirección de correo de respuesta |
| `attachments` | file[] | No | Archivos para adjuntar al correo |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si el correo se envió correctamente |
| `messageId` | string | ID de mensaje del servidor SMTP |
| `to` | string | Dirección de correo del destinatario |
| `subject` | string | Asunto del correo |
| `error` | string | Mensaje de error si el envío falló |

## Instrucciones de uso

Envíe correos electrónicos con cualquier servidor SMTP (Gmail, Outlook, servidores personalizados, etc.). Configure los ajustes de conexión SMTP y envíe correos con control total sobre el contenido, los destinatarios y los archivos adjuntos.
