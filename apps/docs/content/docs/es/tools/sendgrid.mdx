| `subject` | string | No | Asunto del correo \(obligatorio a menos que se use una plantilla con asunto predefinido\) |

| `replyTo` | string | No | Dirección de correo de respuesta |
| `replyToName` | string | No | Nombre de respuesta |
| `attachments` | file[] | No | Archivos para adjuntar al correo |
| `templateId` | string | No | ID de plantilla de SendGrid que se usará |
| `dynamicTemplateData` | json | No | Objeto JSON con datos dinámicos de la plantilla |

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si el correo se envió correctamente |
| `messageId` | string | ID de mensaje de SendGrid |
| `to` | string | Dirección de correo del destinatario |
| `subject` | string | Asunto del correo |
