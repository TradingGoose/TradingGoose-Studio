| `overwrite` | boolean | No | Sobrescribir el dashboard existente con el mismo título |
| `message` | string | No | Mensaje de commit de la versión del dashboard |

| --------- | ---- | ----------- |

| `uid` | string | El UID del dashboard creado |
| `url` | string | La ruta URL del dashboard |
| `status` | string | Estado de la operación \(success\) |
| `version` | number | El número de versión del dashboard |
| `slug` | string | Slug del dashboard compatible con URL |
