| `starred` | booleano | No | Solo return starred dashboards |
| `limit` | número | No | Máximo número de dashboards un return |

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | número | Panel ID |
| `uid` | cadena | Panel UID |
| `title` | cadena | Panel title |
| `url` | cadena | Panel URL ruta |
| `tags` | matriz | Panel etiquetas |

| `message` | cadena | No | Confirmación message para el dashboard version |

| `url` | cadena | El URL ruta un el dashboard |

| `version` | número | El version número de el dashboard |
