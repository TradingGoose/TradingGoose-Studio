Envía mensajes a canales de Slack o mensajes directos. Admite el formato mrkdwn de Slack.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `destinationType` | string | No | Tipo de destino: channel o dm |
| `channel` | string | No | Canal de Slack de destino \(p. ej., #general\) |
| `dmUserId` | string | No | Usuario de Slack de destino para mensajes directos |
| `text` | string | Sí | Texto del mensaje que se enviará \(admite formato mrkdwn de Slack\) |
| `thread_ts` | string | No | Marca de tiempo del hilo al que responder \(crea una respuesta en el hilo\) |
| `files` | file[] | No | Archivos para adjuntar al mensaje |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | object | Objeto de mensaje completo con todas las propiedades devueltas por Slack |
| `ts` | string | Marca de tiempo del mensaje |
| `channel` | string | ID del canal donde se envió el mensaje |
| `fileCount` | number | Número de archivos cargados \(cuando hay archivos adjuntos\) |

</div>

## Instrucciones de uso

Integra Slack en el workflow. Puede enviar mensajes, crear canvas y leer mensajes. Se puede usar en modo trigger para activar un workflow cuando se envía un mensaje a un canal.
