<div className="text-base font-semibold mb-2">Send Message (<code>slack_message</code>)</div>

Enviar mensajes a Slack canales o direct mensajes. Supports Slack mrkdwn formatting.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `authMethod` | cadena | No | Autenticación método: oauth o bot_token |
| `destinationType` | cadena | No | Destination tipo: canal o dm |
| `botToken` | cadena | No | Bot token para Personalizado Bot |
| `channel` | cadena | No | Destino Slack canal \(p. ej., #general\) |
| `dmUserId` | cadena | No | Destino Slack usuario para direct mensajes |
| `text` | cadena | Sí | Mensaje texto a enviar \(supports Slack mrkdwn formatting\) |
| `thread_ts` | cadena | No | Hilo marca de tiempo a reply a \(crea hilo reply\) |
| `files` | file[] | No | Archivos a attach a el mensaje |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | objeto | Complete mensaje objeto con todos propiedades devuelto por Slack |
| `ts` | cadena | Mensaje marca de tiempo |
| `channel` | cadena | Canal ID donde mensaje fue enviados |

</div>

## Uso Instrucciones

Integra Slack en el workflow. Permite enviar mensajes, crear lienzos, y leer mensajes. Requiere Token del bot instead de OAuth en advanced modo. Permite ser usado en trigger modo a trigger un workflow cuando un mensaje es enviados a un canal.
