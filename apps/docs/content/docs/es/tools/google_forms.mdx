## Herramientas

### `google_forms_get_responses`

Recupera una respuesta individual o enumera las respuestas de un formulario de Google

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `formId` | string | Sí | El ID del formulario de Google |
| `responseId` | string | No | Si se proporciona, devuelve esta respuesta específica |
| `pageSize` | number | No | Número máximo de respuestas a devolver \(el servicio puede devolver menos\). Valor predeterminado: 5000. |

#### Salida (contrato a nivel de bloque)

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | json | Respuesta o lista de respuestas |

## Instrucciones de uso

Integra Google Forms en tu flujo de trabajo. Proporciona un Form ID para listar las respuestas, o especifica un Response ID para obtener una sola respuesta. Requiere OAuth.
