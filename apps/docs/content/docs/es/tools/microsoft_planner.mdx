Leer tareas de Microsoft Planner: obtener todas las tareas del usuario o todas las tareas de un plan específico

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `planId` | string | No | ID del plan del que obtener las tareas \(si no se proporciona, se obtienen todas las tareas del usuario\) |
| `taskId` | string | No | ID de la tarea que se va a obtener |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Indica si las tareas se recuperaron correctamente |
| `tasks` | array | Matriz de objetos de tarea con propiedades filtradas |
| `metadata` | object | Metadatos que incluyen planId, userId y planUrl |

</div>

Crear una nueva tarea en Microsoft Planner

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `planId` | string | Sí | El ID del plan donde se creará la tarea |
| `title` | string | Sí | El título de la tarea |
| `description` | string | No | La descripción de la tarea |
| `dueDateTime` | string | No | La fecha y hora de vencimiento de la tarea \(formato ISO 8601\) |
| `assigneeUserId` | string | No | El ID de usuario al que asignar la tarea |
| `bucketId` | string | No | El ID del cubo donde colocar la tarea |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Si la tarea se creó correctamente |
| `task` | object | El objeto de la tarea creada con todas las propiedades |
| `metadata` | object | Metadatos que incluyen planId, taskId y taskUrl |

</div>
