| `distinctId` | cadena | Sí | Único identificador para el usuario o dispositivo. Permite ser usuario ID, dispositivo ID, o anonymous ID |
| `properties` | cadena | No | JSON cadena de evento propiedades \(p. ej., \{"button_name": "signup", "page": "homepage"\}\) |
| `timestamp` | cadena | No | ISO 8601 marca de tiempo para cuando el evento occurred. Si no proporcionado, usa actual time |
