## Tools

### `browser_use_run_task`

Ejecuta un browser automatización task mediante BrowserUse

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `task` | cadena | Sí | Tarea que debe realizar el agente del navegador |
| `variables` | json | No | Opcional variables un usar como secrets \(format: \{key: value\}\) |
| `format` | cadena | No | No description |
| `save_browser_data` | booleano | No | Indica si se debe save browser data |
| `model` | cadena | No | Modelo LLM que se utilizará \(predeterminado: gpt-4o\) |
| `apiKey` | cadena | Sí | clave de API para BrowserUse API |
| `profile_id` | cadena | No | Browser profile ID para persistent sessions \(cookies, login state\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | Tarea execution identificador |
| `success` | booleano | Tarea completion status |
| `output` | json | Tarea output data |


## Usage Instructions

Integra Browser Use en el workflow. Permite navegar por la web y realizar acciones como lo haría una persona en el navegador.
