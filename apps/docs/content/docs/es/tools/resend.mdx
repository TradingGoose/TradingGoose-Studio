## Herramientas

### `resend_send`

Envía un email mediante tu propio Resend API clave y de dirección

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `fromAddress` | cadena | Sí | Correo electrónico dirección a enviar desde |
| `to` | cadena | Sí | Destinatario email dirección |
| `subject` | cadena | Sí | Correo electrónico asunto |
| `body` | cadena | Sí | Correo electrónico cuerpo contenido |
| `contentType` | cadena | No | Contenido tipo para el email cuerpo \(texto o html\) |
| `resendApiKey` | cadena | Sí | Resend API clave para sending correos electrónicos |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el email fue enviados successfully |
| `to` | cadena | Destinatario email dirección |
| `subject` | cadena | Correo electrónico asunto |


## Uso Instrucciones

Integra Resend en el workflow. Permite enviar correos electrónicos. Requiere API Clave.
