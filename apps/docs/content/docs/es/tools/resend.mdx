## Herramientas

### `resend_send`

Envía un correo electrónico con tu propia clave de API de Resend y dirección de origen

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `fromAddress` | string | Sí | Dirección de correo desde la que se envía |
| `to` | string | Sí | Dirección de correo del destinatario |
| `subject` | string | Sí | Asunto del correo |
| `body` | string | Sí | Contenido del cuerpo del correo |
| `contentType` | string | No | Tipo de contenido del cuerpo del correo \(text o html\) |
| `resendApiKey` | string | Sí | Clave de API de Resend para enviar correos |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Indica si el correo se envió correctamente |
| `to` | string | Dirección de correo del destinatario |
| `subject` | string | Asunto del correo |
| `body` | string | Contenido del cuerpo del correo |

## Instrucciones de uso

Integra Resend en el flujo de trabajo. Puede enviar correos electrónicos. Requiere clave de API.
