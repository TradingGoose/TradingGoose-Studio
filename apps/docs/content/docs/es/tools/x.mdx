| `maxResults` | number | No | Número máximo de resultados a devolver \(predeterminado: 10, máx.: 100\) |
| `startTime` | string | No | Hora de inicio de la búsqueda \(formato ISO 8601\) |
| `endTime` | string | No | Hora de fin de la búsqueda \(formato ISO 8601\) |
| `sortOrder` | string | No | Orden de los resultados \(recency o relevancy\) |

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `tweets` | array | Array de tweets que coinciden con la consulta de búsqueda |
| `includes` | object | Datos adicionales, incluidos perfiles de usuario y contenido multimedia |
| `meta` | object | Metadatos de búsqueda, incluido el recuento de resultados y los tokens de paginación |
