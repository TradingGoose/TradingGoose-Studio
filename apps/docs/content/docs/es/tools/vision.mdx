## Uso y salidas

Proporciona una URL de imagen o un archivo cargado y escribe las instrucciones de análisis. Los archivos siguen el procesamiento autenticado y la descarga desde almacenamiento. Mastra recibe el contenido multimodal y selecciona el protocolo del proveedor a partir del identificador completo, también para Anthropic. Las salidas conservan `content`, `model`, `tokens` y el desglose nativo de uso disponible.

## Uso y coste

Los registros distinguen el coste informado por el proveedor, la estimación nativa y el coste no disponible. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, pero su coste en USD se muestra como no disponible.
