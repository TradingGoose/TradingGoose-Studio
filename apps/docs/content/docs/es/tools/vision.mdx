## Herramientas

### `vision_tool`

Process y analyze imágenes mediante advanced visión modelos. Capable de understanding imagen contenido, extracting texto, identifying objetos, y providing detallado visual descriptions.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | cadena | Sí | API clave para el seleccionado model proveedor |
| `imageUrl` | cadena | No | Publicly accessible imagen URL |
| `imageFile` | file | No | Imagen file a analyze |
| `model` | cadena | No | Visión model a usar \(gpt-4o, claude-3-opus-20240229, etc\) |
| `prompt` | cadena | No | Personalizado prompt para imagen analysis |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | cadena | El analyzed contenido y descripción de el imagen |
| `model` | cadena | El visión model ese fue usado para analysis |
| `tokens` | número | Total tokens usado para el analysis |
| `input_tokens` | número | Tokens usado para entrada procesamiento |
| `output_tokens` | número | Tokens usado para respuesta generación |


## Uso Instrucciones

Integra Visión en el workflow. Permite analyze imágenes con visión modelos.
