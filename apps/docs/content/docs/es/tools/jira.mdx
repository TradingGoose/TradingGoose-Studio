Actualizar un Jira issue

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `domain` | cadena | Sí | Tu Jira dominio \(p. ej., yourcompany.atlassian.net\) |
| `projectId` | cadena | No | ID del proyecto de Jira donde se actualizarán las incidencias. Si no se proporciona, se recuperarán todas las incidencias. |
| `issueKey` | cadena | Sí | Jira issue clave un update |
| `summary` | cadena | No | Nuevo summary para el issue |
| `description` | cadena | No | Nuevo descripción para el issue |
| `status` | cadena | No | Nuevo estado para el issue |
| `priority` | cadena | No | Nuevo prioridad para el issue |
| `assignee` | cadena | No | Nuevo assignee para el issue |
| `cloudId` | cadena | No | ID de Jira Cloud de la instancia. Si no se proporciona, se obtendrá mediante el dominio. |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |

| `issueKey` | cadena | Updated issue clave \(p. ej., PROJ-123\) |

| `description` | cadena | No | Descripción para el issue |
| `priority` | cadena | No | Prioridad ID o nombre para el issue \(p. ej., "10000" o "High"\) |
| `assignee` | cadena | No | Assignee ID de cuenta para el issue |
| `cloudId` | cadena | No | ID de Jira Cloud de la instancia. Si no se proporciona, se obtendrá mediante el dominio. |
| `issueType` | cadena | Sí | Tipo de issue un create \(p. ej., Tarea, Story\) |
| `labels` | matriz | No | Etiquetas para el issue \(matriz de etiqueta names\) |
| `duedate` | cadena | No | Due date para el issue \(formato: YYYY-MM-DD\) |
| `reporter` | cadena | No | Reporter ID de cuenta para el issue |
| `environment` | cadena | No | Entorno información para el issue |
| `customFieldId` | cadena | No | Personalizado campo ID \(p. ej., customfield_10001\) |
| `customFieldValue` | cadena | No | Valor para el personalizado campo |

| `summary` | cadena | Incidencia summary |
