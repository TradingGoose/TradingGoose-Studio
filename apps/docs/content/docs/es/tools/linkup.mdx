## Herramientas

### `linkup_search`

Buscar el web para información mediante Linkup

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `q` | cadena | Sí | El search query |
| `depth` | cadena | Sí | Buscar profundidad \(has un either be "standard" o "deep"\) |
| `outputType` | cadena | Sí | Tipo de output un return \(has un either be "sourcedAnswer" o "searchResults"\) |
| `apiKey` | cadena | Sí | Introduce tu Linkup clave de API |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `answer` | cadena | El sourced respuesta un el search query |


## Uso Instrucciones

Integrar Linkup en el workflow. Puede search el web.
