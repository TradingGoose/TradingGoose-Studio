## Herramientas

### `sqs_send`

Enviar un mensaje a un Amazon SQS cola

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `region` | cadena | Sí | AWS región \(p. ej., us-east-1\) |
| `accessKeyId` | cadena | Sí | AWS acceder clave ID |
| `secretAccessKey` | cadena | Sí | AWS secreto acceder clave |
| `queueUrl` | cadena | Sí | Cola URL |
| `data` | objeto | Sí | Mensaje cuerpo a enviar |
| `messageGroupId` | cadena | No | Mensaje grupo ID \(opcional\) |
| `messageDeduplicationId` | cadena | No | Mensaje deduplication ID \(opcional\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | cadena | Mensaje de estado de la operación |


## Uso Instrucciones

Integra Amazon SQS en el workflow. Permite enviar mensajes a SQS queues.
