## Herramientas

### `sqs_send`

Enviar un mensaje a una cola de Amazon SQS

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `region` | string | Sí | Región de AWS \(p. ej., us-east-1\) |
| `accessKeyId` | string | Sí | ID de clave de acceso de AWS |
| `secretAccessKey` | string | Sí | Clave de acceso secreta de AWS |
| `queueUrl` | string | Sí | URL de la cola |
| `data` | object | Sí | Cuerpo del mensaje que se enviará |
| `messageGroupId` | string | No | ID de grupo de mensajes \(opcional\) |
| `messageDeduplicationId` | string | No | ID de desduplicación de mensajes \(opcional\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | string | Mensaje de estado de la operación |
| `id` | string | ID del mensaje |

## Instrucciones de uso

Integra Amazon SQS en el workflow. Permite enviar mensajes a colas de SQS.
