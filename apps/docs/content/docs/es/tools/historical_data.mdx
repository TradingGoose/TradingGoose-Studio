## Usage Instructions

Elige un proveedor de datos de mercado, selecciona una cotización canónica y obtiene series de barras que incluyen apertura, máximo, mínimo, cierre, volumen y marcas de tiempo. El inicio y el final pueden ser cadenas ISO o marcas de tiempo UNIX.
