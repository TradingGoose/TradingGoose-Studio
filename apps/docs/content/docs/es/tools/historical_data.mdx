## Herramientas

### `historical_data_fetch`

Obtiene y normaliza series de mercado de proveedores de mercado registrados.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `provider` | string | Sí | Id del proveedor de datos de mercado \(p. ej., alpaca, finnhub, yahoo-finance\). |
| `listing` | listingIdentity | Sí | Carga útil estructurada del listado de TradingGoose Market. |
| `apiKey` | string | Sí | Clave API de Alpha Vantage. |
| `apiSecret` | string | Sí | Clave secreta de API de Alpaca. |
| `feed` | string | Sí | Feed de datos de Alpaca \(obligatorio para barras de acciones\). |
| `interval` | string | No | Intervalo/periodo de la serie admitido por el proveedor. |
| `normalizationMode` | string | No | Modo de normalización admitido por el proveedor \(opcional\). |
| `window` | json | Sí | Ventana de serie \(rango, barras, absoluta o todo el historial si es compatible\). |
| `providerParams` | json | No | Parámetros opcionales específicos del proveedor. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `listingBase` | string | Símbolo base del listado |
| `listingQuote` | string | Moneda de cotización del listado |
| `listing` | listingIdentity | Payload estructurado del identificador del listado |
| `bars` | array | Barras OHLCV con marcas de tiempo |
| `start` | string | Inicio de la serie devuelta |
| `end` | string | Fin de la serie devuelta |
| `timezone` | string | Zona horaria del exchange para la serie |
| `normalizationMode` | string | Modo de normalización utilizado |

## Instrucciones de uso

Elige un proveedor de datos de mercado, un listado canónico y un Rango de datos (`rangePresetId`). Los preajustes disponibles dependen del proveedor y seleccionan el intervalo automáticamente. Para Fechas personalizadas (`custom`), configura un intervalo admitido y las fechas de inicio y fin obligatorias, en formato ISO o como timestamps UNIX.
