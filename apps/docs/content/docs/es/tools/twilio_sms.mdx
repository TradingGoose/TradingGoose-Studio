## Herramientas

### `twilio_send_sms`

Envía texto mensajes a único o varios destinatarios mediante el Twilio API.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `phoneNumbers` | cadena | Sí | Teléfono numbers a enviar el mensaje a, separado por newlines |
| `message` | cadena | Sí | Mensaje a enviar |
| `accountSid` | cadena | Sí | Twilio Cuenta SID |
| `authToken` | cadena | Sí | Twilio Token de autenticación |
| `fromNumber` | cadena | Sí | Twilio phone número a enviar el mensaje desde |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | SMS enviar éxito estado |
| `messageId` | cadena | Único Twilio mensaje identificador \(SID\) |
| `status` | cadena | Mensaje delivery estado desde Twilio |
| `fromNumber` | cadena | Teléfono número mensaje fue enviados desde |


## Uso Instrucciones

Integra Twilio en el workflow. Permite enviar SMS mensajes.
