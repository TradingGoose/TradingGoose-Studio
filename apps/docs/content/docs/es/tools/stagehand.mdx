## Herramientas

### `stagehand_extract`

Extract structured datos desde un webpage mediante Stagehand

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | cadena | Sí | URL de el webpage a extract datos desde |
| `instruction` | cadena | Sí | Instrucciones para extracción |
| `provider` | cadena | No | AI proveedor a usar: openai o anthropic |
| `apiKey` | cadena | Sí | API clave para el seleccionado proveedor |
| `schema` | json | Sí | JSON esquema defining el structure de el datos a extract |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | json | Extracted datos |


## Uso Instrucciones

Integra Stagehand en el workflow. Permite extract structured datos desde webpages.
