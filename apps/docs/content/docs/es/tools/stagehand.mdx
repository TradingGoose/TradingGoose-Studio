## Herramientas

### `stagehand_extract`

Extrae datos estructurados de una página web con Stagehand

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | string | Sí | URL de la página web de la que extraer datos |
| `instruction` | string | Sí | Instrucciones para la extracción |
| `provider` | string | No | Proveedor de IA a usar: openai o anthropic |
| `apiKey` | string | Sí | Clave de API del proveedor seleccionado |
| `schema` | json | Sí | Esquema JSON que define la estructura de los datos a extraer |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | object | Datos estructurados extraídos que coinciden con el esquema proporcionado |

## Instrucciones de uso

Integra Stagehand en el workflow. Puede extraer datos estructurados de páginas web.
