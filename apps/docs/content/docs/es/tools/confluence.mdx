Actualizar un Confluence página mediante el Confluence API.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `domain` | cadena | Sí | tu Confluence dominio \(e.g., yourcompany.atlassian.net\) |
| `pageId` | cadena | Sí | Confluence página ID un update |
| `title` | cadena | No | Nuevo title para el página |
| `content` | cadena | No | Nuevo content para el página en Confluence storage formato |
| `version` | número | No | Version número de el página \(required for preventing conflicts\) |
| `cloudId` | cadena | No | ID de Confluence Cloud de la instancia. Si no se proporciona, se obtendrá mediante el dominio. |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `ts` | cadena | Timestamp de update |
| `pageId` | cadena | Confluence página ID |
| `title` | cadena | Updated página title |

</div>
