| `pageId` | string | ID de página de Confluence |
| `content` | string | Contenido de la página con las etiquetas HTML eliminadas |
| `title` | string | Título de la página |

<div className="text-base font-semibold mb-2">Actualizar página (<code>confluence_update</code>)</div>

Actualiza una página de Confluence con la API de Confluence.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `domain` | string | Sí | Tu dominio de Confluence \(p. ej., yourcompany.atlassian.net\) |
| `pageId` | string | Sí | ID de la página de Confluence a actualizar |
| `title` | string | No | Nuevo título de la página |
| `content` | string | No | Nuevo contenido de la página en formato de almacenamiento de Confluence |
| `version` | number | No | Número de versión de la página \(obligatorio para evitar conflictos\) |
| `cloudId` | string | No | ID de Confluence Cloud de la instancia. Si no se proporciona, se obtendrá mediante el dominio. |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `ts` | string | Marca temporal de la actualización |
| `pageId` | string | ID de página de Confluence |
| `title` | string | Título de la página actualizada |
| `success` | boolean | Estado de éxito de la operación de actualización |

</div>
