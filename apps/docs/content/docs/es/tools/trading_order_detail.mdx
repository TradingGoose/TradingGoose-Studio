## Herramientas

### `trading_order_detail`

Recuperar todos provider-available detalles para un anteriormente registrado trading orden por Trading Goose orden ID.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `orderId` | cadena | Sí | Trading Goose orden ID \(orderHistoryTable.id\) creado cuando el orden fue enviado. |
| `provider` | cadena | No | Expected proveedor para este orden. Usado para credential selection y mismatch validation. |
| `environment` | cadena | No | Opcional entorno override \(paper o live\) para proveedor order-detail fetch. |
| `credential` | cadena | No | OAuth credential id para el seleccionado bróker \(populated desde seleccionado cuenta\). |
| `tradierCredential` | cadena | No | Tradier OAuth credential id. |
| `robinhoodCredential` | cadena | No | Robinhood OAuth credential id. |
| `alpacaCredential` | cadena | No | Alpaca OAuth credential id. |
| `apiKey` | cadena | No | Alpaca API clave ID \(opcional si mediante OAuth\). |
| `apiSecret` | cadena | No | Alpaca API secreto clave \(opcional si mediante OAuth\). |
| `accountId` | cadena | No | Tradier cuenta ID override si no present en stored orden metadatos. |
| `accountUrl` | cadena | No | Robinhood cuenta URL override si needed. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `summary` | cadena | Estado mensaje para orden detail retrieval. |
| `provider` | cadena | Bróker/proveedor de el orden. |
| `appOrderId` | cadena | Trading Goose orden ID \(orderHistoryTable.id\). |
| `providerOrderId` | cadena | Provider-native orden ID usado para el API lookup. |


## Uso Instrucciones

Looks arriba el Trading Goose orden historial record por orden ID, resolves el proveedor orden ID, y fetches el últimos proveedor orden detail.
