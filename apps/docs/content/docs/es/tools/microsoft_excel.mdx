Leer datos de una hoja de cálculo de Microsoft Excel

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `spreadsheetId` | string | Sí | El ID de la hoja de cálculo a leer |
| `range` | string | No | El rango de celdas a leer. Acepta "NombreHoja!A1:B2" para rangos explícitos o solo "NombreHoja" para leer el rango usado de esa hoja. Si se omite, lee el rango usado de la primera hoja. |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | object | Datos de rango de la hoja de cálculo |
| `metadata` | object | Metadatos de la hoja de cálculo |

</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |

| `updatedColumns` | number | Número de columnas que se actualizaron |
| `updatedCells` | number | Número de celdas que se actualizaron |
| `metadata` | object | Metadatos de la hoja de cálculo |
