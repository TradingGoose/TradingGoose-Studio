<div className="text-base font-semibold mb-2">Ejecutar actor (<code>apify_run_actor_sync</code>)</div>

Ejecuta un actor de APIFY de forma síncrona y obtén resultados (máx. 5 minutos)

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Yes | Token de API de APIFY desde console.apify.com/account#/integrations |
| `actorId` | string | Yes | ID del actor o usuario/nombre-del-actor \(p. ej., "janedoe/my-actor" o ID del actor\) |
| `input` | string | No | Entrada del actor como cadena JSON. Consulta la documentación del actor para conocer los campos obligatorios. |
| `timeout` | number | No | Tiempo de espera en segundos \(predeterminado: el del actor\) |
| `build` | string | No | Compilación del actor que se ejecutará \(p. ej., "latest", "beta" o etiqueta/número de compilación\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Indica si la ejecución del actor se completó correctamente |
| `runId` | string | ID de ejecución de APIFY |
| `status` | string | Estado de la ejecución \(SUCCEEDED, FAILED, etc.\) |
| `items` | array | Elementos del dataset \(si se completó\) |

</div>

| `runId` | string | ID de ejecución de APIFY |
| `status` | string | Estado de ejecución \(SUCCEEDED, FAILED, etc.\) |
| `datasetId` | string | ID del dataset que contiene los resultados |
| `items` | array | Elementos del dataset \(si se completó\) |

## Instrucciones de uso

Integra Apify en tu flujo de trabajo. Ejecuta cualquier actor de Apify con entrada personalizada y recupera resultados. Admite ejecución tanto síncrona como asíncrona con obtención automática de datasets.
