<div className="text-base font-semibold mb-2">Ejecutar Actor (<code>apify_run_actor_sync</code>)</div>

Ejecutar un APIFY actor synchronously y get resultados (max 5 minutes)

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | cadena | Sí | APIFY API token desde console.apify.com/account#/integrations |
| `actorId` | cadena | Sí | Actor ID o nombre de usuario/actor-name \(e.g., "janedoe/my-actor" or actor ID\) |
| `input` | cadena | No | Actor input como JSON cadena. See actor documentation para required campos. |
| `timeout` | número | No | Tiempo de espera en segundos \(predeterminado: valor del actor\) |
| `build` | cadena | No | Actor build un run \(e.g., "latest", "beta", or build tag/number\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Si el actor run succeeded |
| `runId` | cadena | APIFY run ID |
| `status` | cadena | Ejecutar status \(SUCCEEDED, FAILED, etc.\) |

</div>

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | cadena | Sí | APIFY API token desde console.apify.com/account#/integrations |
| `actorId` | cadena | Sí | Actor ID o nombre de usuario/actor-name \(e.g., "janedoe/my-actor" or actor ID\) |
| `input` | cadena | No | Actor input como JSON cadena |
| `waitForFinish` | número | No | Initial esperar time en seconds \(0-60\) antes de polling starts |
| `itemLimit` | número | No | Número máximo de elementos del conjunto de datos que se obtendrán \(1-250000; predeterminado: 100\) |
| `timeout` | número | No | Tiempo de espera en segundos \(predeterminado: valor del actor\) |
| `build` | cadena | No | Actor build un run \(e.g., "latest", "beta", or build tag/number\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Si el actor run succeeded |
| `runId` | cadena | APIFY run ID |
| `status` | cadena | Ejecutar status \(SUCCEEDED, FAILED, etc.\) |
| `datasetId` | cadena | Dataset ID containing resultados |

## Usage Instructions

Integrate Apify en tu workflow. Ejecutar cualquier Apify actor con personalizado input y retrieve resultados. Supports both synchronous y asynchronous execution con automático dataset fetching.
