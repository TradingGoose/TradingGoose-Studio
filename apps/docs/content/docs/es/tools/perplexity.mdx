## Herramientas

### `perplexity_chat`

Genera completions con los modelos de chat de Perplexity AI

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | No | Prompt del sistema para orientar el comportamiento del modelo |
| `content` | string | Sí | El contenido del mensaje del usuario que se envía al modelo |
| `model` | string | Sí | Modelo que se usa para las completions de chat \(p. ej., sonar, mistral\) |
| `max_tokens` | number | No | Número máximo de tokens que se generarán |
| `temperature` | number | No | Temperatura de muestreo entre 0 y 1 |
| `apiKey` | string | Sí | Clave de API de Perplexity |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación |
| `output` | object | Resultados de la compleción de chat |

## Instrucciones de uso

Integre Perplexity en el flujo de trabajo. Puede generar compleciones con modelos de chat de Perplexity AI.
