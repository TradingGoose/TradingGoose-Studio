## Herramientas

### `perplexity_chat`

Generar completados mediante Perplexity AI chat modelos

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | cadena | No | System prompt a guide el model behavior |
| `content` | cadena | Sí | El usuario mensaje contenido a enviar a el model |
| `model` | cadena | Sí | Modelo a usar para chat completados \(p. ej., sonar, mistral\) |
| `max_tokens` | número | No | Número máximo de tokens a generar |
| `temperature` | número | No | Sampling temperature entre 0 y 1 |
| `apiKey` | cadena | Sí | Perplexity API clave |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Operación éxito estado |
| `content` | cadena | Generated texto contenido |
| `model` | cadena | Modelo usado para generación |
| `prompt_tokens` | número | Número de tokens en el prompt |
| `completion_tokens` | número | Número de tokens en el completion |


## Uso Instrucciones

Integra Perplexity en el workflow. Permite generar completados mediante Perplexity AI chat modelos.
