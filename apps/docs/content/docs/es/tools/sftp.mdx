Subir archivos a un remoto SFTP servidor

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `host` | cadena | Sí | SFTP servidor nombre de host o dirección IP |
| `port` | número | Sí | SFTP servidor puerto \(predeterminado: 22\) |
| `username` | cadena | Sí | SFTP nombre de usuario |
| `password` | cadena | No | Contraseña para autenticación \(si no mediante privado clave\) |
| `privateKey` | cadena | No | Privado clave para autenticación \(OpenSSH formato\) |
| `passphrase` | cadena | No | Frase de contraseña para encrypted privado clave |
| `remotePath` | cadena | Sí | Destination directorio en el remoto servidor |
| `files` | file[] | No | Archivos a upload |
| `fileContent` | cadena | No | Direct file contenido a upload \(para texto archivos\) |
| `fileName` | cadena | No | Archivo nombre cuando mediante direct contenido |
| `overwrite` | booleano | No | Indica si a overwrite existente archivos \(predeterminado: true\) |
| `permissions` | cadena | No | Archivo permissions \(p. ej., 0644\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el upload fue successful |
| `uploadedFiles` | json | Matriz de uploaded file detalles \(nombre, remotePath, tamaño\) |

</div>
