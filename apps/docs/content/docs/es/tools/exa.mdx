| `publishedDate` | cadena | Fecha cuando el content was publicado |
| `author` | cadena | El author de el content |
| `summary` | cadena | Un brief summary de el content |
| `favicon` | cadena | URL de el sitio |
| `image` | cadena | URL de un representative imagen desde el página |
| `text` | cadena | Texto snippet o completo content desde el página |

| `text` | cadena | El completo text content de el webpage |
