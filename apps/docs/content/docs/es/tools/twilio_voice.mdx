<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">Realizar llamada (<code>twilio_voice_make_call</code>)</div>

Realiza una llamada telefónica saliente con la API de Twilio Voice.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `to` | string | Sí | Número de teléfono al que llamar \(formato E.164, p. ej., +14155551234\) |
| `from` | string | Sí | Tu número de teléfono de Twilio desde el que llamar \(formato E.164\) |
| `url` | string | No | URL que devuelve instrucciones TwiML para la llamada |
| `twiml` | string | No | Instrucciones TwiML que ejecutar \(alternativa a la URL\). Usa corchetes en lugar de corchetes angulares, p. ej., \[Response\]\[Say\]Hello\[/Say\]\[/Response\] |
| `statusCallback` | string | No | URL de webhook para actualizaciones del estado de la llamada |
| `statusCallbackMethod` | string | No | Método HTTP para el callback de estado \(GET o POST\) |
| `accountSid` | string | Sí | Account SID de Twilio |
| `authToken` | string | Sí | Auth Token de Twilio |
| `record` | boolean | No | Si se debe grabar la llamada |
| `recordingStatusCallback` | string | No | URL de webhook para actualizaciones del estado de la grabación |
| `timeout` | number | No | Tiempo de espera de respuesta antes de abandonar \(segundos, valor predeterminado: 60\) |
| `machineDetection` | string | No | Detección de contestador automático: Enable o DetectMessageEnd |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si la llamada se inició correctamente |
| `callSid` | string | Identificador único de la llamada |
| `status` | string | Estado de la llamada \(queued, ringing, in-progress, completed, etc.\) |
| `direction` | string | Dirección de la llamada \(outbound-api\) |
| `from` | string | Número de teléfono de origen de la llamada |
| `to` | string | Número de teléfono de destino de la llamada |
| `duration` | number | Duración de la llamada en segundos |
| `price` | string | Costo de la llamada |
| `priceUnit` | string | Moneda del precio |
| `error` | string | Mensaje de error si la llamada falló |

</div>

<div className="text-base font-semibold mb-2">Listar llamadas (<code>twilio_voice_list_calls</code>)</div>

Recupera una lista de llamadas realizadas hacia y desde una cuenta.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `accountSid` | string | Sí | SID de cuenta de Twilio |
| `authToken` | string | Sí | Token de autenticación de Twilio |
| `to` | string | No | Filtrar por llamadas a este número de teléfono |
| `from` | string | No | Filtrar por llamadas desde este número de teléfono |
| `status` | string | No | Filtrar por estado de la llamada \(queued, ringing, in-progress, completed, etc.\) |
| `startTimeAfter` | string | No | Filtrar llamadas que comenzaron en esta fecha o después \(YYYY-MM-DD\) |
| `startTimeBefore` | string | No | Filtrar llamadas que comenzaron en esta fecha o antes \(YYYY-MM-DD\) |
| `pageSize` | number | No | Número de registros que se devolverán \(máx. 1000, valor predeterminado 50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Si las llamadas se recuperaron correctamente |
| `calls` | array | Array de objetos de llamada |
| `total` | number | Número total de llamadas devueltas |
| `page` | number | Número de página actual |
| `pageSize` | number | Número de llamadas por página |
| `error` | string | Mensaje de error si falló la recuperación |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| --------- | ---- | -------- | ----------- |
| `recordingSid` | string | Sí | SID de grabación que se va a recuperar |
| `accountSid` | string | Sí | SID de cuenta de Twilio |
| `authToken` | string | Sí | Token de autenticación de Twilio |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Indica si la grabación se recuperó correctamente |
| `recordingSid` | string | Identificador único de la grabación |
| `callSid` | string | SID de la llamada a la que pertenece esta grabación |
| `duration` | number | Duración de la grabación en segundos |
| `status` | string | Estado de la grabación \(completed, processing, etc.\) |
| `channels` | number | Número de canales \(1 para mono, 2 para dual\) |
| `source` | string | Cómo se creó la grabación |
| `mediaUrl` | string | URL para descargar el archivo multimedia de la grabación |
| `price` | string | Costo de la grabación |
| `priceUnit` | string | Moneda del precio |
| `uri` | string | URI relativa del recurso de grabación |
| `transcriptionText` | string | Texto transcrito de la grabación \(si está disponible\) |
| `transcriptionStatus` | string | Estado de la transcripción \(completed, in-progress, failed\) |
| `transcriptionPrice` | string | Costo de la transcripción |
| `transcriptionPriceUnit` | string | Moneda del precio de la transcripción |
| `error` | string | Mensaje de error si falla la recuperación |
