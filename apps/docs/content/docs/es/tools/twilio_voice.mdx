<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">Make Call (<code>twilio_voice_make_call</code>)</div>

Realizar un outbound phone llamada mediante Twilio Voz API.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `to` | cadena | Sí | Teléfono número a llamada \(E.164 formato, p. ej., +14155551234\) |
| `from` | cadena | Sí | Tu Twilio phone número a llamada desde \(E.164 formato\) |
| `url` | cadena | No | URL ese devuelve TwiML instrucciones para el llamada |
| `twiml` | cadena | No | TwiML instrucciones a ejecutar \(alternative a URL\). Usar square brackets instead de angle brackets, p. ej., \[Respuesta\]\[Say\]Hello\[/Say\]\[/Respuesta\] |
| `statusCallback` | cadena | No | Webhook URL para llamada estado actualiza |
| `statusCallbackMethod` | cadena | No | HTTP método para estado callback \(GET o POST\) |
| `accountSid` | cadena | Sí | Twilio Cuenta SID |
| `authToken` | cadena | Sí | Twilio Token de autenticación |
| `record` | booleano | No | Indica si a record el llamada |
| `recordingStatusCallback` | cadena | No | Webhook URL para grabación estado actualiza |
| `timeout` | número | No | Hora a wait para respuesta antes giving arriba \(segundos, predeterminado: 60\) |
| `machineDetection` | cadena | No | Answering machine detection: Activar o DetectMessageEnd |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el llamada fue successfully initiated |
| `callSid` | cadena | Único identificador para el llamada |
| `status` | cadena | Llamada estado \(queued, ringing, in-progress, completado, etc.\) |
| `direction` | cadena | Llamada direction \(outbound-api\) |
| `from` | cadena | Teléfono número el llamada es desde |
| `to` | cadena | Teléfono número el llamada es a |
| `duration` | número | Llamada duración en segundos |
| `price` | cadena | Cost de el llamada |
| `priceUnit` | cadena | Moneda de el precio |

</div>

<div className="text-base font-semibold mb-2">List Calls (<code>twilio_voice_list_calls</code>)</div>

Recuperar un listar de llamadas realizado a y desde un cuenta.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `accountSid` | cadena | Sí | Twilio Cuenta SID |
| `authToken` | cadena | Sí | Twilio Token de autenticación |
| `to` | cadena | No | Filtro por llamadas a este phone número |
| `from` | cadena | No | Filtro por llamadas desde este phone número |
| `status` | cadena | No | Filtro por llamada estado \(queued, ringing, in-progress, completado, etc.\) |
| `startTimeAfter` | cadena | No | Filtro llamadas ese started en o después este fecha \(YYYY-MM-DD\) |
| `startTimeBefore` | cadena | No | Filtro llamadas ese started en o antes este fecha \(YYYY-MM-DD\) |
| `pageSize` | número | No | Número de registros que se devolverán \(máximo: 1000; predeterminado: 50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el llamadas fueron successfully retrieved |
| `calls` | matriz | Matriz de llamada objetos |
| `total` | número | Total número de llamadas devuelto |
| `page` | número | Actual página número |
| `pageSize` | número | Número de llamadas por página |

</div>

Recuperar llamada grabación información y transcription (si activado via TwiML).

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `recordingSid` | cadena | Sí | Grabación SID a recuperar |
| `accountSid` | cadena | Sí | Twilio Cuenta SID |
| `authToken` | cadena | Sí | Twilio Token de autenticación |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el grabación fue successfully retrieved |
| `recordingSid` | cadena | Único identificador para el grabación |
| `callSid` | cadena | Llamada SID este grabación belongs a |
| `duration` | número | Duración de el grabación en segundos |
| `status` | cadena | Grabación estado \(completado, procesamiento, etc.\) |
| `channels` | número | Número de canales \(1 para mono, 2 para dual\) |
| `source` | cadena | Cómo el grabación fue creado |
| `mediaUrl` | cadena | URL a download el grabación multimedia file |
| `price` | cadena | Cost de el grabación |
| `priceUnit` | cadena | Moneda de el precio |
| `uri` | cadena | Relative URI de el grabación recurso |
| `transcriptionText` | cadena | Transcribed texto desde el grabación \(si disponible\) |
| `transcriptionStatus` | cadena | Transcription estado \(completado, in-progress, failed\) |
| `transcriptionPrice` | cadena | Cost de el transcription |
| `transcriptionPriceUnit` | cadena | Moneda de el transcription precio |

</div>
