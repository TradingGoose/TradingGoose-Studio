## Herramientas

### `trading_place_order`

Coloca órdenes de compra o venta a través de Alpaca o Tradier.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `provider` | string | Sí | Proveedor de bróker seleccionado para la cuenta y la disponibilidad de listados. |
| `portfolioIdentity` | json | Sí | Identidad canónica de la cuenta de bróker seleccionada para esta orden. |
| `listing` | listingIdentity | Sí | Payload estructurado de listado del activo a operar. |
| `side` | string | Sí | Lado de la orden: compra o venta. |
| `quantity` | number | No | Cantidad a operar cuando el modo de dimensionamiento del proveedor seleccionado es quantity. |
| `notional` | number | No | Importe en dólares a operar cuando el proveedor seleccionado lo admite. |
| `orderSizingMode` | string | No | Modo de dimensionamiento de la orden seleccionado según las capacidades del proveedor de trading. |
| `orderType` | string | No | Tipo de orden seleccionado según las capacidades del proveedor de trading. |
| `timeInForce` | string | No | Tiempo en vigor \(day, gtc, gfd, etc.\). |
| `limitPrice` | number | No | Precio límite \(obligatorio para órdenes limitadas\). |
| `stopPrice` | number | No | Precio stop cuando lo exige el tipo de orden seleccionado. |
| `trailPrice` | number | No | Desplazamiento de precio trailing cuando lo admite el tipo de orden seleccionado. |
| `trailPercent` | number | No | Desplazamiento porcentual trailing cuando lo admite el tipo de orden seleccionado. |
| `preview` | boolean | No | Previsualiza la orden del proveedor sin enviarla cuando esté admitido. |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `summary` | string | Mensaje de estado del envío de la orden. |
| `provider` | string | Broker/proveedor utilizado para la orden. |
| `appOrderId` | string | ID de orden de Trading Goose. |
| `clientOrderId` | string | Identidad de orden de cliente del broker para reintentos. |
| `order` | json | Detalles de orden normalizados y respuesta sin procesar. |

## Instrucciones de uso

Bloque de acción de trading unificado que envía órdenes desde una cuenta de broker seleccionada.
