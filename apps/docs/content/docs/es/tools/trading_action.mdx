## Herramientas

### `trading_place_order`

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `summary` | cadena | Orden submission estado |
| `provider` | cadena | Proveedor usado |
| `order` | json | Orden payload y sin procesar respuesta |


## Uso Instrucciones

Bloque unificado de operaciones que admite varios brókeres con autenticación OAuth o mediante clave de API.
