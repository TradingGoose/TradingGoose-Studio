<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `page` | object | Información sobre la página de SharePoint |
| `pages` | array | Lista de páginas de SharePoint |
| `content` | object | Contenido de la página de SharePoint |
| `totalPages` | number | Número total de páginas encontradas |
