Crea página en un SharePoint sitio

| Parámetro | Tipo | Obligatorio | Descripción |

| `pageTitle` | cadena | No | Título de la página \(si no se proporciona, se usa el nombre de la página\) |
| `pageContent` | cadena | No | El contenido de el página |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | El único ID de creado página |
| `name` | cadena | El nombre de el creado página |
| `title` | cadena | El título de el creado página |
| `webUrl` | cadena | El URL a acceder el página |
| `pageLayout` | cadena | El layout tipo de el página |
| `createdDateTime` | cadena | Cuando el página fue creado |
