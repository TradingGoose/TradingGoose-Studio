<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">List Issues (<code>sentry_issues_list</code>)</div>

Listar incidencias desde Sentry para un específico organización y optionally un específico proyecto. Devuelve incidencia detalles incluidos estado, error counts, y último seen timestamps.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | cadena | Sí | Sentry API autenticación token |
| `organizationSlug` | cadena | Sí | El slug de el organización |
| `projectSlug` | cadena | No | Filtro incidencias por específico proyecto slug \(opcional\) |
| `query` | cadena | No | Buscar consulta a filtro incidencias. Supports Sentry buscar syntax \(p. ej., "es:unresolved", "nivel:error"\) |
| `statsPeriod` | cadena | No | Periodo de tiempo para estadísticas \(p. ej., "24h", "7d", "30d"\). El valor predeterminado es 24h si no se especifica. |
| `cursor` | cadena | No | Paginación cursor para retrieving siguiente página de resultados |
| `limit` | número | No | Número de incidencias a devolver por página \(predeterminado: 25, máximo: 100\) |
| `status` | cadena | No | Filtro por incidencia estado: unresolved, resolved, ignored, o muted |
| `sort` | cadena | No | Ordenar orden: fecha, nuevo, freq, prioridad, o usuario \(predeterminado: fecha\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | Proyecto ID |
| `shortId` | cadena | Short incidencia identificador |
| `title` | cadena | Incidencia título |
| `culprit` | cadena | Función o location ese caused el incidencia |
| `permalink` | cadena | Direct enlace a el incidencia en Sentry |
| `logger` | cadena | Logger nombre ese reported el incidencia |
| `level` | cadena | Severity nivel \(error, warning, info, etc.\) |
| `status` | cadena | Actual incidencia estado |
| `platform` | cadena | Plataforma donde la incidencia occurred |
| `name` | cadena | Proyecto nombre |
| `slug` | cadena | Proyecto slug |

</div>

<div className="text-base font-semibold mb-2">Update Issue (<code>sentry_issues_update</code>)</div>

Actualizar un Sentry incidencia por changing su estado, assignment, bookmark estado, o otros propiedades. Devuelve el actualizado incidencia detalles.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | cadena | Sí | Sentry API autenticación token |
| `organizationSlug` | cadena | Sí | El slug de el organización |
| `issueId` | cadena | Sí | El único ID de incidencia a actualizar |
| `status` | cadena | No | Nuevo estado para el incidencia: resolved, unresolved, ignored, o resolvedInNextRelease |
| `assignedTo` | cadena | No | Usuario ID o email a assign el incidencia a. Usar vacío cadena a unassign. |
| `isBookmarked` | booleano | No | Indica si a bookmark el incidencia |
| `isSubscribed` | booleano | No | Indica si a subscribe a incidencia actualiza |
| `isPublic` | booleano | No | Indica si el incidencia debe ser publicly visible |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | Usuario ID |
| `shortId` | cadena | Short incidencia identificador |
| `title` | cadena | Incidencia título |
| `status` | cadena | Actualizado incidencia estado |
| `name` | cadena | Usuario nombre |
