<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Sí | Token de autenticación de la API de Sentry |
| `organizationSlug` | string | Sí | El slug de la organización |
| `projectSlug` | string | No | Filtrar incidencias por el slug de un proyecto concreto \(opcional\) |
| `query` | string | No | Consulta de búsqueda para filtrar incidencias. Admite la sintaxis de búsqueda de Sentry \(p. ej., "is:unresolved", "level:error"\) |
| `statsPeriod` | string | No | Periodo de tiempo para las estadísticas \(p. ej., "24h", "7d", "30d"\). El valor predeterminado es 24h si no se especifica. |
| `cursor` | string | No | Cursor de paginación para obtener la página siguiente de resultados |
| `limit` | number | No | Número de incidencias que se devuelven por página \(valor predeterminado: 25, máximo: 100\) |
| `status` | string | No | Filtrar por estado de incidencia: unresolved, resolved, ignored o muted |
| `sort` | string | No | Orden de clasificación: date, new, freq, priority o user \(valor predeterminado: date\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `issues` | array | Lista de incidencias de Sentry |
| `nextCursor` | string | Cursor de la página siguiente de resultados \(si está disponible\) |
| `hasMore` | boolean | Indica si hay más resultados disponibles |

Crea un registro de despliegue para una versión de Sentry en un entorno específico. Los despliegues registran cuándo y dónde se despliegan las versiones. Devuelve los detalles del despliegue creado.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Sí | Token de autenticación de la API de Sentry |
| `organizationSlug` | string | Sí | El slug de la organización |
| `version` | string | Sí | Identificador de versión de la versión que se está desplegando |
| `environment` | string | Sí | Nombre del entorno donde se está desplegando la versión \(p. ej., "production", "staging"\) |
| `name` | string | No | Nombre opcional para este despliegue \(p. ej., "Despliegue v2.0 a Production"\) |
| `url` | string | No | URL que apunta al despliegue \(p. ej., URL del pipeline de CI/CD\) |
| `dateStarted` | string | No | Timestamp ISO 8601 de inicio del despliegue \(el valor predeterminado es la hora actual\) |
| `dateFinished` | string | No | Timestamp ISO 8601 de finalización del despliegue |

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `deploy` | object | El registro de despliegue recién creado |
