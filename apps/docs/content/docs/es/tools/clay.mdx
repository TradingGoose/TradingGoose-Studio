## Herramientas

### `clay_populate`

Rellena Clay con datos de un archivo JSON. Permite comunicación directa y notificaciones con seguimiento de marcas de tiempo y confirmación de canal.

#### Entrada

| Parámetro | Tipo | Requerido | Descripción |
| --------- | ---- | -------- | ----------- |
| `webhookURL` | string | Sí | La URL del webhook a rellenar |
| `data` | json | Sí | Los datos a rellenar |
| `authToken` | string | No | Token de autenticación opcional para la autenticación del webhook de Clay \(la mayoría de los webhooks no lo requieren\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | json | Datos de respuesta del webhook de Clay |
| `metadata` | object | Metadatos de respuesta del webhook |

## Instrucciones de uso

Integra Clay en el flujo de trabajo. Puede rellenar una tabla con datos.
