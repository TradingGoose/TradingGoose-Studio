## Tools

### `clay_populate`

Populate Clay con data desde un JSON file. Enables direct communication y notifications con marca de tiempo tracking y canal confirmation.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `webhookURL` | cadena | Sí | El webhook URL un populate |
| `data` | json | Sí | El data un populate |
| `authToken` | cadena | No | Token de autenticación opcional para el webhook de Clay \(la mayoría de los webhooks no lo requieren\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `data` | json | Respuesta data desde Clay webhook |
| `status` | número | HTTP status code |
| `statusText` | cadena | HTTP status text |
| `headers` | objeto | Respuesta encabezados desde Clay |
| `timestamp` | cadena | ISO marca de tiempo cuando webhook was received |


## Usage Instructions

Integrate Clay en el workflow. Can populate un table con data.
