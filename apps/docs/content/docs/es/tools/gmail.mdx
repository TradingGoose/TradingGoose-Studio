Enviar correos con Gmail

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `to` | string | Sí | Dirección de correo del destinatario |
| `subject` | string | No | Asunto del correo |
| `body` | string | Sí | Contenido del cuerpo del correo |
| `contentType` | string | No | Tipo de contenido del cuerpo del correo \(text o html\) |
| `threadId` | string | No | ID del hilo al que responder \(para encadenar hilos\) |
| `replyToMessageId` | string | No | ID del mensaje de Gmail al que responder: usa el campo "id" de los resultados de Gmail Read \(no el "messageId" de RFC\) |
| `cc` | string | No | Destinatarios en CC \(separados por comas\) |
| `bcc` | string | No | Destinatarios en CCO \(separados por comas\) |
| `attachments` | file[] | No | Archivos para adjuntar al correo |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | string | Mensaje de éxito |
| `metadata` | object | Metadatos del correo |

| `includeAttachments` | boolean | No | Descargar e incluir los archivos adjuntos del correo |

| `metadata` | json | Metadatos del correo |
| `attachments` | file[] | Archivos adjuntos del correo |

## Instrucciones de uso

Integra Gmail en el flujo de trabajo. Puede enviar, leer y buscar correos. Se puede usar en modo de disparador para activar un flujo de trabajo cuando se recibe un correo nuevo.
