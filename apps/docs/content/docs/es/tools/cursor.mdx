<div className="text-base font-semibold mb-2">Iniciar agente (<code>cursor_launch_agent</code>)</div>

Inicia un nuevo agente en la nube para trabajar en un repositorio de GitHub con las instrucciones proporcionadas.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | Sí | Clave de API de Cursor |
| `repository` | string | Sí | URL del repositorio de GitHub \(p. ej., [https://github.com/your-org/your-repo](https://github.com/your-org/your-repo)) |
| `ref` | string | No | Rama, etiqueta o commit desde el que trabajar \(por defecto, la rama predeterminada\) |
| `promptText` | string | Sí | El texto de instrucción para el agente |
| `promptImages` | string | No | Array JSON de objetos de imagen con datos base64 y dimensiones |
| `model` | string | No | Modelo a usar \(dejar vacío para selección automática\) |
| `branchName` | string | No | Nombre de rama personalizado para que lo use el agente |
| `autoCreatePr` | boolean | No | Crear automáticamente un PR cuando el agente termine |
| `openAsCursorGithubApp` | boolean | No | Abrir el PR como la app de GitHub de Cursor |
| `skipReviewerRequest` | boolean | No | Omitir la solicitud de revisores en el PR |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | string | Mensaje de éxito con los detalles del agente |
| `metadata` | object | Metadatos del resultado del lanzamiento |

## Instrucciones de uso

Interactúa con la API de Cursor Cloud Agents para lanzar agentes de IA que pueden trabajar en tus repositorios de GitHub. Admite el lanzamiento de agentes, la incorporación de instrucciones de seguimiento, la consulta del estado, la visualización de conversaciones y la gestión del ciclo de vida de los agentes.
