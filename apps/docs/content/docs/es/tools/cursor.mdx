<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| --------- | ---- | -------- | ----------- |

| `repository` | cadena | Sí | GitHub repositorio URL \(e.g., https://github.com/your-org/your-repo\) |
| `ref` | cadena | No | Rama, etiqueta o commit desde el que se trabajará \(se usa la rama predeterminada\) |
| `promptText` | cadena | Sí | El instruction text para el agent |
| `promptImages` | cadena | No | JSON matriz de imagen objects con base64 data y dimensions |
| `model` | cadena | No | Modelo que se utilizará \(déjalo vacío para la selección automática\) |
| `branchName` | cadena | No | Custom rama name para el agent un usar |
| `autoCreatePr` | booleano | No | Automatically create un PR cuando el agent finishes |
| `openAsCursorGithubApp` | booleano | No | Abrir el PR como el Cursor GitHub App |
| `skipReviewerRequest` | booleano | No | Skip requesting reviewers en el PR |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | cadena | Correcto message con agent detalles |
| `id` | cadena | Agent ID |

## Usage Instructions

Interactúa con la API de Cursor Cloud Agents para iniciar agentes de IA que trabajen en tus repositorios de GitHub. Permite iniciar agentes, añadir instrucciones de seguimiento, consultar su estado, ver conversaciones y gestionar su ciclo de vida.
