<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |

| `includeAttachments` | boolean | No | Descargar e incluir los archivos adjuntos del mensaje \(contenidos hospedados\) en el almacenamiento |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | boolean | Estado de éxito de la operación de lectura del chat de Teams |
| `messageCount` | number | Número de mensajes recuperados del chat |
| `chatId` | string | ID del chat del que se leyó |
| `messages` | array | Array de objetos de mensajes de chat |
| `attachmentCount` | number | Número total de archivos adjuntos encontrados |
| `attachmentTypes` | array | Tipos de archivos adjuntos encontrados |
| `content` | string | Contenido con formato de los mensajes de chat |
| `attachments` | file[] | Archivos adjuntos cargados por conveniencia \(aplanados\) |

</div>

## Instrucciones de uso

Integra Microsoft Teams en el flujo de trabajo. Puede leer y escribir mensajes de chat, y leer y escribir mensajes de canal. Se puede usar en modo de activación para activar un flujo de trabajo cuando se envía un mensaje a un chat o canal.
