| `chatId` | cadena | ID de el chat que was read desde |
| `messages` | matriz | Array de chat message objects |
| `attachmentCount` | número | Total número de archivos adjuntos found |
| `attachmentTypes` | matriz | Types de archivos adjuntos found |
| `content` | cadena | Formatted content de chat messages |

## Usage Instructions

Integra Microsoft Teams en el workflow. Permite leer y escribir mensajes de chat y de canal. También puede usarse como trigger para iniciar un workflow cuando se envía un mensaje a un chat o canal.
