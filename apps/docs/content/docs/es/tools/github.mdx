## Instrucciones de uso

Integrar Github en el flujo de trabajo. Puede obtener detalles de PR, crear comentarios de PR, obtener información del repositorio y obtener el último commit. Se puede usar en modo trigger para activar un flujo de trabajo cuando se crea un PR, se comenta en él o se hace push de un commit.
