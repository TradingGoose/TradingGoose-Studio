## Usage Instructions

Integra GitHub en el workflow. Permite obtener detalles de un PR, crear comentarios en un PR, consultar información del repositorio y obtener el commit más reciente. También puede usarse como trigger para iniciar un workflow cuando se crea o comenta un PR, o cuando se envía un commit.
