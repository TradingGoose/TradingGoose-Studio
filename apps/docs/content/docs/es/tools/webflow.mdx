## Uso Instrucciones

Integrates Webflow CMS en el workflow. Permite crear, get, listar, actualizar, o delete elementos en Webflow CMS colecciones. Gestionar tu Webflow contenido programmatically. Permite ser usado en trigger modo a trigger workflows cuando colección elementos cambio o formularios son enviado.
