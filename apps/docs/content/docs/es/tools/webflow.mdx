## Instrucciones de uso

Integra Webflow CMS en el flujo de trabajo. Permite crear, obtener, listar, actualizar o eliminar elementos en las colecciones de Webflow CMS. Gestione el contenido de Webflow de forma programática. Se puede usar en modo de activación para activar flujos de trabajo cuando cambian los elementos de una colección o se envían formularios.
