Descargar archivos uploaded en Typeform respuestas

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `formId` | cadena | Sí | Typeform formulario ID |
| `responseId` | cadena | Sí | Respuesta ID que contiene el archivos |
| `fieldId` | cadena | Sí | Único ID de file upload campo |
| `filename` | cadena | Sí | Filename de el uploaded file |
| `inline` | booleano | No | Indica si a solicitud el file con inline Contenido-Disposition |
| `apiKey` | cadena | Sí | Typeform Personal Acceder Token |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `fileUrl` | cadena | Direct download URL para el uploaded file |
| `contentType` | cadena | MIME tipo de el uploaded file |

Integra Typeform en el workflow. Permite recuperar respuestas, download archivos, y get formulario estadísticas. Requiere API Clave.
