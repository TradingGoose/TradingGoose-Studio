<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |

| `parameters` | objeto | No | Parámetros de la consulta Cypher como objeto JSON. Úsalo para valores dinámicos, incluido LIMIT \(p. ej., consulta: "MATCH \(n\) RETURN n LIMIT $limit", parámetros: \{límite: 100\}\). |
| `parameters` | cadena | No | Sin descripción |
