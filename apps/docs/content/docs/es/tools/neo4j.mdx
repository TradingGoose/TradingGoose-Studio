<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">Consulta (MATCH) (<code>neo4j_query</code>)</div>

Ejecuta consultas MATCH para leer nodos y relaciones de la base de datos de grafos Neo4j. Para un mejor rendimiento y para evitar conjuntos de resultados grandes, incluye LIMIT en tu consulta (p. ej., "MATCH (n:User) RETURN n LIMIT 100") o usa LIMIT $limit con un parámetro limit.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `host` | string | Sí | Nombre de host o dirección IP del servidor Neo4j |
| `port` | number | Sí | Puerto del servidor Neo4j \(valor predeterminado: 7687 para el protocolo Bolt\) |
| `database` | string | Sí | Nombre de la base de datos a la que conectarse |
| `username` | string | Sí | Nombre de usuario de Neo4j |
| `password` | string | Sí | Contraseña de Neo4j |
| `encryption` | string | No | Modo de cifrado de la conexión \(enabled, disabled\) |
| `cypherQuery` | string | Sí | Consulta Cypher que ejecutar \(normalmente sentencias MATCH\) |
| `parameters` | object | No | Parámetros de la consulta Cypher como objeto JSON. Úsalos para cualquier valor dinámico, incluido LIMIT \(p. ej., query: "MATCH \(n\) RETURN n LIMIT $limit", parameters: \{limit: 100\}\). |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `message` | string | Mensaje de estado de la operación |
| `records` | array | Array de registros devueltos por la consulta |
| `recordCount` | number | Número de registros devueltos |
| `summary` | json | Resumen de ejecución de la consulta con tiempos y contadores |

</div>
