| `instagram` | cadena | Instagram profile de el organización |

| `country` | cadena | Country donde el organización is located |
| `state` | cadena | Estado donde el organización is located |
| `city` | cadena | City donde el organización is located |
| `postal_code` | cadena | Postal code de el organización |
| `street` | cadena | Street address de el organización |

| `gibberish` | booleano | Si el email appears un be gibberish |

| `webmail` | booleano | Si el email is desde un webmail proveedor |
| `mx_records` | booleano | Si MX records exist para el dominio |
| `smtp_server` | booleano | Si el SMTP servidor is reachable |
| `smtp_check` | booleano | Si el SMTP check was correcto |
| `accept_all` | booleano | Si el dominio accepts todos email addresses |
| `block` | booleano | Si el email is blocked |
| `status` | cadena | Verification estado: válido, no válido, accept_all, webmail, disposable, o unknown |
