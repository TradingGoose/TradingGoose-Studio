<div className="text-base font-semibold mb-2">Búsqueda de dominio (<code>hunter_domain_search</code>)</div>

Devuelve todas las direcciones de correo electrónico encontradas usando un nombre de dominio dado, con sus fuentes.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `domain` | string | Sí | Nombre de dominio en el que buscar direcciones de correo electrónico |
| `limit` | number | No | Número máximo de direcciones de correo electrónico a devolver \(predeterminado: 10\) |
| `type` | string | No | Filtro para correos personales o genéricos |
| `seniority` | string | No | Filtro por nivel de antigüedad: junior, senior o ejecutivo |
| `department` | string | No | Filtro por departamentos específicos \(p. ej., ventas, marketing\) |
| `apiKey` | string | Sí | Clave de API de Hunter.io |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `domain` | string | El nombre de dominio buscado |
| `disposable` | boolean | Indica si el dominio acepta direcciones de correo desechables |
| `webmail` | boolean | Indica si el dominio es un proveedor de correo web |
| `accept_all` | boolean | Indica si el dominio acepta todas las direcciones de correo electrónico |
| `pattern` | string | El patrón de correo electrónico que utiliza la organización |
| `organization` | string | El nombre de la organización |
| `description` | string | Descripción de la organización |
| `industry` | string | Sector de la organización |
| `twitter` | string | Perfil de Twitter de la organización |
| `facebook` | string | Perfil de Facebook de la organización |
| `linkedin` | string | Perfil de LinkedIn de la organización |
| `instagram` | string | Perfil de Instagram de la organización |
| `youtube` | string | Canal de YouTube de la organización |
| `technologies` | array | Matriz de tecnologías utilizadas por la organización |
| `country` | string | País donde se ubica la organización |
| `state` | string | Estado donde se ubica la organización |
| `city` | string | Ciudad donde se ubica la organización |
| `postal_code` | string | Código postal de la organización |
| `street` | string | Dirección de la organización |
| `emails` | array | Matriz de direcciones de correo electrónico encontradas para el dominio; cada una contiene valor, tipo, confianza, fuentes y datos de la persona |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `email` | string | Sí | La dirección de correo electrónico a verificar |
| `apiKey` | string | Sí | Clave de API de Hunter.io |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `result` | string | Resultado de entregabilidad: deliverable, undeliverable o risky |
| `score` | number | Puntuación de confianza del resultado de verificación |
| `email` | string | La dirección de correo verificada |
| `regexp` | boolean | Indica si el correo sigue un patrón regex válido |
| `gibberish` | boolean | Indica si el correo parece ser texto sin sentido |
| `disposable` | boolean | Indica si el correo proviene de un proveedor de correo desechable |
| `webmail` | boolean | Indica si el correo proviene de un proveedor de webmail |
| `mx_records` | boolean | Indica si existen registros MX para el dominio |
| `smtp_server` | boolean | Indica si se puede acceder al servidor SMTP |
| `smtp_check` | boolean | Indica si la comprobación SMTP fue correcta |
| `accept_all` | boolean | Indica si el dominio acepta todas las direcciones de correo |
| `block` | boolean | Indica si el correo está bloqueado |
| `status` | string | Estado de verificación: valid, invalid, accept_all, webmail, disposable o unknown |
| `sources` | array | Matriz de fuentes donde se encontró el correo |

</div>
