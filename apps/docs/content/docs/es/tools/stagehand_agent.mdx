## Herramientas

### `stagehand_agent`

Ejecutar un autonomous web agent a complete tareas y extract structured datos

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `startUrl` | cadena | Sí | URL de el webpage a inicio el agent en |
| `task` | cadena | Sí | El tarea a complete o goal a achieve en el website |
| `variables` | json | No | Opcional variables a substitute en el tarea \(formato: \{clave: valor\}\). Reference en tarea mediante %clave% |
| `format` | cadena | No | Sin descripción |
| `provider` | cadena | No | AI proveedor a usar: openai o anthropic |
| `apiKey` | cadena | Sí | API clave para el seleccionado proveedor |
| `outputSchema` | json | No | Opcional JSON esquema defining el structure de datos el agent debe devolver |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | Indica si el agent tarea completado successfully |
| `completed` | booleano | Indica si el tarea fue fully completado |
| `message` | cadena | Estado mensaje o final resultado |


## Uso Instrucciones

Integra Stagehand Agent en el flujo de trabajo. Permite navegar por la web y realizar tareas.
