## Herramientas

### `stagehand_agent`

Ejecutar un agente web autónomo para completar tareas y extraer datos estructurados

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `startUrl` | string | Sí | URL de la página web en la que se inicia el agente |
| `task` | string | Sí | La tarea que se debe completar o el objetivo que se debe alcanzar en el sitio web |
| `variables` | json | No | Variables opcionales para sustituir en la tarea \(formato: \{key: value\}\). Haga referencia en la tarea con %key% |
| `provider` | string | No | Proveedor de IA que se debe usar: openai o anthropic |
| `apiKey` | string | Sí | Clave de API del proveedor seleccionado |
| `outputSchema` | json | No | Esquema JSON opcional que define la estructura de los datos que debe devolver el agente |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `agentResult` | object | Resultado de la ejecución del agente Stagehand |
| `structuredOutput` | object | Datos extraídos que coinciden con el esquema de salida proporcionado |

## Instrucciones de uso

Integra Stagehand Agent en el flujo de trabajo. Puede navegar por la web y realizar tareas.
