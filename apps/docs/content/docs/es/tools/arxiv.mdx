| `searchQuery` | string | Sí | La consulta de búsqueda que se va a ejecutar |
| `searchField` | string | No | Campo en el que buscar: all, ti \(título\), au \(autor\), abs \(resumen\), co \(comentario\), jr \(revista\), cat \(categoría\), rn \(número de informe\) |
| `maxResults` | number | No | Número máximo de resultados a devolver \(predeterminado: 10, máx.: 2000\) |
| `sortBy` | string | No | Ordenar por: relevance, lastUpdatedDate, submittedDate \(predeterminado: relevance\) |
| `sortOrder` | string | No | Orden de clasificación: ascending, descending \(predeterminado: descending\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `papers` | json | Arreglo de artículos que coinciden con la consulta de búsqueda |
| `totalResults` | number | Número total de resultados encontrados para la consulta de búsqueda |

## Instrucciones de uso

Integra ArXiv en el flujo de trabajo. Permite buscar artículos, obtener detalles de los artículos y obtener los artículos de un autor. No requiere OAuth ni una clave de API.
