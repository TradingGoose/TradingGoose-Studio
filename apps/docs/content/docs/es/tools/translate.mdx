## Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `context` | string | Sí | Texto a traducir |
| `targetLanguage` | string | Sí | Idioma de destino |
| `model` | combobox | Sí | Modelo |
| `apiKey` | string | No | Clave de API del proveedor |
| `azureEndpoint` | string | No | URL del punto de conexión de Azure OpenAI |
| `azureApiVersion` | string | No | Versión de API de Azure |

## Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | string | Texto traducido |
| `model` | string | Modelo usado |
| `tokens` | json | Uso de tokens |

## Instrucciones de uso

Traduce texto a cualquier idioma. La lista de modelos se carga en tiempo de ejecución a partir de los modelos base, Ollama y OpenRouter disponibles en el despliegue.
