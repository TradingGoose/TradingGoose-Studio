## Herramientas

### `whatsapp_send_message`

Envía mensajes de WhatsApp

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `phoneNumber` | cadena | Sí | Destinatario phone número con país código |
| `message` | cadena | Sí | Mensaje contenido a enviar |
| `phoneNumberId` | cadena | Sí | WhatsApp Business Número de teléfono ID |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `success` | booleano | WhatsApp mensaje enviar éxito estado |
| `messageId` | cadena | Único WhatsApp mensaje identificador |
| `phoneNumber` | cadena | Destinatario phone número |
| `status` | cadena | Mensaje delivery estado |


## Uso Instrucciones

Integra WhatsApp en el workflow. Permite enviar mensajes.
