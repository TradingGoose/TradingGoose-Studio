## Herramientas

### `serper_search`

A potente web buscar herramienta ese proporciona acceder a Google buscar resultados mediante Serper.dev API. Supports diferentes tipos de busca incluidos normal web buscar, noticias, lugares, y imágenes, con cada resultado que contiene relevantes metadatos como titles, URLs, fragmentos, y type-específico información.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | cadena | Sí | El buscar consulta |
| `num` | número | No | Número de resultados a devolver |
| `gl` | cadena | No | País código para buscar resultados |
| `hl` | cadena | No | Idioma código para buscar resultados |
| `type` | cadena | No | Tipo de buscar a perform |
| `apiKey` | cadena | Sí | Serper API Clave |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `searchResults` | json | Buscar resultados datos |


## Uso Instrucciones

Integra Serper en el workflow. Permite buscar el web.
