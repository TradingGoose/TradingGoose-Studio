Cargar un file un Dropbox

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `path` | cadena | Sí | El path en Dropbox donde el file debe be saved \(e.g., /folder/document.pdf\) |
| `fileContent` | cadena | Sí | El base64 encoded content de el file un upload |
| `fileName` | cadena | No | Nombre de archivo opcional \(se usa si la ruta corresponde a una carpeta\) |
| `mode` | cadena | No | Modo de escritura: add \(predeterminado\) u overwrite |
| `autorename` | booleano | No | Si es verdadero, cambia el nombre del archivo cuando hay un conflicto |
| `mute` | booleano | No | Si es verdadero, no notifica al usuario sobre esta carga |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `id` | cadena | Unique identificador para el file |
| `name` | cadena | Nombre de el file |
| `path_display` | cadena | Display path de el file |
| `path_lower` | cadena | Lowercase path de el file |
| `size` | número | Size de el file en bytes |
| `client_modified` | cadena | Client modification time |
| `server_modified` | cadena | Server modification time |
| `rev` | cadena | Revision identificador |
