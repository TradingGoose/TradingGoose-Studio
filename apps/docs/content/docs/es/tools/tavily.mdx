Realiza búsquedas web con IA mediante la API de búsqueda de Tavily. Devuelve resultados estructurados con títulos, URL, fragmentos y contenido sin procesar opcional, optimizados para relevancia y precisión.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | string | Sí | La consulta de búsqueda que se va a ejecutar |
| `max_results` | number | No | Número máximo de resultados \(1-20\) |
| `apiKey` | string | Sí | Clave API de Tavily |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `query` | string | La consulta de búsqueda que se ejecutó |
| `results` | array | Resultados de búsqueda con títulos, URL y fragmentos de contenido |
| `response_time` | number | Tiempo empleado en la solicitud de búsqueda, en segundos |

</div>

<div className="text-base font-semibold mb-2">Extraer contenido (<code>tavily_extract</code>)</div>

Extrae contenido sin procesar de varias páginas web simultáneamente mediante la API de extracción de Tavily. Admite profundidades de extracción básica y avanzada, con informes de error detallados para las URL que fallen.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `urls` | string | Sí | URL o array de URL de las que extraer contenido |
| `extract_depth` | string | No | La profundidad de extracción \(basic=1 crédito/5 URL, advanced=2 créditos/5 URL\) |
| `apiKey` | string | Sí | Clave API de Tavily |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `results` | array | Contenido extraído correctamente de las URL |
| `failed_results` | array | URL de las que no se pudo extraer contenido |
| `response_time` | number | Tiempo empleado en la solicitud de extracción, en segundos |

</div>

## Instrucciones de uso

Integra Tavily en el flujo de trabajo. Puede buscar en la web y extraer contenido de URL específicas. Requiere una clave de API.
