Ejecuta un comando de shell en un servidor SSH remoto

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `host` | string | Sí | Nombre de host o dirección IP del servidor SSH |
| `port` | number | Sí | Puerto del servidor SSH \(predeterminado: 22\) |
| `username` | string | Sí | Nombre de usuario SSH |
| `password` | string | No | Contraseña de autenticación \(si no se usa clave privada\) |
| `privateKey` | string | No | Clave privada de autenticación \(formato OpenSSH\) |
| `passphrase` | string | No | Frase de contraseña de la clave privada cifrada |
| `command` | string | Sí | Comando de shell que se ejecutará en el servidor remoto |
| `workingDirectory` | string | No | Directorio de trabajo para la ejecución del comando |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `stdout` | string | Salida estándar del comando |
| `stderr` | string | Salida de error estándar |
| `exitCode` | number | Código de salida del comando |
| `success` | boolean | Si el comando se ejecutó correctamente \(código de salida 0\) |
| `message` | string | Mensaje de estado de la operación |

</div>
