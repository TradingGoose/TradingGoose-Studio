Ejecutar un shell comando en un remoto SSH servidor

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Entrada</div>

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `host` | cadena | Sí | SSH servidor nombre de host o dirección IP |
| `port` | número | Sí | SSH servidor puerto \(predeterminado: 22\) |
| `username` | cadena | Sí | SSH nombre de usuario |
| `password` | cadena | No | Contraseña para autenticación \(si no mediante privado clave\) |
| `privateKey` | cadena | No | Privado clave para autenticación \(OpenSSH formato\) |
| `passphrase` | cadena | No | Frase de contraseña para encrypted privado clave |
| `command` | cadena | Sí | Shell comando a ejecutar en el remoto servidor |
| `workingDirectory` | cadena | No | Working directorio para comando ejecución |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">Salida</div>

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `stdout` | cadena | Estándar salida desde comando |
| `stderr` | cadena | Estándar error salida |
| `exitCode` | número | Comando exit código |
| `success` | booleano | Indica si comando succeeded \(exit código 0\) |

</div>
