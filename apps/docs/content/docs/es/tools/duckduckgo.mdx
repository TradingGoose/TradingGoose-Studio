## Tools

### `duckduckgo_search`

Buscar el web mediante DuckDuckGo Instant Answers API. Devuelve instant answers, abstracts, y relacionado topics para tu query. Free un usar sin un clave de API.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | cadena | Sí | El search query un execute |
| `noHtml` | booleano | No | Elimina el HTML del texto de los resultados \(predeterminado: true\) |
| `skipDisambig` | booleano | No | Omite los resultados de desambiguación \(predeterminado: false\) |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `heading` | cadena | El heading/title de el instant respuesta |
| `abstract` | cadena | Un short abstract summary de el topic |
| `abstractText` | cadena | Plain text version de el abstract |
| `abstractSource` | cadena | El origen de el abstract \(e.g., Wikipedia\) |
| `abstractURL` | cadena | URL un el origen de el abstract |
| `image` | cadena | URL un un imagen relacionado un el topic |
| `answer` | cadena | Respuesta directa, si está disponible \(p. ej., para cálculos\) |
| `answerType` | cadena | Tipo de el respuesta \(e.g., calc, ip, etc.\) |
| `type` | cadena | Respuesta type: Un \(article\), D \(disambiguation\), C \(category\), N \(name\), E \(exclusive\) |
| `FirstURL` | cadena | URL un el relacionado topic |
| `Text` | cadena | Descripción de el relacionado topic |
