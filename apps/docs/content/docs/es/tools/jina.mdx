## Herramientas

### `jina_read_url`

Extrae y procesa contenido web en texto limpio y apto para LLM con Jina AI Reader. Admite análisis avanzado de contenido, recopilación de enlaces y varios formatos de salida con opciones de procesamiento configurables.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | string | Sí | La URL que se va a leer y convertir a markdown |
| `useReaderLMv2` | boolean | No | Indica si se debe usar ReaderLM-v2 para obtener mejor calidad |
| `gatherLinks` | boolean | No | Indica si se deben recopilar todos los enlaces al final |
| `jsonResponse` | boolean | No | Indica si se debe devolver la respuesta en formato JSON |
| `apiKey` | string | Sí | Tu clave de API de Jina AI |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | string | El contenido extraído de la URL, procesado en texto limpio y apto para LLM |

## Instrucciones de uso

Integra Jina en el workflow. Extrae contenido de sitios web.
