## Tools

### `jina_read_url`

Extract y procesar web content en clean, LLM-friendly text mediante Jina AI Reader. Supports avanzado content parsing, link gathering, y varios output formats con configurable processing opciones.

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `url` | cadena | Sí | El URL un read y convertir un markdown |
| `useReaderLMv2` | booleano | No | Indica si se debe usar ReaderLM-v2 para better quality |
| `gatherLinks` | booleano | No | Indica si se debe gather todos enlaces en el end |
| `jsonResponse` | booleano | No | Indica si se debe return response en JSON formato |
| `apiKey` | cadena | Sí | tu Jina AI clave de API |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `content` | cadena | Extracted content |
