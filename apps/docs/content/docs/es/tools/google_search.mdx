## Tools

### `google_search`

Buscar el web con el Custom Buscar API

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | cadena | Sí | El search query un execute |
| `searchEngineId` | cadena | Sí | Custom Buscar Engine ID |
| `num` | cadena | No | Número de resultados que se devolverán \(predeterminado: 10; máximo: 10\) |
| `apiKey` | cadena | Sí | Google clave de API |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `title` | cadena | Título de el search resultado |
| `link` | cadena | URL de el search resultado |
| `snippet` | cadena | Snippet o description de el search resultado |
| `displayLink` | cadena | Display URL |


## Usage Instructions

Integrate Google Buscar en el workflow. Can search el web.
