## Herramientas

### `google_search`

Busca en la web con la API de Custom Search

#### Entrada

| Parámetro | Tipo | Obligatorio | Descripción |
| --------- | ---- | -------- | ----------- |
| `query` | string | Sí | La consulta de búsqueda que se va a ejecutar |
| `searchEngineId` | string | Sí | ID del motor de búsqueda personalizado |
| `num` | string | No | Número de resultados que se devolverán \(predeterminado: 10, máximo: 10\) |
| `apiKey` | string | Sí | Clave de API de Google |

#### Salida

| Parámetro | Tipo | Descripción |
| --------- | ---- | ----------- |
| `items` | array | Array de resultados de búsqueda de Google |
| `searchInformation` | object | Información sobre la consulta de búsqueda y los resultados |

## Instrucciones de uso

Integra la Búsqueda de Google en el flujo de trabajo. Puede buscar en la web.
