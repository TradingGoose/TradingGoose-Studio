## Array (52 métodos)

Los arrays son colecciones ordenadas de elementos. Puede crear, manipular y consultar arrays para implementar lógica avanzada en los indicadores.

### Creación

```javascript
const a = array.from(1, 2, 3, 4, 5);
const b = array.new_float(10, 0.0);    // 10 elements, all 0.0
const c = array.new_int(5, 0);
const d = array.new_bool(3, false);
const e = array.new_string(2, '');
```

### Acceso y modificación

| Función | Descripción |
|----------|-------------|
| `array.get(arr, index)` | Obtiene el elemento del índice |
| `array.set(arr, index, value)` | Establece el elemento del índice |
| `array.first(arr)` | Obtiene el primer elemento |
| `array.last(arr)` | Obtiene el último elemento |
| `array.push(arr, value)` | Añade un elemento al final |
| `array.pop(arr)` | Elimina y devuelve el último elemento |
| `array.unshift(arr, value)` | Añade un elemento al principio |
| `array.shift(arr)` | Elimina y devuelve el primer elemento |
| `array.insert(arr, index, value)` | Inserta un elemento en el índice |
| `array.remove(arr, index)` | Elimina el elemento del índice |
| `array.clear(arr)` | Elimina todos los elementos |

### Tamaño y transformación

| Función | Descripción |
|----------|-------------|
| `array.size(arr)` | Número de elementos |
| `array.slice(arr, start, end)` | Extrae un subarray |
| `array.concat(arr1, arr2)` | Concatena arrays |
| `array.copy(arr)` | Copia superficial |
| `array.fill(arr, value, start?, end?)` | Rellena con un valor |
| `array.reverse(arr)` | Invierte el orden en el mismo array |
| `array.sort(arr, order?)` | Ordena el mismo array |
| `array.sort_indices(arr, order?)` | Devuelve los índices ordenados |
| `array.join(arr, separator)` | Une los elementos en una cadena |

### Búsqueda

| Función | Descripción |
|----------|-------------|
| `array.indexof(arr, value)` | Primer índice del valor |
| `array.lastindexof(arr, value)` | Último índice del valor |
| `array.includes(arr, value)` | Comprueba si contiene el valor |
| `array.binary_search(arr, value)` | Búsqueda binaria (array ordenado) |
| `array.every(arr, fn)` | Verdadero si todos cumplen el predicado |
| `array.some(arr, fn)` | Verdadero si alguno cumple el predicado |

### Estadística

| Función | Descripción |
|----------|-------------|
| `array.sum(arr)` | Suma |
| `array.avg(arr)` | Promedio |
| `array.min(arr)` | Mínimo |

## Map (11 métodos)

Diccionarios de pares clave-valor para datos asociativos:

```javascript
const m = map.new();
map.put(m, 'ema', ta.ema(close, 20));
map.put(m, 'sma', ta.sma(close, 20));

const emaValue = map.get(m, 'ema');
const hasKey = map.contains(m, 'ema');     // true
const allKeys = map.keys(m);               // ['ema', 'sma']
```

| Función | Descripción |
|----------|-------------|
| `map.new()` | Crea un mapa vacío |
| `map.get(m, key)` | Obtiene un valor |
| `map.put(m, key, value)` | Establece un valor |
| `map.put_all(m, other)` | Copia todos los elementos de otro mapa |
| `map.contains(m, key)` | Comprueba si existe una clave |
| `map.remove(m, key)` | Elimina una clave |
| `map.keys(m)` | Todas las claves |
| `map.values(m)` | Todos los valores |
| `map.size(m)` | Número de elementos |
| `map.clear(m)` | Elimina todos los elementos |
| `map.copy(m)` | Duplica el mapa |

## Matrix (50 métodos)

Estructuras de datos bidimensionales para operaciones matemáticas avanzadas:

```javascript
const m = matrix.new(3, 3, 0);  // 3x3 matrix of zeros
matrix.set(m, 0, 0, 1);
matrix.set(m, 1, 1, 1);
matrix.set(m, 2, 2, 1);         // Identity matrix
```

### Operaciones principales

| Categoría | Funciones |
|----------|-----------|
| **Acceso** | `get`, `set`, `row`, `col` |
| **Tamaño** | `rows`, `columns`, `elements_count` |
| **Modificación** | `add_row`, `add_col`, `remove_row`, `remove_col`, `swap_rows`, `swap_columns`, `fill`, `reverse` |
| **Transformación** | `transpose`, `reshape`, `slice`, `submatrix`, `concat`, `copy` |
| **Aritmética** | `mult`, `pow`, `diff` |
| **Álgebra lineal** | `det`, `inv`, `pinv`, `eigenvalues`, `eigenvectors`, `rank`, `trace` |
| **Estadística** | `sum`, `avg`, `min`, `max`, `median`, `mode`, `stdev`, `variance` |
| **Pruebas booleanas** | `is_square`, `is_identity`, `is_diagonal`, `is_symmetric`, `is_triangular`, `is_zero`, `is_binary`, `is_stochastic` |

## String (19 métodos)

| `str.replace(s, old, new)` | Sustituye la primera coincidencia |
| `str.replace_all(s, old, new)` | Sustituye todas las coincidencias |
| `str.lower(s)` | Convierte a minúsculas |
| `str.upper(s)` | Convierte a mayúsculas |
| `str.trim(s)` | Elimina espacios en blanco |
| `str.repeat(s, count)` | Repite la cadena |
| `str.format(fmt, ...)` | Da formato a la cadena |
| `str.tonumber(s)` | Convierte en número |
| `str.tostring(value)` | Convierte en cadena |
