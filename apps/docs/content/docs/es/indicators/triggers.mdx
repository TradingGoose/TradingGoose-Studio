La función `trigger()` es una extensión de TradingGoose para PineTS que permite a los indicadores iniciar ejecuciones de workflows cuando se cumplen determinadas condiciones. Un indicador puede detectar una señal y activar de inmediato una acción, como enviar una notificación, colocar una operación o ejecutar un workflow complejo con varios pasos.

## Sintaxis

```javascript
trigger(event, options)
```

### Parámetros

| Parámetro | Tipo | Obligatorio | Descripción |
|-----------|------|----------|-------------|
| `event` | `string` | Sí | Identificador del nombre del evento |
| `options` | `object` | Sí | Configuración del trigger (consulta la sección siguiente) |

### Objeto de opciones

| Propiedad | Tipo | Obligatorio | Descripción |
|----------|------|----------|-------------|
| `condition` | `any` | Sí | Condición que debe ser verdadera para activar el trigger |
| `input` | `string` | Sí | Entrada de texto enviada al workflow (p. ej., un descripción de qué happened) |
| `signal` | `'long' \| 'short' \| 'flat'` | Sí | Dirección de la señal de trading |
| `position` | `'aboveBar' \| 'belowBar' \| 'inBar'` | No | Posición del marcador en el gráfico (predeterminado: `'aboveBar'`) |
| `color` | `string` | No | Color del marcador (hex cadena, p. ej., `'#FF0000'`) |

### Reglas del nombre del evento

- Debe coincidir con el patrón: `/^[a-z][a-z0-9_]{0,63}$/`
- Empieza por una letra minúscula
- Solo admite letras minúsculas, números y guiones bajos
- Máximo de 64 caracteres

## Ejemplo básico

```javascript
indicator('RSI Trigger Example');

const rsi = ta.rsi(close, 14);
plot(rsi, 'RSI');
hline(70, { linestyle: hline.style_dashed });
hline(30, { linestyle: hline.style_dashed });

// Fire when RSI crosses above 70 (overbought)
if (ta.crossover(rsi, 70)) {
  trigger('rsi_overbought', {
    condition: ta.crossover(rsi, 70),
    input: 'RSI crossed above 70 — overbought signal',
    signal: 'short',
    position: 'aboveBar',
    color: '#FF0000'
  });
}

// Fire when RSI crosses below 30 (oversold)
if (ta.crossunder(rsi, 30)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, 30),
    input: 'RSI crossed below 30 — oversold signal',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## Varios triggers

Un indicador puede definir varios eventos de trigger. Cada evento puede conectarse a un workflow diferente:

```javascript
indicator('Multi-Signal', { overlay: true });

const fast = ta.ema(close, 9);
const slow = ta.ema(close, 21);
const [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9);

// EMA crossover trigger
if (ta.crossover(fast, slow)) {
  trigger('ema_bullish_cross', {
    condition: ta.crossover(fast, slow),
    input: 'Fast EMA crossed above slow EMA',
    signal: 'long',
    position: 'belowBar',
    color: '#26A69A'
  });
}

// MACD histogram reversal trigger
if (hist > 0 && hist[1] <= 0) {
  trigger('macd_positive_flip', {
    condition: hist > 0 && hist[1] <= 0,
    input: 'MACD histogram flipped positive',
    signal: 'long',
    position: 'belowBar',
    color: '#2962FF'
  });
}
```

## Funcionamiento

1. **Evaluación** — En cada barra, PineTS evalúa el código del indicador, incluidas las llamadas a `trigger()`
2. **Comprobación de la condición** — La propiedad `condition` se resuelve para la barra actual. Si es falsa, el trigger se omite sin mostrar mensajes
3. **Validación** — Se validan el nombre del evento, la estructura de opciones, la entrada y la señal. Las llamadas no válidas generan advertencias, no errores
4. **Captura** — Los triggers válidos se capturan con sus metadatos (evento, entrada, señal, posición, color, hora e índice de barra)
5. **Envío al workflow** — Durante la ejecución en vivo, los eventos capturados se envían a los workflows conectados mediante Indicator Trigger

## Conexión con workflows

Para usar triggers de indicadores en un workflow:

1. Crea un indicador con llamadas a `trigger()`
2. Añade un bloque **Indicator Trigger** como punto inicial en el editor del workflow
3. Configúralo para escuchar los eventos del indicador
4. El workflow recibe el texto `input` y la señal `signal` del trigger como datos de entrada

## Advertencias de validación

Las llamadas a trigger no válidas generan advertencias, no errores, para que el indicador continúe ejecutándose:

| Código de advertencia | Causa |
|-------------|-------|
| `indicator_trigger_invalid_event` | El nombre del evento no coincide con el patrón obligatorio |
| `indicator_trigger_invalid_options` | El parámetro de opciones no es un objeto |
| `indicator_trigger_condition_unresolved` | No se pudo resolver el valor de la condición |
| `indicator_trigger_invalid_input` | Falta la entrada o no es una cadena |
| `indicator_trigger_invalid_signal` | La señal no es `'long'`, `'short'` ni `'flat'` |
| `indicator_trigger_invalid_time` | La hora de apertura de la barra no está disponible |

<Callout type="info">
  La API `trigger()` es una extensión específica de TradingGoose. No existe en Pine Script estándar ni en PineTS. Los indicadores que llaman a `trigger()` funcionan normalmente en todos los entornos; fuera de TradingGoose, el trigger no produce ningún efecto.
</Callout>
