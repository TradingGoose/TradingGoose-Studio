PineTS proporciona series de datos integradas que están disponibles en cada indicador sin necesidad de importaciones. Estas representan los datos OHLCV del símbolo actual, la información temporal y el estado de la barra.

## Datos de precio (OHLCV)

| Serie | Tipo | Descripción |
|--------|------|-------------|
| `open` | `series<number>` | Precio de apertura de cada barra |
| `high` | `series<number>` | Precio máximo de cada barra |
| `low` | `series<number>` | Precio mínimo de cada barra |
| `close` | `series<number>` | Precio de cierre de cada barra |
| `volume` | `series<number>` | Volumen de operaciones de cada barra |

### Series de precio calculadas

| Serie | Fórmula | Descripción |
|--------|---------|-------------|
| `hl2` | `(high + low) / 2` | Precio del punto medio |
| `hlc3` | `(high + low + close) / 3` | Precio típico |
| `ohlc4` | `(open + high + low + close) / 4` | Precio promedio |

```javascript
// Use any price series in calculations
const typicalPrice = hlc3;
const sma = ta.sma(typicalPrice, 20);
plot(sma, 'SMA of Typical Price');
```

## Series temporales

| Serie | Tipo | Descripción |
|--------|------|-------------|
| `openTime` | `series<number>` | Hora de apertura de la barra en milisegundos |
| `closeTime` | `series<number>` | Hora de cierre de la barra en milisegundos |

## Información de la barra

| Variable | Tipo | Descripción |
|----------|------|-------------|
| `bar_index` | `series<number>` | Índice de la barra actual (base 0) |
| `last_bar_index` | `series<number>` | Índice de la última barra del conjunto de datos |
| `last_bar_time` | `series<number>` | Marca de tiempo de la última barra |

```javascript
// Only plot on the last 100 bars
if (bar_index > last_bar_index - 100) {
  plot(close, 'Recent Close');
}
```

## Estado de la barra

El objeto `barstate` proporciona indicadores sobre la posición de la barra actual en el conjunto de datos:

| Propiedad | Tipo | Descripción |
|----------|------|-------------|
| `barstate.isfirst` | `boolean` | Verdadero en la primera barra |
| `barstate.islast` | `boolean` | Verdadero en la última barra |
| `barstate.ishistory` | `boolean` | Verdadero en barras históricas |
| `barstate.isrealtime` | `boolean` | Verdadero en barras en vivo/streaming |
| `barstate.isnew` | `boolean` | Verdadero en el primer tick de una nueva barra |
| `barstate.isconfirmed` | `boolean` | Verdadero cuando la barra está confirmada (cerrada) |
| `barstate.islastconfirmedhistory` | `boolean` | Verdadero en la última barra histórica confirmada |

## Información del símbolo

El objeto `syminfo` proporciona detalles sobre el símbolo actual:

| Propiedad | Descripción |
|----------|-------------|
| `syminfo.ticker` | Nombre del símbolo (ej., `"BTCUSDT"`) |
| `syminfo.tickerid` | ID completo del ticker |
| `syminfo.description` | Descripción del símbolo |
| `syminfo.type` | Tipo de activo (ej., `"crypto"`, `"stock"`) |
| `syminfo.currency` | Moneda de cotización |
| `syminfo.basecurrency` | Moneda base |
| `syminfo.mintick` | Incremento mínimo de precio |
| `syminfo.timezone` | Zona horaria del exchange |

## Valores especiales

| Valor | Descripción |
|-------|-------------|
| `na` | Representa "no disponible" — similar a `null`. Se usa para comprobar si un valor existe |
| `nz(value, replacement?)` | Devuelve `replacement` (predeterminado `0`) si `value` es `na` |

```javascript
const prev = close[1];
// na check
if (!na(prev)) {
  const change = close - prev;
  plot(change, 'Change');
}

// nz shorthand — default to 0 if na
const safeChange = nz(close - close[1], 0);
```

## Constantes globales

| Espacio de nombres | Descripción |
|-----------|-------------|
| `timeframe` | Información del marco temporal actual (`timeframe.period`, `timeframe.multiplier`) |
| `order` | Constantes de orden de clasificación (`order.ascending`, `order.descending`) |
| `currency` | Constantes de códigos de moneda (59 monedas, incluyendo `currency.BTC`, `currency.USD`) |
| `display` | Constantes de modo de visualización |
| `shape` | Constantes de tipo de forma para `plotshape()` |
| `location` | Constantes de ubicación (`location.abovebar`, `location.belowbar`, etc.) |
| `size` | Constantes de tamaño (`size.tiny`, `size.small`, `size.normal`, `size.large`, `size.huge`) |
| `format` | Constantes de formato (`format.price`, `format.volume`, `format.percent`) |
| `dayofweek` | Constantes de día de la semana |

<Callout type="info">
  Todas las series de datos admiten acceso al historial con notación de corchetes: `close[1]` devuelve el cierre de la barra anterior, `close[10]` devuelve 10 barras atrás.
</Callout>
