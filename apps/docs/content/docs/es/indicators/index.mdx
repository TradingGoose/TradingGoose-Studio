Los indicadores son scripts personalizados de análisis técnico que se ejecutan sobre datos de mercado en TradingGoose. Funcionan con [PineTS](https://github.com/nicholasgasior/PineTS), un runtime de JavaScript/TypeScript para Pine Script, ampliado con funciones propias de TradingGoose, como los activadores de flujo de trabajo.

## ¿Qué puedes crear?

- **Indicadores técnicos** — RSI, MACD, bandas de Bollinger o tus propios cálculos personalizados
- **Generadores de señales** — Detecta cruces, rupturas o condiciones personalizadas
- **Activadores de flujo de trabajo** — Lanza ejecuciones de flujo de trabajo cuando se cumplen las condiciones del indicador mediante la API `trigger()`
- **Superposiciones visuales** — Dibuja líneas, formas y rellenos directamente en el gráfico

## Cómo funciona

<Steps>
  <Step>
    **Escribe código PineTS** en el Editor de indicadores con la conocida sintaxis de Pine Script adaptada a JavaScript/TypeScript
  </Step>
  <Step>
    **Define entradas** con `input.int()`, `input.float()`, etc.: se convierten en parámetros configurables en la interfaz
  </Step>
  <Step>
    **Calcula** con más de 57 funciones integradas de análisis técnico (`ta.*`), operaciones matemáticas, arrays y mucho más
  </Step>
  <Step>
    **Visualiza** con `plot()`, `plotshape()`, `fill()`, `bgcolor()` y otras funciones de representación en el gráfico
  </Step>
  <Step>
    **Activa flujos de trabajo** llamando a `trigger()` cuando se cumplen las condiciones: conecta los indicadores con tus canalizaciones de automatización
  </Step>
</Steps>

## Ejemplo rápido

```javascript
indicator('RSI Signal', { overlay: false });

const length = input.int(14, 'RSI Length');
const overbought = input.int(70, 'Overbought');
const oversold = input.int(30, 'Oversold');

const rsi = ta.rsi(close, length);

plot(rsi, 'RSI', { color: '#2962FF' });
hline(overbought, { color: '#FF0000', linestyle: hline.style_dashed });
hline(oversold, { color: '#00FF00', linestyle: hline.style_dashed });

// Trigger a workflow when RSI crosses below oversold
if (ta.crossunder(rsi, oversold)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, oversold),
    input: 'RSI crossed below oversold threshold',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## Indicadores integrados

TradingGoose incluye más de 80 indicadores predefinidos que cubren análisis de momento, tendencia, volatilidad y volumen. Sirven tanto como herramientas listas para usar como de ejemplos de referencia para escribir los tuyos.

<Callout type="info">
  PineTS se basa en la sintaxis de Pine Script v5/v6. Si estás familiarizado con el Pine Script de TradingView, te resultará muy familiar: la principal diferencia es que se usan declaraciones de variables de JavaScript (`const`, `let`, `var`) en lugar de las declaraciones implícitas de Pine Script.
</Callout>
