Los indicadores son scripts personalizados de análisis técnico que se ejecutan con datos de mercado en TradingGoose. Utilizan [PineTS](https://github.com/nicholasgasior/PineTS), un entorno de ejecución JavaScript/TypeScript para Pine Script ampliado con funciones específicas de TradingGoose, como los triggers de flujos de trabajo.

## Qué puedes crear

- **Indicadores técnicos** — RSI, MACD, bandas de Bollinger o tus propios cálculos
- **Generadores de señales** — Detecta cruces, rupturas o condiciones personalizadas
- **Triggers de flujos de trabajo** — Inicia ejecuciones cuando se cumplan las condiciones del indicador mediante la API `trigger()`
- **Capas visuales** — Representa líneas, formas y rellenos directamente en el gráfico

## Cómo funciona

<Steps>
  <Step>
    **Escribe código PineTS** en el editor de indicadores con la sintaxis habitual de Pine Script adaptada a JavaScript/TypeScript
  </Step>
  <Step>
    **Define entradas** con `input.int()`, `input.float()`, etc.; se convertirán en parámetros configurables de la interfaz
  </Step>
  <Step>
    **Calcula** con más de 57 funciones integradas de análisis técnico (`ta.*`), operaciones matemáticas, matrices y otros recursos
  </Step>
  <Step>
    **Visualiza** con `plot()`, `plotshape()`, `fill()`, `bgcolor()` y otras funciones de representación de gráficos
  </Step>
  <Step>
    **Activa flujos de trabajo** llamando a `trigger()` cuando se cumplan las condiciones, y conecta los indicadores con tus canalizaciones de automatización
  </Step>
</Steps>

## Ejemplo rápido

```javascript
indicator('RSI Signal', { overlay: false });

const length = input.int(14, 'RSI Length');
const overbought = input.int(70, 'Overbought');
const oversold = input.int(30, 'Oversold');

const rsi = ta.rsi(close, length);

plot(rsi, 'RSI', { color: '#2962FF' });
hline(overbought, { color: '#FF0000', linestyle: hline.style_dashed });
hline(oversold, { color: '#00FF00', linestyle: hline.style_dashed });

// Trigger a workflow when RSI crosses below oversold
if (ta.crossunder(rsi, oversold)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, oversold),
    input: 'RSI crossed below oversold threshold',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## Indicadores integrados

TradingGoose incluye más de 80 indicadores predefinidos para analizar impulso, tendencia, volatilidad y volumen. Puedes utilizarlos directamente y como referencia para escribir tus propios indicadores.

<Callout type="info">
  PineTS se basa en la sintaxis de Pine Script v5/v6. Si conoces Pine Script de TradingView, la adaptación será sencilla. La diferencia principal es el uso de declaraciones de variables de JavaScript (`const`, `let`, `var`) en lugar de las declaraciones implícitas de Pine Script.
</Callout>
