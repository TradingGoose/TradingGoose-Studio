PineTS utiliza la sintaxis de JavaScript/TypeScript y reproduce el comportamiento de ejecución de Pine Script. Si conoce Pine Script de TradingView, la transición es directa: las principales diferencias están en las declaraciones de variables y las convenciones de sintaxis estándar de JavaScript.

## Declaraciones de variables

PineTS distingue entre `let` y `var` para ajustarse al modelo de ejecución de Pine Script. Este es el concepto más importante que debe comprender.

### `let`: se recalcula en cada barra

Las variables declaradas con `let` (o con `const` para valores inmutables) se vuelven a evaluar en cada barra, igual que las variables estándar de Pine Script:

```javascript
// Recalculated on every bar
const sma20 = ta.sma(close, 20);
let direction = close > open ? 1 : -1;
```

### `var`: estado persistente entre barras

Las variables declaradas con `var` se inicializan una sola vez (en la primera barra) y conservan su valor en las barras posteriores, igual que la palabra clave `var` de Pine Script:

```javascript
// Initialized once, persists across bars
var cumulativeVolume = 0;
cumulativeVolume = cumulativeVolume + volume;
```

<Callout type="warn">
  En PineTS, `var` **no** se comporta como el `var` estándar de JavaScript. Adopta la semántica de Pine Script: la variable se define una vez y conserva su valor. Use `let` si necesita un valor que se reinicie en cada barra.
</Callout>

### Comparación directa

| Comportamiento | Pine Script | PineTS |
|----------|-------------|--------|
| Se recalcula en cada barra | `float x = close` | `let x = close` o `const x = close` |
| Persiste entre barras | `var float x = 0.0` | `var x = 0.0` |
| Reasignación | `x := x + 1` | `x = x + 1` |

## Acceso al historial

Acceda a los valores de barras anteriores mediante la notación entre corchetes, igual que en Pine Script:

```javascript
const prevClose = close[1];     // 1 bar ago
const tenBarsAgo = close[10];   // 10 bars ago
const momentum = close - close[10];
```

## Flujo de control

```javascript
// If/else
if (close > open) {
  direction = 1;
} else {
  direction = -1;
}

// Ternary
const color = close > open ? '#00FF00' : '#FF0000';

// Switch
switch (maType) {
  case 'ema': return ta.ema(close, length);
  case 'sma': return ta.sma(close, length);
  default: return ta.rma(close, length);
}
```

## Funciones

Defina funciones reutilizables mediante la sintaxis estándar de JavaScript:

```javascript
// Pine Script: f_ma(source, length) => ta.sma(source, length)
function f_ma(source, length) {
  return ta.sma(source, length);
}

const ma = f_ma(close, 20);
plot(ma, 'Custom MA');
```

## Tuplas (varios valores de retorno)

Algunas funciones, como `ta.macd()` y `ta.bb()`, devuelven varios valores. Use la desestructuración de arrays:

```javascript
// Pine Script: [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9)
const [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9);

// Pine Script: [middle, upper, lower] = ta.bb(close, 20, 2)
const [middle, upper, lower] = ta.bb(close, 20, 2);
```

## Valores especiales

| Valor | Descripción |
|-------|-------------|
| `na` | No disponible; equivale a `null`/`undefined` en Pine Script |
| `nz(value)` | Sustituye `na` por cero (o por un valor predeterminado específico) |
| `color` | Espacio de nombres de colores para el gráfico |

```javascript
const prev = close[1];
const change = na(prev) ? 0 : close - prev;  // Handle na values
const safeValue = nz(someCalculation, 0);     // Default to 0 if na
```

## Ejemplo completo: SAR parabólico

Este ejemplo muestra el uso de `var` para conservar el estado, la lógica `if/else`, el acceso al historial y las funciones personalizadas:

```javascript
indicator('Custom SAR', { overlay: true });

const start = input.float(0.02, 'Start');
const increment = input.float(0.02, 'Increment');
const maximum = input.float(0.2, 'Maximum');

function pine_sar(start, inc, max) {
  var result = na;
  var maxMin = na;
  var acceleration = na;
  var isBelow = false;

  let isFirstTrendBar = false;

  if (bar_index == 1) {
    if (close > close[1]) {
      isBelow = true;
      maxMin = high;
      result = low[1];
    } else {
      isBelow = false;
      maxMin = low;
      result = high[1];
    }
    isFirstTrendBar = true;
    acceleration = start;
  }

  // ... calculation logic ...
  return result;
}

const sar = pine_sar(start, increment, maximum);
plot(sar, 'SAR', { style: plot.style_cross });
```
