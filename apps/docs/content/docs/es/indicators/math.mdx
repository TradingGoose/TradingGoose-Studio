---
title: Funciones matemáticas
description: Operaciones matemáticas y constantes del espacio de nombres math
---

El espacio de nombres `math` proporciona constantes matemáticas, operaciones básicas, trigonometría y funciones estadísticas.

## Constantes

| Constante | Valor | Descripción |
|----------|-------|-------------|
| `math.pi` | 3.14159... | Pi |
| `math.e` | 2.71828... | Número de Euler |
| `math.phi` | 1.61803... | Proporción áurea |
| `math.rphi` | 0.61803... | Recíproco de la proporción áurea |

## Operaciones básicas

| Función | Descripción |
|----------|-------------|
| `math.abs(x)` | Valor absoluto |
| `math.ceil(x)` | Redondea hacia arriba al entero más próximo |
| `math.floor(x)` | Redondea hacia abajo al entero más próximo |
| `math.round(x, precision?)` | Redondea al entero más próximo o a la precisión indicada |
| `math.round_to_mintick(x)` | Redondea al incremento mínimo del símbolo |
| `math.sign(x)` | Signo del valor (-1, 0 o 1) |
| `math.max(a, b)` | Máximo de dos valores |
| `math.min(a, b)` | Mínimo de dos valores |
| `math.avg(...)` | Media de los valores |
| `math.sum(source, length)` | Suma de valores durante N barras |

## Funciones exponenciales y logarítmicas

| Función | Descripción |
|----------|-------------|
| `math.pow(base, exp)` | Potencia |
| `math.sqrt(x)` | Raíz cuadrada |
| `math.exp(x)` | e elevada a la potencia x |
| `math.log(x)` | Logaritmo natural |
| `math.log10(x)` | Logaritmo en base 10 |

## Funciones trigonométricas

| Función | Descripción |
|----------|-------------|
| `math.sin(x)` | Seno (radianes) |
| `math.cos(x)` | Coseno (radianes) |
| `math.tan(x)` | Tangente (radianes) |
| `math.asin(x)` | Arcoseno |
| `math.acos(x)` | Arcocoseno |
| `math.atan(x)` | Arcotangente |
| `math.todegrees(x)` | Convierte radianes a grados |
| `math.toradians(x)` | Convierte grados a radianes |

## Otras funciones

| Función | Descripción |
|----------|-------------|
| `math.random(min?, max?)` | Número aleatorio |

## Ejemplo

```javascript
indicator('Volatility Ratio');

const atr = ta.atr(14);
const avgAtr = ta.sma(atr, 50);
const ratio = atr / math.max(avgAtr, syminfo.mintick);
const logRatio = math.log(ratio);

plot(logRatio, 'Log Volatility Ratio');
hline(0, { linestyle: hline.style_dashed });
```
