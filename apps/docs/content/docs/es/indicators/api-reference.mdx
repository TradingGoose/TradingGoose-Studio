<Callout type="info">
  Esta referencia cubre las funciones disponibles en el entorno de ejecución de PineTS de TradingGoose. PineTS se basa en el [proyecto PineTS](https://github.com/nicholasgasior/PineTS) de código abierto y admite un subconjunto de las API de Pine Script v5/v6. Actualmente no se admiten funciones como `strategy.*`, `label.*`, `line.*`, `box.*` y `table.*`.
</Callout>
