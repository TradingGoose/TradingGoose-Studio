import { Card, Cards } from 'fumadocs-ui/components/card'

TradingGoose ofrece SDK publicados para TypeScript/JavaScript y Python que permiten ejecutar flujos de trabajo desplegados, comprobar el estado del despliegue, controlar las salidas seleccionadas, gestionar límites de frecuencia y consultar límites de uso.

<Cards>
  <Card title="SDK de Python" href="/sdks/python">
    Instala `tradinggoose-sdk` para usar un cliente síncrono de Python.
  </Card>
  <Card title="SDK de TypeScript" href="/sdks/typescript">
    Instala `tradinggoose-ts-sdk` para aplicaciones de Node.js y navegador.
  </Card>
</Cards>

Ambos clientes se autentican con una clave de API mediante `X-API-Key` y usan `https://tradinggoose.ai`. de forma predeterminada. Exponen la ejecución y el estado de los flujos de trabajo, reintentos ante límites de frecuencia, metadatos de esos límites y límites de uso. Los nombres, tipos y unidades de tiempo de espera específicos de cada lenguaje se documentan en sus páginas correspondientes.

Para una integración HTTP directa, consulta la [API de ejecución](/execution/api).
