El bloque Knowledge conecta el workflow con una base de conocimiento. Permite generación aumentada por recuperación (RAG) mediante búsquedas de similitud vectorial, carga de fragmentos y creación de documentos durante la ejecución.

## Descripción general

<Steps>
  <Step><strong>Search</strong>: ejecuta una consulta semántica y recupera los fragmentos más relevantes.</Step>
  <Step><strong>Upload Chunk</strong>: añade un fragmento a un documento para que pueda encontrarse en consultas futuras.</Step>
  <Step><strong>Create Document</strong>: añade un documento nuevo, con etiquetas opcionales, a la base.</Step>
</Steps>

## Operaciones

<Tabs items={['Search', 'Upload Chunk', 'Create Document']}>
  <Tab>Realiza una búsqueda vectorial y devuelve los fragmentos principales. **Knowledge Base** es obligatorio; **Search Query**, **Number of Results** (10 de forma predeterminada) y **Tag Filters** son opcionales. La consulta puede omitirse para filtrar solo por etiquetas.</Tab>
  <Tab>Añade texto a un documento existente. El fragmento se vectoriza y queda disponible para búsquedas. Requiere **Knowledge Base**, **Document** y **Chunk Content**.</Tab>
  <Tab>Crea un documento, divide su contenido, lo vectoriza y lo indexa. Requiere **Knowledge Base**, **Document Name** y **Document Content**; **Document Tags** es opcional.</Tab>
</Tabs>

## Salidas

| Salida | Tipo | Descripción |
|---|---|---|
| `results` | json | Array de fragmentos coincidentes o confirmación de una escritura. |
| `query` | string | Consulta utilizada. |
| `totalResults` | number | Número de resultados devueltos. |

## Prácticas recomendadas

- **Usa etiquetas para delimitar búsquedas** -- divide una base por tema, cliente o categoría sin crear bases distintas.
- **Mantén los fragmentos enfocados** -- el texto breve y coherente produce mejores coincidencias que el contenido largo con varios temas.
- **Combínalo con Agent** -- pasa los resultados al contexto de un Agent para crear un proceso RAG.

<Callout type="info">La consulta es opcional. Si solo necesitas documentos con ciertas etiquetas, deja la consulta vacía y usa los filtros.</Callout>
