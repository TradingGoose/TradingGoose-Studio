El bloque Conocimiento conecta tu flujo de trabajo con una base de conocimiento, lo que permite la generación aumentada por recuperación (RAG) mediante la realización de búsquedas de similitud vectorial, la carga de nuevos fragmentos y la creación de documentos, todo en tiempo de ejecución.

## Descripción general

<Steps>
  <Step>
    <strong>Buscar</strong>: Ejecuta una consulta de similitud semántica en tu base de conocimiento y recupera los fragmentos más relevantes
  </Step>
  <Step>
    <strong>Subir fragmento</strong>: Añade un nuevo fragmento de texto a un documento existente para que se pueda buscar en futuras consultas
  </Step>
  <Step>
    <strong>Crear documento</strong>: Agrega un documento nuevo (con etiquetas opcionales) a la base de conocimiento
  </Step>
</Steps>

## Operaciones

<Tabs items={['Buscar', 'Subir fragmento', 'Crear documento']}>
  <Tab>
    Realiza una búsqueda de similitud vectorial y devuelve los fragmentos más coincidentes.

    | Campo | Obligatorio | Descripción |
    |---|---|---|
    | **Base de conocimiento** | Sí | La base de conocimiento que se va a buscar |
    | **Consulta de búsqueda** | Sí para búsquedas operativas | Consulta en lenguaje natural; consulta la limitación de filtros por etiquetas. |
    | **Número de resultados** | No | Cuántos fragmentos devolver (predeterminado: 10) |
    | **Filtros de etiquetas** | No | Limita los resultados a documentos que coincidan con etiquetas específicas |

    El filtrado por etiquetas es una capacidad prevista, pero las búsquedas solo por etiquetas fallan y las búsquedas con consulta y etiquetas no aplican estas. No dependas de ellas para restringir los resultados hasta que se corrija.
  </Tab>
  <Tab>
    Añade un fragmento de texto a un documento existente dentro de la base de conocimiento. El fragmento se incrusta automáticamente y queda disponible para futuras búsquedas.

    | Campo | Obligatorio | Descripción |
    |---|---|---|
    | **Base de conocimiento** | Sí | Base de conocimiento de destino |
    | **Documento** | Sí | El documento al que se añade el fragmento |
    | **Contenido del fragmento** | Sí | El contenido de texto que se va a subir |
  </Tab>
  <Tab>
    Crea un documento nuevo en la base de conocimiento. El contenido se divide en fragmentos, se generan los embeddings y se indexa.

    | Campo | Obligatorio | Descripción |
    |---|---|---|
    | **Base de conocimiento** | Sí | Base de conocimiento de destino |
    | **Nombre del documento** | Sí | Nombre del documento nuevo |
    | **Contenido del documento** | Sí | Contenido de texto completo |
    | **Etiquetas del documento** | No | Etiquetas para categorizar y filtrar |
  </Tab>
</Tabs>

## Salidas

| Operación | Salida |
|---|---|
| Search | `results` (fragmentos coincidentes), `query`, `totalResults` |
| Upload Chunk | `message`, `data.chunkId`, `data.content`, `data.chunkIndex`, además de `documentId`, `documentName` y `cost` |
| Create Document | `message` y `data` con `documentId`, `documentName`, `type`, `enabled`, `createdAt` y `updatedAt` |

Usa `<knowledge.data.documentId>` después de Create Document. Las confirmaciones de escritura no se devuelven en `results`.

## Buenas prácticas

- **Mantén los fragmentos enfocados** -- los fragmentos más cortos y coherentes en cuanto al tema producen mejores coincidencias de similitud que un texto largo con múltiples temas.
- **Combínalo con un bloque Agent** -- canaliza los resultados de búsqueda al contexto de un Agent para construir un flujo RAG.

<Callout type="warning">
  El filtrado por etiquetas no es fiable: las búsquedas solo por etiquetas fallan y las búsquedas con consulta y etiquetas no filtran por estas. Consulta [Base de conocimiento](/knowledgebase). Usa una consulta no vacía y revisa los documentos; las etiquetas no son una barrera de control de acceso.
</Callout>
