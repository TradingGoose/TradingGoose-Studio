## Cómo funciona

El bloque Function ejecuta tu código en un entorno seguro y aislado:

1. **Recibir entrada**: Accede a los datos de los bloques anteriores mediante el objeto `input`
2. **Ejecutar código**: Ejecuta tu código JavaScript/Python
3. **Devolver resultados**: Usa `return` para pasar los datos al siguiente bloque
4. **Gestionar errores**: Gestión de errores y registro integrados

## Ejecución remota (E2B)

  - **Lenguajes**: Ejecuta JavaScript y Python en un sandbox de E2B aislado.
  - **Cómo habilitarlo**: Activa “Remote Code Execution” en el bloque Function.
  - **Cuándo usarlo**: Lógica más pesada, bibliotecas externas o código específico de Python.
  - **Rendimiento**: Más lento que el JS local debido al inicio del sandbox y la sobrecarga de red.
  - **Notas**: Requiere `E2B_API_KEY` si se ejecuta de forma local. Para obtener la latencia más baja, usa JS local nativo (Fast Mode).

### Ejemplo: calculadora de puntuación de fidelidad

```javascript title="loyalty-calculator.js"
// Process customer data and calculate loyalty score
const { purchaseHistory, accountAge, supportTickets } = <agent>;

// Calculate metrics
const totalSpent = purchaseHistory.reduce((sum, purchase) => sum + purchase.amount, 0);
const purchaseFrequency = purchaseHistory.length / (accountAge / 365);
const ticketRatio = supportTickets.resolved / supportTickets.total;

// Calculate loyalty score (0-100)
const spendScore = Math.min(totalSpent / 1000 * 30, 30);
const frequencyScore = Math.min(purchaseFrequency * 20, 40);
const supportScore = ticketRatio * 30;

const loyaltyScore = Math.round(spendScore + frequencyScore + supportScore);

return {
  customer: <agent.name>,
  loyaltyScore,
  loyaltyTier: loyaltyScore >= 80 ? "Platinum" : loyaltyScore >= 60 ? "Gold" : "Silver",
  metrics: { spendScore, frequencyScore, supportScore }
};
```

## Buenas prácticas

- **Mantén las funciones enfocadas**: escribe funciones que hagan una sola cosa bien para mejorar el mantenimiento y la depuración
- **Gestiona los errores de forma controlada**: usa bloques try/catch para manejar posibles errores y ofrecer mensajes de error claros
- **Prueba los casos límite**: asegúrate de que tu código maneje correctamente entradas inusuales, valores nulos y condiciones de frontera
- **Optimiza el rendimiento**: ten en cuenta la complejidad computacional y el uso de memoria con grandes volúmenes de datos
- **Usa console.log() para depurar**: aprovecha la salida de stdout para depurar y monitorizar la ejecución de la función
