Selecciona un identificador `proveedor/modelo` de la lista de modelos disponibles. El selector mantiene la búsqueda y la agrupación por proveedor. Las referencias a variables de entorno y salidas de otros bloques se resuelven antes de validar el modelo; un identificador incompatible requiere una nueva selección. La clave de API es necesaria salvo que Studio tenga una conexión configurada para el proveedor. Usar la conexión de Studio cuenta para el uso de la cuenta.

## Uso y salidas

Configura los mensajes del sistema y del usuario, las herramientas y las habilidades. En Campos adicionales puedes conectar el historial y configurar el formato de respuesta.

**Nivel de razonamiento** aparece debajo de **Modelo** cuando Mastra ofrece niveles. Si el modelo admite el nivel guardado en el bloque o, en Copilot, el que guardaste para este espacio de trabajo, Studio lo conserva. En caso contrario, Studio usa el nivel activo que Mastra Code obtiene de su preferencia de razonamiento. Si esa preferencia no da lugar a un nivel activo, Studio selecciona el primer nivel activo de la lista de Mastra.

Auto permite que el modelo elija una herramienta; Force exige cada herramienta marcada en el orden configurado y después vuelve a Auto; None excluye la herramienta. Una combinación no admitida o una secuencia forzada incompleta produce un error. Se conservan los argumentos fijos y el contexto autorizado del flujo.

Sin formato estructurado, las salidas incluyen `content`, `model`, `tokens` y `cost`. Las entradas, los turnos, las llamadas a herramientas y sus resultados están disponibles en el historial de ejecución del flujo de trabajo. Response Format recibe un objeto con un JSON Schema en `schema`; sus campos se devuelven en la raíz para las referencias posteriores. Para persistir el historial, usa Memory Add y conecta Get Memory a Memories.

## Uso y coste

Los registros distinguen el coste informado por el proveedor, la estimación nativa y el coste no disponible. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, pero su coste en USD se muestra como no disponible.
