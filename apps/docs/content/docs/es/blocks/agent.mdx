Selecciona un identificador `proveedor/modelo` del registro de Mastra. El selector mantiene la búsqueda y la agrupación por proveedor. Las referencias a variables de entorno y salidas de otros bloques se resuelven antes de validar el modelo; un identificador incompatible requiere una nueva selección. La clave de API pertenece a esta solicitud. Si la omites, se usa la conexión configurada de Mastra.

## Uso y salidas

Configura los mensajes del sistema y del usuario, las herramientas, las habilidades y el historial. En Campos adicionales puedes configurar el formato de respuesta, el máximo de tokens de salida y los ajustes nativos disponibles. Dejar un ajuste vacío conserva el valor predeterminado del proveedor. Los metadatos publicados del modelo se muestran como orientación. Este entorno de ejecución no admite un selector simplificado de esfuerzo de razonamiento; configura las opciones nativas admitidas mediante Provider Options, incluidos los presupuestos o interruptores de razonamiento que permita el proveedor.

Auto permite que el modelo elija una herramienta; Force exige cada herramienta marcada en el orden configurado y después vuelve a Auto; None excluye la herramienta. Una combinación no admitida o una secuencia forzada incompleta produce un error. Se conservan los argumentos fijos y el contexto autorizado del flujo.

Sin formato estructurado, las salidas incluyen `content`, `model`, `tokens` y `toolCalls`. Response Format recibe un objeto con un JSON Schema en `schema`; sus campos se devuelven en la raíz para las referencias posteriores. Para persistir el historial, usa Memory Add y conecta Get Memory a Memories. La generación y el streaming usan Mastra. El ciclo independiente de creación y consulta de Gemini Interactions/Deep Research se ha eliminado.

## Uso y coste

Los registros distinguen el coste informado por el proveedor, la estimación nativa y el coste no disponible. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, pero su coste en USD se muestra como no disponible.
