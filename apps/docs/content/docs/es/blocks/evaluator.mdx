Selecciona un identificador `proveedor/modelo` de la lista de modelos disponibles. El selector mantiene la búsqueda y la agrupación por proveedor. Las referencias a variables de entorno y salidas de otros bloques se resuelven antes de validar el modelo; un identificador incompatible requiere una nueva selección. La clave de API es necesaria salvo que Studio tenga una conexión configurada para el proveedor. Usar la conexión de Studio cuenta para el uso de la cuenta.

## Uso y salidas

Define las métricas con su nombre, descripción y rango, y proporciona el contenido que se va a evaluar. La generación estructurada nativa devuelve el resultado de la evaluación en `content`, junto con `model`, `tokens` y `cost` cuando están disponibles.

## Uso y coste

Studio calcula el coste con los precios del catálogo models.dev de OpenCode. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, y el coste en USD cuando se conocen los precios y el uso.
