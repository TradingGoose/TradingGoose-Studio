Selecciona un identificador `proveedor/modelo` del registro de Mastra. El selector mantiene la búsqueda y la agrupación por proveedor. Las referencias a variables de entorno y salidas de otros bloques se resuelven antes de validar el modelo; un identificador incompatible requiere una nueva selección. La clave de API pertenece a esta solicitud. Si la omites, se usa la conexión configurada de Mastra.

## Uso y salidas

Escribe las instrucciones de clasificación y conecta los destinos del flujo. El modelo devuelve una selección estructurada; `selectedPath` identifica el bloque de destino. Se mantienen `prompt`, `model`, `tokens` y `cost` como salidas para las referencias del flujo.

## Uso y coste

Los registros distinguen el coste informado por el proveedor, la estimación nativa y el coste no disponible. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, pero su coste en USD se muestra como no disponible.
