Las referencias a variables de entorno y salidas de otros bloques se resuelven antes de validar el modelo; un identificador incompatible requiere una nueva selección. La clave de API pertenece a esta solicitud. Si la omites, se usa la conexión configurada de Mastra.

## Uso y salidas

Elige el tipo de validación y proporciona el texto. La comprobación de alucinaciones usa generación estructurada nativa con el modelo seleccionado y el contexto de referencia. Las validaciones de JSON y datos personales conservan su comportamiento. Las salidas incluyen `passed`, el tipo de validación y, según la operación, `score`, `reasoning`, `maskedText` o las entidades detectadas.

## Uso y coste

Los registros distinguen el coste informado por el proveedor, la estimación nativa y el coste no disponible. Un coste ausente no es cero; los tokens conocidos se conservan aunque falten dólares. Los cargos propios del producto se calculan por separado. Las incrustaciones independientes conservan los vectores y el uso nativo disponible, pero su coste en USD se muestra como no disponible.
