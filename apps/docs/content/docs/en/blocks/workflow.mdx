---
title: Workflow Block
description: Call a child workflow using the current input-mapping block
---

The Workflow block available in the editor uses the `workflow_input` type. Select a child workflow with an Input Form trigger and map its fields in **Input Mapping**.

See [Workflow](/blocks/workflow_input) for the current configuration, outputs, and error handling. Child execution inherits the parent's target: live runs use live child state, and deployed runs use the deployed child snapshot.
