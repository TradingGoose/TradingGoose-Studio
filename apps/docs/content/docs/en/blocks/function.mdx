The Function block runs TypeScript or JavaScript statements to transform data, perform calculations, and call external services. TypeScript is transpiled to JavaScript before execution. Python is not supported by this block.

## Write code

Enter statements directly in the Code editor. An async wrapper is supplied automatically, so use `await` and `return` without declaring a wrapper function.

Reference upstream outputs with source-qualified tags. There is no automatically populated `input` object.

```typescript
const customers = <api.data.customers>;
const activeCustomers = customers.filter((customer) => customer.active);
console.log('Active customers:', activeCustomers.length);
return activeCustomers;
```

Use the actual source block name and output path. Workflow variables use `<variable.name>`; environment variables use `{{VARIABLE_NAME}}`.

## Execution environment

Execution uses an isolated local JavaScript VM or an E2B JavaScript sandbox, according to the deployment's **E2B system-service configuration**. There is no per-block Remote Code Execution toggle or language selector. An administrator configures the E2B service and its API key; setting a block field does not enable it.

- The default code timeout is **180 seconds**. Workflow limits may stop the overall run earlier.
- `fetch()` is available for HTTP requests, subject to runtime URL restrictions.
- External imports require E2B runtime support; they are not available in the local VM.
- `console.log()` is captured in `stdout`.

<Callout>
  Use [Indicators](/indicators) for available indicator definitions. Function code can call `await indicator.RSI(<historical_data>, { Length: 7 })` with the full Historical Data output. Do not pass only a scalar price series or import PineTS directly.
</Callout>

## Outputs

| Reference | Description |
|---|---|
| `<function.result>` | Value returned by the code |
| `<function.stdout>` | Captured console output |

Errors fail the block. Use an error-path connection to handle execution failures, or catch errors within your code when you can recover safely.

## Example: update a counter

Calculate the next value in Function, then assign `<function.result>` with a Variables block:

```typescript
return <variable.retryCount> + 1;
```
