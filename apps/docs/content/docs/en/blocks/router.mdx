## Tools

### `llm_chat`

Send a chat completion request to any supported LLM provider

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `model` | string | Yes | A listed Mastra provider/model identifier |
| `systemPrompt` | string | No | System prompt to set the behavior of the assistant |
| `context` | string | Yes | The user message or context to send to the model |
| `temperature` | number | No | Temperature for response generation, where supported by the selected model |
| `maxTokens` | number | No | Maximum tokens in the response |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | The generated response content |
| `model` | string | The model used for generation |
| `tokens` | object | Available native token usage |
| `cost` | object | Model cost in USD is unavailable |

## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `prompt` | string | Yes | Routing prompt content |
| `model` | string | Yes | AI model to use |
| `apiKey` | string | No | Provider API key |
| `temperature` | number | No | Response randomness level \(low for consistent routing\) |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `prompt` | string | Routing prompt used |
| `model` | string | Model used |
| `tokens` | json | Token usage |
| `cost` | json | Cost information |
| `selectedPath` | json | Selected routing path |


## Usage Instructions

This is a core workflow block. Intelligently direct workflow execution to different paths based on input analysis. Use natural language to instruct the router to route to certain blocks based on the input.
