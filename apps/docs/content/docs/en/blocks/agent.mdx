## Tools

### `llm_chat`

Send a chat completion request to any supported LLM provider

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `model` | string | Yes | Provider/model identifier |
| `systemPrompt` | string | No | System prompt to set the behavior of the assistant |
| `context` | string | Yes | The user message or context to send to the model |
| `temperature` | number | No | Temperature for response generation, where supported by the selected model |
| `maxTokens` | number | No | Maximum tokens in the response |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | The generated response content |
| `model` | string | The model used for generation |
| `tokens` | object | Available native token usage |
| `cost` | object | Reported or estimated model cost in USD, with availability status |

## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | No | Initial system instructions |
| `userPrompt` | string | No | User message or context |
| `memories` | json | No | Agent memory data |
| `model` | string | Yes | AI model to use |
| `apiKey` | string | No | Provider API key |
| `reasoningEffort` | string | No | Selected model reasoning effort. Shown when model supports effort. |
| `responseFormat` | json | No | JSON object containing a JSON Schema in its schema field. Shown when model supports structured output. |
| `tools` | json | No | Available tools configuration |
| `skills` | json | No | Selected skills configuration |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | Generated response content |
| `model` | string | Model used for generation |
| `tokens` | any | Token usage statistics |
| `cost` | object | Reported or estimated model cost in USD, with availability status |


## Usage Instructions

Send system and user prompts to the selected model, optionally with integration tools, custom tools, skills, and conversation history. Configure Tools and Skills directly. Open Additional Fields for the selected model’s reasoning controls, memory, and response format. Choose a thinking level when Mastra Code offers one for the selected model. Mastra manages the agent loop. The final model step supplies the returned content; intermediate commentary and tool results remain in execution history. To retain conversation history across runs, save user and assistant messages with Memory Add, then pass the message array from Get Memory into this block’s Memories field. Workflow variables alone do not persist conversation history. Response Format must contain a JSON Schema in its schema property. Returned JSON fields become top-level outputs alongside response metadata; invalid configuration or malformed JSON fails the run. Without a Response Format, the block returns the standard outputs listed below.
