## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | No | Initial system instructions |
| `userPrompt` | string | No | User message or context |
| `memories` | json | No | Agent memory data |
| `model` | string | Yes | AI model to use |
| `apiKey` | string | No | Provider API key. Shown when applicable to the selected model at runtime. |
| `azureEndpoint` | string | No | Azure OpenAI endpoint URL. Shown when model is one of 'azure/gpt-6.1-sol', 'azure/gpt-6-sol', 'azure/gpt-6-luna', 'azure/gpt-6-astra', 'azure/gpt-5.6-sol', 'azure/gpt-5.6-terra', 'azure/gpt-5.6-luna', 'azure/gpt-5.5', 'azure/gpt-5.4-pro', 'azure/gpt-5.4', 'azure/gpt-5.4-mini', 'azure/gpt-5.4-nano', 'azure/gpt-5.2', 'azure/gpt-5.1', 'azure/gpt-5.1-codex', 'azure/gpt-5', 'azure/gpt-5-mini', 'azure/gpt-5-nano', 'azure/gpt-5-chat', 'azure/o3', 'azure/o4-mini', 'azure/gpt-4.1', 'azure/gpt-4.1-mini', 'azure/gpt-4.1-nano'. |
| `responseFormat` | json | No | JSON object containing a JSON Schema in its schema field |
| `temperature` | number | No | Response randomness level |
| `maxTokens` | number | No | Maximum output tokens |
| `reasoningEffort` | string | No | Model-supported reasoning effort, or auto. Shown when model supports reasoning effort. |
| `verbosity` | string | No | Model-supported response verbosity, or auto. Shown when model supports verbosity. |
| `thinkingLevel` | string | No | Model-supported thinking level, or auto. Shown when model supports thinking level. |
| `tools` | json | No | Available tools configuration |
| `skills` | json | No | Selected skills configuration |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | Generated response content |
| `model` | string | Model used for generation |
| `tokens` | any | Token usage statistics |
| `toolCalls` | any | Tool calls made |
| `toolResults` | any | Tool results returned by the provider |


## Usage Instructions

Send system and user prompts to the selected model, optionally with integration tools, custom tools, skills, and conversation history. Available models come from the deployment catalog and configured provider connections. Configure Tools and Skills directly. Use Additional Fields to configure memory, response format, output token limits, and model-supported temperature, reasoning effort, verbosity, or thinking levels without switching block modes. Unset tuning controls or Auto use the provider’s defaults. To retain conversation history across runs, save user and assistant messages with Memory Add, then pass the message array from Get Memory into this block’s Memories field. Workflow variables alone do not persist conversation history. Response Format must contain a JSON Schema in its schema property. Returned JSON fields become top-level outputs alongside response metadata; invalid configuration or malformed JSON fails the run. Without a Response Format, the block returns the standard outputs listed below.
