## Tools

### `llm_chat`

Send a chat completion request to any supported LLM provider

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `model` | string | Yes | A listed Mastra provider/model identifier |
| `systemPrompt` | string | No | System prompt to set the behavior of the assistant |
| `context` | string | Yes | The user message or context to send to the model |
| `temperature` | number | No | Temperature for response generation, where supported by the selected model |
| `maxTokens` | number | No | Maximum tokens in the response |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | The generated response content |
| `model` | string | The model used for generation |
| `tokens` | object | Reported prompt, completion and total token counts |
| `cost` | object | Reported or estimated USD cost, with availability status |

## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | No | Initial system instructions |
| `userPrompt` | string | No | User message or context |
| `memories` | json | No | Agent memory data |
| `model` | string | Yes | AI model to use |
| `apiKey` | string | No | Provider API key |
| `responseFormat` | json | No | JSON object containing a JSON Schema in its schema field |
| `temperature` | number | No | Response randomness level. Shown when model supports temperature. |
| `maxTokens` | number | No | Maximum output tokens |
| `providerOptions` | json | No | Native provider options for the selected model |
| `tools` | json | No | Available tools configuration |
| `skills` | json | No | Selected skills configuration |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | Generated response content |
| `model` | string | Model used for generation |
| `tokens` | object | Reported prompt, completion and total token counts |
| `cost` | object | Reported or estimated USD cost, with availability status |
| `toolCalls` | any | Tool calls made |
| `toolResults` | any | Tool results returned by the provider |


## Usage Instructions

Send system and user prompts to the selected model, optionally with integration tools, custom tools, skills, and conversation history. Available models come from the configured Mastra registry. Configure Tools and Skills directly. Use Additional Fields to configure memory, response format, output token limits, and model-supported temperature and native Provider Options without switching block modes. Unset tuning controls use the provider’s defaults. To retain conversation history across runs, save user and assistant messages with Memory Add, then pass the message array from Get Memory into this block’s Memories field. Workflow variables alone do not persist conversation history. Response Format must contain a JSON Schema in its schema property. Returned JSON fields become top-level outputs alongside response metadata; invalid configuration or malformed JSON fails the run. Without a Response Format, the block returns the standard outputs listed below.
