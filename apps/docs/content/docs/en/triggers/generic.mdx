Receive webhooks from any service or API

<Callout type="info">
  This is a **webhook-based** trigger. Configure the external service to send events to the workflow webhook URL.
</Callout>


## Setup Instructions

<div class="mb-3"><strong>1.</strong> Copy the webhook URL and use it in your external service or API.</div><div class="mb-3"><strong>2.</strong> Configure your service to send webhooks to this URL.</div><div class="mb-3"><strong>3.</strong> The webhook will receive any HTTP method (GET, POST, PUT, DELETE, etc.).</div><div class="mb-3"><strong>4.</strong> All request data (headers, body, query parameters) will be available in your workflow.</div><div class="mb-3"><strong>5.</strong> If authentication is enabled, include the token in requests using either the custom header or "Authorization: Bearer TOKEN".</div><div class="mb-3"><strong>6.</strong> Common fields like "event", "id", and "data" will be automatically extracted from the payload when available.</div>
