## Setup Instructions

1. Enter a TwiML Response above - this tells Twilio what to do when a call comes in (e.g., play a message, record, gather input). Note: Use square brackets [Tag] instead of angle brackets for TwiML tags

2. Example TwiML for recording with transcription: [Response][Say]Please leave a message.[/Say][Record transcribe="true" maxLength="120"/][/Response]

3. Go to your Twilio Console Phone Numbers page at https://console.twilio.com/us1/develop/phone-numbers/manage/incoming

4. Select the phone number you want to use for incoming calls.

5. Scroll down to the "Voice Configuration" section.

6. In the "A CALL COMES IN" field, select "Webhook" and paste the Webhook URL (from above).

7. Ensure the HTTP method is set to POST.

8. Click "Save configuration".

9. How it works: When a call comes in, Twilio receives your TwiML response immediately and executes those instructions. Your workflow runs in the background with access to caller information, call status, and any recorded/transcribed data.
