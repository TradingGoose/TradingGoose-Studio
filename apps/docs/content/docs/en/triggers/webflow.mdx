## Events

### Collection Item Created

Trigger workflow when a new item is created in a Webflow CMS collection (requires Webflow credentials)

#### Setup Instructions

<div class="mb-3"><strong>1.</strong> Connect your Webflow account using the "Select Webflow credential" button above.</div><div class="mb-3"><strong>2.</strong> Enter your Webflow Site ID (found in the site URL or site settings).</div><div class="mb-3"><strong>3.</strong> Optionally enter a Collection ID to monitor only specific collections.</div><div class="mb-3"><strong>4.</strong> If no Collection ID is provided, the trigger will fire for items created in any collection on the site.</div><div class="mb-3"><strong>5.</strong> The webhook will trigger whenever a new item is created in the specified collection(s).</div><div class="mb-3"><strong>6.</strong> Make sure your Webflow account has appropriate permissions for the specified site.</div>

### Form Submission

Trigger workflow when a form is submitted on a Webflow site (requires Webflow credentials)

#### Setup Instructions

<div class="mb-3"><strong>1.</strong> Connect your Webflow account using the "Select Webflow credential" button above.</div><div class="mb-3"><strong>2.</strong> Enter your Webflow Site ID (found in the site URL or site settings).</div><div class="mb-3"><strong>3.</strong> Optionally enter a Form ID to monitor only a specific form.</div><div class="mb-3"><strong>4.</strong> If no Form ID is provided, the trigger will fire for any form submission on the site.</div><div class="mb-3"><strong>5.</strong> The webhook will trigger whenever a form is submitted on the specified site.</div><div class="mb-3"><strong>6.</strong> Form data will be included in the payload with all submitted field values.</div><div class="mb-3"><strong>7.</strong> Make sure your Webflow account has appropriate permissions for the specified site.</div>
