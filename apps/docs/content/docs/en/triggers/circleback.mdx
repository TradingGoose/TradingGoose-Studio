## Events

### Circleback Meeting Completed

Trigger workflow when a meeting is processed and ready in Circleback

#### Setup Instructions

<div class="mb-3"><strong>Note:</strong> You need access to Circleback automations to set up webhooks.</div><div class="mb-3"><strong>1.</strong> In Circleback, click <strong>Automations</strong> in the sidebar.</div><div class="mb-3"><strong>2.</strong> Create a new automation or edit an existing one.</div><div class="mb-3"><strong>3.</strong> Add a <strong>Send webhook request</strong> step to your automation.</div><div class="mb-3"><strong>4.</strong> Paste the <strong>Webhook URL</strong> from above into the Endpoint field.</div><div class="mb-3"><strong>5.</strong> Optionally, copy the <strong>Signing Secret</strong> from Circleback and paste it above to verify webhook signatures.</div><div class="mb-3"><strong>6.</strong> Toggle what to include in the request (Meeting notes, Action items, Transcript). For this trigger: <strong>All meeting data</strong>.</div><div class="mb-3"><strong>7.</strong> Click <strong>"Done"</strong> and save the automation.</div>
