## Events

### HubSpot Contact Created

Trigger workflow when a new contact is created in HubSpot

#### Setup Instructions

<div class="mb-3"><strong>Step 1: Create a HubSpot Developer Account</strong><br />Sign up for a free developer account at <a href="https://developers.hubspot.com" target="_blank">developers.hubspot.com</a> if you don't have one.</div><div class="mb-3"><strong>Step 2: Create a Public App via CLI</strong><br /><strong>Note:</strong> HubSpot has deprecated the web UI for creating apps. You must use the HubSpot CLI to create and manage apps. Install the CLI with <code>npm install -g @hubspot/cli</code> and run <code>hs project create</code> to create a new app. See <a href="https://developers.hubspot.com/docs/platform/create-an-app" target="_blank">HubSpot's documentation</a> for details.</div><div class="mb-3"><strong>Step 3: Save OAuth App Credentials</strong><br />Add <code>https://www.tradinggoose.ai/api/auth/oauth2/callback/hubspot</code> to your HubSpot OAuth redirect URLs. Retrieve your <strong>Client ID</strong> and <strong>Client Secret</strong> from your HubSpot app configuration and enter them in the fields above.</div><div class="mb-3"><strong>Step 4: Get App ID and Developer API Key</strong><br />In your HubSpot developer account, find your <strong>App ID</strong> (shown below your app name) and your <strong>Developer API Key</strong> (in app settings). You'll need both for the next steps.</div><div class="mb-3"><strong>Step 5: Set Required Scopes</strong><br />Configure your app to include the required OAuth scope: <code>crm.objects.contacts.read</code></div><div class="mb-3"><strong>Step 6: Save Configuration in TradingGoose</strong><br />Click the <strong>"Save Configuration"</strong> button above. This will generate your unique webhook URL.</div><div class="mb-3"><strong>Step 7: Configure Webhook in HubSpot via API</strong><br />After saving above, copy the <strong>Webhook URL</strong> and run the two curl commands below (replace <code>&#123;YOUR_APP_ID&#125;</code>, <code>&#123;YOUR_DEVELOPER_API_KEY&#125;</code>, and <code>&#123;YOUR_WEBHOOK_URL_FROM_ABOVE&#125;</code> with your actual values).</div><div class="mb-3"><strong>Step 8: Test Your Webhook</strong><br />Create or modify a contact in HubSpot to trigger the webhook. Check your workflow execution logs in TradingGoose to verify it's working.</div><div class="mb-3"><strong>Additional Info:</strong> The webhook will trigger whenever a new contact is created in your HubSpot account, regardless of the source (manual entry, form submission, API, import, etc.).</div>
