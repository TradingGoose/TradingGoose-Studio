## Events

### Microsoft Teams Channel

Trigger workflow from Microsoft Teams channel messages via outgoing webhooks

#### Setup Instructions

<div class="mb-3"><strong>1.</strong> Open Microsoft Teams and go to the team where you want to add the webhook.</div><div class="mb-3"><strong>2.</strong> Click the three dots (•••) next to the team name and select "Manage team".</div><div class="mb-3"><strong>3.</strong> Go to the "Apps" tab and click "Create an outgoing webhook".</div><div class="mb-3"><strong>4.</strong> Provide a name, description, and optionally a profile picture.</div><div class="mb-3"><strong>5.</strong> Set the callback URL to your TradingGoose webhook URL above.</div><div class="mb-3"><strong>6.</strong> Copy the HMAC security token and paste it into the "HMAC Secret" field.</div><div class="mb-3"><strong>7.</strong> Click "Create" to finish setup.</div>

### Microsoft Teams Chat

Trigger workflow from new messages in Microsoft Teams chats via Microsoft Graph subscriptions

#### Setup Instructions

<div class="mb-3"><strong>1.</strong> Connect your Microsoft Teams account and grant the required permissions.</div><div class="mb-3"><strong>2.</strong> Enter the Chat ID of the Teams chat you want to monitor.</div><div class="mb-3"><strong>3.</strong> We will create a Microsoft Graph change notification subscription that delivers chat message events to your TradingGoose webhook URL.</div>
