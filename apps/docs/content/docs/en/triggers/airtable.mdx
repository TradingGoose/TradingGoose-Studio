Trigger workflow from Airtable record changes like create, update, and delete events (requires Airtable credentials)

<Callout type="info">
  This is a **webhook-based** trigger. Configure the external service to send events to the workflow webhook URL.
</Callout>

<Cards>
  <Card title="Use as a Tool" href="/tools/airtable">
    See workflow actions, operations, and tool inputs for Airtable.
  </Card>
</Cards>


## Setup Instructions

<div class="mb-3"><strong>1.</strong> Connect your Airtable account using the "Select Airtable credential" button above.</div><div class="mb-3"><strong>2.</strong> Ensure you have provided the correct Base ID and Table ID above.</div><div class="mb-3"><strong>3.</strong> You can find your Base ID in the Airtable URL: https://airtable.com/[baseId]/...</div><div class="mb-3"><strong>4.</strong> You can find your Table ID by clicking on the table name and looking in the URL.</div><div class="mb-3"><strong>5.</strong> The webhook will trigger whenever records are created, updated, or deleted in the specified table.</div><div class="mb-3"><strong>6.</strong> Make sure your Airtable account has appropriate permissions for the specified base.</div>
