Triggers when Stripe events occur (payments, subscriptions, invoices, etc.)

<Callout type="info">
  This is a **webhook-based** trigger. Configure the external service to send events to the workflow webhook URL.
</Callout>

<Cards>
  <Card title="Use as a Tool" href="/tools/stripe">
    See workflow actions, operations, and tool inputs for Stripe.
  </Card>
</Cards>


## Setup Instructions

<div class="mb-3"><strong>1.</strong> Open the <a href="https://dashboard.stripe.com/webhooks" target="_blank" rel="noopener noreferrer">Stripe webhook settings</a></div><div class="mb-3"><strong>2.</strong> Click "Add destination" button</div><div class="mb-3"><strong>3.</strong> In "Events to send", select the events you want to listen to (must match the events selected above, or select "Select all events" to receive everything)</div><div class="mb-3"><strong>4.</strong> Select <code>Webhook Endpoint</code>, press continue, and paste the <strong>Webhook URL</strong> above into the "Endpoint URL" field</div><div class="mb-3"><strong>5.</strong> Click "Create Destination" to save</div><div class="mb-3"><strong>6.</strong> After creating the endpoint, click "Reveal" next to "Signing secret" and copy it</div><div class="mb-3"><strong>7.</strong> Paste the signing secret into the <strong>Webhook Signing Secret</strong> field above</div><div class="mb-3"><strong>8.</strong> Click "Save" to activate your webhook trigger</div>
