## Events

### Grain Webhook

Generic webhook trigger for all Grain events

#### Setup Instructions

<div class="mb-3"><strong>1.</strong> Enter your Grain API Key (Personal Access Token) above.</div><div class="mb-3"><strong>2.</strong> You can find or create your API key in Grain at <strong>Settings > Integrations > API</strong>.</div><div class="mb-3"><strong>3.</strong> Click <strong>"Save Configuration"</strong> to automatically create the webhook in Grain for <strong>All events</strong> events.</div><div class="mb-3"><strong>4.</strong> The webhook will be automatically deleted when you remove this trigger.</div>

<ShowcaseCard>
  <BlockConfigPreview
    name="Grain Webhook"
    type="grain_webhook"
    hideHeader
    subBlocks={[
        {
            "id": "apiKey",
            "type": "short-input",
            "title": "API Key",
            "placeholder": "Enter your Grain API key (Personal Access Token)",
            "description": "Required to create the webhook in Grain.",
            "password": true,
            "required": true
        }
    ]}
  />
</ShowcaseCard>

#### Output Schema

<SchemaTree
  title="Event Payload"
  fields={[
      {
          "name": "type",
          "type": "string",
          "description": "Event type (e.g., recording_added)"
      },
      {
          "name": "user_id",
          "type": "string",
          "description": "User UUID who triggered the event"
      },
      {
          "name": "data",
          "type": "object",
          "description": "Event data object (recording, highlight, etc.)"
      }
  ]}
/>
