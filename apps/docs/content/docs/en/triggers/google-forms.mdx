## Setup Instructions

<div class="mb-3"><strong>1.</strong> Open your Google Form → More (⋮) → Script editor.</div><div class="mb-3"><strong>2.</strong> Paste the Apps Script snippet from below into <code>Code.gs</code> → Save.</div><div class="mb-3"><strong>3.</strong> Triggers (clock icon) → Add Trigger → Function: <code>onFormSubmit</code> → Event source: <code>From form</code> → Event type: <code>On form submit</code> → Save.</div><div class="mb-3"><strong>4.</strong> Authorize when prompted. Submit a test response and verify the run in TradingGoose → Logs.</div>
