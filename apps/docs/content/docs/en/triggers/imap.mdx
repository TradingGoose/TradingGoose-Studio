Triggers when new emails are received via IMAP (works with any email provider)

<Callout type="info">
  This is a **polling-based** trigger. TradingGoose checks the source for matching changes on a regular interval.
</Callout>


## Setup Instructions

<div class="mb-3"><strong>1.</strong> Enter your IMAP server details (host, port, SSL settings)</div><div class="mb-3"><strong>2.</strong> Enter your email credentials (username and password)</div><div class="mb-3"><strong>3.</strong> For Gmail: Use an <a href="https://support.google.com/accounts/answer/185833" target="_blank">App Password</a> instead of your regular password</div><div class="mb-3"><strong>4.</strong> Select the mailbox to monitor (INBOX is most common)</div><div class="mb-3"><strong>5.</strong> Optionally configure search criteria and processing options</div><div class="mb-3"><strong>6.</strong> The system will automatically check for new emails and trigger your workflow</div>
