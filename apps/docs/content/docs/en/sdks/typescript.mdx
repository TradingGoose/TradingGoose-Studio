title: TypeScript SDK
description: TypeScript and JavaScript client for TradingGoose workflows
---

## Install

```bash
npm install tradinggoose-ts-sdk
```

## Execute a workflow

```typescript
import { TradingGooseClient } from 'tradinggoose-ts-sdk'

const client = new TradingGooseClient({
  apiKey: process.env.TRADINGGOOSE_API_KEY!,
  baseUrl: 'https://tradinggoose.ai',
})

const result = await client.executeWorkflow('workflow-id', {
  input: { message: 'Analyze this' },
  timeout: 30000,
  stream: true,
  selectedOutputs: ['agent1.content'],
})
```

`ExecutionOptions` contains `input`, `timeout` (milliseconds, default `30000`), `stream`, and `selectedOutputs`. The streaming fields are request controls; the current SDK returns a `WorkflowExecutionResult`, not an SSE iterator.

## Status and validation

- `getWorkflowStatus(workflowId)` returns `WorkflowStatus`.
- `validateWorkflow(workflowId)` returns whether the workflow is deployed.
- `setApiKey(apiKey)` and `setBaseUrl(baseUrl)` update client configuration.

## Retry and limits

`executeWithRetry(workflowId, options, retryOptions)` retries only `RATE_LIMIT_EXCEEDED`. `RetryOptions` defaults to `maxRetries: 3`, `initialDelay: 1000` ms, `maxDelay: 30000` ms, and `backoffMultiplier: 2`. The client honors `Retry-After` and applies ±25% jitter.

- `getRateLimitInfo(): RateLimitInfo | null` exposes `limit`, `remaining`, `reset`, and optional `retryAfter` in milliseconds.
- `getUsageLimits(): Promise<UsageLimits>` exposes sync and async `isLimited`, `limit`, `remaining`, and `resetAt`, plus `authType` and usage `currentPeriodCost`, `limit`, and `plan`.

## Errors and results

`TradingGooseError` preserves API `code` and HTTP `status`. The client uses `TIMEOUT`, `EXECUTION_ERROR`, `STATUS_ERROR`, `RATE_LIMIT_EXCEEDED`, and `USAGE_ERROR` for its own failure paths. Successful execution returns `WorkflowExecutionResult` with `success` and optional output, error, logs, metadata, trace spans, and duration.

See the [TypeScript SDK package README](https://github.com/TradingGoose/TradingGoose-Studio/blob/staging/packages/ts-sdk/README.md) for complete examples and file-upload behavior.
