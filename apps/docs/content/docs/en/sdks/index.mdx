import { Card, Cards } from 'fumadocs-ui/components/card'

TradingGoose provides published TypeScript/JavaScript and Python SDKs for executing deployed workflows, checking deployment status, controlling selected outputs, handling rate limits, and querying usage limits.

<Cards>
  <Card title="Python SDK" href="/sdks/python">
    Install `tradinggoose-sdk` for a synchronous Python client.
  </Card>
  <Card title="TypeScript SDK" href="/sdks/typescript">
    Install `tradinggoose-ts-sdk` for Node.js and browser applications.
  </Card>
</Cards>

Both clients authenticate with an API key through `X-API-Key` and default to `https://tradinggoose.ai`. They expose workflow execution and status, retry-on-rate-limit behavior, rate-limit metadata, and usage limits. Language-specific names, types, and timeout units are documented on their respective pages.

For direct HTTP integration, see the [Execution API](/execution/api).
