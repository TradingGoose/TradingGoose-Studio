The TradingGoose Studio repository contains preview TypeScript/JavaScript and Python clients for executing deployed workflows, checking deployment status, handling rate limits, and querying usage limits.

> The SDK packages are under development and are not currently published to npm or PyPI. The installation commands for those registries are therefore unavailable. For production integrations, use the supported [Execution API](/execution/api).

When used from repository source, both clients authenticate with an API key through `X-API-Key` and default to `https://www.tradinggoose.ai`. They expose non-streaming workflow execution and status, retry-on-rate-limit behavior, and usage limits. Language-specific names, types, limitations, and timeout units are documented on their respective pages.

Streaming execution is available from the HTTP API as server-sent events, but the preview SDK clients do not consume that stream. Use the [Execution API](/execution/api) directly for streaming or when you need a Response block's custom HTTP status and headers.
