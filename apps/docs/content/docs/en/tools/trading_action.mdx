## Tools

### `trading_place_order`

Place buy or sell orders via Alpaca or Tradier.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `provider` | string | Yes | Broker provider selected for account and listing availability. |
| `portfolioIdentity` | json | Yes | Canonical broker account identity selected for this order. |
| `listing` | listingIdentity | Yes | Structured listing payload for the asset to trade. |
| `side` | string | Yes | Order side: buy or sell. |
| `quantity` | number | No | Quantity to trade when the selected provider sizing mode is quantity. |
| `notional` | number | No | Dollar amount to trade when supported by the selected provider. |
| `orderSizingMode` | string | No | Order sizing mode selected from trading provider capabilities. |
| `orderType` | string | No | Order type selected from trading provider capabilities. |
| `timeInForce` | string | No | Time in force \(day, gtc, gfd, etc.\). |
| `limitPrice` | number | No | Limit price \(required for limit orders\). |
| `stopPrice` | number | No | Stop price when required by the selected order type. |
| `trailPrice` | number | No | Trailing price offset when supported by the selected order type. |
| `trailPercent` | number | No | Trailing percent offset when supported by the selected order type. |
| `preview` | boolean | No | Preview the provider order without submitting when supported. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `summary` | string | Status message for the order submission. |
| `provider` | string | Broker/provider used for the order. |
| `appOrderId` | string | Trading Goose order ID. |
| `clientOrderId` | string | Broker client order identity for retries. |
| `order` | json | Normalized order details and raw response. |


## Usage Instructions

Unified trading action block that submits orders from a selected broker account.
