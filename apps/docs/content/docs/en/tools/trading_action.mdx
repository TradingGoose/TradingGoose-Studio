## Tools

### `trading_place_order`

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `summary` | string | Order submission status |
| `provider` | string | Provider used |
| `appOrderId` | string | Trading Goose order ID |
| `clientOrderId` | string | Broker client order identity |
| `order` | json | Order payload and raw response |


## Usage Instructions

Unified trading action block that submits orders from a selected broker account.
