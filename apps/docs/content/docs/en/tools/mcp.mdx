## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `server` | string | Yes | MCP server ID to execute the tool on |
| `tool` | string | No | Name of the tool to execute |
| `arguments` | json | No | Arguments to pass to the tool |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | array | Content array from MCP tool response - the standard format for all MCP tools |


## Usage Instructions

Integrate MCP into the workflow. Can execute tools from MCP servers configured in the workspace dashboard widgets.
