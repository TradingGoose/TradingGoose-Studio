## Tools

### `openai_embeddings`

Generate embeddings from text using OpenAI's embedding models

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `input` | string | Yes | Exact text or an array of texts to generate embeddings for |
| `model` | string | No | Listed native OpenAI embedding provider/model identifier |
| `apiKey` | string | Yes | OpenAI API key |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `success` | boolean | Operation success status |
| `output` | object | Embeddings generation results |
| `output.tokens` | object | Reported prompt and total token counts |
| `output.cost` | object | Reported or estimated USD cost, with availability status |
| `output.embeddingUsage` | object | Completed batch count and usage availability |


## Usage Instructions

Generate embeddings from exact input text. Select a listed OpenAI embedding model using its full provider/model identifier. Inputs above the selected model limit are rejected. Reported token counts and available USD costs accompany the vectors. Missing counters stay unknown; a later batch failure retains completed usage and marks incomplete cost coverage.
