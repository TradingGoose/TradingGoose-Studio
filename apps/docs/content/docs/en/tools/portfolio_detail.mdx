## Tools

### `trading_get_portfolio_detail`

Fetch account summary, cash, and supported position fields from a connected trading provider.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `portfolioIdentity` | json | Yes | Canonical portfolioIdentity selected by the broker account field. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `summary` | string | Status message for portfolio detail retrieval. |
| `provider` | string | Broker/provider used for the request. |
| `portfolioDetail` | json | Portfolio fields supported by the selected broker. |


## Usage Instructions

Returns account summary, cash, and position fields supported by the selected trading provider.
