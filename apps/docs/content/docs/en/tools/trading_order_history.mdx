## Tools

### `trading_order_history`

Retrieve workspace order submissions recorded within a datetime range.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `startDate` | string | Yes | Start datetime \(ISO 8601\). |
| `endDate` | string | Yes | End datetime \(ISO 8601\). |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `history` | array | Ordered list of recorded order submissions. |
| `count` | number | Number of records returned. |
| `workspaceId` | string | Workspace ID used for filtering. |
| `startDate` | string | Start datetime used for filtering. |
| `endDate` | string | End datetime used for filtering. |


## Usage Instructions

Fetches order submission history recorded by the Trading Action tool for the selected date range.
