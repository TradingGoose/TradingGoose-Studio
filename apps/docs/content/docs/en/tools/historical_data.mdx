## Tools

### `historical_data_fetch`

Fetch and normalize market series data from registered market providers.

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `provider` | string | Yes | Market data provider id \(e.g., alpaca, finnhub, yahoo-finance\). |
| `listing` | listingIdentity | Yes | Structured listing payload from TradingGoose Market. |
| `apiKey` | string | Yes | Alpha Vantage API key. |
| `apiSecret` | string | Yes | Alpaca API secret key. |
| `feed` | string | Yes | Alpaca data feed \(required for stock bars\). |
| `interval` | string | No | Series interval/timeframe supported by the provider. |
| `normalizationMode` | string | No | Normalization mode supported by the provider \(optional\). |
| `window` | json | Yes | Primary series window \(range, bars, or absolute\). |
| `fallbackWindow` | json | No | Fallback series window if the primary is unsupported or invalid. |
| `providerParams` | json | No | Optional provider-specific parameters. |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `listingBase` | string | Listing base symbol |
| `listingQuote` | string | Listing quote currency |
| `listing` | listingIdentity | Structured listing identifier payload |
| `bars` | array | OHLCV bars with timestamps |
| `start` | string | Start of the returned series |
| `end` | string | End of the returned series |
| `timezone` | string | Exchange timezone for the series |
| `normalizationMode` | string | Normalization mode used |


## Usage Instructions

Choose a market data provider, select a canonical listing, and fetch series bars that include open, high, low, close, volume, and timestamps. Start and end can be ISO strings or UNIX timestamps.
