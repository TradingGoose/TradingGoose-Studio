## Tools

### `llm_chat`

Send a chat completion request to any supported LLM provider

#### Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `model` | string | Yes | A listed Mastra provider/model identifier |
| `systemPrompt` | string | No | System prompt to set the behavior of the assistant |
| `context` | string | Yes | The user message or context to send to the model |
| `temperature` | number | No | Temperature for response generation, where supported by the selected model |
| `maxTokens` | number | No | Maximum tokens in the response |

#### Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | The generated response content |
| `model` | string | The model used for generation |
| `tokens` | object | Reported prompt, completion and total token counts |
| `cost` | object | Reported or estimated USD cost, with availability status |


## Usage Instructions

Translate text to any language. The model list comes from the configured Mastra registry.
