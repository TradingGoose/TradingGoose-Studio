## Input

| Parameter | Type | Required | Description |
| --------- | ---- | -------- | ----------- |
| `context` | string | Yes | Text to translate |
| `targetLanguage` | string | Yes | Target language |
| `model` | combobox | Yes | Model |
| `apiKey` | string | No | Provider API key |
| `azureEndpoint` | string | No | Azure OpenAI endpoint URL |
| `azureApiVersion` | string | No | Azure API version |

## Output

| Parameter | Type | Description |
| --------- | ---- | ----------- |
| `content` | string | Translated text |
| `model` | string | Model used |
| `tokens` | json | Token usage |


## Usage Instructions

Translate text to any language. The model list is loaded at runtime from the base, Ollama, and OpenRouter models available to the deployment.
