知识区块将你的工作流连接到知识库，通过执行向量相似度搜索、上传新片段和创建文档来启用检索增强生成（RAG）——全部在运行时完成。

## 概述

<Steps>
  <Step>
    <strong>搜索</strong>：针对知识库运行语义相似度查询，检索最相关的片段
  </Step>
  <Step>
    <strong>上传片段</strong>：将新的文本片段追加到现有文档，使其在未来的查询中可被搜索
  </Step>
  <Step>
    <strong>创建文档</strong>：向知识库添加全新文档（可带标签）
  </Step>
</Steps>

## 操作

<Tabs items={['搜索', '上传片段', '创建文档']}>
  <Tab>
    执行向量相似度搜索，并返回最匹配的片段。

    | 字段 | 必填 | 说明 |
    |---|---|---|
    | **知识库** | 是 | 要搜索的知识库 |
    | **搜索查询** | 当前可用搜索需要 | 自然语言查询；请参阅下方标签过滤限制。 |
    | **结果数量** | 否 | 返回的片段数量（默认：10） |
    | **标签筛选** | 否 | 将结果缩小到匹配特定标签的文档 |

    标签过滤是预期能力，但当前仅按标签搜索会失败，查询与标签同时提供时不会应用标签。修复前请勿依赖标签来限制结果。
  </Tab>
  <Tab>
    将文本片段追加到知识库中的现有文档。片段会自动嵌入，并在后续搜索中可用。

    | 字段 | 必填 | 说明 |
    |---|---|---|
    | **知识库** | 是 | 目标知识库 |
    | **文档** | 是 | 要添加分块的文档 |
    | **分块内容** | 是 | 要上传的文本内容 |
  </Tab>
  <Tab>
    在知识库中创建新文档。内容会被分块、嵌入并建立索引。

    | 字段 | 必填 | 说明 |
    |---|---|---|
    | **知识库** | 是 | 目标知识库 |
    | **文档名称** | 是 | 新文档的名称 |
    | **文档内容** | 是 | 完整文本内容 |
    | **文档标签** | 否 | 用于分类和筛选的标签 |
  </Tab>
</Tabs>

## 输出

| 操作 | 输出 |
|---|---|
| Search | `results`（匹配分块）、`query`、`totalResults` |
| Upload Chunk | `message`、`data.chunkId`、`data.content`、`data.chunkIndex`，以及 `documentId`、`documentName`、`cost` |
| Create Document | `message` 和包含 `documentId`、`documentName`、`type`、`enabled`、`createdAt`、`updatedAt` 的 `data` |

在 Create Document 后使用 `<knowledge.data.documentId>`。写入确认信息不在 `results` 中。

## 最佳实践

- **保持块聚焦** -- 更短、主题连贯的块比冗长、多主题的文本能产生更好的相似度匹配。
- **与 Agent 块配合使用** -- 将搜索结果传入 Agent 的上下文，以构建 RAG 管道。

<Callout type="warning">
  当前标签过滤不可靠：仅按标签搜索会失败，查询加标签的搜索不会按标签过滤。请参阅[知识库](/knowledgebase)。使用非空查询并检查返回文档；标签不是访问控制边界。
</Callout>
