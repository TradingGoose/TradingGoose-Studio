## 使用和输出

选择验证类型并提供文本。幻觉检查使用选定模型和参考上下文进行原生结构化生成。JSON 验证和个人信息验证保持原有行为。输出包括 `passed` 和验证类型，并按操作提供 `score`、`reasoning`、`maskedText` 或检测到的实体。

## 用量和费用

记录会区分提供方报告的费用、原生估算费用和不可用费用。缺失费用不等于零；即使美元金额缺失，已知 token 用量仍会保留。产品自身的费用单独计算。独立嵌入保留向量及可用的原生用量，其美元费用显示为不可用。
