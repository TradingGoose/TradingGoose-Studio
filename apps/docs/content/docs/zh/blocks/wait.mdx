等待块会将你的工作流暂停指定时长，然后再继续执行下一个块。可用于在操作之间添加延迟、遵守 API 速率限制或分散操作。

## 概述

等待块可用于：

<Steps>
  <Step>
    <strong>添加时间延迟</strong>：在工作流步骤之间暂停执行
  </Step>
  <Step>
    <strong>遵守速率限制</strong>：分散 API 调用以保持在限制内
  </Step>
  <Step>
    <strong>安排序列</strong>：创建带有操作间延迟的定时工作流
  </Step>
</Steps>

## 配置

### 等待时长

输入暂停执行的时长：
- **输入**：正数
- **最大值**：600 秒（10 分钟）或 10 分钟

### 单位

选择时间单位：
- **秒**：用于短暂、精确的延迟
- **分钟**：用于较长的暂停

<Callout type="info">
  等待块可以通过停止工作流来取消。最大等待时间为 10 分钟。
</Callout>

## 输出

- **`<wait.waitDuration>`**：等待时长（毫秒）
- **`<wait.status>`**：等待状态（'waiting'、'completed' 或 'cancelled'）

## 最佳实践

- **保持等待时间合理**：使用等待块处理最长 10 分钟的延迟。对于更长的延迟，考虑使用计划工作流
- **监控执行时间**：请记住，等待会延长总工作流持续时间
