工作流块会在当前（父）工作流内执行另一个（子）工作流。它会读取子工作流的 **输入表单触发器** 架构，并展示映射 UI，以便你将父变量传入子工作流预期的输入。这是将复杂自动化模块化为可复用子工作流的主要机制。

## 概述

<Steps>
  <Step>
    <strong>选择子工作流</strong>：选择工作区中的任意工作流（当前工作流除外）
  </Step>
  <Step>
    <strong>映射输入</strong>：该块会读取子工作流的输入表单触发器，并显示每个预期字段。为每个字段映射父变量或硬编码值。
  </Step>
  <Step>
    <strong>执行</strong>：子工作流将使用映射的输入运行至完成
  </Step>
  <Step>
    <strong>返回结果</strong>：子工作流的最终输出将作为该块的 `result` 输出返回给父工作流
  </Step>
</Steps>

## 工作原理

子工作流必须使用 **输入表单触发器** 作为起始块。该触发器定义输入架构（字段名称、类型和描述）。在此块中选择子工作流时，输入映射 UI 会动态呈现这些字段，以便你将其连接起来。

运行时，该块会：

1. 从父工作流的当前状态解析所有映射值。
2. 调用子工作流的执行器，并传入解析后的输入。
3. 等待子工作流完成。
4. 从子工作流执行中返回 `success`、`childWorkflowName` 以及完整的 `result`。

<Callout type="info">
  下拉列表仅显示你工作区中与当前工作流不同的工作流。你无法递归调用工作流。
</Callout>

### 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| **选择工作流** | 是 | 要执行的子工作流。必须具有输入表单触发器。 |
| **输入映射** | -- | 将父工作流的值动态映射到子工作流的触发器结构。选择工作流后显示。 |

## 输出

| 输出 | 类型 | 说明 |
|---|---|---|
| `success` | boolean | 子工作流是否成功完成 |
| `childWorkflowName` | string | 所执行子工作流的名称 |
| `result` | json | 子工作流的完整执行结果 |
| `error` | string | 子工作流失败时的错误信息 |

## 最佳实践

- **设计具有清晰输入表单触发器的子工作流** -- 以描述性方式命名字段，以便在父工作流中轻松使用映射界面。
- **保持子工作流专注** -- 子工作流应做好一件事，使其可在多个父工作流中复用。
- **检查 `success` 输出** -- 在工作流块之后使用条件块，以妥善处理失败。
