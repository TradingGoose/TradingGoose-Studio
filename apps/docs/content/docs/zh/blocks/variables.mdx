## 如何使用变量

### 1. 在工作流变量中初始化

首先，在工作流的“变量”部分创建变量（可从工作流设置中访问）：

```
customerEmail = ""
retryCount = 0
currentStatus = "pending"
```

### 2. 使用变量块更新

使用变量块在执行期间更新这些值：

```
customerEmail = <api.email>
retryCount = <variable.retryCount> + 1
currentStatus = "processing"
```

### 3. 随处访问

在任何块中引用变量：

```
Agent prompt: "Send email to <variable.customerEmail>"
Condition: <variable.retryCount> < 5
API body: {"status": "<variable.currentStatus>"}
```

## 输出

- **`<variables.assignments>`**：包含此块所有变量赋值的 JSON 对象

## 最佳实践

- **在工作流设置中初始化**：使用前，请始终在工作流的变量部分创建变量
- **动态更新**：使用变量块根据块输出或计算结果更新值
- **在循环中使用**：非常适合跨迭代跟踪状态
- **使用描述性名称**：使用清晰的名称，如 `currentIndex`、`totalProcessed` 或 `lastError`
