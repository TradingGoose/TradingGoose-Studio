## 概述

Router 区块让你可以：

<Steps>
  <Step>
    <strong>智能内容路由</strong>：使用 AI 理解意图和上下文
  </Step>
  <Step>
    <strong>动态路径选择</strong>：基于非结构化内容分析来路由工作流
  </Step>
  <Step>
    <strong>上下文感知决策</strong>：做出超越简单规则的智能路由选择
  </Step>
  <Step>
    <strong>多路径管理</strong>：处理具有多个潜在目标的复杂工作流
  </Step>
</Steps>

## 路由块与条件块对比

<Accordions>
  <Accordion title="何时使用路由块">
    - 需要 AI 驱动的内容分析
    - 内容类型非结构化或变化多样
    - 基于意图的路由（例如，将支持工单路由到相应部门）
    - 需要结合上下文的决策
  </Accordion>
  <Accordion title="何时使用条件块">
    - 简单、基于规则的决策
    - 结构化数据或数值比较
    - 需要快速、确定性的路由
    - 布尔逻辑即可满足
  </Accordion>
</Accordions>

## 工作原理

路由块：

<Steps>
  <Step>
    <strong>分析内容</strong>：使用 LLM 理解输入的内容与上下文
  </Step>
  <Step>
    <strong>评估目标</strong>：将内容与可用的目标块进行比较
  </Step>
  <Step>
    <strong>选择目标</strong>：根据意图确定最合适的路径
  </Step>
  <Step>
    <strong>执行路由</strong>：将工作流导向选定的块
  </Step>
</Steps>

## 配置选项

### 内容/提示词

路由块用于分析并做出路由决策的内容或提示词。可以是：

- 用户的直接查询或输入
- 上一个块的输出
- 系统生成的消息

### 目标块

路由块可供选择的目标块。路由块会自动检测已连接的块，但你也可以：

- 自定义目标块的描述，以提高路由准确性
- 为每个目标块指定路由条件
- 将某些块排除在路由目标之外

### 模型选择

选择一个 AI 模型来驱动路由决策：

**OpenAI**：GPT-4o、o1、o3、o4-mini、gpt-4.1  \
**Anthropic**：Claude 3.7 Sonnet \
**Google**：Gemini 2.5 Pro、Gemini 2.0 Flash \
**其他提供商**：Groq、Cerebras、xAI、DeepSeek \
**本地模型**：任何在 Ollama 上运行的模型

**建议**：使用 GPT-4o 或 Claude 3.7 Sonnet 等具备强推理能力的模型，以获得更准确的路由决策。

### API 密钥

所选 LLM 提供商的 API 密钥。该密钥会被安全存储，并用于身份验证。

### 访问结果

路由器做出决策后，你可以访问其输出：

- **`<router.prompt>`**：所用路由提示词的摘要
- **`<router.selected_path>`**：所选目标块的详情
- **`<router.tokens>`**：LLM 的 token 用量统计
- **`<router.cost>`**：路由调用的成本汇总（输入、输出、总计）
- **`<router.model>`**：用于决策的模型

## 最佳实践

- **提供清晰的目标描述**：通过具体、详细的描述帮助路由器理解何时选择每个目标
- **使用具体的路由条件**：为每条路径定义清晰的条件和示例以提高准确性
- **实现回退路径**：连接默认目标，以便在没有合适路径时使用
- **使用多样输入进行测试**：确保路由器处理各种输入类型、边缘情况和意外内容
- **监控路由性能**：定期审查路由决策，并根据实际使用模式优化条件
- **选择合适的模型**：对于复杂的路由决策，使用具有强大推理能力的模型
