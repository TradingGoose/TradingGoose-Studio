块是您连接在一起以创建AI工作流的构建组件。将它们视为专用模块，每个模块负责特定任务——从与AI模型聊天到进行API调用或处理数据。

## 核心块类型

TradingGoose提供处理AI工作流核心功能的基本块类型：

### 处理块
- **[智能体](/blocks/agent)** - 与AI模型（OpenAI、Anthropic、Google、本地模型）聊天
- **[函数](/blocks/function)** - 运行自定义JavaScript/TypeScript代码
- **[API](/blocks/api)** - 通过HTTP请求连接外部服务

### 逻辑块
- **[条件](/blocks/condition)** - 基于布尔表达式分支工作流路径
- **[路由](/blocks/router)** - 使用AI智能地将请求路由到不同路径
- **[评估器](/blocks/evaluator)** - 使用AI对内容质量进行评分和评估

### 控制流块
- **[变量](/blocks/variables)** - 设置和管理工作流范围的变量
- **[等待](/blocks/wait)** - 暂停工作流执行指定时间

### 输出块
- **[响应](/blocks/response)** - 格式化并返回工作流的最终结果

## 块如何工作

每个块有三个主要组件：

**输入**：来自其他块或用户输入的数据进入块
**配置**：控制块行为的设置
**输出**：块为其他块使用而生成的数据

<Steps>
  <Step>
    <strong>接收输入</strong>：块从连接的块或用户输入接收数据
  </Step>
  <Step>
    <strong>处理</strong>：块根据其配置处理输入
  </Step>
  <Step>
    <strong>输出结果</strong>：块为工作流中的下一个块生成输出数据
  </Step>
</Steps>

## 连接块

通过将块连接在一起创建工作流。一个块的输出成为另一个块的输入：

- **拖拽连接**：从输出端口拖拽到输入端口
- **多重连接**：一个输出可以连接到多个输入
- **分支路径**：某些块可以根据条件路由到不同的路径

## 常见模式

### 顺序处理
将块连接成链，每个块处理前一个块的输出：

```
User Input → Agent → Function → Response
```

### 条件分支
使用条件或路由块创建不同的路径：

```
User Input → Router → Agent A (for questions)
                   → Agent B (for commands)
```

### 质量控制
使用评估器块来评估和过滤输出：

```
Agent → Evaluator → Condition → Response (if good)
                              → Agent (retry if bad)
```

## 块配置

每种块类型都有特定的配置选项：

**所有块**：
- 输入/输出连接
- 错误处理行为
- 执行超时设置

**AI 块**（代理、路由、评估器）：
- 模型选择（OpenAI、Anthropic、Google、本地）
- API 密钥和认证
- 温度和其他模型参数
- 系统提示和指令

**逻辑块**（条件、函数）：
- 自定义表达式或代码
- 变量引用
- 执行环境设置

**集成块**（API、响应）：
- 端点配置
- 标头和认证
- 请求/响应格式化
