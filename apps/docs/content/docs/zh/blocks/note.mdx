Note 模块是工作流画布上的纯可视化注释。它不会执行，没有输入或输出，执行器会完全忽略它。你可以用它记录决策、为协作者留下说明，或解释工作流中的复杂部分。

## 概述

Note 模块仅用于组织信息：

- **记录设计决策** -- 说明选择特定分支策略或模型的原因。
- **留下说明** -- 告知协作者如何配置环境变量，或说明工作流某个部分的作用。
- **嵌入参考资料** -- 粘贴 YouTube 链接，即可直接在画布中显示嵌入式视频。

<Callout type="info">
  Note 模块不会影响工作流执行。它不产生输出，无法连接到其他模块，并会在工作流运行时被完全移除。
</Callout>

## 配置

该模块只有一个 Markdown 文本区域。你可以输入纯文本、使用 Markdown 格式（标题、列表、粗体和代码块），或粘贴 YouTube URL 来嵌入视频。

## 最佳实践

- **将注释放在所说明的模块附近**，以便立即查看上下文。
- **使用 Markdown 标题和列表**，使较长的注释易于浏览。
- **优先使用注释而不是代码模块中的注释** -- 无需打开模块配置即可在画布层级看到 Note 模块。
