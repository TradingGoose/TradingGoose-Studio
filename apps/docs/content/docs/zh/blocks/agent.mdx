## 使用和输出

配置系统提示词、用户提示词、工具、技能和历史消息。附加字段提供响应格式、最大输出 token 数以及可用的原生设置。留空时使用提供方默认值。模型已发布的元数据仅供参考。当前运行时不支持简化的推理强度选择器；请通过 Provider Options 配置提供方支持的原生选项，包括可用的推理预算或开关。

Auto 允许模型自行选择工具；Force 按配置顺序要求执行所有标记的工具，然后恢复 Auto；None 会排除工具。不支持的组合或未完成的强制序列会产生明确错误。固定参数和已授权的工作流上下文保持有效。

未指定结构化格式时，输出包含 `content`、`model`、`tokens` 和 `toolCalls`。Response Format 接受一个在 `schema` 属性中包含 JSON Schema 的对象；返回字段位于输出根级，可供后续区块引用。需要跨运行保存历史时，使用 Memory Add，并将 Get Memory 的消息数组连接到 Memories。生成和流式输出均由 Mastra 执行。独立的 Gemini Interactions/Deep Research 创建及轮询生命周期已移除。

## 用量和费用

记录会区分提供方报告的费用、原生估算费用和不可用费用。缺失费用不等于零；即使美元金额缺失，已知 token 用量仍会保留。产品自身的费用单独计算。独立嵌入保留向量及可用的原生用量，其美元费用显示为不可用。
