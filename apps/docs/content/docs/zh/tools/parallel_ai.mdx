## 工具

### `parallel_search`

使用 Parallel AI 搜索网页。提供经智能处理和内容提取的全面搜索结果。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `objective` | string | 是 | 要回答的搜索目标或问题 |
| `search_queries` | string | 否 | 可选，要执行的搜索查询列表，以逗号分隔 |
| `processor` | string | 否 | 处理方式：base 或 pro \(默认：base\) |
| `max_results` | number | 否 | 返回的最大结果数 \(默认：5\) |
| `max_chars_per_result` | number | 否 | 每条结果的最大字符数 \(默认：1500\) |
| `apiKey` | string | 是 | Parallel AI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `results` | array | 包含相关页面摘录的搜索结果 |

## 使用说明

将 Parallel AI 集成到工作流中。可搜索网页。
