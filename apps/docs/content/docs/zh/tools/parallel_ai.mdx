## 工具

### `parallel_search`

使用 Parallel AI 搜索网页。通过智能处理和内容提取提供全面的搜索结果。

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `objective` | 字符串 | 是 | 搜索目标或要回答的问题 |
| `search_queries` | 字符串 | 否 | 可选 comma-separated 列出的搜索查询到执行 |
| `processor` | 字符串 | 否 | 处理方法: base或pro \(默认值： base\) |
| `max_results` | 数字 | 否 | 最大数量：结果到返回 \(默认值： 5\) |
| `max_chars_per_result` | 数字 | 否 | 最大字符每个结果 \(默认值： 1500\) |
| `apiKey` | 字符串 | 是 | Parallel AI API 键 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `url` | 字符串 | URL的搜索结果 |
| `title` | 字符串 | 标题的搜索结果 |


## 用法说明

将Parallel AI集成到 workflow 中。可以搜索 web.
