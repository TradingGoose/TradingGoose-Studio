## 工具

### `google_forms_get_responses`

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `data` | json | 响应或列表的 responses |


## 用量说明

集成 Google Forms 到你的 workflow. 提供一个表单 ID 到列表 responses, 或 specify 一个响应 ID 到 fetch 一个单个 response. Requires OAuth.
