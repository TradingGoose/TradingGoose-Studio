## 工具

### `google_forms_get_responses`

获取 Google 表单的单条回复或回复列表

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `formId` | string | 是 | Google 表单的 ID |
| `responseId` | string | 否 | 若提供，则返回该指定回复 |
| `pageSize` | number | 否 | 返回的回复数量上限 \(服务可能返回更少\)。默认 5000。 |

#### 输出（块级契约）

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `data` | json | 单条回复或回复列表 |

## 使用说明

将 Google Forms 集成到你的工作流中。提供表单 ID 以列出响应，或指定响应 ID 以获取单个响应。需要 OAuth。
