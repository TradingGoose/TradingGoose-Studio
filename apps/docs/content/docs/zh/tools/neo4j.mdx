执行 MATCH 查询，从 Neo4j 图数据库读取节点和关系。为提高性能并避免返回过大的结果集，请在查询中加入 LIMIT（例如：

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `host` | 字符串 | 是 | Neo4j 服务器的主机名或 IP 地址 |
| `port` | 数字 | 是 | Neo4j 服务器端口 \(默认值： 7687，用于Bolt 协议\) |
| `database` | 字符串 | 是 | 要连接的数据库名称 |
| `username` | 字符串 | 是 | Neo4j 用户名 |
| `password` | 字符串 | 是 | Neo4j 密码 |
| `encryption` | 字符串 | 否 | 连接加密模式 \(已启用, 已禁用\) |
| `cypherQuery` | 字符串 | 是 | 要执行的 Cypher 查询 \(通常为 MATCH 语句\) |
| `parameters` | 对象 | 否 | 以 JSON 对象表示的 Cypher 查询参数。 用于所有动态值，包括 LIMIT \(例如： 查询: "MATCH \(n\) RETURN n LIMIT $limit", 参数: \{限制: 100\}\). |
| `parameters` | 字符串 | 否 | 无描述 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | 字符串 | 操作状态消息 |
| `records` | 数组 | 查询返回的记录数组 |
| `recordCount` | 数字 | 返回的记录数 |
