<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">查询 (MATCH) (<code>neo4j_query</code>)</div>

执行 MATCH 查询，从 Neo4j 图数据库读取节点和关系。为获得最佳性能并避免结果集过大，请在查询中包含 LIMIT（例如 "MATCH (n:User) RETURN n LIMIT 100"），或使用 LIMIT $limit 并配合 limit 参数。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `host` | string | 是 | Neo4j 服务器主机名或 IP 地址 |
| `port` | number | 是 | Neo4j 服务器端口 \(默认：Bolt 协议为 7687\) |
| `database` | string | 是 | 要连接的数据库名称 |
| `username` | string | 是 | Neo4j 用户名 |
| `password` | string | 是 | Neo4j 密码 |
| `encryption` | string | 否 | 连接加密模式 \(enabled、disabled\) |
| `cypherQuery` | string | 是 | 要执行的 Cypher 查询 \(通常为 MATCH 语句\) |
| `parameters` | object | 否 | Cypher 查询参数，JSON 对象。用于包括 LIMIT 在内的所有动态值 \(例如 query: "MATCH \(n\) RETURN n LIMIT $limit", parameters: \{limit: 100\}\)。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `message` | string | 操作状态消息 |
| `records` | array | 查询返回的记录数组 |
| `recordCount` | number | 返回的记录数 |
| `summary` | json | 查询执行摘要，包含耗时和计数器 |

</div>
