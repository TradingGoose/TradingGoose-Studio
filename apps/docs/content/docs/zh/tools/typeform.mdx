| `until` | string | 否 | 获取此日期之前提交的回复 \(ISO 8601 格式\) |
| `completed` | string | 否 | 按完成状态筛选 \(true/false\) |

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `total_items` | number | 响应总数 |
| `page_count` | number | 总页数 |
| `items` | json | 响应项 |

| `apiKey` | string | 是 | Typeform 个人访问令牌 |

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `fileUrl` | string | 已上传文件的直接下载 URL |
| `contentType` | string | 已上传文件的 MIME 类型 |
| `filename` | string | 已上传文件的原始文件名 |

将 Typeform 集成到工作流中。可获取回复、下载文件并获取表单洞察。需要 API Key。
