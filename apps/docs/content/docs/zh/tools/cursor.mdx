<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | Cursor API 密钥 |
| `repository` | 字符串 | 是 | GitHub 仓库 URL \(例如, https://github.com/your-org/your-repo\) |
| `ref` | 字符串 | 否 | 工作分支、标签或提交（默认为默认分支） |
| `promptText` | 字符串 | 是 | 提供给 Agent 的任务说明 |
| `promptImages` | 字符串 | 否 | 包含 base64 数据和尺寸的图像对象 JSON 数组 |
| `model` | 字符串 | 否 | 使用的模型（留空时自动选择） |
| `branchName` | 字符串 | 否 | Agent 使用的自定义分支名称 |
| `autoCreatePr` | 布尔值 | 否 | Agent 完成任务后自动创建 PR |
| `openAsCursorGithubApp` | 布尔值 | 否 | 以 Cursor GitHub App 身份打开 PR |
| `skipReviewerRequest` | 布尔值 | 否 | 跳过为 PR 请求审阅者 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | 字符串 | 包含 Agent 详细信息的成功消息 |
| `id` | 字符串 | Agent ID |
