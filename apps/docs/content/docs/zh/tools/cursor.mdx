| `promptImages` | string | 否 | 包含 base64 数据和尺寸的图像对象的 JSON 数组 |
| `model` | string | 否 | 要使用的模型 \(留空以自动选择\) |

| `autoCreatePr` | boolean | 否 | 智能体完成后自动创建 PR |
| `openAsCursorGithubApp` | boolean | 否 | 以 Cursor GitHub App 身份打开 PR |
| `skipReviewerRequest` | boolean | 否 | 跳过在 PR 上请求审阅者 |

## 使用说明

通过 Cursor Cloud Agents API 启动可在您的 GitHub 仓库上工作的 AI 智能体。支持启动智能体、添加跟进指令、检查状态、查看对话以及管理智能体生命周期。
