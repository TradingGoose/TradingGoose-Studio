发送 emails 使用 Gmail

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `to` | 字符串 | 是 | Recipient 电子邮件 address |
| `subject` | 字符串 | 否 | 电子邮件 subject |
| `body` | 字符串 | 是 | 电子邮件 body content |
| `contentType` | 字符串 | 否 | 内容 type 用于该 电子邮件 body \(text 或 html\) |
| `threadId` | 字符串 | 否 | Thread ID 到 reply 到 \(用于 threading\) |
| `replyToMessageId` | 字符串 | 否 | Gmail message ID 到 reply 到 - 使用该 "id" 字段从 Gmail 读取结果 \(not 该 RFC "messageId"\) |
| `cc` | 字符串 | 否 | CC recipients \(comma-separated\) |
| `bcc` | 字符串 | 否 | BCC recipients \(comma-separated\) |
| `attachments` | file[] | 否 | 文件到 attach 到该 电子邮件 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | 字符串 | 成功 message |
| `id` | 字符串 | Gmail message ID |
| `threadId` | 字符串 | Gmail thread ID |
| `items` | 字符串 | 项目 output |

</div>

读取 emails 从 Gmail

| `metadata` | json | 元数据的该 电子邮件 |

将 Gmail 集成到工作流中。你可以发送、读取和搜索电子邮件。也可在触发器模式下，当收到新邮件时触发工作流。
