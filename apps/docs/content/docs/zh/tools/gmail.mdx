使用 Gmail 发送邮件

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `to` | string | 是 | 收件人邮箱地址 |
| `subject` | string | 否 | 邮件主题 |
| `body` | string | 是 | 邮件正文内容 |
| `contentType` | string | 否 | 邮件正文的内容类型 \(text 或 html\) |
| `threadId` | string | 否 | 要回复的会话 ID \(用于邮件串接\) |
| `replyToMessageId` | string | 否 | 要回复的 Gmail 消息 ID - 使用 Gmail 读取结果中的 "id" 字段 \(不是 RFC 的 "messageId"\) |
| `cc` | string | 否 | 抄送收件人 \(逗号分隔\) |
| `bcc` | string | 否 | 密送收件人 \(逗号分隔\) |
| `attachments` | file[] | 否 | 要附加到邮件的文件 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | string | 成功消息 |
| `metadata` | object | 邮件元数据 |

## 使用说明

将 Gmail 集成到工作流中。可发送、读取和搜索邮件。可在触发模式下使用，在收到新邮件时触发工作流。

## 注意事项

- 分类：`tools`
- 类型：`gmail`
