搜索用于 academic papers 在 ArXiv 按关键词, authors, titles, 或 other 字段.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `searchQuery` | 字符串 | 是 | 该 search query 到 execute |
| `searchField` | 字符串 | 否 | 字段到 search 在: 全部, ti \(title\), au \(author\), abs \(abstract\), co \(comment\), jr \(journal\), cat \(类别\), rn \(report 数字\) |
| `maxResults` | 数字 | 否 | 最大数字的结果到 return \(默认: 10, max: 2000\) |
| `sortBy` | 字符串 | 否 | 排序按: relevance, lastUpdatedDate, submittedDate \(默认: relevance\) |
| `sortOrder` | 字符串 | 否 | 排序顺序: 升序, 降序 \(默认: 降序\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | id output |
| `title` | 字符串 | title output |
| `summary` | 字符串 | summary output |
| `authors` | 字符串 | authors output |
| `published` | 字符串 | 已发布 output |

## 用量说明

将 ArXiv 集成到工作流中。可以搜索论文、获取论文详情以及查询作者的论文。无需 OAuth 或 API 密钥。
