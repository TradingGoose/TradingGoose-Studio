<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `searchQuery` | string | 是 | 要执行的搜索查询 |
| `searchField` | string | 否 | 搜索字段：all, ti \(标题\), au \(作者\), abs \(摘要\), co \(评论\), jr \(期刊\), cat \(分类\), rn \(报告编号\) |
| `maxResults` | number | 否 | 返回的最大结果数 \(默认：10，最大：2000\) |
| `sortBy` | string | 否 | 排序依据：relevance, lastUpdatedDate, submittedDate \(默认：relevance\) |
| `sortOrder` | string | 否 | 排序顺序：ascending, descending \(默认：descending\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `papers` | json | 与搜索查询匹配的论文数组 |
| `totalResults` | number | 搜索查询找到的结果总数 |

## 使用说明

将 ArXiv 集成到工作流中。可搜索论文、获取论文详情，以及获取作者的论文。无需 OAuth 或 API 密钥。
