## 工具

### `clay_populate`

使用 JSON 文件中的数据填充 Clay。支持直接通信和通知，并具备时间戳跟踪与渠道确认功能。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `webhookURL` | string | 是 | 要填充的 Webhook URL |
| `data` | json | 是 | 要填充的数据 |
| `authToken` | string | 否 | 可选的 Clay Webhook 认证令牌 \(大多数 Webhook 不需要\) |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `data` | json | 来自 Clay Webhook 的响应数据 |
| `metadata` | object | Webhook 响应元数据 |

## 使用说明

将 Clay 集成到工作流中。可向表格填充数据。

## 注意事项

- 类别：`tools`
- 类型：`clay`
