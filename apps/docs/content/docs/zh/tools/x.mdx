| `maxResults` | number | 否 | 返回结果的最大数量（默认：10，最大：100） |
| `startTime` | string | 否 | 搜索开始时间（ISO 8601 格式） |
| `endTime` | string | 否 | 搜索结束时间（ISO 8601 格式） |
| `sortOrder` | string | 否 | 结果排序方式（recency 或 relevancy） |

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `tweets` | array | 匹配搜索查询的推文数组 |
| `includes` | object | 附加数据，包括用户资料和媒体 |
| `meta` | object | 搜索元数据，包括结果数量和分页令牌 |
