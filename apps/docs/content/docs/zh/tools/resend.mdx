## 工具

### `resend_send`

使用你的自己的 Resend API 键和来自地址发送一个 email

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `fromAddress` | 字符串 | 是 | 电子邮件地址到发送，来源为|
| `to` | 字符串 | 是 | 收件人 email 地址 |
| `subject` | 字符串 | 是 | 电子邮件主题 |
| `body` | 字符串 | 是 | 电子邮件正文内容 |
| `contentType` | 字符串 | 否 | 内容类型，用于email 正文 \(文本或html\) |
| `resendApiKey` | 字符串 | 是 | Resend API 键，用于sending 电子邮件 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否email 曾为已发送 successfully |
| `to` | 字符串 | 收件人 email 地址 |
| `subject` | 字符串 | 电子邮件主题 |


## 用法说明

将Resend集成到 workflow 中。可以发送电子邮件. 需要 API 键.
