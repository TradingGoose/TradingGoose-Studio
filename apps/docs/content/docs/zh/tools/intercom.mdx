创建一个新 contact 在 Intercom 使用 电子邮件, external_id, 或 角色

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `role` | 字符串 | 否 | 联系人的角色。接受 'user' 或 'lead'；未指定时默认为 'lead'。 |
| `email` | 字符串 | 否 | 该 contact's 电子邮件 address |
| `external_id` | 字符串 | 否 | 一个唯一标识符用于该 contact 提供的按该客户端 |
| `phone` | 字符串 | 否 | 该 contact's phone 数字 |
| `name` | 字符串 | 否 | 该 contact's 名称 |
| `avatar` | 字符串 | 否 | 一个 avatar 图像 URL 用于该 contact |
| `signed_up_at` | 数字 | 否 | 该 time 该 用户 signed up 作为一个 Unix 时间戳 |
| `last_seen_at` | 数字 | 否 | 该 time 该 用户 was 最后一个 seen 作为一个 Unix 时间戳 |
| `owner_id` | 字符串 | 否 | 该 id 的一个 admin 该 has been assigned account ownership 的该 contact |
| `unsubscribed_from_emails` | 布尔值 | 否 | 是否该 contact is unsubscribed 从 emails |
| `custom_attributes` | 字符串 | 否 | 自定义 attributes 作为 JSON 对象 \(例如, \{"attribute_name": "value"\}\) |
| `company_id` | 字符串 | 否 | 公司 ID 到 associate 该 contact 使用 during creation |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 唯一标识符用于该 contact |
| `type` | 字符串 | 列出 type |
| `role` | 字符串 | 角色的该 contact \(用户 或 lead\) |
| `email` | 字符串 | 电子邮件 address 的该 contact |
| `phone` | 字符串 | Phone 数字的该 contact |
| `name` | 字符串 | 名称的该 contact |
| `avatar` | 字符串 | Avatar URL 的该 contact |
| `owner_id` | 字符串 | ID 的该 admin assigned 到此 contact |
| `external_id` | 字符串 | 外部标识符用于该 contact |
| `created_at` | 数字 | Unix 时间戳何时 contact was created |
| `updated_at` | 数字 | Unix 时间戳何时 contact was 最后一个 updated |
| `signed_up_at` | 数字 | Unix 时间戳何时 用户 signed up |
| `last_seen_at` | 数字 | Unix 时间戳何时 用户 was 最后一个 seen |
| `workspace_id` | 字符串 | 工作区 ID 该 contact belongs 到 |
| `custom_attributes` | 对象 | 自定义 attributes set 在该 contact |
| `url` | 字符串 | URL 到 fetch 标签 |
| `data` | 数组 | 数组的标签 objects |
| `has_more` | 布尔值 | 是否还有更多标签 |
