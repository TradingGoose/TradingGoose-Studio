<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `role` | string | 否 | 联系人角色。可接受 'user' 或 'lead'。未指定时默认为 'lead'。 |
| `email` | string | 否 | 联系人的邮箱地址 |
| `external_id` | string | 否 | 客户端提供的联系人唯一标识符 |
| `phone` | string | 否 | 联系人的电话号码 |
| `name` | string | 否 | 联系人的姓名 |
| `avatar` | string | 否 | 联系人的头像图片 URL |
| `signed_up_at` | number | 否 | 用户注册时间，Unix 时间戳 |
| `last_seen_at` | number | 否 | 用户上次出现时间，Unix 时间戳 |
| `owner_id` | string | 否 | 被指定为该联系人账户所有者的管理员 ID |
| `unsubscribed_from_emails` | boolean | 否 | 联系人是否已退订邮件 |
| `custom_attributes` | string | 否 | 自定义属性，JSON 对象 \(例如 \{"attribute_name": "value"\}\) |
| `company_id` | string | 否 | 创建时要关联到该联系人的公司 ID |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `contact` | object | 已创建的联系人对象 |
| `metadata` | object | 操作元数据 |
| `success` | boolean | 操作成功状态 |

</div>
