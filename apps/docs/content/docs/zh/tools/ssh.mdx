<div className="text-base font-semibold mb-2">Execute Command (<code>ssh_execute_command</code>)</div>

执行一个 shell 命令在 一个远程 SSH 服务器

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `host` | 字符串 | 是 | SSH 服务器主机名或IP 地址 |
| `port` | 数字 | 是 | SSH 服务器端口 \(默认值： 22\) |
| `username` | 字符串 | 是 | SSH 用户名 |
| `password` | 字符串 | 否 | 密码，用于身份验证 \(如果不 使用私有键\) |
| `privateKey` | 字符串 | 否 | 私有键，用于身份验证 \(OpenSSH 格式\) |
| `passphrase` | 字符串 | 否 | 密码短语，用于encrypted 私有键 |
| `command` | 字符串 | 是 | Shell 命令到执行在 远程服务器 |
| `workingDirectory` | 字符串 | 否 | Working 目录，用于命令执行 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `stdout` | 字符串 | 标准输出，来源为命令 |
| `stderr` | 字符串 | 标准错误输出 |
| `exitCode` | 数字 | 命令 exit 代码 |
| `success` | 布尔值 | 是否命令 succeeded \(exit 代码 0\) |

</div>
