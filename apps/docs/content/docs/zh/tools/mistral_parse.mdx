使用 Mistral OCR API 解析 PDF 文档

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `filePath` | string | 是 | 要处理的 PDF 文档 URL |
| `resultType` | string | 否 | 解析结果类型 \(markdown、text 或 json\)。默认为 markdown。 |
| `pages` | array | 否 | 要处理的指定页面 \(页码数组，从 0 开始\) |
| `apiKey` | string | 是 | 本次请求使用的 Mistral API 密钥。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 是否成功解析 PDF |
| `content` | string | 按请求格式提取的内容 \(markdown、text 或 JSON\) |
| `metadata` | object | 处理元数据，包括 jobId、fileType、pageCount 和使用信息 |

</div>
