## 工具

### `linkup_search`

使用 Linkup 搜索网络信息

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `q` | string | 是 | 搜索查询 |
| `depth` | string | 是 | 搜索深度 \(必须为 "standard" 或 "deep"\) |
| `outputType` | string | 是 | 返回的输出类型 \(必须为 "sourcedAnswer" 或 "searchResults"\) |
| `apiKey` | string | 是 | 输入你的 Linkup API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `answer` | string | 搜索查询的来源答案 |
| `sources` | array | 用于生成答案的来源数组，每项包含 name、url 和 snippet |

## 使用说明

将 Linkup 集成到工作流中。可搜索网络。
