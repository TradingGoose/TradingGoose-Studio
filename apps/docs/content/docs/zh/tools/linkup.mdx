## 工具

### `linkup_search`

搜索该 web 用于信息使用 Linkup

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `q` | 字符串 | 是 | 该 search query |
| `depth` | 字符串 | 是 | 搜索深度 \(has 到 either be "standard" 或 "deep"\) |
| `outputType` | 字符串 | 是 | 类型的 output 到 return \(has 到 either be "sourcedAnswer" 或 "searchResults"\) |
| `apiKey` | 字符串 | 是 | 输入你的 Linkup API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `answer` | 字符串 | 该 sourced 答案到该 search query |


## 用量说明

集成 Linkup 到该 workflow. 可以 search 该 web.
