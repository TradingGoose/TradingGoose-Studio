检索账户，来源为Salesforce CRM

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `idToken` | 字符串 | 否 | ID token，来源为Salesforce OAuth \(包含实例 URL\) |
| `instanceUrl` | 字符串 | 否 | Salesforce 实例 URL |
| `limit` | 字符串 | 否 | 数量：结果到返回 \(默认值： 100, 最大: 2000\) |
| `fields` | 字符串 | 否 | 以逗号分隔的列表：字段到返回 \(例如： "Id,名称,行业,电话"\) |
| `orderBy` | 字符串 | 否 | 字段到订单由\(例如： "名称 ASC"或"CreatedDate DESC"\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 操作成功状态 |
| `accounts` | 数组 | 以下内容的数组：账户对象 |
| `paging` | 对象 | 分页信息 |
| `metadata` | 对象 | 操作元数据 |

</div>
