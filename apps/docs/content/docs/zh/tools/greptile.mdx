<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| `genius` | 布尔值 | 否 | 启用天才模式以进行更彻底的分析 \(速度较慢但更准确\) |
| `apiKey` | 字符串 | 是 | Greptile API 密钥 |
| `githubToken` | 字符串 | 是 | 具有仓库读取权限的 GitHub 个人访问令牌 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | string | AI 生成的查询答案 |
| `sources` | array | 支持该答案的相关代码引用 |

</div>

<div className="text-base font-semibold mb-2">索引仓库 (<code>greptile_index_repo</code>)</div>

向 Greptile 提交仓库以进行索引。必须完成索引后才能查询该仓库。小型仓库需要 3-5 分钟，较大的仓库可能需要超过一小时。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `remote` | string | 是 | Git 远程类型：github 或 gitlab |
| `repository` | string | 是 | 仓库，格式为 owner/repo \(例如 \"facebook/react\"\) |
| `branch` | string | 是 | 要索引的分支 \(例如 \"main\" 或 \"master\"\) |
| `reload` | boolean | 否 | 即使已索引也强制重新索引 |
| `notify` | boolean | 否 | 索引完成时发送邮件通知 |
| `apiKey` | string | 是 | Greptile API 密钥 |
| `githubToken` | string | 是 | 具有仓库读取权限的 GitHub 个人访问令牌 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `repositoryId` | string | 已索引仓库的唯一标识符（格式：remote:branch:owner/repo） |
| `statusEndpoint` | string | 用于检查索引状态的 URL 端点 |
| `message` | string | 索引操作的状态消息 |

</div>

| `remote` | string | Git 远程仓库 \(github/gitlab\) |
| `branch` | string | 分支名称 |
| `private` | boolean | 仓库是否为私有 |
| `status` | string | 索引状态：submitted、cloning、processing、completed 或 failed |
| `filesProcessed` | number | 已处理的文件数量 |
| `numFiles` | number | 仓库中的文件总数 |
| `sampleQuestions` | array | 已索引仓库的示例问题 |
| `sha` | string | 已索引版本的 Git 提交 SHA |

## 使用说明

使用 Greptile 以自然语言查询和搜索代码库。获取关于代码的 AI 生成答案，查找相关文件，并理解复杂的代码库。
