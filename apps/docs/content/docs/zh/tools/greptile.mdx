<div className="text-base font-semibold mb-2">查询 (<code>greptile_query</code>)</div>

使用自然语言查询代码仓库，并获得带有相关代码引用的答案。Greptile 使用 AI 理解代码库并回答问题。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | Natural 语言问题 关于 该 codebase |
| `repositories` | 字符串 | 是 | 以逗号分隔列表的 repositories. 格式: "github:分支:owner/repo" 或 just "owner/repo" \(默认为 github:main\) |
| `sessionId` | 字符串 | 否 | Session ID 用于对话 continuity |
| `genius` | 布尔值 | 否 | 启用 genius 模式以进行更彻底的分析\(速度较慢，但更准确\) |
| `apiKey` | 字符串 | 是 | Greptile API 密钥 |
| `githubToken` | 字符串 | 是 | GitHub 个人访问令牌使用 repo read 访问权限 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `message` | 字符串 | AI-generated 答案到该 query |
| `repository` | 字符串 | 仓库 名称 \(owner/repo\) |
| `remote` | 字符串 | Git remote \(github/gitlab\) |
| `branch` | 字符串 | 分支 名称 |
| `filepath` | 字符串 | 路径到该 file |
| `linestart` | 数字 | Starting line 数字 |
| `lineend` | 数字 | Ending line 数字 |
| `summary` | 字符串 | 摘要的该 code section |

</div>

<div className="text-base font-semibold mb-2">索引仓库 (<code>greptile_index_repo</code>)</div>

提交仓库，由 Greptile 建立索引。必须等待索引完成后才能查询该仓库。小型仓库通常需要 3–5 分钟，大型仓库可能需要一小时以上。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `remote` | 字符串 | 是 | Git remote type: github 或 gitlab |
| `repository` | 字符串 | 是 | 仓库在 owner/repo 格式 \(例如, "facebook/react"\) |
| `branch` | 字符串 | 是 | 分支到 index \(例如, "main" 或 "master"\) |
| `reload` | 布尔值 | 否 | 强制 re-indexing even if already indexed |
| `notify` | 布尔值 | 否 | 发送 电子邮件 notification 何时 indexing completes |
| `apiKey` | 字符串 | 是 | Greptile API 密钥 |
| `githubToken` | 字符串 | 是 | GitHub 个人访问令牌使用 repo read 访问权限 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `repositoryId` | 字符串 | 唯一标识符用于该 indexed 仓库 \(格式: remote:分支:owner/repo\) |
| `statusEndpoint` | 字符串 | URL 端点到 check indexing status |

</div>
