<div className="text-base font-semibold mb-2">查询文档 (<code>mongodb_query</code>)</div>

在 MongoDB 集合上执行查询操作

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `host` | string | 是 | MongoDB 服务器主机名或 IP 地址 |
| `port` | number | 是 | MongoDB 服务器端口 \\(默认值：27017\\) |
| `database` | string | 是 | 要连接的数据库名称 |
| `username` | string | 否 | MongoDB 用户名 |
| `password` | string | 否 | MongoDB 密码 |
| `authSource` | string | 否 | 认证数据库 |
| `ssl` | string | 否 | SSL 连接模式 \\(禁用, 必需, 首选\\) |
| `collection` | string | 是 | 要查询的集合名称 |
| `query` | string | 否 | 作为 JSON 字符串的 MongoDB 查询过滤器 |
| `limit` | number | 否 | 返回的最大文档数量 |
| `sort` | string | 否 | 作为 JSON 字符串的排序条件 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | string | 操作状态消息 |
| `documents` | array | 查询返回的文档数组 |
| `documentCount` | number | 返回的文档数量 |

</div>

将文档插入 MongoDB 集合

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `database` | string | 是 | 要连接的数据库名称 |
| `username` | string | 否 | MongoDB 用户名 |
| `password` | string | 否 | MongoDB 密码 |
| `authSource` | string | 否 | 认证数据库 |
| `ssl` | string | 否 | SSL 连接模式 \(disabled, required, preferred\) |
| `collection` | string | 是 | 要插入的目标集合名称 |
| `documents` | array | 是 | 要插入的文档数组 |

| `insertedId` | string | 插入文档的 ID \(单条插入\) |
| `insertedIds` | array | 插入文档 ID 的数组 \(多条插入\) |

更新 MongoDB 集合中的文档

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `host` | string | 是 | MongoDB 服务器主机名或 IP 地址 |
| `port` | number | 是 | MongoDB 服务器端口 \(默认：27017\) |
| `database` | string | 是 | 要连接的数据库名称 |
| `username` | string | 否 | MongoDB 用户名 |
| `password` | string | 否 | MongoDB 密码 |
| `authSource` | string | 否 | 认证数据库 |
| `ssl` | string | 否 | SSL 连接模式 \(disabled、required、preferred\) |
| `collection` | string | 是 | 要更新的集合名称 |
| `filter` | string | 是 | JSON 字符串格式的筛选条件 |
| `update` | string | 是 | JSON 字符串格式的更新操作 |
| `upsert` | boolean | 否 | 未找到时创建文档 |
| `multi` | boolean | 否 | 更新多个文档 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | string | 操作状态消息 |
| `matchedCount` | number | 筛选匹配的文档数量 |
| `modifiedCount` | number | 已修改的文档数量 |
| `documentCount` | number | 受影响的文档总数 |
| `insertedId` | string | 插入文档的 ID \(启用 upsert 时\) |

</div>
