<div className="text-base font-semibold mb-2">查找文档 (<code>mongodb_query</code>)</div>

执行 find operation 在 MongoDB 集合

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `host` | 字符串 | 是 | MongoDB 服务器 hostname 或 IP address |
| `port` | 数字 | 是 | MongoDB 服务器 port \(默认: 27017\) |
| `database` | 字符串 | 是 | 数据库 名称 到 connect 到 |
| `username` | 字符串 | 否 | MongoDB 用户名 |
| `password` | 字符串 | 否 | MongoDB 密码 |
| `authSource` | 字符串 | 否 | Authentication database |
| `ssl` | 字符串 | 否 | SSL connection 模式 \(已禁用, required, preferred\) |
| `collection` | 字符串 | 是 | 集合 名称 到 query |
| `query` | 字符串 | 否 | MongoDB query filter 作为 JSON 字符串 |
| `limit` | 数字 | 否 | 最大数字的 documents 到 return |
| `sort` | 字符串 | 否 | 排序 criteria 作为 JSON 字符串 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `message` | 字符串 | 操作 status message |
| `documents` | 数组 | 数组的 documents returned 从该 query |

</div>
