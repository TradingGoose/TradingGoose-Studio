<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `domain` | 字符串 | 是 | 你的 Confluence 域名 \(例如, yourcompany.atlassian.net\) |
| `pageId` | 字符串 | 是 | Confluence 页面 ID 到 update |
| `title` | 字符串 | 否 | 新 title 用于该页面 |
| `content` | 字符串 | 否 | 新 content 用于该页面在 Confluence storage 格式 |
| `version` | 数字 | 否 | Version 数字的该页面 \(required 用于 preventing conflicts\) |
| `cloudId` | 字符串 | 否 | 该实例的 Confluence Cloud ID。如果未提供，将通过域名获取。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `ts` | 字符串 | 时间戳的 update |
| `pageId` | 字符串 | Confluence 页面 ID |
| `title` | 字符串 | Updated 页面 title |
