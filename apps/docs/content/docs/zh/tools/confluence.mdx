使用 Confluence API 更新 Confluence 页面。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `domain` | string | 是 | 您的 Confluence 域名 \\(例如：yourcompany.atlassian.net\\) |
| `pageId` | string | 是 | 要更新的 Confluence 页面 ID |
| `title` | string | 否 | 页面的新标题 |
| `content` | string | 否 | 以 Confluence 存储格式表示的页面新内容 |
| `version` | number | 否 | 页面版本号 \\(用于防止冲突\\) |
| `cloudId` | string | 否 | 实例的 Confluence Cloud ID。如果未提供，将使用域名获取。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `ts` | 字符串 | 更新时间戳 |
| `pageId` | 字符串 | Confluence 页面 ID |
| `title` | 字符串 | 更新后的页面标题 |
| `success` | 布尔值 | 更新操作是否成功 |

</div>
