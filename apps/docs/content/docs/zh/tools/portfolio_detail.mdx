## 工具

### `trading_get_portfolio_detail`

从 Alpaca 或 Tradier 获取账户摘要、现金、持仓和订单。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `portfolioIdentity` | json | 是 | 由券商账户字段选定的规范 portfolioIdentity。 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `summary` | string | 投资组合详情获取的状态消息。 |
| `provider` | string | 本次请求使用的券商/提供商。 |
| `portfolioDetail` | json | 包含现金、持仓和摘要的规范投资组合详情。 |

## 使用说明

投资组合详情区块，从 Alpaca 或 Tradier 返回账户摘要、现金、持仓和订单。
