## 工具

### `trading_get_portfolio_detail`

获取账户摘要, cash, 持仓,和订单，来源为Alpaca或Tradier.

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `portfolioIdentity` | json | 是 | Canonical portfolioIdentity 所选由经纪商账户字段. |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `summary` | 字符串 | 状态消息，用于portfolio detail retrieval. |
| `provider` | 字符串 | 经纪商/提供商使用的，用于请求. |
| `portfolioDetail` | json | Canonical portfolio detail 使用cash, 持仓,和摘要. |


## 用法说明

Portfolio detail 块该 返回账户摘要, cash, 持仓,和订单，来源为Alpaca或Tradier.
