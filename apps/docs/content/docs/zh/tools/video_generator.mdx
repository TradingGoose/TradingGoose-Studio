<div className="text-base font-semibold mb-2">Runway Gen-4（<code>video_runway</code>）</div>

使用 Runway Gen-4 生成视频，具备世界一致性与视觉参考

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `provider` | string | 是 | 视频提供商 \(runway\) |
| `apiKey` | string | 是 | Runway API 密钥 |
| `model` | string | 否 | Runway 模型：gen-4 \(默认，画质更高\) 或 gen-4-turbo \(更快\) |
| `prompt` | string | 是 | 描述要生成视频的文本提示词 |
| `duration` | number | 否 | 视频时长（秒）\(5 或 10，默认：5\) |
| `aspectRatio` | string | 否 | 画面比例：16:9 \(横屏\)、9:16 \(竖屏\) 或 1:1 \(方形\) |
| `resolution` | string | 否 | 视频分辨率 \(输出 720p\)。注意：Gen-4 Turbo 原生输出 720p |
| `visualReference` | json | 是 | Gen-4 必须提供参考图 \(UserFile 对象\)。Gen-4 仅支持图生视频，不支持纯文本生成 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `videoUrl` | string | 生成的视频 URL |
| `videoFile` | json | 包含元数据的视频文件对象 |
| `duration` | number | 视频时长（秒） |
| `width` | number | 视频宽度（像素） |
| `height` | number | 视频高度（像素） |
| `provider` | string | 所用提供商 \(runway\) |
| `model` | string | 所用模型 |
| `jobId` | string | Runway 任务 ID |
