<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| --------- | ---- | -------- | ----------- |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 是否成功获取任务 |
| `tasks` | array | 筛选后的任务对象数组 |
| `metadata` | object | 元数据，包含 planId、userId 和 planUrl |

在 Microsoft Planner 中创建新任务

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `planId` | string | 是 | 将在其中创建任务的计划 ID |
| `title` | string | 是 | 任务标题 |
| `description` | string | 否 | 任务描述 |
| `dueDateTime` | string | 否 | 任务的截止日期和时间（ISO 8601 格式） |
| `assigneeUserId` | string | 否 | 要将任务分配给的用户 ID |
| `bucketId` | string | 否 | 要将任务放入的存储桶 ID |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 任务是否创建成功 |
| `task` | object | 包含全部属性的已创建任务对象 |
| `metadata` | object | 包含 planId、taskId 和 taskUrl 的元数据 |

</div>

## 使用说明

将 Microsoft Planner 集成到工作流中。可读取和创建任务。
