<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">搜索 (<code>elasticsearch_search</code>)</div>

搜索 documents 在 Elasticsearch 使用查询 DSL. 返回匹配 documents 使用 scores 和 metadata.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `deploymentType` | 字符串 | 是 | 部署 type: self_hosted 或 cloud |
| `host` | 字符串 | 否 | Elasticsearch 主机 URL \(用于 self-hosted\) |
| `cloudId` | 字符串 | 否 | Elastic Cloud ID \(用于 cloud deployments\) |
| `authMethod` | 字符串 | 是 | Authentication 方法: api_key 或 basic_auth |
| `apiKey` | 字符串 | 否 | Elasticsearch API 密钥 |
| `username` | 字符串 | 否 | 用户名用于基本 auth |
| `password` | 字符串 | 否 | 密码用于基本 auth |
| `index` | 字符串 | 是 | 索引 名称 到 search |
| `query` | 字符串 | 否 | 查询 DSL 作为 JSON 字符串 |
| `from` | 数字 | 否 | Starting offset 用于分页 \(默认: 0\) |
| `size` | 数字 | 否 | 数字的结果到 return \(默认: 10\) |
| `sort` | 字符串 | 否 | 排序 specification 作为 JSON 字符串 |
| `sourceIncludes` | 字符串 | 否 | 以逗号分隔列表的字段到包含在 _source |
| `sourceExcludes` | 字符串 | 否 | 以逗号分隔列表的字段到排除从 _source |
| `trackTotalHits` | 布尔值 | 否 | Track accurate 总计 hit 数量 \(默认: 是\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `took` | 数字 | 时间在 milliseconds 该 search took |
| `timed_out` | 布尔值 | 是否该 search timed out |
| `hits` | 对象 | 搜索结果使用总计数量和匹配 documents |

</div>
