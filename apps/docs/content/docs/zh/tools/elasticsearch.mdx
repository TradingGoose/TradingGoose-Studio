<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">搜索（<code>elasticsearch_search</code>）</div>

使用 Query DSL 在 Elasticsearch 中搜索文档。返回匹配的文档及其评分和元数据。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `deploymentType` | string | 是 | 部署类型：self_hosted 或 cloud |
| `host` | string | 否 | Elasticsearch 主机 URL\(自托管部署\) |
| `cloudId` | string | 否 | Elastic Cloud ID\(云端部署\) |
| `authMethod` | string | 是 | 认证方式：api_key 或 basic_auth |
| `apiKey` | string | 否 | Elasticsearch API 密钥 |
| `username` | string | 否 | 基本认证用户名 |
| `password` | string | 否 | 基本认证密码 |
| `index` | string | 是 | 要搜索的索引名称 |
| `query` | string | 否 | JSON 字符串形式的 Query DSL |
| `from` | number | 否 | 分页起始偏移量\(默认：0\) |
| `size` | number | 否 | 返回结果数量\(默认：10\) |
| `sort` | string | 否 | JSON 字符串形式的排序规则 |
| `sourceIncludes` | string | 否 | 要包含在 _source 中的字段列表，以逗号分隔 |
| `sourceExcludes` | string | 否 | 要从 _source 中排除的字段列表，以逗号分隔 |
| `trackTotalHits` | boolean | 否 | 跟踪准确的总命中数\(默认：true\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `took` | 数字 | 搜索耗时（毫秒） |
| `timed_out` | 布尔值 | 搜索是否超时 |
| `hits` | 对象 | 搜索结果，包含总数和匹配的文档 |
| `aggregations` | JSON | 聚合结果（如有） |

</div>

| `username` | string | 否 | 基本认证的用户名 |
| `password` | string | 否 | 基本认证的密码 |
| `index` | string | 是 | 索引名称 |

| `sourceIncludes` | string | 否 | 要包含的字段列表，以逗号分隔 |
