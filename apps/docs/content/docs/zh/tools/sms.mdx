## 工具

### `sms_send`

使用internal SMS 服务提供支持由Twilio发送一个 SMS 消息

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `to` | 字符串 | 是 | 收件人 phone 数字 \(包括国家代码, 例如： +1234567890\) |
| `body` | 字符串 | 是 | SMS 消息内容 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否SMS 曾为已发送 successfully |
| `to` | 字符串 | 收件人 phone 数字 |


## 用法说明

使用internal SMS 服务提供支持由Twilio. 无外部配置或OAuth 必填. Perfect，用于sending 通知, 警报,或general 用途文本消息，来源为你的 workflow. 需要有效 phone numbers 使用国家代码.发送SMS 消息 directly
