## 工具

### `historical_data_fetch`

从注册的市场提供商获取并标准化市场序列数据。

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `provider` | string | 是 | 市场数据提供商 ID（例如：alpaca、finnhub、yahoo-finance）。 |
| `listing` | listingIdentity | 是 | 来自 TradingGoose Market 的结构化标的负载。 |
| `apiKey` | string | 是 | Alpha Vantage API 密钥。 |
| `apiSecret` | string | 是 | Alpaca API 私钥。 |
| `feed` | string | 是 | Alpaca 数据源（股票 K 线所需）。 |
| `interval` | string | 否 | 提供商支持的序列间隔/时间范围。 |
| `normalizationMode` | string | 否 | 提供商支持的标准化模式（可选）。 |
| `window` | json | 是 | 主序列窗口（范围、K 线或绝对时间）。 |
| `fallbackWindow` | json | 否 | 如果主序列不支持或无效，则使用备用序列窗口。 |
| `providerParams` | json | 否 | 可选的提供商特定参数。 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `listingBase` | string | 列表基础符号 |
| `listingQuote` | string | 列表报价货币 |
| `listing` | listingIdentity | 结构化列表标识符载荷 |
| `bars` | array | 带时间戳的OHLCV柱状数据 |
| `start` | string | 返回序列的开始 |
| `end` | string | 返回序列的结束 |
| `timezone` | string | 序列的交易所时区 |
| `normalizationMode` | string | 使用的规范化模式 |

## 使用说明

选择市场数据提供商，选择一个规范列表，并获取包含开盘价、最高价、最低价、收盘价、成交量和时间戳的K线数据。开始和结束时间可以是ISO字符串或UNIX时间戳。
