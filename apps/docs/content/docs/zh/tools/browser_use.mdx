## 工具

### `browser_use_run_task`

运行一个 browser 自动化 task 使用 BrowserUse

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `task` | 字符串 | 是 | 内容应该 browser agent do |
| `variables` | json | 否 | 可选变量到使用作为 secrets \(格式: \{key: value\}\) |
| `format` | 字符串 | 否 | 否说明 |
| `save_browser_data` | 布尔值 | 否 | 是否 save browser data |
| `model` | 字符串 | 否 | LLM 模型到使用 \(默认: gpt-4o\) |
| `apiKey` | 字符串 | 是 | API 密钥用于 BrowserUse API |
| `profile_id` | 字符串 | 否 | Browser profile ID 用于 persistent sessions \(cookies, login state\) |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 任务 execution 标识符 |
| `success` | 布尔值 | 任务 completion status |
| `output` | json | 任务 output data |


## 用量说明

将 Browser Use 集成到工作流中。你可以浏览网页并执行操作，效果如同真实用户与浏览器交互。
