## 工具

### `browser_use_run_task`

使用 BrowserUse 运行浏览器自动化任务

#### 输入

| 参数 | 类型 | 必需 | 描述 |
| --------- | ---- | -------- | ----------- |
| `task` | string | 是 | 浏览器代理应执行什么操作 |
| `variables` | json | 否 | 用作密钥的可选变量 \(格式: \{key: value\}\) |
| `save_browser_data` | boolean | 否 | 是否保存浏览器数据 |
| `model` | string | 否 | 要使用的 LLM 模型 \(默认: gpt-4o\) |
| `apiKey` | string | 是 | BrowserUse API 的 API 密钥 |
| `profile_id` | string | 否 | 用于持久会话的浏览器配置文件 ID \(Cookie、登录状态\) |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `id` | string | 任务执行标识符 |
| `success` | boolean | 任务完成状态 |
| `output` | json | 任务输出数据 |
| `steps` | json | 执行步骤 |

## 使用说明

将 Browser Use 集成到工作流中。可以像真实用户与浏览器交互一样浏览网页并执行操作。

## 注意事项

- 类别：`tools`
- 类型：`browser_use`
