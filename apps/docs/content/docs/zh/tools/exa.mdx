<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| --------- | ---- | -------- | ----------- |
| `query` | string | 是 | 要执行的搜索查询 |
| `numResults` | number | 否 | 要返回的结果数量 \(默认: 10, 最大: 25\) |
| `useAutoprompt` | boolean | 否 | 是否使用 autoprompt 来改进查询 \(默认: false\) |
| `type` | string | 否 | 搜索类型：神经、关键词、自动或快速 \(默认: 自动\) |
| `apiKey` | string | 是 | Exa AI API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `results` | array | 包含标题、URL 和文本片段的搜索结果 |
