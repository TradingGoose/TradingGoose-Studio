<div className="text-base font-semibold mb-2">搜索 (<code>exa_search</code>)</div>

搜索该 web 使用 Exa AI. 返回 relevant search 结果使用 titles, URLs, 和 text snippets.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 该 search query 到 execute |
| `numResults` | 数字 | 否 | 数字的结果到 return \(默认: 10, max: 25\) |
| `useAutoprompt` | 布尔值 | 否 | 是否使用 autoprompt 到 improve 该 query \(默认: 否\) |
| `type` | 字符串 | 否 | 搜索 type: neural, 关键词, auto 或 fast \(默认: auto\) |
| `apiKey` | 字符串 | 是 | Exa AI API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `title` | 字符串 | 该 title 的该 search 结果 |
| `url` | 字符串 | 该 URL 的该 search 结果 |
| `publishedDate` | 字符串 | 日期何时该 content was 已发布 |
| `author` | 字符串 | 该 author 的该 content |
| `summary` | 字符串 | 一个 brief summary 的该 content |
| `favicon` | 字符串 | URL 的该站点 |
| `image` | 字符串 | URL 的一个 representative 图像从该页面 |
| `text` | 字符串 | 文本 snippet 或完整 content 从该页面 |

</div>

<div className="text-base font-semibold mb-2">获取 Contents (<code>exa_get_contents</code>)</div>

检索该 contents 的 webpages 使用 Exa AI. 返回该 title, text content, 和可选 summaries 用于每个 URL.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `urls` | 字符串 | 是 | 以逗号分隔列表的 URLs 到 retrieve content 从 |
| `text` | 布尔值 | 否 | 如果为是，则使用默认设置返回完整页面文本；如果为否，则不返回文本。 |
| `summaryQuery` | 字符串 | 否 | 查询到 guide 该 summary generation |
| `apiKey` | 字符串 | 是 | Exa AI API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `url` | 字符串 | 该 URL 该 content was retrieved 从 |
| `title` | 字符串 | 该 title 的该 webpage |
| `text` | 字符串 | 该完整 text content 的该 webpage |
