## 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `server` | string | 是 | 用于执行工具的 MCP 服务器 ID |
| `tool` | string | 否 | 要执行的工具名称 |
| `arguments` | json | 否 | 传递给工具的参数 |

## 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | array | 来自 MCP 工具响应的内容数组，即所有 MCP 工具的标准格式 |

## 使用说明

将 MCP 集成到工作流中。可执行工作区仪表盘小组件中已配置的 MCP 服务器上的工具。
