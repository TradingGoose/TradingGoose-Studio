| `webmail` | 布尔值 | 是否该 电子邮件 is 从一个 webmail 提供商 |
| `mx_records` | 布尔值 | 是否 MX records exist 用于该域名 |
| `smtp_server` | 布尔值 | 是否该 SMTP 服务器 is reachable |
| `smtp_check` | 布尔值 | 是否该 SMTP check was 成功 |
| `accept_all` | 布尔值 | 是否该域名 accepts 全部 电子邮件 addresses |
| `block` | 布尔值 | 是否该 电子邮件 is blocked |
| `status` | 字符串 | Verification status: 有效, 无效, accept_all, webmail, disposable, 或 unknown |
