创建新的付款意向以处理付款

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | 是 | Stripe API 密钥（密钥） |
| `amount` | number | 是 | 金额，以美分为单位（例如 2000 表示 $20.00） |
| `currency` | string | 是 | 三字母 ISO 货币代码（例如 usd、eur） |
| `customer` | string | 否 | 要关联到此付款的客户 ID |
| `payment_method` | string | 否 | 付款方式 ID |
| `description` | string | 否 | 付款说明 |
| `receipt_email` | string | 否 | 用于接收收据的电子邮件地址 |
| `metadata` | json | 否 | 用于存储附加信息的键值对 |
| `automatic_payment_methods` | json | 否 | 启用自动付款方式（例如 {"enabled": true}） |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `payment_intent` | json | 已创建的付款意向对象 |
| `metadata` | json | 付款意向元数据，包括 ID、状态、金额和货币 |
