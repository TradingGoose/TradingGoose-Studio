上传一个 file 到 Dropbox

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `path` | 字符串 | 是 | 该 path 在 Dropbox 位置该 file 应 be saved \(例如, /folder/document.pdf\) |
| `fileContent` | 字符串 | 是 | 该 base64 encoded content 的该 file 到 upload |
| `fileName` | 字符串 | 否 | 可选文件名\(当路径为文件夹时使用\) |
| `mode` | 字符串 | 否 | 写入模式: add \(默认\) 或 overwrite |
| `autorename` | 布尔值 | 否 | 如果为是，则在文件名冲突时自动重命名文件 |
| `mute` | 布尔值 | 否 | If 是, don't notify 该 用户 关于 此 upload |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 唯一标识符用于该 file |
| `name` | 字符串 | 名称的该 file |
| `path_display` | 字符串 | Display path 的该 file |
| `path_lower` | 字符串 | Lowercase path 的该 file |
| `size` | 数字 | 大小的该 file 在 bytes |
| `client_modified` | 字符串 | 客户端 modification time |
| `server_modified` | 字符串 | 服务器 modification time |
| `rev` | 字符串 | Revision 标识符 |
