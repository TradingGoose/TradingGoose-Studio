## 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `context` | string | 是 | 要翻译的文本 |
| `targetLanguage` | string | 是 | 目标语言 |
| `model` | combobox | 是 | 模型 |
| `apiKey` | string | 否 | 提供商 API 密钥 |
| `azureEndpoint` | string | 否 | Azure OpenAI 终结点 URL |
| `azureApiVersion` | string | 否 | Azure API 版本 |

## 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | string | 翻译文本 |
| `model` | string | 所用模型 |
| `tokens` | json | Token 用量 |

## 使用说明

将文本翻译为任意语言。模型列表在运行时从该部署可用的基础模型、Ollama 和 OpenRouter 模型加载。
