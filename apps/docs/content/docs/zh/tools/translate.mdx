#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `content` | 字符串 | Translated 文本 |
| `model` | 字符串 | 模型使用的 |
| `tokens` | json | token usage |
