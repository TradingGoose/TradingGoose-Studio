更新一个 Jira issue

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `issueKey` | 字符串 | 是 | Jira issue key 到 update |
| `summary` | 字符串 | 否 | 新 summary 用于该 issue |
| `description` | 字符串 | 否 | 新说明用于该 issue |
| `status` | 字符串 | 否 | 新 status 用于该 issue |
| `priority` | 字符串 | 否 | 新优先级用于该 issue |
| `assignee` | 字符串 | 否 | 新 assignee 用于该 issue |
| `cloudId` | 字符串 | 否 | 该实例的 Jira Cloud ID。如果未提供，将通过域名获取。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `issueType` | 字符串 | 是 | 类型的 issue 到 create \(例如, 任务, Story\) |
| `labels` | 数组 | 否 | 标签用于该 issue \(数组的标签 names\) |
| `duedate` | 字符串 | 否 | Due date 用于该 issue \(格式: YYYY-MM-DD\) |
| `reporter` | 字符串 | 否 | Reporter 账户 ID 用于该 issue |
| `environment` | 字符串 | 否 | 环境信息用于该 issue |
| `customFieldId` | 字符串 | 否 | 自定义字段 ID \(例如, customfield_10001\) |
| `customFieldValue` | 字符串 | 否 | 值用于该自定义字段 |

| `summary` | 字符串 | 问题 summary |
| `url` | 字符串 | URL 到该 created issue |
