写入一个 Jira Issue

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `projectId` | string | 是 | Issue 的项目 ID |
| `summary` | string | 是 | Issue 的摘要 |
| `description` | string | 否 | Issue 的描述 |
| `priority` | string | 否 | Issue 的优先级 ID 或名称\(例如 "10000" 或 "High"\) |
| `assignee` | string | 否 | Issue 的经办人账号 ID |
| `labels` | array | 否 | Issue 的标签\(标签名称数组\) |
| `duedate` | string | 否 | Issue 的截止日期\(格式：YYYY-MM-DD\) |
| `reporter` | string | 否 | Issue 的报告人账号 ID |
| `environment` | string | 否 | Issue 的环境信息 |
| `customFieldId` | string | 否 | 自定义字段 ID\(例如 customfield_10001\) |
| `customFieldValue` | string | 否 | 自定义字段的值 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `ts` | string | 操作的时间戳 |
| `issueKey` | string | 创建的 Issue 键\(例如 PROJ-123\) |
| `summary` | string | Issue 摘要 |
| `url` | string | 所创建 Issue 的 URL |
| `assigneeId` | string | 被分配用户的账号 ID\(如果已分配\) |

</div>
