| `toName` | string | 否 | 收件人名称 |

| `cc` | string | 否 | 抄送邮箱地址 |
| `bcc` | string | 否 | 密送邮箱地址 |
| `replyTo` | string | 否 | 回复邮箱地址 |
| `replyToName` | string | 否 | 回复人名称 |
| `attachments` | file[] | 否 | 要附加到邮件的文件 |
| `templateId` | string | 否 | 要使用的 SendGrid 模板 ID |
| `dynamicTemplateData` | json | 否 | 动态模板数据的 JSON 对象 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 邮件是否发送成功 |
| `messageId` | string | SendGrid 消息 ID |
| `to` | string | 收件人邮箱地址 |
| `subject` | string | 邮件主题 |
