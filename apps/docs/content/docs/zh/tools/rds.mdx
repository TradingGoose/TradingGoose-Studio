| `database` | string | 否 | 数据库名称 \(可选\) |
| `query` | string | 是 | 要执行的 SQL SELECT 查询 |

| `rowCount` | number | 返回的行数 |

## 使用说明

使用 Data API 将 Amazon RDS Aurora Serverless 集成到工作流中。无需管理数据库连接即可查询、插入、更新、删除和执行原始 SQL。
