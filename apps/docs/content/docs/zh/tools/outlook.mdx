使用Outlook发送电子邮件

| `body` | 字符串 | 是 | 电子邮件正文内容 |
| `contentType` | 字符串 | 否 | 内容类型，用于email 正文 \(文本或html\) |
| `replyToMessageId` | 字符串 | 否 | 消息 ID到reply到\(用于 threading\) |
| `conversationId` | 字符串 | 否 | 对话 ID，用于threading |
| `cc` | 字符串 | 否 | CC 收件人 \(comma-separated\) |
| `bcc` | 字符串 | 否 | BCC 收件人 \(comma-separated\) |
| `attachments` | file[] | 否 | 文件到attach到email |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |

| `status` | 字符串 | Delivery 状态的email |
| `timestamp` | 字符串 | 时间戳当email 曾为已发送 |

## 用法说明

将Outlook集成到 workflow 中。可以读取, 草稿,和发送 email 消息. 可为使用的在trigger 模式到trigger 一个 workflow 当一个新建 email 为 received.
