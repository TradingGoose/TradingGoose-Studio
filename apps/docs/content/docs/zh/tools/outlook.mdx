使用 Outlook 发送邮件

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `subject` | string | 是 | 邮件主题 |
| `body` | string | 是 | 邮件正文内容 |
| `contentType` | string | 否 | 邮件正文的内容类型 \(text 或 html\) |
| `replyToMessageId` | string | 否 | 要回复的消息 ID \(用于会话串联\) |
| `conversationId` | string | 否 | 用于会话串联的会话 ID |
| `cc` | string | 否 | 抄送收件人 \(以逗号分隔\) |
| `bcc` | string | 否 | 密送收件人 \(以逗号分隔\) |
| `attachments` | file[] | 否 | 要附加到邮件的文件 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 邮件发送成功状态 |
| `status` | string | 邮件的送达状态 |
| `timestamp` | string | 邮件发送时间戳 |
| `message` | string | 成功或错误消息 |

## 使用说明

将 Outlook 集成到工作流中。可读取、起草和发送电子邮件。可在触发模式下使用，在收到新邮件时触发工作流。
