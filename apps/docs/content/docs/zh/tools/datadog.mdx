<div className="text-base font-semibold mb-2">创建停机时间 (<code>datadog_create_downtime</code>)</div>

安排停机时间，以在维护窗口期间抑制监控器通知。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必需 | 描述 |
| --------- | ---- | -------- | ----------- |
| `scope` | string | 是 | 应用停机时间的范围 \(例如，"host:myhost"、"env:production"，或 "*" 表示全部\) |
| `message` | string | 否 | 停机期间显示的消息 |
| `start` | number | 否 | 停机开始的 Unix 时间戳 \(默认为当前时间\) |
| `end` | number | 否 | 停机结束的 Unix 时间戳 |
| `timezone` | string | 否 | 停机的时区 \(例如，"America/New_York"\) |
| `monitorId` | string | 否 | 要静音的特定监控器 ID |
| `monitorTags` | string | 否 | 要匹配的逗号分隔的监控器标签 \(例如，"team:backend,priority:high"\) |
| `muteFirstRecoveryNotification` | boolean | 否 | 静音第一个恢复通知 |
| `apiKey` | string | 是 | Datadog API 密钥 |
| `applicationKey` | string | 是 | Datadog 应用程序密钥 |
| `site` | string | 否 | Datadog 站点/区域 \(默认：datadoghq.com\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `downtime` | object | 创建的停机时间详细信息 |

</div>
