<div className="text-base font-semibold mb-2">创建事件 (<code>datadog_create_event</code>)</div>

Post 一个 event 到该 Datadog event stream. 使用用于部署 notifications, alerts, 或任何 significant occurrences.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `title` | 字符串 | 是 | 事件 title |
| `text` | 字符串 | 是 | 事件 body/说明. Supports markdown. |
| `alertType` | 字符串 | 否 | 警报 type: error, warning, info, success, user_update, recommendation, 或 snapshot |
| `priority` | 字符串 | 否 | 事件优先级: normal 或 low |
| `host` | 字符串 | 否 | 主机 名称 到 associate 使用此 event |
| `tags` | 字符串 | 否 | 以逗号分隔列表的标签 \(例如, "env:production,服务:api"\) |
| `aggregationKey` | 字符串 | 否 | 键到 aggregate events together |
| `sourceTypeName` | 字符串 | 否 | 来源 type 名称 用于该 event |
| `dateHappened` | 数字 | 否 | Unix 时间戳何时该 event occurred \(默认为 now\) |
| `apiKey` | 字符串 | 是 | Datadog API 密钥 |
| `site` | 字符串 | 否 | Datadog 站点/region \(默认: datadoghq.com\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 数字 | 事件 ID |
| `title` | 字符串 | 事件 title |
| `text` | 字符串 | 事件 text |
| `date_happened` | 数字 | Unix 时间戳何时 event occurred |
| `priority` | 字符串 | 事件优先级 |
| `alert_type` | 字符串 | 警报 type |
| `host` | 字符串 | 关联主机 |
| `tags` | 数组 | 事件标签 |

</div>

| `query` | 字符串 | 是 | 监控器 query \(例如, "avg\(last_5m\):avg:system.cpu.idle\{*\} &lt; 20"\) |
| `message` | 字符串 | 否 | 消息到包含使用 notifications. 可以包含 @-mentions 和 markdown. |
| `tags` | 字符串 | 否 | 以逗号分隔列表的标签 |
| `priority` | 数字 | 否 | 监控器优先级 \(1-5, 位置 1 is highest\) |
| `options` | 字符串 | 否 | JSON 字符串的 monitor 选项 \(thresholds, notify_no_data, renotify_interval, etc.\) |
| `apiKey` | 字符串 | 是 | Datadog API 密钥 |
| `applicationKey` | 字符串 | 是 | Datadog 应用程序 key |
| `site` | 字符串 | 否 | Datadog 站点/region \(默认: datadoghq.com\) |
