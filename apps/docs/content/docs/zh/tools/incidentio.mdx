<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| `page_size` | 数字 | 否 | 数字的 incidents 到 return 每页面 \(默认: 25\) |
| `after` | 字符串 | 否 | 分页 cursor 到 fetch 该下一个页面的结果 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 严重程度 ID |
| `name` | 字符串 | 严重程度 名称 |
| `summary` | 字符串 | Brief summary 的该 incident |
| `description` | 字符串 | Detailed 说明的该 incident |
| `mode` | 字符串 | 事件模式 \(例如, standard, retrospective\) |
| `call_url` | 字符串 | URL 用于该 incident call/bridge |

创建一个新 incident 在 incident.io. Requires idempotency_key, severity_id, 和可见性. Optionally accepts 名称, summary, type, 和 status.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | incident.io API 密钥 |
| `idempotency_key` | 字符串 | 是 | 唯一标识符到 prevent duplicate incident creation. 使用一个 UUID 或唯一字符串. |
| `name` | 字符串 | 否 | 名称的该 incident \(可选\) |
| `summary` | 字符串 | 否 | Brief summary 的该 incident |
| `severity_id` | 字符串 | 是 | ID 的该严重程度 level \(required\) |
| `incident_type_id` | 字符串 | 否 | ID 的该 incident type |
| `incident_status_id` | 字符串 | 否 | ID 的该 initial incident status |
| `visibility` | 字符串 | 是 | 可见性的该 incident: "公开" 或 "私有" \(required\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 严重程度 ID |
| `name` | 字符串 | 严重程度 名称 |
| `summary` | 字符串 | Brief summary 的该 incident |
| `description` | 字符串 | Detailed 说明的该 incident |
| `mode` | 字符串 | 事件模式 \(例如, standard, retrospective\) |
| `call_url` | 字符串 | URL 用于该 incident call/bridge |
