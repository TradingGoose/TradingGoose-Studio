## 工具

### `trading_order_history`

获取在日期时间范围内记录的工作区订单提交。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `startDate` | string | 是 | 开始日期时间 \(ISO 8601\)。 |
| `endDate` | string | 是 | 结束日期时间 \(ISO 8601\)。 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `history` | array | 已记录订单提交的有序列表。 |
| `count` | number | 返回的记录数。 |
| `workspaceId` | string | 用于筛选的工作区 ID。 |
| `startDate` | string | 用于筛选的开始日期时间。 |
| `endDate` | string | 用于筛选的结束日期时间。 |

## 使用说明

获取 Trading Action 工具在所选日期范围内记录的订单提交历史。
