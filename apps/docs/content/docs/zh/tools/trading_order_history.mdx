## 工具

### `trading_order_history`

检索workspace 订单提交范围内一个 datetime 范围.

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `startDate` | 字符串 | 是 | 启动datetime \(ISO 8601\). |
| `endDate` | 字符串 | 是 | 结束 datetime \(ISO 8601\). |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 订单历史记录 record ID |
| `provider` | 字符串 | Trading 提供商 |
| `recordedAt` | 字符串 | 已记录时间戳 |
| `logId` | 字符串 | Linked workflow log ID |


## 用法说明

Fetches 订单 submission 历史记录已记录由Trading 操作工具，用于workspace和日期范围.
