## 工具

### `stagehand_agent`

运行一个 autonomous web agent到complete 任务和extract structured 数据

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `startUrl` | 字符串 | 是 | URL的webpage到开始 agent 在 |
| `task` | 字符串 | 是 | 任务到complete或goal到achieve 在 website |
| `variables` | json | 否 | 可选 variables到substitute在任务 \(格式: \{键: 值\}\). Reference在任务使用 %键% |
| `format` | 字符串 | 否 | 无描述 |
| `provider` | 字符串 | 否 | AI 提供商到使用: openai或anthropic |
| `apiKey` | 字符串 | 是 | API 键，用于所选提供商 |
| `outputSchema` | json | 否 | 可选 JSON 架构 defining structure的数据 agent 应返回 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否agent 任务已完成 successfully |
| `completed` | 布尔值 | 是否任务曾为 fully 已完成 |
| `message` | 字符串 | 状态消息或final 结果 |


## 用法说明

将Stagehand Agent集成到 workflow 中。可以navigate web和perform 任务.
