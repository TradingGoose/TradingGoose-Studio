## 工具

### `stagehand_agent`

运行自主网页智能体，完成任务并提取结构化数据

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `startUrl` | string | 是 | 智能体起始网页的 URL |
| `task` | string | 是 | 要在网站上完成的任务或达成的目标 |
| `variables` | json | 否 | 可在任务中替换的可选变量\(格式：\{key: value\}\)。在任务中使用 %key% 引用 |
| `provider` | string | 否 | 要使用的 AI 提供商：openai 或 anthropic |
| `apiKey` | string | 是 | 所选提供商的 API 密钥 |
| `outputSchema` | json | 否 | 可选 JSON schema，用于定义智能体应返回的数据结构 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `agentResult` | object | Stagehand Agent 的执行结果 |
| `structuredOutput` | object | 与所提供输出架构匹配的提取数据 |

## 使用说明

将 Stagehand Agent 集成到工作流中。可浏览网页并执行任务。
