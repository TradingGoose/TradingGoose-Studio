## 工具

### `jina_read_url`

提取和处理 web content 到 clean, LLM-friendly text 使用 Jina AI Reader. Supports 高级 content parsing, link gathering, 和多个 output formats 使用 configurable processing 选项.

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `url` | 字符串 | 是 | 该 URL 到 read 和转换到 markdown |
| `useReaderLMv2` | 布尔值 | 否 | 是否使用 ReaderLM-v2 用于 better quality |
| `gatherLinks` | 布尔值 | 否 | 是否 gather 全部链接在该 end |
| `jsonResponse` | 布尔值 | 否 | 是否 return response 在 JSON 格式 |
| `apiKey` | 字符串 | 是 | 你的 Jina AI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | 字符串 | Extracted content |


## 用量说明

集成 Jina 到该 workflow. Extracts content 从 websites.
