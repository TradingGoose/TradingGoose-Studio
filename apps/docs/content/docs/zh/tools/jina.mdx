## 工具

### `jina_read_url`

使用 Jina AI Reader 将网页内容提取并处理为干净、适合 LLM 的文本。支持高级内容解析、链接收集以及多种输出格式，并提供可配置的处理选项。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `url` | string | 是 | 要读取并转换为 Markdown 的 URL |
| `useReaderLMv2` | boolean | 否 | 是否使用 ReaderLM-v2 以获得更好质量 |
| `gatherLinks` | boolean | 否 | 是否在末尾收集所有链接 |
| `jsonResponse` | boolean | 否 | 是否以 JSON 格式返回响应 |
| `apiKey` | string | 是 | 你的 Jina AI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | string | 从 URL 提取的内容，已处理为干净、适合 LLM 的文本 |

## 使用说明

将 Jina 集成到工作流中。从网站提取内容。
