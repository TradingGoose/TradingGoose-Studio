## 使用和输出

提供图片 URL 或上传文件，并输入分析指令。文件继续经过身份验证、存储引用处理及下载。所选模型会接收图片内容。输出保留 `content`、`model`、`tokens` 及可用的原生用量明细。

## 用量和费用

Studio 按 OpenCode models.dev 目录价格计算费用。缺失费用不等于零；即使美元金额缺失，已知 token 用量仍会保留。产品自身的费用单独计算。独立嵌入会保留向量和用量，并在价格和用量均已知时记录美元费用。
