## 工具

### `vision_tool`

Process和analyze 图像使用 advanced 视觉模型. Capable的understanding 图像内容, extracting 文本, identifying 对象,和providing 详细 visual descriptions.

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | API 键，用于所选 model 提供商 |
| `imageUrl` | 字符串 | 否 | Publicly accessible 图像 URL |
| `imageFile` | file | 否 | 图像 file到analyze |
| `model` | 字符串 | 否 | 视觉 model到使用 \(gpt-4o, claude-3-opus-20240229, etc\) |
| `prompt` | 字符串 | 否 | 自定义 prompt，用于图像 analysis |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `content` | 字符串 | analyzed 内容和描述的图像 |
| `model` | 字符串 | 视觉 model 该曾为使用的，用于analysis |
| `tokens` | 数字 | 总计 tokens 使用的，用于analysis |
| `input_tokens` | 数字 | Tokens 使用的，用于输入处理 |
| `output_tokens` | 数字 | Tokens 使用的，用于response 生成 |


## 用法说明

将视觉集成到 workflow 中。可以analyze 图像使用视觉模型.
