## 使用和输出

提供图片 URL 或上传文件，并输入分析指令。文件继续经过身份验证、存储引用处理及下载。Mastra 接收多模态内容，并根据完整模型标识符选择提供方协议，包括 Anthropic。输出保留 `content`、`model`、`tokens` 及可用的原生用量明细。

## 用量和费用

记录会区分提供方报告的费用、原生估算费用和不可用费用。缺失费用不等于零；即使美元金额缺失，已知 token 用量仍会保留。产品自身的费用单独计算。独立嵌入保留向量及可用的原生用量，其美元费用显示为不可用。
