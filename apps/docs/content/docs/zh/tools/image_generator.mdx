使用 OpenAI 的图像模型生成图像

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `model` | string | 是 | 要使用的模型 \(gpt-image-1 或 dall-e-3\) |
| `prompt` | string | 是 | 所需图像的文本描述 |
| `size` | string | 是 | 生成图像的尺寸 \(1024x1024、1024x1792 或 1792x1024\) |
| `quality` | string | 否 | 图像质量 \(standard 或 hd\) |
| `style` | string | 否 | 图像风格 \(vivid 或 natural\) |
| `background` | string | 否 | 背景颜色，仅适用于 gpt-image-1 |
| `apiKey` | string | 是 | 你的 OpenAI API key |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `output` | object | 生成的图像数据 |

</div>
