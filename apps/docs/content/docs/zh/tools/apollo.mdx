<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |

| `person_seniorities` | array | 否 | 资历级别 \\(例如，\\[\"高级\", \"高管\", \"经理\"\\]\\) |
| `organization_names` | array | 否 | 要在其中搜索的公司名称 |
| `q_keywords` | string | 否 | 要搜索的关键词 |
| `page` | number | 否 | 分页的页码 \\(默认：1\\) |
| `per_page` | number | 否 | 每页结果数 \\(默认：25，最大：100\\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `people` | json | 符合搜索条件的人员数组 |
| `metadata` | json | 分页信息，包括 page、per_page 和 total_entries |
