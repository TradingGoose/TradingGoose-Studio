| --------- | ---- | -------- | ----------- |

| `content` | 字符串 | 否 | 文本内容到upload \(如果否 file 为提供的\) |
| `mimeType` | 字符串 | 否 | MIME 类型的file到创建 \(例如： 文本/plain，用于.txt, 应用/vnd.openxmlformats-officedocument.spreadsheetml.sheet，用于.xlsx\) |

| `manualFolderId` | 字符串 | 否 | Manually entered 文件夹 ID \(advanced 模式\) |

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否file 曾为 uploaded successfully |
