| 参数 | 类型 | 必填 | 说明 |

| `mimeType` | string | 否 | 要创建文件的 MIME 类型 \(例如：.txt 对应 text/plain，.xlsx 对应 application/vnd.openxmlformats-officedocument.spreadsheetml.sheet\) |
| `folderId` | string | 否 | 要将文件上传到的文件夹 ID |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 文件是否上传成功 |
| `file` | object | 已上传的文件对象，包含 id、name、webViewLink、webContentLink 和时间戳等元数据 |

</div>

将 OneDrive 集成到工作流中。可创建文本和 Excel 文件、上传文件以及列出文件。
