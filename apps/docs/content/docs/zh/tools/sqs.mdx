## 工具

### `sqs_send`

发送一个消息到一个 Amazon SQS 队列

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `region` | 字符串 | 是 | AWS 区域 \(例如： us-east-1\) |
| `accessKeyId` | 字符串 | 是 | AWS 访问键 ID |
| `secretAccessKey` | 字符串 | 是 | AWS 密钥访问键 |
| `queueUrl` | 字符串 | 是 | 队列 URL |
| `data` | 对象 | 是 | 消息正文到发送 |
| `messageGroupId` | 字符串 | 否 | 消息组 ID \(可选\) |
| `messageDeduplicationId` | 字符串 | 否 | 消息 deduplication ID \(可选\) |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | 字符串 | 操作状态消息 |


## 用法说明

将Amazon SQS集成到 workflow 中。可以发送消息到SQS queues.
