## 工具

### `openai_embeddings`

使用 OpenAI 的嵌入模型从文本生成嵌入

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `input` | string | 是 | 用于生成嵌入的文本 |
| `model` | string | 否 | 用于生成嵌入的模型 |
| `apiKey` | string | 是 | OpenAI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `output` | object | 嵌入生成结果 |

## 使用说明

将 Embeddings 接入工作流，可从文本生成嵌入。

## 备注

- 类别：`tools`
- 类型：`openai`


模型字段从原生注册表加载可用的 OpenAI 嵌入模型。请选择完整标识符，例如 `openai/text-embedding-3-small`。输入文本会原样保留；超过模型限制的文本将被拒绝。只有模型报告时才显示令牌用量；模型的美元成本不可用。
