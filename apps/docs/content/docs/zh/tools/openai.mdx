## 工具

### `openai_embeddings`

使用 OpenAI 从文本生成 embeddings。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `input` | string | 是 | 用于生成 embeddings 的文本 |
| `model` | string | 否 | 用于生成 embeddings 的模型 |
| `encodingFormat` | string | 否 | 返回 embeddings 的格式 |
| `apiKey` | string | 是 | OpenAI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作是否成功 |
| `embeddings` | array | embedding 向量数组 |
| `model` | string | 用于生成 embeddings 的模型 |
| `prompt_tokens` | number | prompt 中的 token 数量 |


## 使用说明

将 Embeddings 集成到 workflow 中，以从文本生成 embeddings。
