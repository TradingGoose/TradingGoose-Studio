## 工具

### `openai_embeddings`

使用 OpenAI 的嵌入模型从文本生成嵌入

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `input` | string | 是 | 用于生成嵌入的文本 |
| `model` | string | 否 | 用于生成嵌入的模型 |
| `apiKey` | string | 是 | OpenAI API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `output` | object | 嵌入生成结果 |

## 使用说明

将 Embeddings 接入工作流，可从文本生成嵌入。
