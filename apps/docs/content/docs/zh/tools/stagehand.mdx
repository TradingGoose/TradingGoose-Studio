## 工具

### `stagehand_extract`

Extract structured 数据，来源为一个 webpage 使用 Stagehand

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `url` | 字符串 | 是 | URL的webpage到extract 数据，来源为|
| `instruction` | 字符串 | 是 | 说明，用于提取 |
| `provider` | 字符串 | 否 | AI 提供商到使用: openai或anthropic |
| `apiKey` | 字符串 | 是 | API 键，用于所选提供商 |
| `schema` | json | 是 | JSON 架构 defining structure的数据到extract |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `data` | json | Extracted 数据 |


## 用法说明

将Stagehand集成到 workflow 中。可以extract structured 数据，来源为webpages.
