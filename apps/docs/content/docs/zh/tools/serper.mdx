## 工具

### `serper_search`

强大的网络搜索工具，可通过 Serper.dev API 获取 Google 搜索结果。支持常规网页搜索、新闻、地点和图片等多种搜索类型，每条结果均包含标题、URL、摘要以及特定类型信息等元数据。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | string | 是 | 搜索查询 |
| `num` | number | 否 | 返回的结果数量 |
| `gl` | string | 否 | 搜索结果的国家/地区代码 |
| `hl` | string | 否 | 搜索结果的语言代码 |
| `type` | string | 否 | 要执行的搜索类型 |
| `apiKey` | string | 是 | Serper API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `searchResults` | array | 搜索结果，包含标题、链接、摘要以及特定类型的元数据 \(新闻为 date，地点为 rating，图片为 imageUrl\) |

## 使用说明

将 Serper 集成到工作流中。可用于搜索网页。
