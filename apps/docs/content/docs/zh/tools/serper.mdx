## 工具

### `serper_search`

一款通过 Serper.dev API 访问 Google 搜索结果的强大 Web 搜索工具。支持常规 Web、新闻、地点和图像等搜索类型；每条结果都包含标题、URL、摘要和类型专属信息等相关元数据。

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 搜索查询 |
| `num` | 数字 | 否 | 数量：结果到返回 |
| `gl` | 字符串 | 否 | 国家代码，用于搜索结果 |
| `hl` | 字符串 | 否 | 语言代码，用于搜索结果 |
| `type` | 字符串 | 否 | 类型的搜索到perform |
| `apiKey` | 字符串 | 是 | Serper API 键 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `searchResults` | json | 搜索结果数据 |


## 用法说明

将Serper集成到 workflow 中。可以搜索 web.
