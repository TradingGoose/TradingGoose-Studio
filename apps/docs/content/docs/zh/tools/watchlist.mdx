<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `watchlistId` | string | 是 | 要读取的根观察列表 ID。 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `watchlist` | json | 自选列表记录。 |
| `items` | array | 按显示顺序排列的自选列表项，包括标的和分组。 |
| `listings` | array | 自选列表中的标的项。 |
| `sections` | array | 自选列表中的分组/分类项。 |

</div>

## 使用说明

读取根工作区的自选列表，查看按顺序排列的标的项，以及分组/分类项。

- 类别：`tools`
