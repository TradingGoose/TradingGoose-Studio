## 工具

### `google_search`

使用 Custom Search API 搜索网络

#### 输入

| 参数 | 类型 | 是否必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 要执行的搜索查询 |
| `searchEngineId` | 字符串 | 是 | 自定义搜索引擎 ID |
| `num` | 字符串 | 否 | 要返回的结果数量（默认：10，最大：10） |
| `apiKey` | 字符串 | 是 | Google API 密钥 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `items` | 数组 | 来自 Google 的搜索结果数组 |
| `searchInformation` | 对象 | 有关搜索查询和结果的信息 |

## 使用说明

将 Google Search 集成到工作流中。可搜索网络。
