## 工具

### `google_search`

搜索该 web 使用该自定义搜索 API

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 该 search query 到 execute |
| `searchEngineId` | 字符串 | 是 | 自定义搜索 Engine ID |
| `num` | 字符串 | 否 | 数字的结果到 return \(默认: 10, max: 10\) |
| `apiKey` | 字符串 | 是 | Google API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `title` | 字符串 | 标题的该 search 结果 |
| `link` | 字符串 | URL 的该 search 结果 |
| `snippet` | 字符串 | Snippet 或说明的该 search 结果 |
| `displayLink` | 字符串 | Display URL |


## 用量说明

集成 Google 搜索到该 workflow. 可以 search 该 web.
