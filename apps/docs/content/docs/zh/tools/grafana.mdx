<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | Grafana 服务账户令牌 |
| `baseUrl` | 字符串 | 是 | Grafana 实例 URL \(例如, https://your-grafana.com\) |
| `organizationId` | 字符串 | 否 | 组织 ID 用于 multi-org Grafana instances |
| `query` | 字符串 | 否 | 搜索 query 到 filter dashboards 按 title |
| `tag` | 字符串 | 否 | 按条件筛选标签 \(comma-separated 用于多个标签\) |
| `folderIds` | 字符串 | 否 | 按条件筛选 folder IDs \(comma-separated\) |
| `starred` | 布尔值 | 否 | 仅 return starred dashboards |
| `limit` | 数字 | 否 | 最大数字的 dashboards 到 return |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 数字 | 仪表板 ID |
| `uid` | 字符串 | 仪表板 UID |
| `title` | 字符串 | 仪表板 title |
| `url` | 字符串 | 仪表板 URL path |
| `tags` | 数组 | 仪表板标签 |

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | Grafana 服务账户令牌 |
| `baseUrl` | 字符串 | 是 | Grafana 实例 URL \(例如, https://your-grafana.com\) |
| `organizationId` | 字符串 | 否 | 组织 ID 用于 multi-org Grafana instances |
| `title` | 字符串 | 是 | 该 title 的该新 dashboard |
| `folderUid` | 字符串 | 否 | 该 UID 的该 folder 到 create 该 dashboard 在 |
| `tags` | 字符串 | 否 | 以逗号分隔列表的标签 |
| `timezone` | 字符串 | 否 | 仪表板时区 \(例如, browser, utc\) |
| `refresh` | 字符串 | 否 | Auto-refresh 间隔 \(例如, 5s, 1m, 5m\) |
| `panels` | 字符串 | 否 | JSON 数组的 panel configurations |
| `overwrite` | 布尔值 | 否 | Overwrite 现有 dashboard 使用 same title |
| `message` | 字符串 | 否 | 提交 message 用于该 dashboard version |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `id` | 数字 | 该 numeric ID 的该 created dashboard |
| `uid` | 字符串 | 该 UID 的该 created dashboard |
| `url` | 字符串 | 该 URL path 到该 dashboard |
| `status` | 字符串 | 状态的该 operation \(success\) |
| `version` | 数字 | 该 version 数字的该 dashboard |
