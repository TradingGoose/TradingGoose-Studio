| `pageObjectIds` | string | 否 | 逗号分隔的幻灯片对象 ID 列表，用于将替换限制到特定幻灯片\(留空表示所有幻灯片\) |

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `occurrencesChanged` | number | 被替换的文本出现次数 |
| `metadata` | json | 操作元数据，包括演示文稿 ID 和 URL |
