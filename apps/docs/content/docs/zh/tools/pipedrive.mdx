<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `status` | 字符串 | 否 | 仅获取特定状态的交易。取值：open、won、lost。若省略，则返回所有未删除的交易 |
| `person_id` | 字符串 | 否 | 若提供，则仅返回关联到指定联系人的交易 |
| `org_id` | 字符串 | 否 | 若提供，则仅返回关联到指定组织的交易 |
| `pipeline_id` | 字符串 | 否 | 若提供，则仅返回指定管道中的交易 |
| `updated_since` | 字符串 | 否 | 若设置，则仅返回此时间之后更新的交易。格式：2025-01-01T10:20:00Z |
| `limit` | 字符串 | 否 | 返回的结果数量（默认：100，最大：500） |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `deals` | array | 来自 Pipedrive 的交易对象数组 |
| `metadata` | object | 操作元数据 |
| `success` | boolean | 操作成功状态 |
