## 工具

### `duckduckgo_search`

搜索该 web 使用 DuckDuckGo Instant Answers API. 返回 instant answers, abstracts, 和相关 topics 用于你的 query. Free 到使用不含一个 API 密钥.

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 该 search query 到 execute |
| `noHtml` | 布尔值 | 否 | 移除 HTML 从 text 在结果 \(默认: 是\) |
| `skipDisambig` | 布尔值 | 否 | Skip disambiguation 结果 \(默认: 否\) |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `heading` | 字符串 | 该 heading/title 的该 instant 答案 |
| `abstract` | 字符串 | 一个 short abstract summary 的该 topic |
| `abstractText` | 字符串 | 纯文本 version 的该 abstract |
| `abstractSource` | 字符串 | 该来源的该 abstract \(例如, Wikipedia\) |
| `abstractURL` | 字符串 | URL 到该来源的该 abstract |
| `image` | 字符串 | URL 到一个图像相关到该 topic |
| `answer` | 字符串 | Direct 答案 if 可用 \(例如, 用于 calculations\) |
| `answerType` | 字符串 | 类型的该答案 \(例如, calc, ip, etc.\) |
| `type` | 字符串 | 响应 type: 一个 \(article\), D \(disambiguation\), C \(类别\), N \(名称\), E \(exclusive\) |
| `FirstURL` | 字符串 | URL 到该相关 topic |
| `Text` | 字符串 | 说明的该相关 topic |


## 用量说明
