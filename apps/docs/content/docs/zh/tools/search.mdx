## 工具

### `search_tool`

搜索网页. 返回最相关 web 结果, 包括标题, 链接, snippet,和日期，用于每个结果.

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `query` | 字符串 | 是 | 搜索查询 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `results` | json | 搜索结果 |
| `query` | 字符串 | 搜索查询 |
| `totalResults` | 数字 | 总计数字的结果 |
| `source` | 字符串 | 搜索来源 \(exa\) |
| `cost` | json | Cost 信息 \($0.01\) |


## 用法说明

搜索网页使用搜索工具. 每个搜索 costs $0.01 每个查询.
