创建页面在一个 SharePoint 站点

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `siteId` | 字符串 | 否 | 以下对象的 ID：SharePoint 站点 \(internal 使用\) |
| `siteSelector` | 字符串 | 否 | 选择SharePoint 站点 |
| `pageName` | 字符串 | 是 | 名称的页面到创建 |
| `pageTitle` | 字符串 | 否 | 页面标题\(如果未提供，默认为页面名称\) |
| `pageContent` | 字符串 | 否 | 内容的页面 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 唯一 ID：已创建页面 |
| `name` | 字符串 | 名称的已创建页面 |
| `title` | 字符串 | 标题的已创建页面 |
| `webUrl` | 字符串 | URL到访问页面 |
| `pageLayout` | 字符串 | layout 类型的页面 |
| `createdDateTime` | 字符串 | 当页面曾为已创建 |
