## 工具

### `trading_place_order`

通过 Alpaca 或 Tradier 下达买入或卖出订单。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `provider` | string | 是 | 所选经纪商提供方，用于账户与标的可用性。 |
| `portfolioIdentity` | json | 是 | 此订单所选的规范经纪账户标识。 |
| `listing` | listingIdentity | 是 | 待交易资产的结构化标的载荷。 |
| `side` | string | 是 | 订单方向：buy 或 sell。 |
| `quantity` | number | 否 | 当所选提供方的规模模式为 quantity 时要交易的数量。 |
| `notional` | number | 否 | 在所选提供方支持时要交易的美元金额。 |
| `orderSizingMode` | string | 否 | 从交易提供方能力中选择的订单规模模式。 |
| `orderType` | string | 否 | 从交易提供方能力中选择的订单类型。 |
| `timeInForce` | string | 否 | 有效期 \(day、gtc、gfd 等\)。 |
| `limitPrice` | number | 否 | 限价 \(限价单必填\)。 |
| `stopPrice` | number | 否 | 所选订单类型需要时的止损价。 |
| `trailPrice` | number | 否 | 所选订单类型支持时的跟踪价格偏移。 |
| `trailPercent` | number | 否 | 所选订单类型支持时的跟踪百分比偏移。 |
| `preview` | boolean | 否 | 在支持时预览提供方订单而不提交。 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `summary` | string | 订单提交的状态消息。 |
| `provider` | string | 该订单使用的券商/服务商。 |
| `appOrderId` | string | Trading Goose 订单 ID。 |
| `clientOrderId` | string | 用于重试的券商客户订单标识。 |
| `order` | json | 标准化订单详情及原始响应。 |

## 使用说明

统一交易操作块，用于从所选券商账户提交订单。
