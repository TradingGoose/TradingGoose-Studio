## 工具

### `trading_place_order`

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `summary` | 字符串 | 订单 submission 状态 |
| `provider` | 字符串 | 提供商使用的 |
| `order` | json | 订单 payload和原始 response |


## 用法说明

Unified trading 操作块 该 supports 多个 brokerages 使用任一 OAuth或API-key 身份验证.
