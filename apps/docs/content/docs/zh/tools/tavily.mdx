使用 Tavily 的搜索 API 执行 AI 驱动的网页搜索。返回包含标题、URL、摘要以及可选原始内容的结构化结果，针对相关性和准确性优化。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `query` | string | 是 | 要执行的搜索查询 |
| `max_results` | number | 否 | 最大结果数 \(1-20\) |
| `apiKey` | string | 是 | Tavily API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `query` | string | 已执行的搜索查询 |
| `results` | array | 包含标题、URL 和内容摘要的搜索结果 |
| `response_time` | number | 搜索请求耗时（秒）|

</div>

<div className="text-base font-semibold mb-2">提取内容 (<code>tavily_extract</code>)</div>

使用 Tavily 提取 API，可同时从多个网页提取原始内容。支持基础和高级提取深度，并对提取失败的 URL 提供详细错误报告。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `urls` | string | 是 | 要从中提取内容的 URL 或 URL 数组 |
| `extract_depth` | string | 否 | 提取深度 \(basic=每 5 个 URL 消耗 1 积分，advanced=每 5 个 URL 消耗 2 积分\) |
| `apiKey` | string | 是 | Tavily API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `results` | array | 已成功从 URL 提取的内容 |
| `failed_results` | array | 提取内容失败的 URL |
| `response_time` | number | 提取请求耗时（秒） |

</div>

## 使用说明

将 Tavily 集成到工作流中。可搜索网页并从指定 URL 提取内容。需要 API 密钥。
