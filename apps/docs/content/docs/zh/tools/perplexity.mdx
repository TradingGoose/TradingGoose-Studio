## 工具

### `perplexity_chat`

生成补全使用 Perplexity AI chat 模型

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | 字符串 | 否 | System prompt到guide model behavior |
| `content` | 字符串 | 是 | user 消息内容到发送到model |
| `model` | 字符串 | 是 | 模型到使用，用于chat 补全 \(例如： sonar, mistral\) |
| `max_tokens` | 数字 | 否 | 要生成的最大 token 数量 |
| `temperature` | 数字 | 否 | Sampling temperature 之间 0和1 |
| `apiKey` | 字符串 | 是 | Perplexity API 键 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 操作成功状态 |
| `content` | 字符串 | Generated 文本内容 |
| `model` | 字符串 | 模型使用的，用于生成 |
| `prompt_tokens` | 数字 | 数量：tokens在prompt |
| `completion_tokens` | 数字 | 数量：tokens在completion |


## 用法说明

将 Perplexity 集成到工作流中。你可以使用 Perplexity AI 聊天模型生成补全。
