## 工具

### `perplexity_chat`

使用 Perplexity AI 聊天模型生成补全

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | 否 | 用于引导模型行为的系统提示词 |
| `content` | string | 是 | 发送给模型的用户消息内容 |
| `model` | string | 是 | 用于聊天补全的模型 \(例如 sonar、mistral\) |
| `max_tokens` | number | 否 | 生成的最大 Token 数 |
| `temperature` | number | 否 | 采样温度，范围为 0 到 1 |
| `apiKey` | string | 是 | Perplexity API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `output` | object | 聊天补全结果 |

## 使用说明

将 Perplexity 集成到工作流中。可使用 Perplexity AI 聊天模型生成补全。
