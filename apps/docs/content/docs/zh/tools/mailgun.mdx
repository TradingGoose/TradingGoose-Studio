## 用量说明

集成 Mailgun 到你的 workflow. 发送 transactional emails, manage mailing lists 和 members, view 域名信息, 和 track 电子邮件 events. Supports text 和 HTML emails, 标签用于 tracking, 和 comprehensive 列表管理.
