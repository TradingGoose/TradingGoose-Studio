上传一个 file 到 Google Drive

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `content` | 字符串 | 否 | 要上传的文本内容 \(与 file 二选一，不能同时使用\) |
| `mimeType` | 字符串 | 否 | 要上传文件的 MIME 类型 \(未提供时从文件自动检测\) |
| `folderSelector` | 字符串 | 否 | 选择文件要上传到的文件夹 |
| `folderId` | 字符串 | 否 | 文件要上传到的文件夹 ID \(内部使用\) |
