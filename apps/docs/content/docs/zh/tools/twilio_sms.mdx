## 工具

### `twilio_send_sms`

使用Twilio API.发送文本消息到单个或多个收件人

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `phoneNumbers` | 字符串 | 是 | 电话 numbers到发送消息到, 分隔由newlines |
| `message` | 字符串 | 是 | 消息到发送 |
| `accountSid` | 字符串 | 是 | Twilio 账户 SID |
| `authToken` | 字符串 | 是 | Twilio 身份验证 token |
| `fromNumber` | 字符串 | 是 | Twilio phone 数字到发送消息，来源为|

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | SMS 发送成功状态 |
| `messageId` | 字符串 | 唯一 Twilio 消息标识符 \(SID\) |
| `status` | 字符串 | 消息 delivery 状态，来源为Twilio |
| `fromNumber` | 字符串 | 电话数字消息曾为已发送，来源为|


## 用法说明

将Twilio集成到 workflow 中。可以发送 SMS 消息.
