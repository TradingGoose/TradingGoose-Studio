## 工具

### `twilio_send_sms`

使用 Twilio API 向单个或多个收件人发送短信。

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `phoneNumbers` | string | 是 | 要发送消息的电话号码，以换行分隔 |
| `message` | string | 是 | 要发送的消息 |
| `accountSid` | string | 是 | Twilio 账户 SID |
| `authToken` | string | 是 | Twilio Auth Token |
| `fromNumber` | string | 是 | 用于发送消息的 Twilio 电话号码 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 短信发送成功状态 |
| `messageId` | string | 唯一的 Twilio 消息标识符 \(SID\) |
| `status` | string | Twilio 返回的消息送达状态 |
| `fromNumber` | string | 发送消息所用的电话号码 |
| `toNumber` | string | 消息发送到的电话号码 |

## 使用说明

将 Twilio 集成到工作流中。可发送短信。
