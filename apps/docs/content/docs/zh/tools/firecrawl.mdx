| `html` | string | 页面的原始 HTML 内容 |
| `metadata` | object | 页面元数据，包括 SEO 和 Open Graph 信息 |

爬取整个网站，并从所有可访问页面提取结构化内容

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 是否必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `url` | string | 是 | 要爬取的网站 URL |
| `limit` | number | 否 | 要爬取的最大页面数 \(默认值：100\) |
| `onlyMainContent` | boolean | 否 | 仅从页面提取主要内容 |
| `apiKey` | string | 是 | Firecrawl API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `pages` | array | 抓取页面的数组，包含其内容和元数据 |
| `total` | number | 抓取期间发现的页面总数 |
| `creditsUsed` | number | 抓取操作消耗的积分数量 |

</div>
