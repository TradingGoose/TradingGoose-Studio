发送一个 message 到一个 Discord 频道

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `botToken` | 字符串 | 是 | 该 bot 令牌用于 authentication |
| `channelId` | 字符串 | 是 | 该 Discord 频道 ID 到 send 该 message 到 |
| `content` | 字符串 | 否 | 该 text content 的该 message |
| `serverId` | 字符串 | 是 | 该 Discord 服务器 ID \(guild ID\) |
| `files` | file[] | 否 | 文件到 attach 到该 message |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `message` | 字符串 | 成功或 error message |
| `id` | 字符串 | Author 用户 ID |
| `content` | 字符串 | 消息 content |
| `channel_id` | 字符串 | 频道 ID 位置 message was sent |
| `username` | 字符串 | Author 用户名 |
| `avatar` | 字符串 | Author avatar hash |

</div>
