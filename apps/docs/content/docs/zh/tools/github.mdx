## 使用说明

将 GitHub 集成到工作流中。可获取 PR 详情、创建 PR 评论、获取仓库信息以及获取最新提交。可在触发器模式下使用，当创建 PR、对 PR 发表评论或推送提交时触发工作流。

## 说明

- 类别：`tools`
- 类型：`github`
