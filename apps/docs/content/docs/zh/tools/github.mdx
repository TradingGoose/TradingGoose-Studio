| `title` | 字符串 | PR title |
| `state` | 字符串 | PR state \(open/已关闭/merged\) |
| `html_url` | 字符串 | GitHub web URL |
| `diff_url` | 字符串 | 原始 diff URL |
| `created_at` | 字符串 | Creation 时间戳 |
| `updated_at` | 字符串 | 最后一个 update 时间戳 |
| `filename` | 字符串 | 文件 path |
| `additions` | 数字 | Lines added |
| `deletions` | 数字 | Lines deleted |
| `changes` | 数字 | 总计 changes |
| `patch` | 字符串 | 文件 diff patch |
| `blob_url` | 字符串 | GitHub blob URL |
| `raw_url` | 字符串 | 原始 file URL |

## 用量说明

将 GitHub 集成到工作流中。你可以获取 PR 详细信息、创建 PR 评论、获取仓库信息和最新提交。也可在触发器模式下，当 PR 创建、收到评论或提交被推送时触发工作流。
