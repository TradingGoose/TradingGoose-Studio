创建一个新 event 在 Google 日历

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `calendarId` | 字符串 | 否 | 日历 ID \(默认为 primary\) |
| `summary` | 字符串 | 是 | 事件 title/summary |
| `description` | 字符串 | 否 | 事件说明 |
| `location` | 字符串 | 否 | 事件位置 |
| `startDateTime` | 字符串 | 是 | 启动 date 和 time \(RFC3339 格式, 例如, 2025-06-03T10:00:00-08:00\) |
| `endDateTime` | 字符串 | 是 | End date 和 time \(RFC3339 格式, 例如, 2025-06-03T11:00:00-08:00\) |
| `timeZone` | 字符串 | 否 | 时间 zone \(例如, America/Los_Angeles\) |
| `attendees` | 数组 | 否 | 数组的 attendee 电子邮件 addresses |
| `sendUpdates` | 字符串 | 否 | 方式到 send updates 到 attendees: 全部, externalOnly, 或 none |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | 字符串 | 事件 creation confirmation message |
