在 Google Calendar 中创建新活动

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `calendarId` | string | 否 | 日历 ID \(默认使用 primary\) |
| `summary` | string | 是 | 活动标题/摘要 |
| `description` | string | 否 | 活动描述 |
| `location` | string | 否 | 活动地点 |
| `startDateTime` | string | 是 | 开始日期和时间 \(RFC3339 格式，例如 2025-06-03T10:00:00-08:00\) |
| `endDateTime` | string | 是 | 结束日期和时间 \(RFC3339 格式，例如 2025-06-03T11:00:00-08:00\) |
| `timeZone` | string | 否 | 时区 \(例如 America/Los_Angeles\) |
| `attendees` | array | 否 | 参会者电子邮件地址数组 |
| `sendUpdates` | string | 否 | 如何向参会者发送更新：all、externalOnly 或 none |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `content` | string | 活动创建确认消息 |
| `metadata` | json | 已创建活动的元数据，包括 ID、状态和详细信息 |
