## 工具

### `whatsapp_send_message`

发送 WhatsApp 消息

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `phoneNumber` | 字符串 | 是 | 收件人 phone 数字使用国家代码 |
| `message` | 字符串 | 是 | 消息内容到发送 |
| `phoneNumberId` | 字符串 | 是 | WhatsApp Business 电话号码 ID |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | WhatsApp 消息发送成功状态 |
| `messageId` | 字符串 | 唯一 WhatsApp 消息标识符 |
| `phoneNumber` | 字符串 | 收件人 phone 数字 |
| `status` | 字符串 | 消息 delivery 状态 |


## 用法说明

将WhatsApp集成到 workflow 中。可以发送消息.
