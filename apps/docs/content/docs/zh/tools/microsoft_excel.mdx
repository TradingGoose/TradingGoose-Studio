<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `data` | object | 来自电子表格的范围数据 |
| `metadata` | object | 电子表格元数据 |

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `index` | 数字 | 添加的第一行的索引 |
| `values` | 数组 | 添加到表格的行的数组 |
| `metadata` | 对象 | 电子表格元数据 |

## 使用说明

将 Microsoft Excel 集成到工作流中。可以读取、写入、更新和添加到表格。

## 注意事项

- 类别：`tools`
- 类型：`microsoft_excel`
