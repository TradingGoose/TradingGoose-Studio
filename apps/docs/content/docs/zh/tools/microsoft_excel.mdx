<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `range` | 字符串 | 该 range 该 was read |

写入 data 到一个 Microsoft Excel 电子表格

| `updatedRows` | 数字 | 数字的 rows 该 were updated |
| `updatedColumns` | 数字 | 数字的 columns 该 were updated |
| `updatedCells` | 数字 | 数字的 cells 该 were updated |
| `spreadsheetId` | 字符串 | 该 ID 的该电子表格 |

| 参数 | 类型 | 必填 | 说明 |

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `index` | 数字 | 索引的该第一个 row 该 was added |
| `values` | 数组 | 数组的 rows 该 were added 到该 table |
| `spreadsheetId` | 字符串 | 该 ID 的该电子表格 |
