| `resource_type` | 字符串 | 资源 type \(task\) |
| `resource_subtype` | 字符串 | 资源 subtype |
| `name` | 字符串 | 任务 名称 |
| `notes` | 字符串 | 任务备注或说明 |
| `completed` | 布尔值 | 是否该 task is 已完成 |
