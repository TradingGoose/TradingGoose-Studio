<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |

| `project` | string | 否 | 用于筛选任务的项目 GID |
| `limit` | number | 否 | 返回任务的最大数量 \(默认：50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `ts` | string | 响应时间戳 |
| `gid` | string | 任务全局唯一标识符 |
| `resource_type` | string | 资源类型 \(task\) |
| `resource_subtype` | string | 资源子类型 |
| `name` | string | 任务名称 |
| `notes` | string | 任务备注或描述 |
| `completed` | boolean | 任务是否已完成 |
| `assignee` | object | 负责人详情 |
| `created_by` | object | 创建者详情 |
| `due_on` | string | 截止日期 \(YYYY-MM-DD\) |
| `created_at` | string | 任务创建时间戳 |
| `modified_at` | string | 任务最后修改时间戳 |
| `tasks` | array | 任务数组 \(获取多个时\) |

</div>
