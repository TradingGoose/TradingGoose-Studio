创建Zoom 会议

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `userId` | 字符串 | 是 | user ID或email 地址. 使用 "me"，用于authenticated user. |
| `topic` | 字符串 | 是 | 会议 topic |
| `type` | 数字 | 否 | 会议类型: 1=instant, 2=scheduled, 3=recurring 否 fixed time, 8=recurring fixed time |
| `startTime` | 字符串 | 否 | 会议开始 time在ISO 8601 格式 \(例如： 2025-06-03T10:00:00Z\) |
| `duration` | 数字 | 否 | 会议时长在minutes |
| `timezone` | 字符串 | 否 | Timezone，用于会议 \(例如： America/Los_Angeles\) |
| `password` | 字符串 | 否 | 会议密码 |
| `agenda` | 字符串 | 否 | 会议 agenda |
| `hostVideo` | 布尔值 | 否 | 启动使用主机视频在 |
| `participantVideo` | 布尔值 | 否 | 启动使用participant 视频在 |
| `joinBeforeHost` | 布尔值 | 否 | 允许 participants到join 之前主机 |
| `muteUponEntry` | 布尔值 | 否 | Mute participants 在 entry |
| `waitingRoom` | 布尔值 | 否 | 启用waiting room |
| `autoRecording` | 字符串 | 否 | Auto 录制内容 setting: 本地, 云,或无 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `id` | 数字 | 会议 ID |
| `uuid` | 字符串 | 会议 UUID |
| `host_id` | 字符串 | 主机 user ID |
| `host_email` | 字符串 | 主机 email |
| `topic` | 字符串 | 会议 topic |
| `type` | 数字 | 会议类型 |
| `status` | 字符串 | 会议状态 |
| `start_time` | 字符串 | 启动time |
| `duration` | 数字 | 时长在minutes |
| `timezone` | 字符串 | Timezone |
| `agenda` | 字符串 | 会议 agenda |
| `created_at` | 字符串 | 创建时间戳 |
| `start_url` | 字符串 | 主机开始 URL |
| `join_url` | 字符串 | Participant join URL |
| `password` | 字符串 | 会议密码 |

</div>
