| `password` | string | 否 | 会议密码 |
| `agenda` | string | 否 | 会议议程 |
| `hostVideo` | boolean | 否 | 开始时开启主持人视频 |
| `participantVideo` | boolean | 否 | 开始时开启参会者视频 |
