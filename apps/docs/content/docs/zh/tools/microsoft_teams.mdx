读取 content 从一个 Microsoft Teams chat

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `chatId` | 字符串 | 是 | 该 ID 的该 chat 到 read 从 |
| `includeAttachments` | 布尔值 | 否 | 下载和包含 message 附件 \(hosted contents\) 到 storage |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | Teams chat read operation success status |
| `messageCount` | 数字 | 数字的 messages retrieved 从 chat |
| `chatId` | 字符串 | ID 的该 chat 该 was read 从 |
| `messages` | 数组 | 数组的 chat message objects |
| `attachmentCount` | 数字 | 总计数字的附件 found |
| `attachmentTypes` | 数组 | 类型的附件 found |
| `content` | 字符串 | Formatted content 的 chat messages |

</div>

## 用量说明

将 Microsoft Teams 集成到工作流中。你可以读写聊天消息和频道消息。也可在触发器模式下，当聊天或频道中发送消息时触发工作流。
