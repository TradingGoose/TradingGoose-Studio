<div className="text-base font-semibold mb-2">运行 Actor (<code>apify_run_actor_sync</code>)</div>

运行一个 APIFY actor synchronously 和 get 结果 (max 5 minutes)

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | APIFY API 令牌从 console.apify.com/account#/集成 |
| `actorId` | 字符串 | 是 | Actor ID 或用户名/actor-名称 \(例如, "janedoe/my-actor" 或 actor ID\) |
| `input` | 字符串 | 否 | Actor input 作为 JSON 字符串. See actor documentation 用于 required 字段. |
| `timeout` | 数字 | 否 | Timeout 在 seconds \(默认: actor 默认\) |
| `build` | 字符串 | 否 | Actor build 到 run \(例如, "latest", "beta", 或 build 标签/数字\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否该 actor run succeeded |
| `runId` | 字符串 | APIFY run ID |
| `status` | 字符串 | 运行 status \(SUCCEEDED, FAILED, etc.\) |

</div>

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |

| `input` | 字符串 | 否 | Actor input 作为 JSON 字符串 |
| `waitForFinish` | 数字 | 否 | Initial 等待 time 在 seconds \(0-60\) 之前 polling starts |
| `itemLimit` | 数字 | 否 | Max dataset 项目到 fetch \(1-250000, 默认 100\) |
| `timeout` | 数字 | 否 | Timeout 在 seconds \(默认: actor 默认\) |
| `build` | 字符串 | 否 | Actor build 到 run \(例如, "latest", "beta", 或 build 标签/数字\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否该 actor run succeeded |
| `runId` | 字符串 | APIFY run ID |
| `status` | 字符串 | 运行 status \(SUCCEEDED, FAILED, etc.\) |
| `datasetId` | 字符串 | Dataset ID containing 结果 |

</div>

## 用量说明

集成 Apify 到你的 workflow. 运行任何 Apify actor 使用自定义 input 和 retrieve 结果. Supports both synchronous 和 asynchronous execution 使用自动 dataset fetching.
