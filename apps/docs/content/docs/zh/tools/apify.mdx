<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | 是 | 来自 console.apify.com/account#/integrations 的 APIFY API 令牌 |
| `actorId` | string | 是 | Actor ID 或 username/actor-name（例如："janedoe/my-actor" 或 actor ID） |
| `input` | string | 否 | 以 JSON 字符串形式提供的 Actor 输入。必填字段请参阅 actor 文档。 |
| `timeout` | number | 否 | 超时时间（秒，默认值：actor 默认） |
| `build` | string | 否 | 要运行的 Actor 构建版本（例如："latest"、"beta" 或构建标签/编号） |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | Actor 运行是否成功 |
| `runId` | string | APIFY 运行 ID |
| `status` | string | 运行状态（SUCCEEDED、FAILED 等） |
| `items` | array | 数据集条目（如果已完成） |

| `status` | 字符串 | 运行状态 \(SUCCEEDED、FAILED 等\) |
| `datasetId` | 字符串 | 包含结果的数据集 ID |

## 使用说明

将 Apify 集成到你的工作流中。使用自定义输入运行任意 Apify actor 并获取结果。支持同步和异步执行，并自动获取数据集。
