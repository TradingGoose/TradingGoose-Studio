<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |

| `totalResults` | 数字 | 数量：结果已返回 |
| `hasMore` | 布尔值 | 是否更多结果为 可用 |
| `nextCursor` | 字符串 | Cursor，用于分页 |
| `id` | 字符串 | 页面 ID |
| `properties` | 对象 | 页面属性 |
| `created_time` | 字符串 | 创建时间戳 |
| `last_edited_time` | 字符串 | 最后一个 edit 时间戳 |
| `url` | 字符串 | 页面 URL |

</div>
