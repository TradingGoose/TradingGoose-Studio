| `file` | file | 否 | 要上传的文件 |
| `content` | string | 否 | 要上传的文本内容（文件的替代方式） |
| `contentType` | string | 否 | Content-Type 请求头（未提供时根据文件自动检测） |

| `uri` | string | 已上传对象的 S3 URI（s3://bucket/key） |
| `metadata` | object | 上传元数据，包含 ETag 和位置 |

## 使用说明

将 S3 集成到工作流中。上传文件、下载对象、列出存储桶内容、删除对象，以及在存储桶之间复制对象。需要 AWS 访问密钥和秘密访问密钥。

- 类别：`tools`
- 类型：`s3`
