## 工具

### `huggingface_chat`

使用 Hugging Face Inference API 生成补全

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | string | 否 | 用于引导模型行为的系统提示 |
| `content` | string | 是 | 发送给模型的用户消息内容 |
| `provider` | string | 是 | 用于 API 请求的提供商 \(例如 novita、cerebras 等\) |
| `model` | string | 是 | 用于聊天补全的模型 \(例如 Qwen/Qwen2.5-7B-Instruct\) |
| `maxTokens` | number | 否 | 生成的最大 token 数 |
| `temperature` | number | 否 | 采样温度 \(0-2\)。值越高，输出越随机 |
| `apiKey` | string | 是 | Hugging Face API 令牌 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 操作成功状态 |
| `output` | object | 聊天补全结果 |

## 使用说明

将 Hugging Face 集成到工作流中。可使用 Hugging Face Inference API 生成补全。
