## 工具

### `huggingface_chat`

生成 completions 使用 Hugging Face Inference API

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `systemPrompt` | 字符串 | 否 | System 提示词到 guide 该模型 behavior |
| `content` | 字符串 | 是 | 该 用户 message content 到 send 到该模型 |
| `provider` | 字符串 | 是 | 该提供商到使用用于该 API request \(例如, novita, cerebras, etc.\) |
| `model` | 字符串 | 是 | 模型到使用用于 chat completions \(例如, Qwen/Qwen2.5-7B-Instruct\) |
| `maxTokens` | 数字 | 否 | 最多生成的 token 数量 |
| `temperature` | 数字 | 否 | 采样温度 \(0-2\)。值越高，输出的随机性越强 |
| `apiKey` | 字符串 | 是 | Hugging Face API 令牌 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 操作 success status |
| `content` | 字符串 | Generated text content |
| `model` | 字符串 | 模型使用用于 generation |
| `prompt_tokens` | 数字 | 数字的 tokens 在该提示词 |
| `completion_tokens` | 数字 | 数字的 tokens 在该 completion |


## 用量说明

将 Hugging Face 集成到工作流中。你可以使用 Hugging Face Inference API 生成补全内容。
