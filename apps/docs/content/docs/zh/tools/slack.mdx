发送消息到Slack 频道或direct 消息. Supports Slack mrkdwn formatting.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `authMethod` | 字符串 | 否 | 身份验证方法: oauth或bot_token |
| `destinationType` | 字符串 | 否 | Destination 类型: 频道或dm |
| `botToken` | 字符串 | 否 | 机器人 token，用于自定义机器人 |
| `channel` | 字符串 | 否 | 目标 Slack 频道 \(例如： #general\) |
| `dmUserId` | 字符串 | 否 | 目标 Slack user，用于direct 消息 |
| `text` | 字符串 | 是 | 消息文本到发送 \(supports Slack mrkdwn formatting\) |
| `thread_ts` | 字符串 | 否 | 线程时间戳到reply到\(创建线程 reply\) |
| `files` | file[] | 否 | 文件到attach到消息 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `message` | 对象 | Complete 消息对象使用所有属性已返回由Slack |
| `ts` | 字符串 | 消息时间戳 |
| `channel` | 字符串 | 频道 ID 其中消息曾为已发送 |

</div>

## 用法说明

将Slack集成到 workflow 中。可以发送消息, 创建画布,和读取消息. 需要机器人 token instead的OAuth在advanced 模式. 可为使用的在trigger 模式到trigger 一个 workflow 当一个消息为 已发送到一个频道.
