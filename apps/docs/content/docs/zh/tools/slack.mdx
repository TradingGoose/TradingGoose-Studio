向 Slack 频道或私信发送消息。支持 Slack mrkdwn 格式。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `destinationType` | string | 否 | 目标类型：channel 或 dm |
| `channel` | string | 否 | 目标 Slack 频道（例如 #general） |
| `dmUserId` | string | 否 | 私信的目标 Slack 用户 |
| `text` | string | 是 | 要发送的消息文本（支持 Slack mrkdwn 格式） |
| `thread_ts` | string | 否 | 要回复的线程时间戳（创建线程回复） |
| `files` | file[] | 否 | 要附加到消息的文件 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `message` | object | 包含 Slack 返回的全部属性的完整消息对象 |
| `ts` | string | 消息时间戳 |
| `channel` | string | 消息发送到的频道 ID |
| `fileCount` | number | 上传的文件数量（附加文件时） |

</div>

## 使用说明

将 Slack 集成到工作流中。可发送消息、创建画布并读取消息。也可用于触发模式，在有消息发送到频道时触发工作流。
