<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | string | 是 | Sentry API 认证令牌 |
| `organizationSlug` | string | 是 | 组织的 slug |
| `projectSlug` | string | 否 | 按指定项目 slug 筛选问题 \(可选\) |
| `query` | string | 否 | 用于筛选问题的搜索查询。支持 Sentry 搜索语法 \(例如 "is:unresolved"、"level:error"\) |
| `statsPeriod` | string | 否 | 统计时间范围 \(例如 "24h"、"7d"、"30d"\)。未指定时默认为 24h。 |
| `cursor` | string | 否 | 用于获取下一页结果的分页游标 |
| `limit` | number | 否 | 每页返回的问题数量 \(默认：25，最大：100\) |
| `status` | string | 否 | 按问题状态筛选：unresolved、resolved、ignored 或 muted |
| `sort` | string | 否 | 排序方式：date、new、freq、priority 或 user \(默认：date\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `issues` | array | Sentry 问题列表 |
| `nextCursor` | string | 下一页结果的游标 \(如有\) |
| `hasMore` | boolean | 是否还有更多结果 |
