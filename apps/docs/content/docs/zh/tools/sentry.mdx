<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">List Issues (<code>sentry_issues_list</code>)</div>

列出议题，来源为Sentry，用于一个特定组织和optionally 一个特定项目. 返回议题详细信息包括状态, 错误 counts,和最后一个 seen timestamps.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `apiKey` | 字符串 | 是 | Sentry API 身份验证 token |
| `organizationSlug` | 字符串 | 是 | slug的组织 |
| `projectSlug` | 字符串 | 否 | 筛选条件议题由特定项目 slug \(可选\) |
| `query` | 字符串 | 否 | 搜索查询到筛选条件议题. Supports Sentry 搜索 syntax \(例如： "为:unresolved", "级别:错误"\) |
| `statsPeriod` | 字符串 | 否 | 统计数据的时间段\(例如："24h"、"7d"、"30d"\)。如果未指定，默认为 24h。 |
| `cursor` | 字符串 | 否 | 分页 cursor，用于retrieving 下一个页面的结果 |
| `limit` | 数字 | 否 | 数量：议题到返回每个页面 \(默认值： 25, 最大: 100\) |
| `status` | 字符串 | 否 | 筛选条件由议题状态: unresolved, resolved, ignored,或muted |
| `sort` | 字符串 | 否 | 排序订单: 日期, 新建, freq, 优先级,或user \(默认值： 日期\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `id` | 字符串 | 项目 ID |
| `shortId` | 字符串 | Short 议题标识符 |
| `title` | 字符串 | 议题标题 |
| `culprit` | 字符串 | 函数或location 该 caused 议题 |
| `permalink` | 字符串 | Direct 链接到议题在Sentry |
| `logger` | 字符串 | Logger 名称该 reported 议题 |
| `level` | 字符串 | Severity 级别 \(错误, warning, info, etc.\) |
| `status` | 字符串 | 当前议题状态 |
| `platform` | 字符串 | 平台其中议题 occurred |
| `name` | 字符串 | 项目名称 |
| `slug` | 字符串 | 项目 slug |

</div>
