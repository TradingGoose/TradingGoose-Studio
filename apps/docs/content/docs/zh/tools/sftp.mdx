<div className="text-base font-semibold mb-2">Upload Files (<code>sftp_upload</code>)</div>

上传文件到一个远程 SFTP 服务器

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `host` | 字符串 | 是 | SFTP 服务器主机名或IP 地址 |
| `port` | 数字 | 是 | SFTP 服务器端口 \(默认值： 22\) |
| `username` | 字符串 | 是 | SFTP 用户名 |
| `password` | 字符串 | 否 | 密码，用于身份验证 \(如果不 使用私有键\) |
| `privateKey` | 字符串 | 否 | 私有键，用于身份验证 \(OpenSSH 格式\) |
| `passphrase` | 字符串 | 否 | 密码短语，用于encrypted 私有键 |
| `remotePath` | 字符串 | 是 | Destination 目录在 远程服务器 |
| `files` | file[] | 否 | 文件到upload |
| `fileContent` | 字符串 | 否 | Direct file 内容到upload \(用于文本文件\) |
| `fileName` | 字符串 | 否 | 文件名称当使用 direct 内容 |
| `overwrite` | 布尔值 | 否 | 是否到 overwrite 现有文件 \(默认值： true\) |
| `permissions` | 字符串 | 否 | 文件 permissions \(例如： 0644\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否upload 曾为 successful |
| `uploadedFiles` | json | 以下内容的数组：uploaded file 详细信息 \(名称, remotePath, 大小\) |

</div>

## 用法说明

Upload, download, 列出,和管理文件在 远程 servers via SFTP. Supports 两者密码和私有键 身份验证，用于安全 file 传输.
