## 工具

### `elevenlabs_tts`

转换 TTS 使用 ElevenLabs voices

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `text` | 字符串 | 是 | 该 text 到转换到 speech |
| `voiceId` | 字符串 | 是 | 该 ID 的该 voice 到使用 |
| `modelId` | 字符串 | 否 | 该 ID 的该模型到使用 \(默认为 eleven_monolingual_v1\) |
| `apiKey` | 字符串 | 是 | 你的 ElevenLabs API 密钥 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `audioUrl` | 字符串 | 该 URL 的该 generated 音频 |


## 用量说明

集成 ElevenLabs 到该 workflow. 可以转换 text 到 speech.
