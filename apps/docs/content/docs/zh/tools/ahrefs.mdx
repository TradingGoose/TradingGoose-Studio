<div className="text-base font-semibold mb-2">反向链接 (<code>ahrefs_backlinks</code>)</div>

获取一个列表的 backlinks pointing 到一个目标域名或 URL. 返回详细信息 关于 每个反向链接包括来源 URL, anchor text, 和域名评级.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `target` | 字符串 | 是 | 该目标域名或 URL 到分析 |
| `mode` | 字符串 | 否 | 分析模式: 域名 \(entire 域名\), 前缀 \(URL 前缀\), subdomains \(包含全部 subdomains\), 准确 \(准确 URL 匹配\) |
| `date` | 字符串 | 否 | 日期用于历史数据在 YYYY-MM-DD 格式 \(默认为今天\) |
| `limit` | 数字 | 否 | 最大数字的结果到 return \(默认: 100\) |
| `offset` | 数字 | 否 | 数字的结果到 skip 用于分页 |
| `apiKey` | 字符串 | 是 | Ahrefs API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `urlFrom` | 字符串 | 该 URL 的该页面 containing 该反向链接 |
| `urlTo` | 字符串 | 该 URL being linked 到 |
| `anchor` | 字符串 | 该 anchor text 的该 link |
| `domainRatingSource` | 数字 | 域名评级的该 linking 域名 |
| `isDofollow` | 布尔值 | 是否该 link is dofollow |
| `firstSeen` | 字符串 | 何时该反向链接 was 第一个 discovered |

</div>
