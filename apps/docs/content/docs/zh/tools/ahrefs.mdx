<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">域名评级 (<code>ahrefs_domain_rating</code>)</div>

获取目标域名的域名评分（DR）和 Ahrefs Rank。域名评分显示网站反向链接配置的强度，范围从 0 到 100。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `target` | string | 是 | 要分析的目标域名 \(例如 example.com\) |
| `date` | string | 否 | 历史数据的日期，格式为 YYYY-MM-DD \(默认为今天\) |
| `apiKey` | string | 是 | Ahrefs API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `domainRating` | number | 域名评分 \(0-100\) |
| `ahrefsRank` | number | Ahrefs Rank - 基于反向链接配置强度的全球排名 |

</div>

| `limit` | number | 否 | 返回的最大结果数 \(默认：100\) |
| `offset` | number | 否 | 分页时跳过的结果数 |
| `apiKey` | string | 是 | Ahrefs API 密钥 |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `backlinks` | array | 指向目标的回链列表 |
