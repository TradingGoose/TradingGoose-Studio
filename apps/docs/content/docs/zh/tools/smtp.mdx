## 工具

### `smtp_send_mail`

发送电子邮件 via SMTP 服务器

#### 输入

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `smtpHost` | 字符串 | 是 | SMTP 服务器主机名 \(例如： smtp.gmail.com\) |
| `smtpPort` | 数字 | 是 | SMTP 服务器端口 \(587，用于TLS, 465，用于SSL\) |
| `smtpUsername` | 字符串 | 是 | SMTP 身份验证用户名 |
| `smtpPassword` | 字符串 | 是 | SMTP 身份验证密码 |
| `smtpSecure` | 字符串 | 是 | 安全协议 \(TLS, SSL,或无\) |
| `from` | 字符串 | 是 | 发件人 email 地址 |
| `to` | 字符串 | 是 | 收件人 email 地址 |
| `subject` | 字符串 | 是 | 电子邮件主题 |
| `body` | 字符串 | 是 | 电子邮件正文内容 |
| `contentType` | 字符串 | 否 | 内容类型 \(文本或html\) |
| `fromName` | 字符串 | 否 | 显示名称，用于发件人 |
| `cc` | 字符串 | 否 | CC 收件人 \(comma-separated\) |
| `bcc` | 字符串 | 否 | BCC 收件人 \(comma-separated\) |
| `replyTo` | 字符串 | 否 | 回复地址 |
| `attachments` | file[] | 否 | 要附加到电子邮件的文件 |

#### 输出

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否email 曾为已发送 successfully |
| `messageId` | 字符串 | 消息 ID，来源为SMTP 服务器 |
| `to` | 字符串 | 收件人 email 地址 |
| `subject` | 字符串 | 电子邮件主题 |


## 用法说明

使用任何 SMTP 服务器 (Gmail, Outlook, 自定义 servers, etc.). Configure SMTP connection 设置和发送电子邮件使用完整控制 over 内容, 收件人,和附件.发送电子邮件
