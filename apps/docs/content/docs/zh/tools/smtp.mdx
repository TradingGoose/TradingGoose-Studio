## 工具

### `smtp_send_mail`

通过 SMTP 服务器发送邮件

#### 输入

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `smtpHost` | string | 是 | SMTP 服务器主机名（例如 smtp.gmail.com） |
| `smtpPort` | number | 是 | SMTP 服务器端口（TLS 使用 587，SSL 使用 465） |
| `smtpUsername` | string | 是 | SMTP 认证用户名 |
| `smtpPassword` | string | 是 | SMTP 认证密码 |
| `smtpSecure` | string | 是 | 安全协议（TLS、SSL 或 None） |
| `from` | string | 是 | 发件人邮箱地址 |
| `to` | string | 是 | 收件人邮箱地址 |
| `subject` | string | 是 | 邮件主题 |
| `body` | string | 是 | 邮件正文 |
| `contentType` | string | 否 | 内容类型（text 或 html） |
| `fromName` | string | 否 | 发件人显示名称 |
| `cc` | string | 否 | 抄送收件人（逗号分隔） |
| `bcc` | string | 否 | 密送收件人（逗号分隔） |
| `replyTo` | string | 否 | 回复地址 |
| `attachments` | file[] | 否 | 要附加到邮件的文件 |

#### 输出

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 邮件是否发送成功 |
| `messageId` | string | SMTP 服务器返回的邮件 ID |
| `to` | string | 收件人邮箱地址 |
| `subject` | string | 邮件主题 |
| `error` | string | 发送失败时的错误信息 |

## 使用说明

使用任意 SMTP 服务器（Gmail、Outlook、自定义服务器等）发送邮件。配置 SMTP 连接设置，全面控制邮件内容、收件人和附件。
