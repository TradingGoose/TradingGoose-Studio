<div className="mt-6 border-t border-fd-border pt-4">
<div className="text-base font-semibold mb-2">Make Call (<code>twilio_voice_make_call</code>)</div>

发起一个 outbound phone 通话使用 Twilio 语音 API.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `to` | 字符串 | 是 | 电话数字到通话 \(E.164 格式, 例如： +14155551234\) |
| `from` | 字符串 | 是 | 你的Twilio phone 数字到通话，来源为\(E.164 格式\) |
| `url` | 字符串 | 否 | URL 该返回 TwiML 说明，用于通话 |
| `twiml` | 字符串 | 否 | TwiML 说明到执行 \(alternative到URL\). 使用 square brackets instead的angle brackets, 例如： \[响应\]\[Say\]Hello\[/Say\]\[/响应\] |
| `statusCallback` | 字符串 | 否 | webhook URL，用于通话状态更新 |
| `statusCallbackMethod` | 字符串 | 否 | HTTP 方法，用于状态 callback \(GET或POST\) |
| `accountSid` | 字符串 | 是 | Twilio 账户 SID |
| `authToken` | 字符串 | 是 | Twilio 身份验证 token |
| `record` | 布尔值 | 否 | 是否到 record 通话 |
| `recordingStatusCallback` | 字符串 | 否 | webhook URL，用于录制内容状态更新 |
| `timeout` | 数字 | 否 | 时间到wait，用于回答之前 giving 上 \(秒, 默认值： 60\) |
| `machineDetection` | 字符串 | 否 | Answering machine detection: 启用或 DetectMessageEnd |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否通话曾为 successfully initiated |
| `callSid` | 字符串 | 唯一标识符，用于通话 |
| `status` | 字符串 | 通话状态 \(queued, ringing, in-progress, 已完成, etc.\) |
| `direction` | 字符串 | 通话 direction \(outbound-api\) |
| `from` | 字符串 | 电话数字通话为，来源为|
| `to` | 字符串 | 电话数字通话为到|
| `duration` | 数字 | 通话时长在秒 |
| `price` | 字符串 | Cost的通话 |
| `priceUnit` | 字符串 | 货币的价格 |

</div>

<div className="text-base font-semibold mb-2">List Calls (<code>twilio_voice_list_calls</code>)</div>

检索一个列出的调用完成到和，来源为一个账户.

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `accountSid` | 字符串 | 是 | Twilio 账户 SID |
| `authToken` | 字符串 | 是 | Twilio 身份验证 token |
| `to` | 字符串 | 否 | 筛选条件由调用到此 phone 数字 |
| `from` | 字符串 | 否 | 筛选条件由调用，来源为此 phone 数字 |
| `status` | 字符串 | 否 | 筛选条件由通话状态 \(queued, ringing, in-progress, 已完成, etc.\) |
| `startTimeAfter` | 字符串 | 否 | 筛选条件调用该 started 在或之后此 日期 \(YYYY-MM-DD\) |
| `startTimeBefore` | 字符串 | 否 | 筛选条件调用该 started 在或之前此 日期 \(YYYY-MM-DD\) |
| `pageSize` | 数字 | 否 | 数量：记录到返回 \(最大 1000, 默认 50\) |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否调用曾为 successfully retrieved |
| `calls` | 数组 | 以下内容的数组：通话对象 |
| `total` | 数字 | 总计数字的调用已返回 |
| `page` | 数字 | 当前页面数字 |
| `pageSize` | 数字 | 数量：调用每个页面 |

</div>

检索通话录制内容信息和transcription (如果已启用 via TwiML).

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 描述 |
| --------- | ---- | -------- | ----------- |
| `recordingSid` | 字符串 | 是 | 录制内容 SID到检索 |
| `accountSid` | 字符串 | 是 | Twilio 账户 SID |
| `authToken` | 字符串 | 是 | Twilio 身份验证 token |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 描述 |
| --------- | ---- | ----------- |
| `success` | 布尔值 | 是否录制内容曾为 successfully retrieved |
| `recordingSid` | 字符串 | 唯一标识符，用于录制内容 |
| `callSid` | 字符串 | 通话 SID 此录制内容 belongs到|
| `duration` | 数字 | 时长的录制内容在秒 |
| `status` | 字符串 | 录制内容状态 \(已完成, 处理, etc.\) |
| `channels` | 数字 | 数量：频道 \(1，用于mono, 2，用于dual\) |
| `source` | 字符串 | 如何录制内容曾为已创建 |
| `mediaUrl` | 字符串 | URL到download 录制内容媒体 file |
| `price` | 字符串 | Cost的录制内容 |
| `priceUnit` | 字符串 | 货币的价格 |
| `uri` | 字符串 | Relative URI的录制内容资源 |
| `transcriptionText` | 字符串 | Transcribed 文本，来源为录制内容 \(如果可用\) |
| `transcriptionStatus` | 字符串 | Transcription 状态 \(已完成, in-progress, failed\) |
| `transcriptionPrice` | 字符串 | Cost的transcription |
| `transcriptionPriceUnit` | 字符串 | 货币的transcription 价格 |

</div>
