<div className="text-base font-semibold mb-2">拨打电话 (<code>twilio_voice_make_call</code>)</div>

使用 Twilio Voice API 发起外呼电话。

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输入</div>

| 参数 | 类型 | 必填 | 说明 |
| --------- | ---- | -------- | ----------- |
| `to` | string | 是 | 要拨打的电话号码 \(E.164 格式，例如 +14155551234\) |
| `from` | string | 是 | 用于外呼的 Twilio 电话号码 \(E.164 格式\) |
| `url` | string | 否 | 返回该通话 TwiML 指令的 URL |
| `twiml` | string | 否 | 要执行的 TwiML 指令 \(URL 的替代方案\)。请使用方括号而非尖括号，例如 \[Response\]\[Say\]Hello\[/Say\]\[/Response\] |
| `statusCallback` | string | 否 | 通话状态更新的 Webhook URL |
| `statusCallbackMethod` | string | 否 | 状态回调的 HTTP 方法 \(GET 或 POST\) |
| `accountSid` | string | 是 | Twilio Account SID |
| `authToken` | string | 是 | Twilio Auth Token |
| `record` | boolean | 否 | 是否录制通话 |
| `recordingStatusCallback` | string | 否 | 录音状态更新的 Webhook URL |
| `timeout` | number | 否 | 放弃前等待接听的时间 \(秒，默认：60\) |
| `machineDetection` | string | 否 | 答录机检测：Enable 或 DetectMessageEnd |

<div className="text-sm font-medium text-fd-muted-foreground mt-4 mb-2">输出</div>

| 参数 | 类型 | 说明 |
| --------- | ---- | ----------- |
| `success` | boolean | 通话是否成功发起 |
| `callSid` | string | 通话的唯一标识符 |
| `status` | string | 通话状态 \(queued、ringing、in-progress、completed 等\) |
| `direction` | string | 通话方向 \(outbound-api\) |
| `from` | string | 主叫电话号码 |
| `to` | string | 被叫电话号码 |
| `duration` | number | 通话时长（秒） |
| `price` | string | 通话费用 |
| `priceUnit` | string | 价格所用货币 |
| `error` | string | 通话失败时的错误信息 |

</div>

| `from` | string | 否 | 按主叫号码筛选 |
| `status` | string | 否 | 按通话状态筛选 \(queued、ringing、in-progress、completed 等\) |
| `startTimeAfter` | string | 否 | 筛选此日期当天或之后开始的通话 \(YYYY-MM-DD\) |
| `startTimeBefore` | string | 否 | 筛选此日期当天或之前开始的通话 \(YYYY-MM-DD\) |
| `pageSize` | number | 否 | 返回的记录数 \(最多 1000，默认 50\) |

| `calls` | array | 通话对象数组 |
| `total` | number | 返回的通话总数 |
| `page` | number | 当前页码 |
| `pageSize` | number | 每页通话数 |
| `error` | string | 获取失败时的错误信息 |

| `callSid` | string | 该录音所属的通话 SID |
| `duration` | number | 录音时长（秒） |
| `status` | string | 录音状态（completed、processing 等） |
| `channels` | number | 声道数（1 为单声道，2 为双声道） |
| `source` | string | 录音的创建方式 |
| `mediaUrl` | string | 录音媒体文件的下载 URL |
| `price` | string | 录音费用 |
| `priceUnit` | string | 价格所用货币 |
| `uri` | string | 录音资源的相对 URI |
| `transcriptionText` | string | 录音转录文本（如有） |

| `transcriptionPrice` | string | 转录费用 |
