TradingGoose Studio 是一个用于技术性 LLM 交易的 AI 工作流平台。它将技术分析与大语言模型相结合，驱动您的交易决策——从分析研究到图表、监控和工作流自动化。

通过连接区块在画布上可视化构建工作流——AI 代理、交易操作、技术指标、API 集成等。大多数工作流无需编码，同时为自定义指标和策略提供完整的 PineTS 脚本支持。

## 您可以构建什么

**交易自动化**
连接券商（Alpaca 和 Tradier），执行订单，监控持仓，并通过 AI 分析和技术指标驱动交易策略的自动化。

**技术分析与图表**
使用 PineTS 编写自定义指标，通过交互式 K 线图可视化 OHLCV 数据，利用实时市场数据管理自选列表，并在指标条件满足时触发工作流。

**AI 驱动的研究**
构建研究代理，使用 OpenAI、Anthropic、Google 等模型分析市场数据、扫描新闻、处理金融文档并生成报告。

**数据处理与集成**
连接数据库、通信工具、CRM 和 API。通过条件、循环、并行执行和错误处理编排复杂的数据管道。

**可视化工作流画布**
拖放区块构建工作流。通过点击连接 AI 模型、交易服务、数据库和 API。

**交易基础设施**
使用 Alpaca 或 Tradier 执行配置的交易操作，并从 Alpaca、Alpha Vantage、Finnhub 或 Yahoo Finance 获取市场数据。

**PineTS 脚本**
在 PineTS 中编写自定义指标 — 一个与 Pine Script 兼容的 JavaScript/TypeScript 运行时。通过 `trigger()` API 将指标信号连接到工作流自动化。

**可扩展性**
使用 MCP 服务器、自定义工具、可复用技能和知识库扩展平台。AI Copilot 帮助您在整个工作区中构建和管理一切。

**多种触发器**
通过聊天界面、REST API、webhooks、计划任务、指标信号或来自 Slack 和 GitHub 等服务的外部事件启动工作流。

## 内置集成

TradingGoose 包含广泛的集成目录：

- **交易与市场**: Alpaca, Tradier, Kalshi, Polymarket
- **市场数据**: Alpaca, Alpha Vantage, Finnhub, Yahoo Finance
- **AI 模型**: OpenAI, Anthropic, Google, Groq, Cerebras, DeepSeek, Ollama (本地)
- **通信**: Gmail, Slack, Teams, Telegram, WhatsApp, Discord
- **生产力**: Notion, Google Sheets, Airtable, Jira, Linear
- **开发**: GitHub, GitLab, 浏览器自动化 (Stagehand)
- **搜索与网络**: Google Search, Perplexity, Tavily, Exa, Firecrawl
- **数据库**: PostgreSQL, MySQL, MongoDB, Supabase, Pinecone, Qdrant

需要自定义功能？使用 [MCP 集成](/utilities/mcp) 连接任何外部服务，或构建 [自定义工具](/utilities/custom-tools)。

## 部署选项

**云托管**：在提供托管注册时，使用托管的 TradingGoose 服务。

**自托管**：在本地运行仓库，或部署到您自己的基础设施上。您可以通过 Ollama 连接本地 AI 模型。
