TradingGoose Studio 是一个面向 LLM 技术交易的 AI 工作流平台。它将技术分析与大语言模型结合，为从分析和研究到图表、监控及工作流自动化的交易决策提供支持。

在画布上连接 AI 代理、交易操作、技术指标和 API 集成等块，即可直观构建工作流。大多数工作流无需编写代码，同时完整支持使用 PineTS 脚本创建自定义指标和策略。

## 可以构建什么

**交易自动化**
连接经纪商（Alpaca、Tradier、Robinhood）、执行订单、监控持仓，并自动运行由 AI 分析和技术指标驱动的交易策略。

**技术分析和图表**
使用 PineTS 编写自定义指标，通过交互式蜡烛图显示 OHLCV 数据，使用实时市场数据管理自选列表，并在满足指标条件时触发工作流。

**AI 驱动的研究**
构建研究代理，以分析市场数据、扫描新闻、处理财务文档，并使用 OpenAI、Anthropic、Google 等提供商的模型生成报告。

**数据处理和集成**
连接 120 多项服务，包括数据库、通信工具、CRM 和 API。通过条件、循环、并行执行和错误处理来编排复杂的数据流水线。

**可视化工作流画布**
拖放块来构建工作流。通过点击操作连接 AI 模型、交易服务、数据库和 API。

**交易基础设施**
内置经纪商集成（Alpaca、Tradier、Robinhood）和市场数据提供商（Alpha Vantage、Finnhub、Yahoo Finance），支持实盘和模拟交易。

**PineTS 脚本**
使用 PineTS 编写自定义指标。PineTS 是兼容 Pine Script 的 JavaScript/TypeScript 运行时。通过 `trigger()` API 将指标信号连接到工作流自动化。

**扩展能力**
通过 MCP 服务器、自定义工具、可复用技能和知识库扩展平台。AI Copilot 可帮助你在整个工作区中构建和管理这些内容。

**多种触发方式**
通过聊天界面、REST API、Webhook、计划任务、指标信号，或 Slack 和 GitHub 等服务的外部事件启动工作流。

## 内置集成

TradingGoose 可连接 120 多项服务：

- **交易**：Alpaca、Tradier、Robinhood、Kalshi、Polymarket
- **市场数据**：Alpha Vantage、Finnhub、Yahoo Finance
- **AI 模型**：OpenAI、Anthropic、Google、Groq、Cerebras、DeepSeek、Ollama（本地）
- **通信**：Gmail、Slack、Teams、Telegram、WhatsApp、Discord
- **生产力**：Notion、Google Sheets、Airtable、Jira、Linear
- **开发**：GitHub、GitLab、浏览器自动化（Stagehand）
- **搜索和网页**：Google Search、Perplexity、Tavily、Exa、Firecrawl
- **数据库**：PostgreSQL、MySQL、MongoDB、Supabase、Pinecone、Qdrant

需要自定义连接？使用 [MCP 集成](/utilities/mcp)连接任何外部服务，或构建[自定义工具](/utilities/custom-tools)。

## 部署选项

**云托管**：即将推出。提供自动扩缩容和内置监控的托管基础设施。

**自行托管**：使用 Docker 部署到自己的基础设施，并通过 Ollama 支持本地 AI 模型，以确保完整的数据隐私。
