[Model Context Protocol](https://modelcontextprotocol.com/) (MCP) 是一项开放标准，使 AI 代理能够安全连接外部工具和数据源。TradingGoose 实现了支持 JSON-RPC 2.0 的 MCP 客户端，并可在多个规范版本之间协商协议版本（`2025-06-18`、`2025-03-26`、`2024-11-05`）。

## 支持的传输方式

注册的每个 MCP 服务器都使用以下三种基于 HTTP 的传输模式之一：

| 传输方式 | 描述 |
|-----------|-------------|
| **HTTP** | 使用 JSON 响应的标准 HTTP POST，适合简单的请求/响应工具。 |
| **SSE** | Server-Sent Events。服务器可使用 `text/event-stream` 返回流式结果。 |
| **Streamable HTTP** | 最新的 MCP 传输方式（规范 2025-03-26）。支持通过 `Mcp-Session-Id` 标头管理会话，并在 JSON 和 SSE 之间协商内容类型。 |

三种传输方式均由同一底层客户端处理。传输字段控制连接标签，客户端则根据服务器的 `Content-Type` 标头自动协商响应格式。

## 添加 MCP 服务器

<Steps>
<Step>
### 打开 MCP Editor 组件

将 **MCP Editor** 组件添加到仪表板，或转到 **Workspace Settings > MCP Servers**。有关组件界面的详细信息，请参阅 [MCP Editor 组件文档](/widgets/editor-mcp)。
</Step>
<Step>
### 提供服务器配置

每个服务器都需要：

- **Name** -- 便于阅读的标签。
- **Transport** -- `http`、`sse` 或 `streamable-http`。
- **URL** -- 服务器端点（例如 `https://mcp.example.com/v1`
- **Headers**（可选）-- 自定义标头，例如 `Authorization`。支持环境变量插值（见下文）。
- **Timeout**（可选）-- 请求超时时间（毫秒）。默认值为 30 000 ms。
- **Retries**（可选）-- 重试次数。默认值为 3。
</Step>
<Step>
### 保存并测试

点击 **Save**，然后使用 MCP Editor 工具栏中的 **Test connection** 按钮。客户端会执行完整的初始化握手，包括版本协商、功能交换和 `initialized` 通知，以确认服务器可访问。
</Step>
</Steps>

## 身份验证和环境变量

可以使用双花括号语法，在服务器 URL 和标头中引用工作区或个人环境变量：

```
Authorization: Bearer {{MY_API_KEY}}
```

运行时，服务会根据解密后的有效环境解析这些 placeholder。如果缺少引用的变量，请求会失败，并返回列出未解析变量名称的明确错误。

<Callout type="warn">
切勿在服务器配置中直接写入密钥。应始终将敏感值存为环境变量，并使用 `{{VAR_NAME}}` 语法引用。
</Callout>

## 工具发现

连接服务器时，客户端会发送 `tools/list` JSON-RPC 请求。响应会解析为工具列表，每项包含：

- **name** -- 该服务器上的唯一工具标识符。
- **description** -- 工具的功能。
- **inputSchema** -- 描述预期参数的 JSON Schema。

发现的工具按工作区缓存，并采用 LRU 淘汰策略（最多 1000 项）。缓存到期后会自动刷新；你也可以从 MCP Editor 工具栏强制刷新。

## 在 Agent 块中使用 MCP 工具

服务器注册并启用后，其工具会与内置工具一起显示在任意 **Agent** 块的工具选择器中。

<Steps>
<Step>
### 选择 MCP 工具

打开 Agent 块并展开 **Tools** 部分。MCP 工具会列在对应的服务器名称下。选择所需工具。
</Step>
<Step>
### 运行代理

执行期间，代理会在相应 MCP 服务器上调用 `tools/call`，并传递工具名称和参数。结果以结构化内容（文本、图像或资源）返回，并加入代理上下文。
</Step>
</Steps>

每次工具执行都通过同意和审计框架。发送调用前，客户端会根据安全策略（已阻止来源、速率限制）检查服务器并记录审计轨迹。

## 安全

MCP 客户端默认实施以下安全措施：

- **Consent gating** -- 发送前根据当前安全策略检查每次工具执行。
- **Origin allowlisting** -- 自动将服务器 URL 的来源添加到允许来源列表。
- **Rate limiting** -- 可配置每小时工具执行上限（默认值：1000）。
- **Audit logging** -- 为每项同意决定添加唯一审计 ID，以便追踪。
- **Blocked origins** -- 立即拒绝阻止列表中的服务器。

## 故障排除

<Cards>
<Card title="Server not connecting">
确认 URL 正确且服务器正在运行。客户端会同时尝试带或不带末尾斜杠的地址，因此可自动处理路径问题。请查看浏览器控制台中的详细连接错误。
</Card>
<Card title="Tools not appearing">
确认服务器已 **enabled** 且未被软删除。使用 MCP Editor 中的 **Refresh tools** 按钮清除缓存并重新发现工具。
</Card>
<Card title="Missing environment variable errors">
错误消息会明确列出未解析的变量。请在工作区或个人环境设置中添加这些变量，然后重试。
</Card>
<Card title="Timeout errors">
在 MCP Editor 中增加服务器超时值。默认值为 30 秒。较慢的服务器或较大的工具响应可能需要更长时间。
</Card>
</Cards>
