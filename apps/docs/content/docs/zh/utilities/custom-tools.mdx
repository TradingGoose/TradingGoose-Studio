自定义工具允许你定义可供 Agent 块在运行时调用的函数。每个工具包含一份声明名称、描述和参数的 **JSON 配置**，以及调用工具时运行的 **JavaScript 函数体**。你可以从编辑器导出自定义工具，并通过 Custom Tool List 组件使用 TradingGoose 共享导出 JSON 格式导入工具。

## 工具架构

每个自定义工具都遵循 OpenAI 函数调用 JSON 格式。编辑器会在每次更改时验证架构，并要求提供下列所有字段。

```json
{
  "type": "function",
  "function": {
    "name": "addItemToOrder",
    "description": "Add one quantity of a food item to the order.",
    "parameters": {
      "type": "object",
      "properties": {
        "itemName": {
          "type": "string",
          "description": "The name of the food item to add to order"
        }
      },
      "required": ["itemName"]
    }
  }
}
```

- `type` 必须为 `"function"`。
- `function.name` 是代理看到并调用的标识符。保存时，该标识符在工作区内必须唯一。导入时发生名称冲突会自动重命名。
- `function.description` 告诉代理何时使用该工具。
- `function.parameters` 是描述输入的标准 JSON Schema 对象。

## 工具代码

代码标签页包含 `async function(params, environmentVariables)` 的函数体。编辑器支持两种引用方式：

- **Parameters** — 直接使用参数名称（例如 `itemName`）。编辑器根据架构提供自动补全。
- **Environment variables** — 使用双花括号语法：`{{API_KEY}}`。

工具需要产生输出时，函数应使用 `return` 返回值。不支持外部导入；请使用 `fetch` 或内置 API。

## 创建和编辑工具

<Steps>
  <Step>
    在工作区仪表板中打开 [Custom Tool Editor](/widgets/editor-custom-tool) 组件。
  </Step>
  <Step>
    从下拉菜单中选择现有工具，或通过 [Custom Tool List](/widgets/list-custom-tool) 组件创建新工具。
  </Step>
  <Step>
    在 **Config** 和 **Code** 标签页之间切换，分别编辑 JSON 架构和 JavaScript 函数体。两个标签页都提供 AI 魔棒，可根据自然语言提示词生成内容。
  </Step>
  <Step>
    点击组件标题栏中的 **Save** 按钮。编辑器会在保存前验证架构，并拒绝重复的工具名称。
  </Step>
</Steps>

## 导入和导出

自定义工具使用 TradingGoose 共享导出 JSON 格式。从 Custom Tool Editor 导出工具，然后通过 [Custom Tool List](/widgets/list-custom-tool) 组件导入。导入的标题和函数名称会自动规范化；发生冲突时会重命名，以便无需手动清理即可完成导入。

## 代理如何调用自定义工具

将自定义工具添加到 Agent 块的工具列表时，该工具会注册为 `type: "custom-tool"`。运行时，Agent 块读取 `function.name` 作为工具标识符，读取 `function.description` 作为工具描述，并读取 `function.parameters` 作为输入架构。代理根据这些字段和对话上下文决定是否以及何时调用工具，然后使用已解析的参数执行 JavaScript 函数体。

<Callout type="info">
  Agent 块不能将核心块（API、Webhook、Function、Workflow、Memory）用作工具。工具列表仅允许使用集成、MCP 工具和自定义工具。
</Callout>

## 自定义工具与 MCP

| 功能 | 自定义工具 | MCP |
|---------|-------------|-----|
| **Definition** | JSON 架构和 JS 函数体 | 实现 Model Context Protocol 的外部服务器 |
| **Scope** | 每个工具包含一个函数 | 单个服务器可公开多个工具 |
| **Code execution** | 编辑器中的内联 JavaScript | 在远程 MCP 服务器上运行 |
| **Best for** | 快速、自包含的逻辑或 API 调用 | 连接标准化的第三方工具服务器 |

有关使用 MCP 的外部工具集成，请参阅 [MCP 实用工具页面](/utilities/mcp)。

<Callout type="warn">
  自定义工具限定于工作区范围。所有工作区成员都可以查看、编辑和删除这些工具。删除自定义工具会永久移除其代码和配置。
</Callout>
