TradingGoose 支持两种互补的变量系统。**环境变量**用于存储配置值和机密信息（API 密钥、令牌、数据库 URL）。它们独立于工作流定义，并在执行时解析。**工作流变量**作为单个工作流中的全局数据存储，使任何块都能在一次运行期间读取和写入共享状态。

这两种变量分别覆盖外部配置和内部数据流。环境变量可安全保存机密信息，并能在不同工作流中使用；工作流变量则使各块无需直接连接即可相互传递数据。

## 变量类型

<Cards>
  <Card title="环境变量" href="/variables/environment-variables">
    在个人或工作区范围管理 API 密钥、令牌和其他机密信息。使用双花括号语法引用，并在工作流运行时解析。
  </Card>
  <Card title="工作流变量" href="/variables/workflow-variables">
    作用域限定于单个工作流的全局键值存储。可以从任何块创建、读取和更新变量，以在工作流中共享状态。
  </Card>
</Cards>

## 快速比较

| | 环境变量 | 工作流变量 |
|---|---|---|
| **范围** | 个人或整个工作区 | 单个工作流 |
| **生命周期** | 在所有运行中持久保留 | 在运行之间保留，除非重置 |
| **典型用途** | API 密钥、令牌、配置 | 在块之间传递数据、保存状态 |
| **访问语法** | `{{VARIABLE_NAME}}` | 通过下拉列表选择 `<variable_name>` |
| **谁可以编辑** | 设置页面（受权限约束） | 编辑器中的 Variables 面板 |
