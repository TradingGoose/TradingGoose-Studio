TradingGoose 支持两套互补的变量系统。**环境变量**用于存储配置和密钥（API 密钥、令牌、数据库 URL），独立于工作流定义之外，并在执行时解析。**工作流变量**保存单次运行内的共享状态：在 Variables 面板定义初始值，在块中引用，并使用 Variables 块更新运行时值。

两者共同覆盖外部配置和内部数据流。环境变量可安全保存密钥，并在多个工作流间复用；工作流变量则让各区块无需直接连接即可互相传递数据。

## 变量类型

<Cards>
  <Card title="环境变量" href="/variables/environment-variables">

  <Card title="工作流变量" href="/variables/workflow-variables">

  </Card>

## 快速对比

| | 环境变量 | 工作流变量 |
|---|---|---|
| **作用域** | 个人或整个工作区 | 单个工作流 |
| **生命周期** | 在所有运行中持久保存 | 运行时更改仅在本次运行有效；新运行加载已保存的初始值 |
| **典型用途** | API 密钥、令牌、配置 | 区块间传递数据、状态 |
| **访问语法** | `{{VARIABLE_NAME}}` | `<variable.name>` 通过下拉菜单 |
| **编辑位置** | Environment 页面（受权限控制） | Workflow Variables 面板/组件；运行时使用 Variables 块赋值 |
