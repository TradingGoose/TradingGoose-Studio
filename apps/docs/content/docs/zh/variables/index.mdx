TradingGoose 支持两套互补的变量系统。**环境变量**用于存储配置值和密钥（API 密钥、令牌、数据库 URL），独立于工作流定义之外，并在执行时解析。**工作流变量**作为单个工作流内的全局数据存储，任意区块均可在运行期间读取和写入共享状态。

两者共同覆盖外部配置和内部数据流。环境变量可安全保存密钥，并在多个工作流间复用；工作流变量则让各区块无需直接连接即可互相传递数据。

## 变量类型

<Cards>
  <Card title="环境变量" href="/variables/environment-variables">
    在个人或工作区级别管理 API 密钥、令牌及其他密钥。使用双花括号语法引用，并在工作流运行时解析。
  </Card>
  <Card title="工作流变量" href="/variables/workflow-variables">
    限定于单个工作流的全局键值存储。可从任意区块创建、读取和更新变量，以在工作流中共享状态。
  </Card>
</Cards>

## 快速对比

| | 环境变量 | 工作流变量 |
|---|---|---|
| **作用域** | 个人或整个工作区 | 单个工作流 |
| **生命周期** | 在所有运行中持久保存 | 在各次运行间保持，除非重置 |
| **典型用途** | API 密钥、令牌、配置 | 区块间传递数据、状态 |
| **访问语法** | `{{VARIABLE_NAME}}` | `<variable_name>` 通过下拉菜单 |
| **谁可编辑** | 设置页面（受权限控制） | 编辑器中的变量面板 |
