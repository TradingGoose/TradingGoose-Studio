TradingGoose 中的变量充当全局数据存储，工作流中的任意区块均可访问和修改，从而通过全局变量在整个工作流中存储并共享数据。变量可用于在工作流的不同部分之间共享信息、维护状态，并构建更动态的应用。

<Callout type="info">
  变量可用于在整个工作流中存储和共享数据，便于维护状态并构建复杂、相互关联的系统。
</Callout>

## 概览

变量功能作为工作流的中心数据存储，可让你：

## 创建变量

你可以在侧边栏的变量面板中创建和管理变量。每个变量包含：

- **名称**：用于引用该变量的唯一标识符
- **值**：变量中存储的数据（支持多种数据类型）
- **描述**（可选）：说明该变量用途的备注

## 访问变量

可从工作流中的任意区块通过变量下拉菜单访问变量。只需：

1. 在区块内的任意文本字段中输入 `<`
2. 浏览下拉菜单，从可用变量中选择
3. 选择要使用的变量

在文本字段中输入 `<` 时，会弹出下拉列表，列出所有可用的工作流变量。选择所需项即可插入对该变量的引用。

<Callout>
  也可以将连接标签拖入字段，以打开变量下拉列表并访问
  可用变量。
</Callout>

## 在区块中使用变量

从区块访问变量时，你可以：

- **读取其值**：在区块逻辑中使用变量的当前值
- **修改变量**：根据区块的处理结果更新变量的值
- **在表达式中使用**：将变量纳入表达式和计算

## 变量作用域

TradingGoose 中的变量具有全局作用域，这意味着：

- 可从工作流中的任意区块访问
- 对变量的更改会在整个工作流执行期间持续有效
- 除非显式重置，变量会在各次运行之间保留其值

## 最佳实践

- **使用描述性名称**：选择能清楚表明变量含义的名称。例如，使用 `userPreferences`，而不是 `up`。
- **为变量添加说明**：给变量添加描述，帮助其他团队成员理解其用途和用法。
- **考虑变量作用域**：请记住变量是全局的，任意区块都可以修改。设计工作流时需考虑到这一点，以避免意外行为。
- **尽早初始化变量**：在工作流开头设置并初始化变量，确保需要时可用。
- **处理缺失变量**：始终考虑变量可能尚不存在或值不符合预期的情况。在区块中加入适当的校验。
- **控制变量数量**：将变量数量保持在可管理的范围内。变量过多会使工作流难以理解和维护。
