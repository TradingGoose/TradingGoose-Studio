## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `editor_mcp` |
| **分类** | 编辑器 |

MCP 编辑器用于查看、配置、测试并刷新已连接到工作区的 Model Context Protocol 服务器。它会显示该服务器的连接状态、配置、已发现的工具，以及当前的测试或保存错误。使用 [MCP 服务器列表](/widgets/list-mcp) 微件添加或移除服务器；编辑器是管理单个服务器配置的主要界面。

## 功能

- **服务器信息标题栏** 显示服务器名称、带颜色编码的连接状态徽章（已连接 / 错误 / 已断开），以及传输类型（例如 HTTP、SSE）。
- **服务器表单** 可编辑名称、描述、传输方式、URL、自定义请求头、超时、重试次数、启用状态，以及已存储的命令、参数和环境值。命令、参数、环境值和重试次数会被保留，但当前 URL 传输运行时不会使用它们。
- **测试连接按钮** 使用当前表单值向服务器发送测试请求，并在页面内显示结果。
- **刷新工具按钮** 触发服务端刷新，重新发现该 MCP 服务器公开的全部工具，并更新本地工具列表。
- **重置表单按钮** 将表单字段恢复为上次保存的服务器配置。
- **保存按钮** 持久化更新后的服务器设置；当服务器已启用且具有 URL 时还会刷新工具。测试是独立操作。
- **清除选择按钮** 取消当前服务器的选中状态。
- **工具列表** 列出从服务器发现的全部工具，并显示每个工具的名称和描述。
- **错误面板** 显示保存或刷新工具操作产生的错误。
- **服务器选择器** 位于标题栏，用于在工作区的 MCP 服务器之间切换。通过颜色链接配对后，会与 MCP 列表微件同步。

## 用法

1. 从小组件选择器将小组件添加到工作区。
2. 从标题栏下拉菜单选择 MCP 服务器，或通过 [MCP 服务器列表](/widgets/list-mcp) 小组件添加。
3. 在顶部查看连接状态和传输方式。
4. 按需编辑服务器配置。
5. 点击 **测试连接**，确认使用当前设置可以访问该服务器。
6. 点击 **刷新工具**，重新发现该服务器提供的工具。
7. 点击 **保存** 以保存更改并刷新工具。需要验证连通性时，请单独执行 **测试连接**。

### 标题栏操作

标题栏提供五个操作按钮（从左到右）：

| 按钮 | 图标 | 操作 |
|--------|------|--------|
| 刷新工具 | Rotate | 重新发现服务器上的工具 |
| 测试连接 | Play | 使用当前表单值发送测试请求 |
| 重置表单 | Undo | 将表单恢复为上次保存的值 |
| 保存服务器 | Save | 对已启用且带有 URL 的服务器保存配置并刷新工具 |
| 清除选择 | X | 取消选择该服务器 |

<Callout>
本小组件支持 **pairColor** 机制。为 MCP 编辑器和 [MCP 服务器列表](/widgets/list-mcp) 小组件指定相同颜色后，在列表中选择服务器即可自动在编辑器中打开。
</Callout>

## 配置

所选服务器以 `mcpServerId` 的形式存储在小组件参数中，并在关联后通过 pair-color 存储同步。表单编辑会立即更新协作 Yjs 草稿；点击 **保存**，将该草稿持久化为已保存的服务器配置。
