## 概述

| 属性 | 值 |
|---|---|
| **键** | `editor_mcp` |
| **类别** | 编辑器 |

MCP Editor 用于检查、配置、测试和刷新附加到工作区的 Model Context Protocol 服务器。它显示连接状态、传输设置、发现的 tools 和近期错误。使用 [MCP List](/utilities/mcp) 添加或删除服务器。

## 功能

- 标题显示服务器名称、彩色状态（Connected / Error / Disconnected）和传输类型。
- 相对时间显示上次更新、tools 刷新和连接时间。
- 表单可编辑传输类型（默认为 streamable-http）、端点 URL、请求超时和自定义 HTTP 标头。
- **Test connection** 使用当前值测试服务器并显示结果。
- **Refresh tools** 在服务器端重新发现 tools 并更新本地列表。
- **Reset form** 恢复上次保存的配置。
- **Save** 保存设置；若尚未测试，会先自动测试，再保存并刷新 tools。
- **Clear selection** 清除当前选择。
- Tools 列表显示各 tool 的名称和说明；服务器存在 `lastError` 时显示错误面板。
- 服务器选择器可通过配对颜色与 MCP List 同步。

## 使用方法

1. 添加 widget 并选择 MCP 服务器，或从 [MCP List](/utilities/mcp) 添加。
2. 查看状态和时间，按需编辑 **URL**、**Timeout** 或 **Headers**。
3. 点击 **Test connection**、**Refresh tools** 和 **Save**。若尚未测试，Save 会自动测试。

### 标题操作

| 按钮 | 图标 | 操作 |
|---|---|---|
| Refresh tools | Rotate | 重新发现服务器 tools。 |
| Test connection | Play | 使用当前表单值发送测试请求。 |
| Reset form | Undo | 恢复上次保存的值。 |
| Save server | Save | 保存配置、按需自动测试并刷新 tools。 |
| Clear selection | X | 取消选择服务器。 |

<Callout>为 MCP Editor 和 [MCP List](/utilities/mcp) 指定相同 **pairColor**，即可自动打开列表中选择的服务器。</Callout>

## 配置

所选服务器以 `mcpServerId` 存储，并通过配对颜色同步。传输、URL、超时和标头是本地状态，点击 Save 后才会持久化。
