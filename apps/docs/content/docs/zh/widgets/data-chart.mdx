## 概述

| 属性 | 值 |
|---|---|
| **键** | `data_chart` |
| **类别** | 数据 |

Data Chart 呈现带技术指标叠加、绘图工具和可配置时间间隔的 OHLCV K 线图。底层使用 [lightweight-charts](https://tradingview.github.io/lightweight-charts/)，支持多个数据提供商和市场时段模式。

## 功能

- **六种 K 线样式** -- Solid、Hollow、Up Hollow、Down Hollow、OHLC 柱和 Area 线。
- **时间间隔** -- 从 1m 到 12mo；1D、5D、1W、1M、3M、6M、1Y、5Y、ALL 范围预设会自动选择合适间隔。
- **技术指标** -- 添加工作区或内置 Pine 风格指标。每个指标在独立窗格或价格窗格中显示，十字光标悬停时显示图线值；可在设置中编辑输入。参阅[指标脚本指南](/indicators)。
- **绘图工具** -- 提供线条、注释、自由绘图、形状和分析工具。绘图按符号持久保存，可批量显示或隐藏。
- **OHLCV 图例** -- 在十字光标位置显示开高低收值；Area 模式显示单值，并按方向使用绿色或红色。
- **时区和时段** -- 使用交易所本地时间、UTC 或任意 IANA 时区；提供商支持时可切换常规和延长时段。
- **价格轴** -- 普通、百分比和对数缩放。
- **实时 K 线** -- 通过 socket 传输实时数据，并将新 K 线合并到可见序列。

## 使用方法

标题分为三组：**左侧**选择提供商并配置参数或凭据；**中间**搜索标的，可与 [Watchlist](/widgets/watchlist) 联动；**右侧**设置间隔、K 线样式和指标。底部提供范围和时区。滚动缩放、拖动平移，悬停查看 OHLCV。

<Callout type="info">为 Data Chart 和 Watchlist 指定相同配对颜色，即可在列表中选择符号时更新图表。</Callout>

## 配置

| 参数 | 说明 |
|---|---|
| `listing` | 要绘制的符号身份，由标题或配对同步设置。 |
| `data.provider` | 市场数据提供商 ID。 |
| `data.auth` | 可选 API 密钥或 secret。 |
| `data.live.enabled` | 启用实时 K 线。 |
| `view.interval` | 当前间隔，如 `1d`、`5m`。 |
| `view.candleType` | `candle_solid`、`candle_stroke`、`candle_up_stroke`、`candle_down_stroke`、`ohlc` 或 `area`。 |
| `view.priceAxisType` | `normal`、`percentage` 或 `log`。 |
| `view.marketSession` | `regular` 或 `extended`。 |
| `view.timezone` | 应用于时间轴的 IANA 时区。 |
| `view.pineIndicators` | 指标引用数组，可含输入覆盖。 |
| `view.drawTools` | 持久化绘图快照。 |
| `view.rangePresetId` | `1d`、`5d`、`1w`、`1m`、`3m`、`6m`、`1y`、`5y` 或 `all`。 |
