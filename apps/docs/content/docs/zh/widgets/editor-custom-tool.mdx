## 概述

| 属性 | 值 |
|---|---|
| **键** | `editor_custom_tool` |
| **类别** | 编辑器 |

Custom Tool Editor 用于定义代理可在工作流中调用的自定义 tools。每个 tool 包含声明名称、说明和参数的 JSON 架构，以及调用时运行的 JavaScript 函数体。使用 [Custom Tool List](/widgets/list-custom-tool) 浏览、创建和导入 tools。

## 功能

- 标题栏中的 **Config** 和 **Code** 切换两个区域。
- **Config** 使用 Monaco 编辑 OpenAI function-calling 架构。架构必须包含 `type: "function"`、`function.name`、`function.description` 和带 `function.parameters`、`type`、`properties` 的 `required`，并实时验证。
- **Code** 使用 Monaco 编辑在 `async function(params, environmentVariables)` 中运行的函数体。用 `<paramName>` 引用参数，用 `{{VAR_NAME}}` 引用环境变量。
- 两个区域的 **AI 魔杖**可根据自然语言说明生成架构或代码。
- 代码编辑器补全架构参数；输入 `{{` 打开环境变量，输入标签模式可引用工作流变量。
- **Export** 下载 TradingGoose JSON。**Save** 验证架构和重复名称并保存；失败时切换到 Config 并显示错误。
- Tool 选择器可通过配对颜色与 Custom Tool List 同步。

## 使用方法

1. 添加 widget 并选择 tool，或从 [Custom Tool List](/widgets/list-custom-tool) 创建/导入。
2. 在 **Config** 中编写或生成 JSON 架构。
3. 在 **Code** 中编写 JavaScript 函数体，直接使用架构参数。
4. 点击 **Save**，修复显示的错误。

### 架构格式

```json
{
  "type": "function",
  "function": {
    "name": "myToolName",
    "description": "What the tool does.",
    "parameters": {
      "type": "object",
      "properties": {
        "paramName": {
          "type": "string",
          "description": "What this parameter is for."
        }
      },
      "required": ["paramName"]
    }
  }
}
```

导出的 tools 使用通用 TradingGoose 导出 JSON 格式。通过列表导入时，重复标题和函数名会自动重命名。

<Callout>为 Custom Tool Editor 和 [Custom Tool List](/widgets/list-custom-tool) 指定相同 **pairColor**，即可自动打开列表中选择的 tool。</Callout>

## 配置

所选 tool 以 `customToolId` 存储并通过配对颜色同步。当前区域通过自定义事件在标题标签和编辑器主体间同步。
