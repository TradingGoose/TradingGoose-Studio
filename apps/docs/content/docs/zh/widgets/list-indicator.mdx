## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_indicator` |
| **分类** | 列表 |

指标列表组件是工作区中自定义 PineTS 指标的浏览器。可用它搜索现有指标、创建新指标、导入 TradingGoose 导出的 JSON，并在指标编辑器中打开所选指标。

## 功能

- **浏览和搜索**当前工作区中的指标。
- 通过创建菜单**新建**指标。
- 通过创建菜单中的**导入指标**操作**导入**指标。
- 在列表中选择指标即可**在编辑器中打开**。
- 当两个组件使用相同颜色时，**配对颜色关联**会使列表与指标编辑器保持同步。

## 用法

1. 将组件添加到工作区面板。
2. 使用创建菜单添加新指标，或导入 TradingGoose 导出的 JSON 文件。
3. 在列表中选择指标，即可在配对的指标编辑器组件中打开。
4. 如需列表与编辑器之间的选择变更保持同步，请指定配对颜色。

<Callout type="info">
  创建和导入操作需要工作区的编辑权限。浏览现有指标只需工作区访问权限。
</Callout>
