## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `watchlist` |
| **分类** | 交易 |

自选列表组件用于创建、整理和监控带实时行情数据的交易品种列表。它显示最新价、涨跌和涨跌幅列，并支持拖放排序、可折叠分组和行内品种编辑。

## 功能

- **多个自选列表** -- 可在工作区内创建、重命名和删除自选列表。通过标题栏中的列表选择器在它们之间切换。最后一个剩余的自选列表无法删除。
- **实时行情列** -- 每行显示 **最新价**、**涨跌** 和 **涨跌幅**，正值为绿色，负值为红色。行情会自动刷新，也可通过标题栏按钮手动刷新。
- **分组** -- 将品种归入可折叠的分组标题下。分组可在行内重命名，并可独立展开或折叠。
- **拖放排序** -- 使用鼠标、触控或键盘（配合可排序键盘传感器的方向键）重新排列品种和分组。项目可在分组之间移动。
- **行内品种编辑** -- 使用行的铅笔操作打开行内标的选择器，无需删除再添加即可更换品种。
- **搜索并添加品种** -- 标题栏中央控件提供标的搜索框。选择品种后点击勾选按钮，即可将其追加到当前自选列表。
- **导入 / 导出** -- 通过列表操作菜单，使用 TradingGoose 共享的导出 JSON 格式导出当前自选列表，或追加已导出的自选列表。分组和品种顺序会保留，导入时同一分组中的重复标的会被跳过。
- **选择数据源** -- 从标题栏左侧控件选择行情数据源。可在设置弹出框中配置该数据源的参数和 API 凭证。
- **配对颜色联动** -- 为组件指定配对颜色后，点击某一行会将所选标的广播给共享同一颜色的其他组件（例如 [数据图表](/widgets/data-chart)），当前联动的品种会高亮显示。

## 用法

将观察列表添加到工作区面板。标题栏分为三组：

- **左侧** -- 提供商设置按钮和提供商选择下拉菜单。
- **中间** -- 标的搜索输入框，以及用于添加所选标的的添加按钮。
- **右侧** -- 带各列表重命名和删除操作的观察列表选择器、用于创建观察列表或分组以及导入或导出的菜单，以及手动刷新按钮。

点击某一行即可选中。当该组件与数据图表使用相同的配对颜色时，点击还会在图表中加载该标的。将鼠标悬停或聚焦某一行，即可显示编辑和移除操作。分组标题同样会显示重命名和删除操作。

<Callout type="info">
为观察列表和数据图表指定相同的配对颜色，点击列表中的标的即可立即加载其图表。
</Callout>

## 配置

| 参数 | 说明 |
|-----------|-------------|
| `watchlistId` | 当前所选观察列表的 ID。 |
| `listing` | 与使用相同配对颜色的组件共享的标的标识。 |
| `provider` | 用于获取行情的市场数据提供商。 |
| `providerParams` | 提供商特定参数（例如交易所、市场类型）。 |
| `auth` | 所选提供商的可选 API 密钥 / Secret。 |
| `runtime.refreshAt` | 更新后会触发行情刷新的纪元时间戳。 |

一个观察列表最多可包含 1,000 个标的。
