## 概述

| 属性 | 值 |
|---|---|
| **键** | `watchlist` |
| **类别** | 数据 |

Watchlist widget 用于创建、组织和监控带实时报价的交易符号列表。它显示最新价、变化和变化百分比，并支持拖放排序、可折叠分区和行内编辑。

## 功能

- **多个自选列表** -- 在工作区中创建、重命名和删除列表。标题选择器用于切换；系统自动生成的列表不能删除。
- **实时报价列** -- 每行显示 **Last**、**Change** 和 **Change %**，正值为绿色，负值为红色。报价自动刷新，也可手动刷新。
- **分区** -- 在可折叠标题下分组符号。分区可行内重命名，并可独立展开或折叠。
- **拖放排序** -- 使用鼠标、触控或键盘重排符号和分区，并可在分区之间移动。
- **行内编辑** -- 双击一行即可更改符号，无需先删除再添加。
- **搜索和添加** -- 使用标题中间的标的搜索框，选择符号后点击确认按钮添加。
- **导入/导出** -- 通过列表操作菜单使用通用 TradingGoose 导出 JSON；保留分区和符号顺序。
- **提供商选择** -- 在左侧选择市场数据提供商，并通过设置配置参数和 API 凭据。
- **配对颜色链接** -- 点击一行会将标的发送到具有相同颜色的 widgets，例如 [Data Chart](/widgets/data-chart)，并突出显示当前链接符号。

## 使用方法

标题分为：**左侧**提供商设置、选择和手动刷新；**中间**标的搜索和添加；**右侧**自选列表选择器及创建列表、添加分区、导入、导出和删除操作。点击一行选择；双击进入编辑模式。行控件可删除项目，分区标题可重命名或删除。

<Callout type="info">为 Watchlist 和 Data Chart 指定相同配对颜色，点击列表符号即可立即加载图表。</Callout>

## 配置

| 参数 | 说明 |
|---|---|
| `watchlistId` | 当前所选自选列表 ID。 |
| `provider` | 用于获取报价的市场数据提供商。 |
| `providerParams` | 提供商参数，如交易所或市场类型。 |
| `auth` | 可选 API 密钥或 secret。 |
| `runtime.refreshAt` | 更新后触发报价刷新的 epoch 时间戳。 |
