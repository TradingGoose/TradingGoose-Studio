## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `editor_workflow` |
| **类别** | 编辑器 |

工作流编辑器是构建 AI 工作流的主画布。它会渲染完整的 React Flow 图，供你放置块、在块之间绘制连线，并配置自动化流水线的每个步骤。每个编辑器都会绑定到所选工作流的实时会话，因此同一工作流的视图会保持同步，而路由到不同工作流的编辑器则彼此独立。

## 功能

- **React Flow 画布**，内置平移、缩放和节点选择
- **块工具栏**位于页头，带可搜索下拉菜单，按类别分组列出块、工具和触发器；从工具栏将块拖到画布即可添加
- **循环块和并行块**作为特殊工具栏项提供，用于控制流逻辑
- **浮动控件**用于快速画布操作（在小组件配置中默认启用）
- **导出控件**位于页头栏，可将当前工作流下载为 TradingGoose 导出 JSON，若存在工作区技能则一并打包。
- **空工作流触发器选择器**，用于选择第一个可用触发器
- **视口感知定位** —— 小组件会跟踪自身边界矩形，使新块落在画布可见区域的中心，即使小组件嵌入在较小面板中也是如此
- **嵌套子流程验证**，当子流程引用无效时会实时高亮错误
- **触发器警告对话框**，在添加重复触发器或触及其他触发器约束时弹出

## 用法

### 添加小组件

在任意工作区面板中打开小组件选择器，然后选择 **工作流编辑器**。从标题栏选择工作流，或将此小组件与另一个支持工作流的小组件配对以共享所选内容。如果尚无工作流，编辑器会显示占位提示。

### 标题栏布局

标题栏分为三个部分：

- **左侧**：模块工具栏——用于浏览和搜索可用模块、工具和触发器，并将其添加到画布的下拉菜单
- **中间**：工作流选择下拉菜单，用于在工作区内切换工作流
- **右侧**：控制栏，包含自动布局、执行、导出、部署以及工作流级操作

### 主要操作

1. **添加模块** —— 打开工具栏下拉菜单，搜索或浏览，然后点击模块，将其放置在视口中心
2. **连接模块** —— 从输出端点拖到输入端点以创建连线
3. **选择并配置** —— 点击节点以选中并编辑其设置；配对的工作区工具可跟随当前工作流
4. **删除** —— 使用模块的操作栏将其移除，或选中连线后按 Delete 或 Backspace
5. **撤销 / 重做** —— 标准键盘快捷键

### 配对颜色同步

指定配对颜色后，编辑器会将其当前工作流与使用相同颜色的其他小组件同步。在标题栏选择器中更改工作流时，所选内容会广播到所有已配对的小组件。当配对颜色为 `gray`（未关联）时，该小组件通过小组件参数独立管理自己的选择。

<Callout>
使用匹配的配对颜色，将此小组件与 **控制台**、**聊天** 或 **变量** 配对。配对颜色仅同步仪表盘小组件；全局 Copilot 面板跟随当前活动布局。
</Callout>

## 配置

画布界面由 `WorkflowCanvasUIConfig` 控制：

| 选项 | 默认值 | 说明 |
|--------|---------|-------------|
| `floatingControls` | `true` | 在画布上显示浮动操作按钮 |
| `triggerList` | `true` | 可编辑工作流为空时显示触发器选择器 |
| `controlBar` | `false` | 显示嵌入式画布控制栏 |

这些是仪表盘小组件提供的有效值。
