## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_custom_tool` |
| **类别** | 列表 |

自定义 tool 列表 widget 用于浏览工作区中的可复用自定义 tools。可用它搜索现有 tool、创建新 tool、导入 TradingGoose 导出 JSON，并在 Custom Tool Editor 中打开所选 tool。

## 功能

- **浏览和搜索**当前工作区中的自定义 tools。
- 从 Create 菜单**新建** tools。
- 使用 Create 菜单中的 **Import custom tools** 操作**导入** tools。
- 从列表中选择 tool，**在编辑器中打开**。
- 当列表与 Custom Tool Editor 使用相同配对颜色时，**配对颜色链接**会使它们保持同步。
- **自动重命名处理**会在导入的标题和函数名与现有 tools 冲突时更新它们。

## 使用方法

1. 将 widget 添加到工作区面板。
2. 使用 Create 菜单新建自定义 tool 或导入 TradingGoose 导出 JSON 文件。
3. 在列表中选择 tool，在配对的 Custom Tool Editor widget 中打开。
4. 如果需要同步列表和编辑器之间的选择，请指定配对颜色。

<Callout type="info">
  创建和导入操作需要工作区编辑权限。浏览现有 tools 只需工作区访问权限。
</Callout>
