## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_custom_tool` |
| **分类** | 列表 |

自定义工具列表组件是工作区中可复用自定义工具的浏览器。用它可以搜索现有工具、创建新工具、导入 TradingGoose 导出的 JSON，并在自定义工具编辑器中打开所选工具。

## 功能

- **浏览和搜索**当前工作区中的自定义工具。
- 通过创建菜单**新建**自定义工具。
- 通过创建菜单中的**导入自定义工具**操作**导入**自定义工具。
- 从列表中选择工具即可**在编辑器中打开**。
- **配对颜色联动**可在列表与自定义工具编辑器使用相同颜色时保持同步。
- **自动重命名处理**会在导入标题与现有工具冲突时更新标题。

## 用法

1. 将组件添加到工作区面板。
2. 使用创建菜单添加新的自定义工具，或导入 TradingGoose 导出的 JSON 文件。
3. 在列表中选择工具，即可在配对的自定义工具编辑器组件中打开。
4. 如需让列表与编辑器的选择变更保持同步，请指定配对颜色。

<Callout type="info">
  创建和导入操作需要工作区的编辑权限。浏览现有工具只需工作区访问权限。
</Callout>
