## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_workflow` |
| **类别** | 列表 |

工作流列表 widget 显示工作区中所有工作流的可浏览列表。可用它创建工作流或文件夹、导入工作流 JSON，以及在编辑器中打开任意工作流。

## 功能

- **浏览**：查看工作区中的所有工作流。
- **搜索和筛选**：快速查找工作流。
- **创建**：直接从 Create 菜单新建文件夹或工作流。
- **导入**：从 Create 菜单导入 TradingGoose 导出的 JSON 文件。如果文件包含 skills，系统会先导入它们，并自动重新链接工作流引用。
- **在编辑器中打开**：点击任意工作流，在编辑器 widget 中打开。

## 使用方法

将此 widget 与工作流编辑器一起添加，以管理工作流。Create 菜单提供文件夹创建、工作流创建和导入功能。

<Callout type="info">
  工作流导入使用 TradingGoose 的通用导出 JSON 格式。系统会先导入捆绑的 skills，并自动重新链接它们。
</Callout>
