## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_workflow` |
| **分类** | 列表 |

工作流列表小组件以可浏览列表展示工作区中的全部工作流。可用它新建工作流或文件夹、导入工作流 JSON，以及在编辑器中打开任意工作流。

## 功能

- **浏览**：查看工作区中的所有工作流
- **创建**：直接从创建菜单新建文件夹或工作流
- **整理**：将工作流拖入文件夹，并在根文件夹下嵌套一层子文件夹
- **导入**：从创建菜单导入 TradingGoose 导出 JSON 文件。若文件包含技能，会先导入技能，并自动重新关联工作流引用。
- **在编辑器中打开**：点击即可在编辑器小组件中打开任意工作流

## 用法

将此小组件与工作流编辑器一并添加，以管理工作流。创建菜单包含创建文件夹、新建工作流和导入。

<Callout type="info">
  工作流导入使用共用的 TradingGoose 导出 JSON 格式。捆绑技能会先导入并自动重新关联。
</Callout>

<Callout type="info">
  文件夹仅支持一层子文件夹：根文件夹可以包含子文件夹，但子文件夹不能再包含文件夹。已包含子文件夹的文件夹也不能移到另一个文件夹下。
</Callout>
