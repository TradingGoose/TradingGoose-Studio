## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `portfolio_snapshot` |
| **类别** | 交易 |

Portfolio Snapshot 是所选经纪商账户在支持的表现周期内的只读摘要。

## 功能

- **表现摘要** -- 显示收益率、期初权益、期末权益、最高权益、最低权益和权益序列。
- **账户详情** -- 显示所选投资组合的现金和持仓数量。
- **报价补充** -- 添加报价估值、日变化、日变化百分比，以及报价请求中已报价持仓占符合条件持仓的覆盖情况。
- **部分可用** -- 报价补充可能不完整或不可用，但不会隐藏经纪商投资组合数据。
- **刷新** -- `runtime.refreshAt` 请求新的经纪商和报价数据。

## 使用方法

选择经纪商和账户，然后从该提供商支持的表现周期中选择 `selectedWindow`。配置市场提供商以补充当前报价。刷新会请求新快照；报价不可用时仍会显示现金、持仓和表现数据。

## 配置

| 参数 | 说明 |
|-----------|-------------|
| `provider` | 提供投资组合数据的交易提供商。 |
| `serviceId` | 经纪商服务标识符。 |
| `portfolioIdentity` | 所选经纪商账户的规范身份。 |
| `marketProvider` | 用于报价补充的提供商。 |
| `marketProviderParams` | 市场提供商专用参数。 |
| `marketAuth` | 可选的市场提供商凭据。 |
| `selectedWindow` | 提供商支持的表现周期。 |
| `runtime.refreshAt` | 用于请求刷新的时间戳。 |
