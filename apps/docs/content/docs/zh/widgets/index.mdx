import { Card, Cards } from 'fumadocs-ui/components/card'

小组件是构成工作区的仪表盘界面组件。每个小组件占据工作区布局中的一个面板，为特定任务提供专注界面——编辑工作流、监控执行、绘制行情图，或管理工作区资源。你可以自由重排、调整大小和替换小组件，搭建符合需求的布局。

<Cards>
  <Card title="仪表盘布局" href="/widgets/dashboard-layouts">
    在工作区中保存并切换个人组件布局。
  </Card>
</Cards>
