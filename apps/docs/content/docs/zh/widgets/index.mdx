Widgets 是构成工作区的 dashboard 界面组件，每个面板用于一项特定任务。你可以自由移动、调整大小和替换 widgets，以构建所需布局。

## Workflow

<Cards>
  <Card title="Workflow Editor" href="/widgets/editor-workflow">通过连接模块构建和编辑工作流。</Card>
  <Card title="Workflow List" href="/widgets/list-workflow">浏览和组织工作流及文件夹。</Card>
  <Card title="Workflow Chat" href="/widgets/workflow-chat">执行时与工作流模块交互。</Card>
  <Card title="Workflow Console" href="/widgets/workflow-console">查看实时日志和流式输出。</Card>
  <Card title="Workflow Variables" href="/widgets/workflow-variables">检查和编辑变量。</Card>
</Cards>
