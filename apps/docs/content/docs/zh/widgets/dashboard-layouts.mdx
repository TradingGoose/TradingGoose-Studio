仪表盘布局可让你在同一工作区中保留多种小组件排列。每个布局各自保存面板结构、所选小组件、小组件配置以及交易对颜色上下文。

布局属于工作区内的当前用户。其他工作区成员管理各自的布局标签页，不会更改你的个人排列。

## 管理布局

布局标签页显示在仪表盘标题栏中央：

1. 选择标签页以激活该布局。
2. 选择**加号**按钮，使用默认面板结构创建布局。
3. 拖动标签页以更改顺序。
4. 对活动标签页使用铅笔操作以重命名。
5. 对非活动标签页使用删除操作以将其移除。

<Callout type="info">
  无法删除活动布局。请先切换到其他布局；这样也能确保始终至少保留一个布局。
</Callout>

对面板大小、拆分、小组件和小组件设置的更改仅应用于活动布局。
