## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `editor_skill` |
| **类别** | 编辑器 |

Skill Editor 用于修改工作区 skill 的名称、说明和指令内容。Skills 是代理可在运行时加载的可复用指令集。使用 [Skill List](/widgets/list-skill) 浏览、创建和导入 skill；在编辑器中编写内容。

## 功能

- **Name** 接受去除首尾空格、工作区唯一且不超过 64 个字符的名称。代理用它加载 skill，保存时会验证唯一性。
- **Description** 简要说明 skill 的用途。
- **Instructions** 是最多 50,000 个字符的自由文本区，支持纯文本或 Markdown，并使用等宽字体。
- 标题栏中的 **Export** 将已保存的 skill 下载为 TradingGoose 导出 JSON。如有未保存更改，请先保存。
- **Save** 保存全部更改，并验证名称、说明、内容和唯一性。
- 标题栏中的 **skill 选择器**用于切换 skill，并可通过配对颜色与 Skill List 同步。

## 使用方法

1. 从 widget 选择器添加此 widget。
2. 从标题下拉菜单选择 skill，或从 [Skill List](/widgets/list-skill) 创建/导入。
3. 编辑 **Name**、**Description** 和 **Instructions**。
4. 点击 **Save**。

### 验证规则

- **Name** 去除首尾空格后必须为 1–64 个字符，不要求其他格式。
- **Name** 在工作区中必须唯一。
- **Description** 和 **Instructions** 均为必填且不能为空。

导入的 skills 会自动规范化；通过 Skill List 导入时，重复名称会自动重命名。

<Callout>此 widget 支持 **pairColor**。为 Skill Editor 和 [Skill List](/widgets/list-skill) 指定相同颜色后，在列表中选择 skill 会自动在编辑器中打开。</Callout>

## 配置

所选 skill 以 `skillId` 存储在 widget 参数中，链接后通过配对颜色存储同步。
