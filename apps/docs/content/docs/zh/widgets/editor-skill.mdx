## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `editor_skill` |
| **类别** | 编辑器 |

技能编辑器用于修改工作区技能的名称、描述和指令内容。技能是可复用的指令集，智能体可在运行时加载以获得专项行为。使用 [技能列表](/widgets/list-skill) 组件浏览、创建和导入技能；技能内容在编辑器中编写。

## 功能

- **名称字段** 接受去除首尾空格、在工作区内唯一的显示名称，最长 64 个字符。智能体加载指令时使用技能的不可变 ID，而非此名称。
- **描述字段** 用于简要说明该技能可帮助智能体完成的工作。
- **指令文本区** 为自由文本区域（最多 50,000 个字符），用于以纯文本或 markdown 编写完整技能指令。文本区使用等宽字体，便于编辑。
- **导出按钮** 位于顶栏，可将编辑器当前的名称、描述和指令下载为 TradingGoose 导出 JSON。
- **保存按钮** 位于顶栏，用于保存所有更改。保存时会执行校验：名称不得为空且最多 64 个字符，描述和内容不得为空，且名称必须在工作区内唯一。
- **技能选择器** 位于顶栏，用于在技能之间切换。通过颜色链接配对后，选择器会与技能列表组件同步。

## 用法

1. 从组件选择器将组件添加到工作区。
2. 从顶栏下拉菜单选择技能，或通过 [技能列表](/widgets/list-skill) 组件创建/导入技能。
3. 编辑 **名称**、**描述** 和 **指令** 字段。
4. 点击 **保存** 按钮以保存更改。

### 验证规则

- **名称**在去除首尾空格后必须为 1-64 个字符。编辑器接受常规工作区名称，无额外格式规则。
- **名称**必须唯一——同一工作区中不能有两个同名技能。
- **描述**和**指令**均为必填，且不能为空。

导入的技能会自动规范化；通过技能列表组件导入时，重复名称会被重命名。

<Callout>
此组件支持 **pairColor** 机制。为技能编辑器和[技能列表](/widgets/list-skill)组件指定相同颜色后，在列表中选中技能即可在编辑器中自动打开。
</Callout>

## 配置

所选技能以 `skillId` 存储在组件参数中；当两个组件使用相同的配对颜色时，会与关联的技能列表共享。
