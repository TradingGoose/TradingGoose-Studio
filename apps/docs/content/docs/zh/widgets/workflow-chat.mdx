## 概述

| 属性 | 值 |
|---|---|
| **键** | `workflow_chat` |
| **类别** | 实用工具 |

Workflow Chat 通过实时 socket 连接活动工作流、流式显示响应，并允许选择要显示的模块输出。可用它测试聊天 trigger、与代理交互或检查响应。

## 功能

- 每个聊天实例使用独立实时 socket。
- 输出选择器选择模块输出、去重并按工作流持久保存。
- Clear 清除当前对话；没有消息时禁用。
- 工作流选择器用于切换；配对时反映共享选择并忽略手动更改。
- 从参数、配对颜色通道或注册表解析活动工作流并持久保存。

## 使用方法

### 添加 widget

选择 **Workflow Chat**。它需要活动工作区，并自动连接第一个可用工作流。

### 标题布局

- **左侧**：输出选择器。
- **中间**：工作流选择器。
- **右侧**：清除聊天按钮。

### 主要操作

1. 输入消息并按 Enter。
2. 响应在执行期间流式显示。
3. 使用输出选择器限定响应。
4. 点击清除开始新对话。

### 配对颜色同步

指定配对颜色后与其他 widgets 共享工作流；`gray` 时独立选择。

<Callout>使用相同颜色与 **Workflow Editor** 配对，使聊天始终针对正在编辑的工作流。</Callout>
