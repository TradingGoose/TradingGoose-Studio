## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `workflow_chat` |
| **类别** | 实用工具 |

工作流聊天组件提供用于与工作流块交互的对话界面。它通过实时套接字连接到当前工作流，实时流式传输响应，并允许你选择哪些块输出会出现在对话中。可用于测试基于聊天的触发器、与工作流内的 AI 智能体对话，或在开发过程中查看响应。

## 功能

- **实时套接字连接** -- 每个聊天实例都会向工作流打开独立套接字，因此消息和响应会实时流式传输
- **输出选择器** -- 标题栏中的多选下拉菜单可让你选择将哪些工作流块输出纳入聊天响应；选择项会去重，并按工作流持久保存
- **清空聊天** -- 标题栏按钮会清除当前工作流的对话历史；没有消息时该按钮不可用
- **工作流选择器** -- 标题栏中央的下拉菜单可在工作区的工作流之间切换；当组件已配对（配对色非灰色）时，下拉菜单会反映共享选择，手动更改会被忽略
- **自动解析工作流** -- 组件会根据组件参数、配对色通道或工作流注册表解析当前工作流，并在会话之间持久保存该选择

## 用法

### 添加组件

打开组件选择器并选择 **工作流聊天**。该组件需要已激活的工作区；若未选择，会显示提示让你选择一个。工作区加载完成后，组件会自动连接到第一个可用的工作流。

### 页眉布局

- **左侧**——输出选择下拉菜单，用于选择将哪些区块输出送入聊天
- **中间**——工作流下拉菜单，用于切换目标工作流
- **右侧**——清空聊天按钮（垃圾桶图标），用于重置对话

### 主要交互

1. 在底部输入框中输入消息，按 Enter 发送
2. 工作流执行时，回复会流式显示在对话区域
3. 使用输出选择器将回复限定到特定区块
4. 点击清空按钮开始新对话

### 配对颜色同步

分配配对颜色后，该小组件会与同一颜色通道上的其他小组件（通常是工作流编辑器）共享当前工作流。在编辑器中更改工作流时，此聊天小组件会自动更新。当配对颜色为 `gray` 时，该小组件独立管理自己的工作流选择。

<Callout>
使用匹配的配对颜色，将此小组件与**工作流编辑器**配对，使聊天始终针对你正在编辑的工作流。
</Callout>
