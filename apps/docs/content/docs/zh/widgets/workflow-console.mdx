## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `workflow_console` |
| **类别** | 实用工具 |

工作流控制台小组件会实时显示工作流执行过程中发生的全部内容。每条记录都会标注产生它的区块、状态和时间戳。该小组件会根据面板宽度自动调整布局。

## 功能

- **实时日志流** —— 各区块执行时立即显示条目，包含区块名称、类型、状态和输出
- **按状态和区块筛选** —— 筛选弹出框可切换 `error` 和 `info` 状态的可见性，并按名称勾选或取消勾选各个区块；已启用的筛选会在筛选图标上高亮显示
- **按时间排序** —— 通过表头上的单个按钮在升序和降序时间顺序之间切换
- **结构化视图** —— 开关可将日志条目切换为格式化的 JSON 样式布局，便于检查复杂输出对象
- **自动换行** —— 开关控制较长日志行是换行显示还是横向滚动
- **导出为 CSV** —— 将当前（已筛选）控制台条目下载为 CSV 文件
- **清空控制台** —— 从控制台存储中删除当前工作流的全部条目
- **工作流选择器** —— 表头下拉菜单，用于在工作流之间切换；在已关联时遵循配对颜色同步

## 用法

### 添加小组件

打开小组件选择器，选择 **工作流控制台**。它会加载当前工作区中活动工作流的条目。

### 页头布局

- **居中** —— 工作流选择下拉菜单
- **右侧** —— 工具栏，包含筛选、排序、结构化视图、自动换行、导出 CSV 和清空按钮（全部成组）

### 关键交互

1. 从编辑器或聊天中运行工作流，并在控制台中查看实时流入的条目
2. 打开筛选弹出框，将结果限定为特定区块或仅错误条目
3. 切换结构化视图，更方便阅读 JSON 负载
4. 当条目包含较长的单行字符串时，切换自动换行
5. 点击下载按钮，将筛选后的条目导出为 CSV，用于离线分析
6. 点击垃圾桶按钮，清空当前工作流的控制台

### 配对颜色同步

分配配对颜色后，控制台会自动跟随配对编辑器中所选的工作流。当配对颜色为 `gray` 时，可通过页头下拉菜单独立选择要监控的工作流。

<Callout>
将此组件与 **工作流编辑器** 配对，即可查看正在构建的工作流的实时执行日志。
</Callout>
