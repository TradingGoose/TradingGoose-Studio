## 概述

| 属性 | 值 |
|---|---|
| **键** | `workflow_console` |
| **类别** | 实用工具 |

Workflow Console 实时显示工作流执行期间发生的所有事件。每条记录包含模块、状态和时间戳；布局会自动适应面板宽度。

## 功能

- 实时日志显示模块名称、类型、状态和输出。
- 按 `error`、`info` 和模块筛选；活动筛选器会突出显示。
- 按时间升序或降序排列。
- 结构化视图用于检查复杂 JSON 对象。
- 切换长文本换行或水平滚动。
- 将当前筛选记录导出为 CSV。
- 清除活动工作流的全部控制台记录。
- 工作流选择器支持配对颜色同步。

## 使用方法

### 添加 widget

选择 **Workflow Console**，加载当前工作区活动工作流的记录。

### 标题布局

- **中间**：工作流选择器。
- **右侧**：筛选、排序、结构化视图、换行、CSV 导出和清除。

### 主要操作

1. 从编辑器或聊天运行工作流并查看记录。
2. 筛选指定模块或错误。
3. 使用结构化视图查看 JSON。
4. 对长行启用换行。
5. 将筛选记录下载为 CSV。
6. 清除当前工作流控制台。

### 配对颜色同步

指定配对颜色后自动跟随编辑器工作流；`gray` 时可独立选择。

<Callout>与 **Workflow Editor** 配对，查看正在构建的工作流的实时执行日志。</Callout>
