## 概述

| 属性 | 值 |
|----------|-------|
| **键** | `list_skill` |
| **类别** | 列表 |

Skill 列表 widget 用于浏览工作区中的可复用 skills。可用它搜索现有 skill、创建新 skill、导入 TradingGoose 导出 JSON，并在 Skill Editor 中打开所选 skill。

## 功能

- **浏览和搜索**当前工作区中的 skills。
- 从 Create 菜单**新建** skills。
- 使用 Create 菜单中的 **Import skills** 操作**导入** skills。
- 从列表中选择 skill，**在编辑器中打开**。
- 当列表与 Skill Editor 使用相同配对颜色时，**配对颜色链接**会使它们保持同步。

## 使用方法

1. 将 widget 添加到工作区面板。
2. 使用 Create 菜单新建 skill 或导入 TradingGoose 导出 JSON 文件。
3. 在列表中选择 skill，在配对的 Skill Editor widget 中打开。
4. 如果需要同步列表和编辑器之间的选择，请指定配对颜色。

<Callout type="info">
  创建和导入操作需要工作区编辑权限。浏览现有 skills 只需工作区访问权限。
</Callout>
