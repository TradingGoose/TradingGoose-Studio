## 连接的工作原理

连接是允许数据在工作流中的块之间流动的通道。在 TradingGoose 中，连接定义了信息如何从一个块传递到另一个块，从而实现整个工作流中的数据流动。

<Callout type="info">
  每个连接代表一种有向关系，数据从源块的输出
  流向目标块的输入。
</Callout>

### 创建连接

<Steps>
  <Step>
    <strong>选择源块</strong>：点击要连接的块的输出端口
  </Step>
  <Step>
    <strong>绘制连接</strong>：拖动到目标块的输入端口
  </Step>
  <Step>
    <strong>确认连接</strong>：松开以创建连接
  </Step>
</Steps>

### 连接流

数据通过连接流动时遵循以下原则：

1. **方向性流动**：数据始终从输出流向输入
2. **执行顺序**：块根据连接按顺序执行
3. **数据转换**：数据在块之间传递时可能被转换
4. **条件路径**：某些块（如 Router 和 Condition）可以将流导向不同路径

<Callout type="warning">
  删除连接将立即停止块之间的数据流。在删除连接之前，请确保这是
  有意为之。
</Callout>
