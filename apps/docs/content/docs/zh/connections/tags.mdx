连接标签是连接块中可用数据的可视化表示，提供了一种在工作流中引用块之间数据和前置块输出的简便方式。

### 什么是连接标签？

连接标签是块连接时出现的交互元素。它们表示可以从一个块流向另一个块的数据，并允许您：

- 可视化源块中可用的数据
- 在目标块中引用特定的数据字段
- 在块之间创建动态数据流

<Callout type="info">
  连接标签使您可以轻松查看前置块中可用的数据，并在当前块中使用这些数据，而无需记住复杂的数据结构。
</Callout>

## 标签语法

连接标签使用简单的语法来引用数据：

```
<blockName.path.to.data>
```

其中：

- `blockName` 是源模块的名称（或其 ID）
- `path.to.data` 是以点分隔的特定数据字段路径

例如：

- `<agent1.content>` - 引用名为 "agent1" 的模块中的内容字段
- `<api2.data.users[0].name>` - 引用名为 "api2" 的模块的数据字段中用户数组的第一个用户名

### 特殊引用类型

除模块引用外，解析器还支持以下特殊前缀：

- **Trigger 别名**：`<start.input>`、`<api.fieldName>`、`<chat.input>`、`<manual.input>` - 对 trigger 模块输出的简写引用
- **变量**：`<variable.myVar>` - 按名称引用工作流变量
- **循环**：`<loop.item>`、`<loop.index>` - 引用循环中的当前项或索引
- **并行执行**：`<parallel.item>`、`<parallel.index>` - 引用并行执行中的当前项或索引

## 动态标签引用

连接标签在运行时进行评估，这意味着：

1. 它们始终引用执行上下文中的最新数据
2. 它们可以在表达式中使用，并与静态文本结合
3. 它们可以嵌套在其他数据结构中
4. 支持使用方括号表示法访问数组索引（例如 `items[0]`）

### 示例

```javascript
// Reference in text
"The user's name is <userBlock.name>"

// Reference in JSON
{
  "userName": "<userBlock.name>",
  "orderTotal": <apiBlock.data.total>
}

// Using trigger aliases
"User said: <start.input>"

// Using loop references inside a loop
"Processing item <loop.index>: <loop.item.name>"
```

<Callout type="warning">
  在数字上下文中使用连接标签时，请确保引用的数据实际上是数字，
  以避免类型转换问题。
</Callout>
