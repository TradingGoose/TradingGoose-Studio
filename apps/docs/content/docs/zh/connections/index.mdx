连接是让数据在工作流的区块之间流动的通道。它们定义了信息如何从一个区块传递到另一个区块，使你能够创建复杂多步骤的流程。

<Callout type="info">
  正确配置的连接对于创建高效的工作流至关重要。它们决定了
  数据如何在你系统中流转，以及区块之间如何相互交互。
</Callout>

要创建连接，请从一个区块的输出端口拖动到另一个区块的输入端口。连接后，源区块产生的数据将通过连接标签在目标区块中可用。
