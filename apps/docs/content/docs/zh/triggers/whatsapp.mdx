## 设置说明

<div class="mb-3"><strong>1.</strong> 前往你的 <a href="https://developers.facebook.com/apps/" target="_blank" rel="noopener noreferrer" class="text-muted-foreground underline transition-colors hover:text-muted-foreground/80">Meta for Developers Apps</a> 页面，进入 “Build with us” --> “App Events” 部分。</div><div class="mb-3"><strong>2.</strong> 如果你还没有应用：<br /><ul class="mt-1 ml-5 list-disc"><li>从头创建应用</li><li>为其命名并选择工作区</li></ul></div><div class="mb-3"><strong>3.</strong> 选择你的应用，然后进入 WhatsApp > Configuration。</div><div class="mb-3"><strong>4.</strong> 找到 Webhooks 部分，点击 “Edit”。</div><div class="mb-3"><strong>5.</strong> 将上方的 <strong>Webhook URL</strong> 粘贴到 “Callback URL” 字段。</div><div class="mb-3"><strong>6.</strong> 将 <strong>验证令牌</strong> 粘贴到 “Verify token” 字段。</div><div class="mb-3"><strong>7.</strong> 点击 “Verify and save”。</div><div class="mb-3"><strong>8.</strong> 点击 Webhook fields 旁的 “Manage”，并订阅 <code>messages</code>。</div>
