Chat trigger 创建一个 conversational 界面，用于你的 workflow. Deploy 你的 workflow 作为一个 chat和用户可 interact 使用it 通过一个 shareable URL. 每个消息 starts 一个新建 workflow 执行.

<Callout type="info">
  此为 一个 **deployment-based** trigger. 用户 interact 使用你的 workflow 通过一个 hosted chat URL.
</Callout>

### 输出架构

| 字段 | 类型 | 描述 |
|-------|------|-------------|
| `input` | 字符串 | 最新 user 消息 |
| `conversationId` | 字符串 | 对话线程 ID |
| `files` | 文件 | 可选 uploaded 文件 |

### 文件属性

| 属性 | 类型 | 描述 |
|----------|------|-------------|
| `<chat.files[0].url>` | 字符串 | Signed download URL |
| `<chat.files[0].name>` | 字符串 | Original filename |
| `<chat.files[0].size>` | 数字 | 文件大小在bytes |
| `<chat.files[0].type>` | 字符串 | MIME 类型 |

<Callout>
每个对话 maintains 其自己的线程. 用户可 有多个 concurrent conversations.
</Callout>
