接收来自任意服务或 API 的 webhook

<Callout type="info">
  这是一个**基于 webhook** 的触发器。请将外部服务配置为向工作流 webhook URL 发送事件。
</Callout>

## 设置说明

<div class="mb-3"><strong>1.</strong> 复制 webhook URL，并在外部服务或 API 中使用。</div><div class="mb-3"><strong>2.</strong> 将服务配置为向此 URL 发送 webhook。</div><div class="mb-3"><strong>3.</strong> 该 webhook 可接收任意 HTTP 方法（GET、POST、PUT、DELETE 等）。</div><div class="mb-3"><strong>4.</strong> 所有请求数据（请求头、请求体、查询参数）都将可在工作流中使用。</div><div class="mb-3"><strong>5.</strong> 如果启用了身份验证，请在请求中通过自定义请求头或 "Authorization: Bearer TOKEN" 携带令牌。</div><div class="mb-3"><strong>6.</strong> 当 payload 中包含 "event"、"id" 和 "data" 等常见字段时，系统会自动提取。</div>
