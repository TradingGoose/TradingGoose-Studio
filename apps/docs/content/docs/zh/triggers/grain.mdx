## 事件

### Grain Webhook

适用于所有 Grain 事件的通用 webhook 触发器

#### 设置说明

<div class="mb-3"><strong>1.</strong> 在上方输入你的 Grain API 密钥（Personal Access Token）。</div><div class="mb-3"><strong>2.</strong> 可在 Grain 的 <strong>Settings > Integrations > API</strong> 中查找或创建 API 密钥。</div><div class="mb-3"><strong>3.</strong> 点击 <strong>"保存配置"</strong>，即可在 Grain 中自动创建适用于 <strong>All events</strong> 事件的 webhook。</div><div class="mb-3"><strong>4.</strong> 移除此触发器时，webhook 将自动删除。</div>
