触发 workflow，来源为portfolio 监控状态 changes

<Callout type="info">
  此为 一个 **event-driven** trigger. Configured portfolio monitors emit workflow 事件当其条件 matches.
</Callout>

## 配置

在工作区的**监控**界面管理投资组合监控器。选择经纪商账户，定义要评估的条件，并选择包含此投资组合触发器的目标工作流。

传递的 `event` 始终为 `portfolio_state_condition_matched`。`input` 消息为 `Portfolio state condition matched for {account}`；`{account}` 优先使用 `portfolio.identity.accountName`，不可用时回退到 `portfolio.identity.accountId`。
