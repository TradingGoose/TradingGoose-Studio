根据投资组合监控的状态变化触发工作流

<Callout type="info">
  这是**基于轮询**的触发器。TradingGoose 会按固定间隔检查数据源是否出现匹配的变化。
</Callout>

## 设置说明

- 打开 `/workspace/[workspaceId]/monitor` 并创建投资组合监控。
- 选择券商账户、投资组合条件和目标工作流。
- 选择 `edge`，仅在条件从 false 变为 true 时运行；或选择 `while_true`，在条件保持为 true 期间反复运行，并受冷却时间限制。
- 轮询间隔默认为 60 秒，可设为 15–3600 秒。冷却时间默认为 300 秒，可设为 0–86400 秒。
