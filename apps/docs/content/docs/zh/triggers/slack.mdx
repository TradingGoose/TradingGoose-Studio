<Callout type="info">

## 设置说明

<div class="mb-3"><strong>1.</strong> 前往 <a href="https://api.slack.com/apps" target="_blank" rel="noopener noreferrer" class="text-muted-foreground underline transition-colors hover:text-muted-foreground/80">Slack 应用页面</a></div><div class="mb-3"><strong>2.</strong> 如果还没有应用：<br /><ul class="mt-1 ml-5 list-disc"><li>从头创建应用</li><li>为其命名并选择工作区</li></ul></div><div class="mb-3"><strong>3.</strong> 前往“基本信息”，找到“Signing Secret”，并将其粘贴到上方字段中。</div><div class="mb-3"><strong>4.</strong> 前往“OAuth 与权限”，添加机器人令牌范围：<br /><ul class="mt-1 ml-5 list-disc"><li><code>app_mentions:read</code> - 用于查看 @ 提及机器人的消息</li><li><code>chat:write</code> - 用于向机器人所在频道发送消息</li></ul></div><div class="mb-3"><strong>5.</strong> 前往“事件订阅”：<br /><ul class="mt-1 ml-5 list-disc"><li>启用事件</li><li>在“订阅机器人事件”下，添加 <code>app_mention</code> 以监听提及机器人的消息</li><li>将上方的 Webhook URL 粘贴到“请求 URL”字段</li></ul></div><div class="mb-3"><strong>6.</strong> 在左侧边栏前往“安装应用”，将应用安装到所需的 Slack 工作区和频道。</div><div class="mb-3"><strong>7.</strong> 在 Slack 和此处均保存更改。</div>
