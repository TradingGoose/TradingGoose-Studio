根据 Telegram 机器人消息和事件触发工作流

<Callout type="info">
  这是**基于 webhook** 的触发器。请将外部服务配置为向工作流 webhook URL 发送事件。
</Callout>

<Cards>
  <Card title="用作工具" href="/tools/telegram">
    查看 Telegram 的工作流操作、运算和工具输入。
  </Card>
</Cards>

## 设置说明

<div class="mb-3"><strong>1.</strong> 在 Telegram 中向 <a href="https://t.me/BotFather" target="_blank" rel="noopener noreferrer" class="text-muted-foreground underline transition-colors hover:text-muted-foreground/80">@BotFather</a> 发送 "/newbot"，创建机器人并复制其令牌。</div><div class="mb-3"><strong>2.</strong> 在上方输入你的机器人令牌。</div><div class="mb-3"><strong>3.</strong> 保存设置后，发送到你机器人的任何消息都会触发工作流。</div>
