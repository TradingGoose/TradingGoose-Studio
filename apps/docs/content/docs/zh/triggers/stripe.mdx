在 Stripe 事件发生时触发（付款、订阅、发票等）

<Callout type="info">
  这是基于 **Webhook** 的触发器。请将外部服务配置为向工作流 Webhook URL 发送事件。
</Callout>

<Cards>
  <Card title="用作工具" href="/tools/stripe">
    查看 Stripe 的工作流动作、操作和工具输入。
  </Card>
</Cards>

## 设置说明

<div class="mb-3"><strong>1.</strong> 打开 <a href="https://dashboard.stripe.com/webhooks" target="_blank" rel="noopener noreferrer">Stripe webhook 设置</a></div><div class="mb-3"><strong>2.</strong> 点击“Add destination”按钮</div><div class="mb-3"><strong>3.</strong> 在“Events to send”中选择要监听的事件（必须与上方所选事件一致，或选择“Select all events”以接收全部事件）</div><div class="mb-3"><strong>4.</strong> 选择 <code>Webhook Endpoint</code>，点击继续，然后将上方的 <strong>Webhook URL</strong> 粘贴到“Endpoint URL”字段</div><div class="mb-3"><strong>5.</strong> 点击“Create Destination”保存</div><div class="mb-3"><strong>6.</strong> 创建端点后，点击“Signing secret”旁的“Reveal”并复制</div><div class="mb-3"><strong>7.</strong> 将签名密钥粘贴到上方的 <strong>Webhook 签名密钥</strong> 字段</div><div class="mb-3"><strong>8.</strong> 点击“Save”以启用 Webhook 触发器</div>
