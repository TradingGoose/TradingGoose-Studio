## 事件

### HubSpot 联系人已创建

在 HubSpot 中创建新联系人时触发工作流

#### 设置说明

<div class="mb-3"><strong>步骤 1：创建 HubSpot 开发者账户</strong><br />如果还没有账户，请前往 <a href="https://developers.hubspot.com" target="_blank">developers.hubspot.com</a> 免费注册开发者账户。</div><div class="mb-3"><strong>步骤 2：通过 CLI 创建公共应用</strong><br /><strong>注意：</strong>HubSpot 已弃用用于创建应用的 Web 界面。必须使用 HubSpot CLI 创建和管理应用。使用 <code>npm install -g @hubspot/cli</code> 安装 CLI，然后运行 <code>hs project create</code> 创建新应用。详情请参阅 <a href="https://developers.hubspot.com/docs/platform/create-an-app" target="_blank">HubSpot 文档</a>。</div><div class="mb-3"><strong>步骤 3：保存 OAuth 应用凭证</strong><br />将 <code>https://www.tradinggoose.ai/api/auth/oauth2/callback/hubspot</code> 添加到 HubSpot OAuth 重定向 URL。从 HubSpot 应用配置中获取 <strong>Client ID</strong> 和 <strong>Client Secret</strong>，并填入上方字段。</div><div class="mb-3"><strong>步骤 4：获取 App ID 和开发者 API 密钥</strong><br />在 HubSpot 开发者账户中，找到 <strong>App ID</strong>（显示在应用名称下方）和 <strong>Developer API Key</strong>（位于应用设置中）。后续步骤需要这两项。</div><div class="mb-3"><strong>步骤 5：设置所需权限范围</strong><br />在应用中配置所需的 OAuth 权限范围：<code>crm.objects.contacts.read</code></div><div class="mb-3"><strong>步骤 6：在 TradingGoose 中保存配置</strong><br />点击上方的<strong>“保存配置”</strong>按钮。系统将生成你的唯一 webhook URL。</div><div class="mb-3"><strong>步骤 7：通过 API 在 HubSpot 中配置 Webhook</strong><br />保存后，复制 <strong>Webhook URL</strong>，然后运行下方两条 curl 命令（将 <code>&#123;YOUR_APP_ID&#125;</code>、<code>&#123;YOUR_DEVELOPER_API_KEY&#125;</code> 和 <code>&#123;YOUR_WEBHOOK_URL_FROM_ABOVE&#125;</code> 替换为实际值）。</div><div class="mb-3"><strong>步骤 8：测试 Webhook</strong><br />在 HubSpot 中创建或修改联系人，以触发 webhook。在 TradingGoose 中查看工作流执行日志，确认其正常工作。</div><div class="mb-3"><strong>补充信息：</strong>无论来源如何（手动录入、表单提交、API、导入等），只要在 HubSpot 账户中创建新联系人，webhook 就会触发。</div>

#### 设置说明

<div class="mb-3"><strong>步骤 1：创建 HubSpot 开发者账号</strong><br />如果还没有账号，请前往 <a href="https://developers.hubspot.com" target="_blank">developers.hubspot.com</a> 免费注册开发者账号。</div><div class="mb-3"><strong>步骤 2：通过 CLI 创建公共应用</strong><br /><strong>注意：</strong>HubSpot 已弃用用于创建应用的网页界面。你必须使用 HubSpot CLI 来创建和管理应用。使用 <code>npm install -g @hubspot/cli</code> 安装 CLI，然后运行 <code>hs project create</code> 创建新应用。详情请参阅 <a href="https://developers.hubspot.com/docs/platform/create-an-app" target="_blank">HubSpot 文档</a>。</div><div class="mb-3"><strong>步骤 3：保存 OAuth 应用凭证</strong><br />将 <code>https://www.tradinggoose.ai/api/auth/oauth2/callback/hubspot</code> 添加到 HubSpot 的 OAuth 重定向 URL。从 HubSpot 应用配置中获取 <strong>客户端 ID</strong> 和 <strong>客户端密钥</strong>，并填入上方字段。</div><div class="mb-3"><strong>步骤 4：获取 App ID 和开发者 API 密钥</strong><br />在 HubSpot 开发者账号中，找到你的 <strong>App ID</strong>（显示在应用名称下方）和 <strong>开发者 API 密钥</strong>（位于应用设置中）。后续步骤需要这两项。</div><div class="mb-3"><strong>步骤 5：设置所需权限范围</strong><br />在应用中配置所需的 OAuth 权限范围：<code>crm.objects.contacts.read</code></div><div class="mb-3"><strong>步骤 6：在 TradingGoose 中保存配置</strong><br />点击上方的 <strong>“保存配置”</strong> 按钮。这将生成你的专属 Webhook URL。</div><div class="mb-3"><strong>步骤 7：通过 API 在 HubSpot 中配置 Webhook</strong><br />在上方保存后，复制 <strong>Webhook URL</strong>，然后运行下方两条 curl 命令（将 <code>&#123;YOUR_APP_ID&#125;</code>、<code>&#123;YOUR_DEVELOPER_API_KEY&#125;</code> 和 <code>&#123;YOUR_WEBHOOK_URL_FROM_ABOVE&#125;</code> 替换为实际值）。</div><div class="mb-3"><strong>步骤 8：测试 Webhook</strong><br />在 HubSpot 中创建或修改联系人，以触发 Webhook。在 TradingGoose 中查看工作流执行日志，确认其正常工作。</div><div class="mb-3"><strong>补充说明：</strong>无论来源如何（手动录入、表单提交、API、导入等），只要在 HubSpot 账号中创建了新工单，Webhook 就会触发。</div>
