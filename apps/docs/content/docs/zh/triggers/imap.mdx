通过 IMAP 收到新邮件时触发（适用于任何邮件服务商）

<Callout type="info">
  这是一个**基于轮询**的触发器。TradingGoose 会按固定间隔检查源中是否有匹配的变更。
</Callout>

## 设置说明

<div class="mb-3"><strong>1.</strong> 输入 IMAP 服务器信息（主机、端口、SSL 设置）</div><div class="mb-3"><strong>2.</strong> 输入邮箱凭据（用户名和密码）</div><div class="mb-3"><strong>3.</strong> Gmail：请使用 <a href="https://support.google.com/accounts/answer/185833" target="_blank">应用专用密码</a>，不要使用普通密码</div><div class="mb-3"><strong>4.</strong> 选择要监控的邮箱（最常用的是 INBOX）</div><div class="mb-3"><strong>5.</strong> 可选择配置搜索条件和处理选项</div><div class="mb-3"><strong>6.</strong> 系统将自动检查新邮件并触发工作流</div>
