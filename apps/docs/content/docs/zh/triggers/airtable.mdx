根据 Airtable 记录的创建、更新和删除等变更触发工作流（需要 Airtable 凭证）

<Callout type="info">
  这是基于 **webhook** 的触发器。请将外部服务配置为向工作流 webhook URL 发送事件。
</Callout>

<Cards>
  <Card title="作为工具使用" href="/tools/airtable">
    查看 Airtable 的工作流动作、操作和工具输入。
  </Card>
</Cards>

## 设置说明

<div class="mb-3"><strong>1.</strong> 使用上方的「选择 Airtable 凭证」按钮连接你的 Airtable 账户。</div><div class="mb-3"><strong>2.</strong> 请确保已在上方提供正确的 Base ID 和 Table ID。</div><div class="mb-3"><strong>3.</strong> 可在 Airtable URL 中找到 Base ID：https://airtable.com/[baseId]/...</div><div class="mb-3"><strong>4.</strong> 点击表名称并查看 URL，即可找到 Table ID。</div><div class="mb-3"><strong>5.</strong> 指定表中的记录被创建、更新或删除时，webhook 都会触发。</div><div class="mb-3"><strong>6.</strong> 请确保你的 Airtable 账户对指定 Base 拥有相应权限。</div>
