## 事件

### Microsoft Teams 频道

通过传出 webhook，从 Microsoft Teams 频道消息触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> 打开 Microsoft Teams，进入要添加 webhook 的团队。</div><div class="mb-3"><strong>2.</strong> 点击团队名称旁的三个点 (•••)，然后选择“管理团队”。</div><div class="mb-3"><strong>3.</strong> 转到“应用”选项卡，点击“创建传出 webhook”。</div><div class="mb-3"><strong>4.</strong> 填写名称、说明，并可选择添加个人资料图片。</div><div class="mb-3"><strong>5.</strong> 将回调 URL 设置为上方的 TradingGoose webhook URL。</div><div class="mb-3"><strong>6.</strong> 复制 HMAC 安全令牌，并将其粘贴到“HMAC 密钥”字段。</div><div class="mb-3"><strong>7.</strong> 点击“创建”完成设置。</div>

### Microsoft Teams 聊天

通过 Microsoft Graph 订阅，从 Microsoft Teams 聊天中的新消息触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> 连接你的 Microsoft Teams 账号并授予所需权限。</div><div class="mb-3"><strong>2.</strong> 输入要监控的 Teams 聊天 ID。</div><div class="mb-3"><strong>3.</strong> 我们将创建 Microsoft Graph 更改通知订阅，把聊天消息事件投递到你的 TradingGoose webhook URL。</div>
