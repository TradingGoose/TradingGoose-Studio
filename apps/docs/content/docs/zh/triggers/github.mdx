## 事件

### GitHub Webhook

通过 GitHub 事件（如 push、pull request、issue 等）触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> 前往 GitHub 仓库 > 设置 > Webhooks。</div><div class="mb-3"><strong>2.</strong> 点击“添加 webhook”。</div><div class="mb-3"><strong>3.</strong> 将上方的 <strong>Webhook URL</strong> 粘贴到“有效负载 URL”字段。</div><div class="mb-3"><strong>4.</strong> 在下拉菜单中选择对应的内容类型。</div><div class="mb-3"><strong>5.</strong> 如果已配置 <strong>Webhook 密钥</strong>，请将其填入“密钥”字段。</div><div class="mb-3"><strong>6.</strong> 按照你的选择设置 SSL 验证。</div><div class="mb-3"><strong>7.</strong> 选择应触发此 webhook 的事件。</div><div class="mb-3"><strong>8.</strong> 确认已勾选“激活”，然后点击“添加 webhook”。</div>

### GitHub 议题已打开

当 GitHub 仓库中打开新议题时触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> 前往 GitHub 仓库 > 设置 > Webhooks。</div><div class="mb-3"><strong>2.</strong> 点击“添加 webhook”。</div><div class="mb-3"><strong>3.</strong> 将上方的 <strong>Webhook URL</strong> 粘贴到“有效负载 URL”字段。</div><div class="mb-3"><strong>4.</strong> 从下拉菜单中选择所需的内容类型。</div><div class="mb-3"><strong>5.</strong> 如果已配置 <strong>Webhook 密钥</strong>，请将其填入“密钥”字段。</div><div class="mb-3"><strong>6.</strong> 根据你的选择设置 SSL 验证。</div><div class="mb-3"><strong>7.</strong> 选择“让我选择单个事件”，并勾选 <strong>issues</strong>（<strong>opened</strong> 操作）。</div><div class="mb-3"><strong>8.</strong> 确保勾选“处于活动状态”，然后点击“添加 webhook”。</div>

### GitHub Actions 工作流运行

当 GitHub Actions 工作流运行被请求、进行中或已完成时触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> 前往 GitHub 仓库 > Settings > Webhooks。</div><div class="mb-3"><strong>2.</strong> 点击“Add webhook”。</div><div class="mb-3"><strong>3.</strong> 将上方的 <strong>Webhook URL</strong> 粘贴到“Payload URL”字段。</div><div class="mb-3"><strong>4.</strong> 从下拉菜单中选择所需的内容类型。</div><div class="mb-3"><strong>5.</strong> 若已配置，将 <strong>Webhook Secret</strong> 填入“Secret”字段。</div><div class="mb-3"><strong>6.</strong> 根据你的选择设置 SSL 验证。</div><div class="mb-3"><strong>7.</strong> 选择“Let me select individual events”，并勾选 <strong>Workflow runs</strong>。</div><div class="mb-3"><strong>8.</strong> 确保已勾选“Active”，然后点击“Add webhook”。</div>
