## 事件

### 集合项已创建

当 Webflow CMS 集合中创建新项目时触发工作流（需要 Webflow 凭据）

#### 设置说明

<div class="mb-3"><strong>1.</strong> 点击上方的“选择 Webflow 凭据”按钮，连接你的 Webflow 账号。</div><div class="mb-3"><strong>2.</strong> 输入 Webflow 站点 ID（可在站点 URL 或站点设置中找到）。</div><div class="mb-3"><strong>3.</strong> 可选择输入集合 ID，仅监控特定集合。</div><div class="mb-3"><strong>4.</strong> 如果未提供集合 ID，站点上任意集合中创建项目时都会触发。</div><div class="mb-3"><strong>5.</strong> 只要在指定集合中创建了新项目，webhook 就会触发。</div><div class="mb-3"><strong>6.</strong> 确保你的 Webflow 账号对指定站点具有相应权限。</div>

### 表单提交

在 Webflow 站点提交表单时触发工作流（需要 Webflow 凭据）

#### 设置说明

<div class="mb-3"><strong>1.</strong> 使用上方的「选择 Webflow 凭据」按钮连接你的 Webflow 账户。</div><div class="mb-3"><strong>2.</strong> 输入你的 Webflow 站点 ID（可在站点 URL 或站点设置中找到）。</div><div class="mb-3"><strong>3.</strong> 可选择输入表单 ID，以仅监控特定表单。</div><div class="mb-3"><strong>4.</strong> 如果未提供表单 ID，该站点上任意表单提交都会触发。</div><div class="mb-3"><strong>5.</strong> 指定站点上提交表单时，webhook 即会触发。</div><div class="mb-3"><strong>6.</strong> 负载中将包含表单数据及所有已提交的字段值。</div><div class="mb-3"><strong>7.</strong> 请确保你的 Webflow 账户对指定站点拥有相应权限。</div>
