当 RSS 源发布新条目时触发

<Callout type="info">
  这是**轮询型**触发器。TradingGoose 会按固定间隔检查来源是否出现匹配的变更。
</Callout>

## 设置说明

<div class="mb-3"><strong>1.</strong> 输入要监控的任意 RSS 或 Atom 源 URL</div><div class="mb-3"><strong>2.</strong> 系统每分钟检查该源是否有新条目</div><div class="mb-3"><strong>3.</strong> 发布新条目时，工作流会被触发，并带上该条目的数据</div>

## 配置

<ShowcaseCard>
  <BlockConfigPreview
    name="RSS 源触发器"
    type="rss_poller"
    hideHeader
    subBlocks={[
        {
            "id": "feedUrl",
            "type": "short-input",
            "title": "源 URL",
            "placeholder": "https://example.com/feed.xml",
            "description": "要监控的 RSS 或 Atom 源 URL",
            "required": true
        }
    ]}
  />
</ShowcaseCard>
