## 设置说明

1. 在上方输入 TwiML Response，用于告知 Twilio 来电时应执行的操作（例如播放留言、录音、收集输入）。注意：TwiML 标签请使用方括号 [Tag]，不要使用尖括号

2. 带转录的录音 TwiML 示例：[Response][Say]Please leave a message.[/Say][Record transcribe="true" maxLength="120"/][/Response]

3. 打开 Twilio Console 的电话号码页面：https://console.twilio.com/us1/develop/phone-numbers/manage/incoming

4. 选择要用于接听来电的电话号码。

5. 向下滚动到 "Voice Configuration" 部分。

6. 在 "A CALL COMES IN" 字段中选择 "Webhook"，并粘贴上方的 Webhook URL。

7. 确保 HTTP 方法设置为 POST。

8. 点击 "Save configuration"。

9. 工作原理：来电时，Twilio 会立即收到你的 TwiML 响应并执行这些指令。工作流在后台运行，可获取来电者信息、通话状态以及任何已录音/已转录的数据。
