<Callout type="info">
  这是**基于轮询**的触发器。TradingGoose 按固定间隔检查数据源中的匹配变化。
</Callout>

## 设置说明

指标监控在 /workspace/[workspaceId]/monitor 中管理。在该处配置提供商、标的、周期、指标和工作流目标。
