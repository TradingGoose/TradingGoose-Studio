手动触发器会在工作流中添加“运行”按钮。需要立即执行工作流且无需收集其他数据时使用此触发器。

<Callout type="info">
这是一个**手动**触发器。无需配置，只需点击“运行”。
</Callout>

## 配置

<ShowcaseCard>
  <BlockConfigPreview
    name="Manual trigger"
    type="manual_trigger"
    hideHeader
    subBlocks={[]}
  />
</ShowcaseCard>

无配置必填. manual trigger 有否 输入字段和produces 否输出.

## 当到使用

- Quick sanity checks和smoke tests
- workflow 该仅 rely 在 internal variables或外部 API 调用
- Development和debugging

<Callout>
需要 structured 输入? 使用一个输入表单 trigger instead.
</Callout>
