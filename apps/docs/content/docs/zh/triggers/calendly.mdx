## 事件

### Calendly Webhook

根据任意 Calendly Webhook 事件触发工作流

#### 设置说明

<div class="mb-3"><strong>1.</strong> <strong>注意：</strong>此触发器需要付费的 Calendly 订阅（Professional、Teams 或 Enterprise 套餐）。</div><div class="mb-3"><strong>2.</strong>在 Calendly 账户的 <strong>Settings > Integrations > API & Webhooks</strong> 中获取个人访问令牌。</div><div class="mb-3"><strong>3.</strong>在 Calendly 模块中使用 “Get Current User” 操作以获取你的组织 URI。</div><div class="mb-3"><strong>4.</strong>保存此触发器时，将自动在 Calendly 中创建 Webhook。</div><div class="mb-3"><strong>5.</strong>此 Webhook 会订阅所有 Calendly 事件（受邀者已创建、受邀者已取消、路由表单已提交）。使用 payload 中的 <code>event</code> 字段判断事件类型。</div>
