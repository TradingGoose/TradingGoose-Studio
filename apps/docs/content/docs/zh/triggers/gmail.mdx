## 设置说明

<div class="mb-3"><strong>1.</strong> 使用 OAuth 凭证连接你的 Gmail 账号</div><div class="mb-3"><strong>2.</strong> 配置要监控的 Gmail 标签（可选）</div><div class="mb-3"><strong>3.</strong> 系统将自动检查新邮件并触发你的工作流</div>
