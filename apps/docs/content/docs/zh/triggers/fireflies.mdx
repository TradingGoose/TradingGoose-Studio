当 Fireflies 会议转录完成时触发工作流

<Callout type="info">
  这是基于 **webhook** 的触发器。请将外部服务配置为向工作流 webhook URL 发送事件。
</Callout>

## 设置说明

<div class="mb-3"><strong>1.</strong> 前往 <a href="https://app.fireflies.ai/settings" target="_blank" rel="noopener noreferrer">app.fireflies.ai/settings</a></div><div class="mb-3"><strong>2.</strong> 转到 <strong>开发者设置</strong> 选项卡</div><div class="mb-3"><strong>3.</strong> 在 <strong>Webhook</strong> 部分，粘贴上方的 Webhook URL</div><div class="mb-3"><strong>4.</strong> 输入 <strong>密钥</strong>（16-32 个字符），并在此处同样保存</div><div class="mb-3"><strong>5.</strong> 在 Fireflies 中点击 <strong>保存</strong> 以启用 webhook</div><div class="mb-3"><strong>6.</strong> 此后，任意会议转录完成后都会触发工作流</div>
