通过 Apps Script 转发器，在 Google Forms 提交时触发工作流

<Callout type="info">
  这是基于 **webhook** 的触发器。请将外部服务配置为向工作流 webhook URL 发送事件。
</Callout>

<Cards>
  <Card title="用作工具" href="/tools/google_forms">
    查看 Google Forms 的工作流动作、操作和工具输入。
  </Card>
</Cards>

## 设置说明

<div class="mb-3"><strong>1.</strong> 打开你的 Google 表单 → 更多 (⋮) → 脚本编辑器。</div><div class="mb-3"><strong>2.</strong> 将下方的 Apps Script 代码片段粘贴到 <code>Code.gs</code> → 保存。</div><div class="mb-3"><strong>3.</strong> 触发器（时钟图标）→ 添加触发器 → 函数：<code>onFormSubmit</code> → 事件来源：<code>From form</code> → 事件类型：<code>On form submit</code> → 保存。</div><div class="mb-3"><strong>4.</strong> 出现提示时完成授权。提交一条测试回复，然后在 TradingGoose → 日志 中验证运行。</div>
