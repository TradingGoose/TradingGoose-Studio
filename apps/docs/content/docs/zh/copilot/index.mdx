Copilot 是一款覆盖整个 TradingGoose 工作区的 AI 助手，并非只能处理 workflow。它可以管理 workflow、MCP 服务器、skill、自定义工具、知识库、部署、变量等资源。在桌面工作区中，使用全局侧边栏的 **Copilot** 控件打开或关闭其常驻面板。移动工作区布局不提供此面板。

## 功能

Copilot 可以使用覆盖整个平台的完整工具集：

### Workflow 管理
- **编辑 workflow** — 添加、移除或重新配置块和连接。编辑内容会实时显示为行内预览，确认后才会提交。
- **部署 workflow** — 检查部署状态并触发新部署。
- **运行 workflow** — 执行 workflow 并检查结果。
- **管理变量** — 获取和设置全局 workflow 变量。
- **查看控制台** — 获取执行日志和流式输出。

### 工作区工具
- **管理 MCP 服务器** — 创建、更新和配置 MCP 服务器连接。
- **管理 skill** — 创建、编辑和删除可复用的 skill 定义。
- **管理自定义工具** — 创建和编辑自定义工具的架构与代码。
- **知识库** — 查询和引用知识库文档。

### 常规功能
- **解释** — 回答有关 TradingGoose 概念或工作区内任意 workflow 的问题。
- **规划** — 对于较大的任务，Copilot 会生成待办事项列表，并在完成各个步骤时记录进度。
- **引用上下文** — 使用 `@` 提及菜单加入以前的聊天、其他 workflow、特定块、知识库文档、文档、模板或执行日志。
- **文件附件** — 直接在消息中附加文件以提供更多上下文。

## 访问级别

输入栏中的访问级别开关用于控制 Copilot 的自主程度。

<Cards>
  <Card title="Limited (default)">
    Copilot 会在执行带中断标志的工具调用以及运行集成工具前暂停。你需要检查并批准每项操作。
  </Card>
  <Card title="Full">
    Copilot 无需确认即可自动执行所有工具调用、集成工具和 workflow 编辑。仅在你信任当前任务并希望加快迭代时使用此模式。
  </Card>
</Cards>

## 支持的模型

Copilot 恰好支持六个 OpenRouter 模型。Studio 会原样发送每个 OpenRouter 模型的规范标识符，你可以从输入栏切换当前模型。

**Anthropic** -- anthropic/claude-fable-5, anthropic/claude-opus-5

**DeepSeek** -- deepseek/deepseek-v4-pro

**OpenAI** -- openai/gpt-5.6-terra, openai/gpt-5.6-sol

**xAI** -- x-ai/grok-4.6

## 设置

<Steps>
  <Step>
    ### 托管版 (tradinggoose.ai)

    Copilot 无需额外配置即可使用。打开任意工作区，使用全局侧边栏中的 **Copilot** 控件打开工作区面板，然后开始聊天。
  </Step>
  <Step>
    ### 自托管版

    自托管实例需要 Copilot API 密钥才能连接到托管推理服务。

    1. 登录 [tradinggoose.ai](https://tradinggoose.ai)，然后打开 **Settings > Copilot**。
    2. 点击 **Create** 生成新的 API 密钥。请立即复制；该密钥只显示一次。
    3. 将自托管部署中的 `COPILOT_API_KEY` 环境变量设为复制的值。
    4. 重启应用。Copilot 全局面板随后会通过该密钥连接。
  </Step>
</Steps>

<Callout type="warn">
  API 密钥会授予完整的 Copilot 访问权限。请妥善保管；如果密钥泄露，请立即轮换。你可以随时在同一设置页面删除密钥；删除后会立即撤销访问权限。
</Callout>

## 聊天管理

每个 Copilot 会话都限定于当前已认证用户和工作区。标题栏下拉菜单按时间分组列出所有历史聊天（今天、昨天、本周、上周、更早）。你可以从标题栏执行以下操作：

- **切换聊天** -- 点击之前的对话以继续聊天。
- **开始新聊天** -- 点击标题栏中的 **+** 按钮创建新会话。
- **删除聊天** -- 将鼠标悬停在聊天条目上并点击垃圾桶图标。确认对话框可防止误删。

在工作区内导航或折叠并重新打开面板时，聊天状态会保留。Copilot 会跟随当前页面和选择，例如知识库详情、所选执行日志或监控器。在仪表板上，当前上下文仅标识活动布局。如果任务需要更多详细信息，Copilot 可以通过仪表板工具读取该布局。

## 编辑器集成

Copilot 能感知上下文。当前页面只会发布所选对象的标识，例如活动仪表板布局、知识库、执行日志或监控器。需要向消息添加其他明确上下文时，请使用 `@` 提及菜单。

当 Copilot 流式返回包含工具调用的响应时，例如添加块、创建 skill 或配置 MCP 服务器，每项操作都会显示为行内预览。在 **Limited** 模式下，你需要批准或拒绝每项更改；在 **Full** 模式下，更改会自动应用。

如果需要撤销 Copilot 操作，可以直接在聊天中还原或编辑之前的任意消息。编辑点之后的消息会变暗，表示这些消息将重新生成。

## 计费

Copilot 完成费用采用 OpenRouter 报告的权威总成本，再应用你的方案对应的 Copilot 成本倍数。这样可使最终计费与实际路由请求保持一致，包括适用的缓存 token、推理、媒体、搜索、长上下文和特定提供商费用。

<Callout type="info">
  Studio 可以在请求前预留一个保守估算金额。最终费用始终采用 OpenRouter 报告的完成成本，而不是估算值。
</Callout>
