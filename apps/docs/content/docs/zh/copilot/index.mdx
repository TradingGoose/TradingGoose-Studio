Copilot 是一款 AI 助手，可在整个 TradingGoose 工作空间中工作——而不只是工作流。它可以管理工作流、MCP 服务器、技能、自定义工具、知识库、部署、变量等。在桌面端工作空间中，可通过全局侧边栏中的 **Copilot** 控件打开或关闭其常驻面板。移动端工作空间布局不提供该面板。

本页介绍内置的 Studio 助手。如需从自己的编码代理使用 TradingGoose，请参阅 [Copilot MCP](/copilot/copilot-mcp)，了解其功能、安装与身份验证。

## 上下文用量

Copilot 会自动限制发送给模型的近期历史记录。已存储的消息、工具结果、图像和提供商元数据保持不变。需要全新对话时，请新建聊天。

## 功能

Copilot 可调用一整套覆盖整个平台的工具：

### 工作流管理
- **编辑工作流** — 添加、删除或重新配置块与连接。编辑内容会以行内预览的形式实时流式呈现，之后才提交。
- **部署工作流** — 查看部署状态并触发新的部署。
- **运行工作流** — 执行工作流并查看结果。
- **管理变量** — 获取和设置全局工作流变量。
- **查看控制台** — 获取执行日志和流式输出。

### 工作空间工具
- **管理 MCP 服务器** — 创建、更新和配置 MCP 服务器连接。
- **管理技能** — 创建、编辑和重命名可复用的技能定义。
- **管理自定义工具** — 创建和编辑自定义工具的 schema 与代码。
- **知识库** — 查询和引用知识库文档。

### 通用
- **解释** — 回答有关 TradingGoose 概念或工作空间中任意工作流的问题。
- **规划** — 对于较大的任务，Copilot 会生成待办清单，在逐步推进的过程中跟踪进度。
- **引用上下文** — 使用 `@` 提及菜单引入之前的对话、工作空间实体、特定块、文档或执行日志。
- **文件附件** — 将文件直接附加到消息中，以提供更多上下文。

## 访问级别

输入栏中的访问级别切换控件决定 Copilot 的自主程度。

<Cards>
  <Card title="有限（默认）">
    在执行任何带中断标记的工具调用之前，以及运行集成工具之前，Copilot 都会暂停。每个操作都由你审核并批准。
  </Card>
  <Card title="完全">
    Copilot 会自动执行所有工具调用、集成工具和工作流编辑，无需确认。当你信任当前任务并希望更快迭代时使用此模式。
  </Card>
</Cards>

## 支持的模型

系统管理员在 **管理 → 系统设置 → Copilot 模型** 中选择可用的提供商/模型组合。你可以在输入栏中切换当前模型。初始模型选择和 Wand 使用配置列表中的第一个模型。

管理员输入各提供商接受的准确模型 ID；模型列表不受 Studio 模型注册表限制。在 **管理 → 服务** 中配置各提供商的 API 密钥。密钥以加密形式保存在服务器上，由同一提供商的 Copilot 模型共用。配置模型及其提供商密钥后，Copilot 才可用。

## 设置

<Steps>
  <Step>
    ### 托管版（tradinggoose.ai）

    Copilot 开箱即用。打开任意工作区，使用全局侧边栏中的 **Copilot** 控件打开工作区面板，即可开始对话。
  </Step>
  <Step>
    ### 自托管版

    Copilot 在 Studio 内运行，复用其 Mastra 模型连接和应用数据库。

    1. 在仓库根目录运行 `bun run db:migrate`，使用 Studio 的 `DATABASE_URL` 应用数据库迁移。共享运行时启动时，Mastra 会在同一数据库中初始化自己的表。
    2. 在 **管理 → 服务** 中配置所需提供商的 API 密钥。在 **管理 → 系统设置 → Copilot 模型** 中添加提供商/模型行并保存。
    3. 打开工作区，选择已配置的模型并开始对话。
  </Step>
</Steps>

[Copilot MCP](/copilot/copilot-mcp#installation) 使用通过其浏览器授权流程获取的个人 TradingGoose API 密钥。

## 对话管理

每个 Copilot 会话都限定于已认证用户和当前工作区。顶部下拉菜单按时间远近列出所有历史对话（今天、昨天、本周、上周、更早）。通过顶部菜单你可以：

- **切换对话** -- 点击任意历史对话即可继续。
- **新建对话** -- 点击顶部的 **+** 按钮创建新会话。
- **删除对话** -- 将鼠标悬停在对话条目上并点击垃圾桶图标。确认对话框可防止误删。

在工作区中导航，或折叠后重新打开面板时，对话状态都会保留。Copilot 会跟随当前页面和选中内容：例如知识详情、选中的执行日志或监控。在仪表盘上，当前上下文仅标识活动布局。当任务需要更多细节时，Copilot 可通过其仪表盘工具读取该布局。

## 编辑器集成

Copilot 具备上下文感知能力。当前页面只会公开所选对象的身份标识，例如活动的仪表盘布局、知识库、执行日志或监控。当你希望为消息添加其他显式上下文时，可使用 `@` 提及菜单。

当 Copilot 流式返回包含工具调用的响应时（例如添加区块、创建技能或配置 MCP 服务器），每个操作都会以内联预览的形式呈现。在 **Limited** 模式下，你需要逐项批准或拒绝每个更改；在 **Full** 模式下，更改会自动应用。

你可以编辑较早的提示词，以截断并重新生成其后的消息，但仅当该提示词之后没有已接受的实时变更时才能这样做。编辑聊天历史不会撤销已应用到工作区的更改；要撤销已执行的操作，请再次更改受影响的实体。可编辑点之后的消息会变暗，表示它们将被重新生成。

## 计费

Copilot 复用 Studio 的用量检查和计费账本。模型估算使用 models.dev 公布的标准价格和报告的 token 用量。使用 Studio 账户用量时，订阅套餐的 Copilot 倍率适用于已知费用，报告和历史中的美元金额与实际计入的费用一致。无法确定费用时，Copilot、标题生成和 Wand 仍可完成：记录调用次数和报告的 token 用量，费用保持不可用，且不会将这部分未知价格的用量计入 Studio 的美元费用。
