---
title: 数学函数
description: math 命名空间中的数学运算和常量
---

`math` 命名空间提供数学常量、基本运算、三角函数和统计函数。

## 常量

| 常量 | 值 | 说明 |
|----------|-------|-------------|
| `math.pi` | 3.14159... | 圆周率 |
| `math.e` | 2.71828... | 欧拉数 |
| `math.phi` | 1.61803... | 黄金比例 |
| `math.rphi` | 0.61803... | 黄金比例的倒数 |

## 基本运算

| 函数 | 说明 |
|----------|-------------|
| `math.abs(x)` | 绝对值 |
| `math.ceil(x)` | 向上舍入到最接近的整数 |
| `math.floor(x)` | 向下舍入到最接近的整数 |
| `math.round(x, precision?)` | 舍入到最接近的整数或指定精度 |
| `math.round_to_mintick(x)` | 舍入到交易品种的最小报价单位 |
| `math.sign(x)` | 值的符号（-1、0 或 1） |
| `math.max(a, b)` | 两个值中的最大值 |
| `math.min(a, b)` | 两个值中的最小值 |
| `math.avg(...)` | 各值的平均值 |
| `math.sum(source, length)` | N 根 K 线内各值的总和 |

## 指数和对数

| 函数 | 说明 |
|----------|-------------|
| `math.pow(base, exp)` | 幂 |
| `math.sqrt(x)` | 平方根 |
| `math.exp(x)` | e 的 x 次幂 |
| `math.log(x)` | 自然对数 |
| `math.log10(x)` | 以 10 为底的对数 |

## 三角函数

| 函数 | 说明 |
|----------|-------------|
| `math.sin(x)` | 正弦（弧度） |
| `math.cos(x)` | 余弦（弧度） |
| `math.tan(x)` | 正切（弧度） |
| `math.asin(x)` | 反正弦 |
| `math.acos(x)` | 反余弦 |
| `math.atan(x)` | 反正切 |
| `math.todegrees(x)` | 将弧度转换为角度 |
| `math.toradians(x)` | 将角度转换为弧度 |

## 其他

| 函数 | 说明 |
|----------|-------------|
| `math.random(min?, max?)` | 随机数 |

## 示例

```javascript
indicator('Volatility Ratio');

const atr = ta.atr(14);
const avgAtr = ta.sma(atr, 50);
const ratio = atr / math.max(avgAtr, syminfo.mintick);
const logRatio = math.log(ratio);

plot(logRatio, 'Log Volatility Ratio');
hline(0, { linestyle: hline.style_dashed });
```
