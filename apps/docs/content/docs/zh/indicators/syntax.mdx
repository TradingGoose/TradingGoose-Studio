PineTS 使用 JavaScript/TypeScript 语法，并复现 Pine Script 的运行时行为。如果您熟悉 TradingView 的 Pine Script，就能直接上手；主要区别在于变量声明和标准 JavaScript 语法约定。

## 变量声明

PineTS 区分 `let` 和 `var`，以匹配 Pine Script 的执行模型。这是需要掌握的最重要概念。

### `let`：在每根 K 线重新计算

使用 `let` 声明的变量（不可变值使用 `const`）会在每根 K 线上重新求值，与标准 Pine Script 变量相同：

```javascript
// Recalculated on every bar
const sma20 = ta.sma(close, 20);
let direction = close > open ? 1 : -1;
```

### `var`：状态跨 K 线持久保留

使用 `var` 声明的变量只在第一根 K 线上初始化一次，并在后续 K 线中保留其值，与 Pine Script 的 `var` 关键字一致：

```javascript
// Initialized once, persists across bars
var cumulativeVolume = 0;
cumulativeVolume = cumulativeVolume + volume;
```

<Callout type="warn">
  在 PineTS 中，`var` 的行为与标准 JavaScript `var` **不同**。它采用 Pine Script 的语义：变量仅设置一次并持续保留。如果需要在每根 K 线上重置值，请使用 `let`。
</Callout>

### 对照比较

| 行为 | Pine Script | PineTS |
|----------|-------------|--------|
| 每根 K 线重新计算 | `float x = close` | `let x = close` 或 `const x = close` |
| 跨 K 线持久保留 | `var float x = 0.0` | `var x = 0.0` |
| 重新赋值 | `x := x + 1` | `x = x + 1` |

## 历史记录访问

使用方括号表示法访问之前 K 线的值，与 Pine Script 相同：

```javascript
const prevClose = close[1];     // 1 bar ago
const tenBarsAgo = close[10];   // 10 bars ago
const momentum = close - close[10];
```

## 控制流

```javascript
// If/else
if (close > open) {
  direction = 1;
} else {
  direction = -1;
}

// Ternary
const color = close > open ? '#00FF00' : '#FF0000';

// Switch
switch (maType) {
  case 'ema': return ta.ema(close, length);
  case 'sma': return ta.sma(close, length);
  default: return ta.rma(close, length);
}
```

## 函数

使用标准 JavaScript 语法定义可复用函数：

```javascript
// Pine Script: f_ma(source, length) => ta.sma(source, length)
function f_ma(source, length) {
  return ta.sma(source, length);
}

const ma = f_ma(close, 20);
plot(ma, 'Custom MA');
```

## 元组（多个返回值）

`ta.macd()` 和 `ta.bb()` 等函数会返回多个值。请使用数组解构：

```javascript
// Pine Script: [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9)
const [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9);

// Pine Script: [middle, upper, lower] = ta.bb(close, 20, 2)
const [middle, upper, lower] = ta.bb(close, 20, 2);
```

## 特殊值

| 值 | 说明 |
|-------|-------------|
| `na` | 不可用；在 Pine Script 中等同于 `null`/`undefined` |
| `nz(value)` | 将 `na` 替换为零（或指定的默认值） |
| `color` | 颜色命名空间用于图表颜色 |

```javascript
const prev = close[1];
const change = na(prev) ? 0 : close - prev;  // Handle na values
const safeValue = nz(someCalculation, 0);     // Default to 0 if na
```

## 完整示例：抛物线 SAR

此示例演示如何使用 `var` 保留状态，以及如何使用 `if/else` 逻辑、历史记录访问和自定义函数：

```javascript
const start = input.float(0.02, 'Start');
const increment = input.float(0.02, 'Increment');
const maximum = input.float(0.2, 'Maximum');

function pine_sar(start, inc, max) {
  var result = na;
  var maxMin = na;
  var acceleration = na;
  var isBelow = false;

  if (bar_index == 1) {

    } else {
      isBelow = false;
      maxMin = low;
      result = high[1];
    }
    isFirstTrendBar = true;
    acceleration = start;
  }

  // ... calculation logic ...
  return result;
}

const sar = pine_sar(start, increment, maximum);
plot(sar, 'SAR', { style: plot.style_cross });
```
