指标是运行在 TradingGoose 市场数据上的自定义技术分析脚本。它们由 [PineTS](https://github.com/nicholasgasior/PineTS) 驱动——这是 Pine Script 的 JavaScript/TypeScript 运行时，并扩展了工作流触发器等 TradingGoose 专属功能。

## 你可以构建什么？

- **技术指标** — RSI、MACD、布林带，或你自己的自定义计算
- **信号生成器** — 检测交叉、突破或自定义条件
- **工作流触发器** — 当指标条件满足时，通过 `trigger()` API 触发工作流执行
- **可视化覆盖层** — 直接在图表上绘制线条、形状和填充

## 工作原理

<Steps>
  <Step>
    在指标编辑器中使用熟悉的 Pine Script 语法**编写 PineTS 代码**，已适配 JavaScript/TypeScript
  </Step>
  <Step>
    使用 `input.int()`、`input.float()` 等**定义输入** — 它们会成为 UI 中可配置的参数
  </Step>
  <Step>
    使用 57+ 个内置技术分析函数（`ta.*`）、数学运算、数组等进行**计算**
  </Step>
  <Step>
    使用 `plot()`、`plotshape()`、`fill()` 及其他图表渲染函数进行**可视化**
  </Step>
  <Step>
    在条件满足时调用 `trigger()` **触发工作流** — 将指标接入你的自动化流水线
  </Step>
</Steps>

## 快速示例

```javascript
indicator('RSI Signal', { overlay: false });

const length = input.int(14, 'RSI Length');
const overbought = input.int(70, 'Overbought');
const oversold = input.int(30, 'Oversold');

const rsi = ta.rsi(close, length);

plot(rsi, 'RSI', { color: '#2962FF' });
hline(overbought, 'Overbought', '#FF0000', hline.style_dashed);
hline(oversold, 'Oversold', '#00FF00', hline.style_dashed);

// Trigger a workflow when RSI crosses below oversold
if (ta.crossunder(rsi, oversold)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, oversold),
    input: 'RSI crossed below oversold threshold',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## 内置指标

TradingGoose 内置 80+ 个预置指标，涵盖动量、趋势、波动率和成交量分析。它们既可直接使用，也可作为编写自定义指标的参考示例。

<Callout type="info">
  PineTS 基于 Pine Script v5/v6 语法。如果你熟悉 TradingView 的 Pine Script，上手会非常自然 — 主要区别在于使用 JavaScript 变量声明（`const`、`let`、`var`）而非 Pine Script 的隐式声明。
</Callout>
