指标是在 TradingGoose 中基于市场数据运行的自定义技术分析脚本。它们由 [PineTS](https://github.com/nicholasgasior/PineTS) 提供支持。PineTS 是面向 Pine Script 的 JavaScript/TypeScript 运行时，并扩展了工作流触发器等 TradingGoose 专用功能。

## 可以构建什么

- **技术指标** — RSI、MACD、布林带或自定义计算
- **信号生成器** — 检测交叉、突破或自定义条件
- **工作流触发器** — 使用 `trigger()` API 在满足指标条件时触发工作流执行
- **可视化叠加层** — 直接在图表上绘制线条、形状和填充区域

## 工作原理

<Steps>
  <Step>
    在指标编辑器中**编写 PineTS 代码**，使用针对 JavaScript/TypeScript 调整的常用 Pine Script 语法
  </Step>
  <Step>
    使用 `input.int()`、`input.float()` 等方法**定义输入**；这些输入会成为界面中的可配置参数
  </Step>
  <Step>
    使用 57 个以上的内置技术分析函数（`ta.*`）、数学运算、数组等功能**执行计算**
  </Step>
  <Step>
    使用 `plot()`、`plotshape()`、`fill()`、`bgcolor()` 及其他图表渲染函数**显示结果**
  </Step>
  <Step>
    在满足条件时调用 `trigger()` **触发工作流**，将指标连接到自动化流水线
  </Step>
</Steps>

## 快速示例

```javascript
indicator('RSI Signal', { overlay: false });

const length = input.int(14, 'RSI Length');
const overbought = input.int(70, 'Overbought');
const oversold = input.int(30, 'Oversold');

const rsi = ta.rsi(close, length);

plot(rsi, 'RSI', { color: '#2962FF' });
hline(overbought, { color: '#FF0000', linestyle: hline.style_dashed });
hline(oversold, { color: '#00FF00', linestyle: hline.style_dashed });

// Trigger a workflow when RSI crosses below oversold
if (ta.crossunder(rsi, oversold)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, oversold),
    input: 'RSI crossed below oversold threshold',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## 内置指标

TradingGoose 随附 80 多个预置指标，涵盖动量、趋势、波动率和成交量分析。这些指标既可以直接使用，也可以作为编写自定义指标的参考示例。

<Callout type="info">
  PineTS 基于 Pine Script v5/v6 语法。如果你熟悉 TradingView 的 Pine Script，即可快速上手。主要区别在于使用 JavaScript 变量声明（`const`、`let`、`var`），而不是 Pine Script 的隐式声明。
</Callout>
