`trigger()` 函数是 TradingGoose 对 PineTS 的扩展，指标可在条件满足时启动 workflow 执行。指标可以检测信号并立即触发操作，例如发送通知、下单或运行复杂的多步骤 workflow。

## 语法

```javascript
trigger(event, options)
```

### 参数

| 参数 | 类型 | 必填 | 描述 |
|-----------|------|----------|-------------|
| `event` | `string` | 是 | 事件名称标识符 |
| `options` | `object` | 是 | trigger 配置（见下文） |

### 选项对象

| 属性 | 类型 | 必填 | 描述 |
|----------|------|----------|-------------|
| `condition` | `any` | 是 | 触发 trigger 时必须为真的条件 |
| `input` | `string` | 是 | 传递给 workflow 的文本输入 (例如： 一个描述的内容 happened) |
| `signal` | `'long' \| 'short' \| 'flat'` | 是 | trading 信号方向 |
| `position` | `'aboveBar' \| 'belowBar' \| 'inBar'` | 否 | 图表上的标记位置 (默认值： `'aboveBar'`) |
| `color` | `string` | 否 | 标记颜色 (hex 字符串, 例如： `'#FF0000'`) |

### 事件名称规则

- 必须匹配以下模式： `/^[a-z][a-z0-9_]{0,63}$/`
- 以小写字母开头
- 仅允许小写字母、数字和下划线
- 最多 64 个字符

## 基本示例

```javascript
indicator('RSI Trigger Example');

const rsi = ta.rsi(close, 14);
plot(rsi, 'RSI');
hline(70, { linestyle: hline.style_dashed });
hline(30, { linestyle: hline.style_dashed });

// Fire when RSI crosses above 70 (overbought)
if (ta.crossover(rsi, 70)) {
  trigger('rsi_overbought', {
    condition: ta.crossover(rsi, 70),
    input: 'RSI crossed above 70 — overbought signal',
    signal: 'short',
    position: 'aboveBar',
    color: '#FF0000'
  });
}

// Fire when RSI crosses below 30 (oversold)
if (ta.crossunder(rsi, 30)) {
  trigger('rsi_oversold', {
    condition: ta.crossunder(rsi, 30),
    input: 'RSI crossed below 30 — oversold signal',
    signal: 'long',
    position: 'belowBar',
    color: '#00FF00'
  });
}
```

## 多个 trigger

一个指标可以定义多个 trigger 事件，每个事件都可以连接到不同的 workflow：

```javascript
indicator('Multi-Signal', { overlay: true });

const fast = ta.ema(close, 9);
const slow = ta.ema(close, 21);
const [macdLine, signalLine, hist] = ta.macd(close, 12, 26, 9);

// EMA crossover trigger
if (ta.crossover(fast, slow)) {
  trigger('ema_bullish_cross', {
    condition: ta.crossover(fast, slow),
    input: 'Fast EMA crossed above slow EMA',
    signal: 'long',
    position: 'belowBar',
    color: '#26A69A'
  });
}

// MACD histogram reversal trigger
if (hist > 0 && hist[1] <= 0) {
  trigger('macd_positive_flip', {
    condition: hist > 0 && hist[1] <= 0,
    input: 'MACD histogram flipped positive',
    signal: 'long',
    position: 'belowBar',
    color: '#2962FF'
  });
}
```

## 工作原理

1. **求值** — 在每根 K 线上，PineTS 都会评估指标代码，包括 `trigger()` 调用
2. **条件检查** — 系统会解析当前 K 线的 `condition` 属性。如果为假，则静默跳过该 trigger
3. **验证** — 系统会验证事件名称、选项结构、输入和信号。无效调用会生成警告，而不是错误
4. **捕获** — 有效 trigger 会连同其元数据一起捕获（事件、输入、信号、位置、颜色、K 线时间和索引）
5. **分派到 workflow** — 实时运行时，捕获的 trigger 事件会通过 Indicator Trigger 分派给已连接的 workflow

## 连接到 workflow

要在 workflow 中使用指标 trigger：

1. 创建包含 `trigger()` 调用的指标
2. 在 workflow 编辑器中添加 **Indicator Trigger** 块作为起点
3. 将其配置为监听指标事件
4. workflow 将 trigger 的 `input` 文本和 `signal` 作为输入数据接收

## 验证警告

无效的 trigger 调用会生成警告而不是错误，因此指标可继续运行：

| 警告代码 | 原因 |
|-------------|-------|
| `indicator_trigger_invalid_event` | 事件名称与必需的模式不匹配 |
| `indicator_trigger_invalid_options` | 选项参数不是对象 |
| `indicator_trigger_condition_unresolved` | 无法解析条件值 |
| `indicator_trigger_invalid_input` | 缺少输入或输入不是字符串 |
| `indicator_trigger_invalid_signal` | 信号不是 `'long'`、`'short'` 或 `'flat'` |
| `indicator_trigger_invalid_time` | K 线开盘时间不可用 |

<Callout type="info">
  `trigger()` API 是 TradingGoose 的专用扩展，在标准 Pine Script 或 PineTS 中不存在。包含 `trigger()` 调用的指标可在所有环境中正常运行；在 TradingGoose 之外，trigger 不会产生任何效果。
</Callout>
